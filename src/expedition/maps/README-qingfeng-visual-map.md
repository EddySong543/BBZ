# 晴风稻田可视化地图编辑

打开 `qingfeng_ricefield_visual_map.tscn` 后，在 Godot 的 2D 面板中直接编辑。

## 图层

- `Ground`：草地、深色草地、泥土、泥土车辙、麦浪和传送点。
- `GroundDetail`：以后放车辙、落叶、散草等贴地细节。
- `LowDecoration`：以后放花朵、矮草、三叶草等可踩叠层。
- `BlockingObjects`：以后放树木、石墙、栅栏等障碍。
- `Containers`：以后放粮筐、麻袋、农具箱等搜索容器。
- `MarkerGuides`：传送、撤离、出生点等编辑期辅助标记。

## 修改单格

1. 在场景树选中 `Ground`。
2. 在下方 TileMap 面板中选择需要的地表缩略图。
3. 用画笔点击目标格；拖动可以连续绘制，右键擦除，`Ctrl+Z` 撤销。
4. 人类所说的“第二行第二格”，在 Godot 格坐标中是 `(1, 1)`。

每个地表图块都带有 `ground_type` 与 `asset_id`。远征运行时读取这两个值，因此选择普通草地或深色草地会直接反映在游戏中。`Ground` 只控制美术；当前通行与墙体仍由远征逻辑地图负责，避免误刷装饰导致玩法损坏。

## 加入花草叠层

1. 在场景树选择 `LowDecoration`，不要选择 `Ground`。
2. 在下方 TileMap 面板选择白花、黄花、粉花、短草或三叶草。
3. 直接点击需要装饰的格子；原本的草地不会被替换，因为装饰画在独立图层。
4. 想删除装饰时，在 `LowDecoration` 图层右键擦除即可，地表仍会保留。

`tools/build_qingfeng_visual_map.gd` 是重建初始地图的工具。开始手动刷图后不要再次运行它，否则会重建场景中的初始格子布局。
