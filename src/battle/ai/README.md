# Battle AI —— 同时博弈短时最优 AI（v1，2026-05-30）

模拟"后期加入游戏的 AI"，并用 AI 自对弈批量积累平衡测试数据。

## 为什么不是"前瞻最优"

本游戏**双方同时盲选**（`select_action` → `resolve` 同时独立结算），不存在"看对手出招再最优应对"。
真正的短时最优 = 求**这一回合零和博弈的纳什均衡混合策略**：

1. 对每个 `(我方动作 i, 对手动作 j)` 组合，`clone()` 战局 → 提交 → `resolve()` → `BattleEval.score()` 评估 → 收益矩阵。
2. `regret-matching` 迭代解出我方**混合策略**（带概率，不可被对手稳定剥削）。
3. 按概率抽样一个动作。

因 `BattleEval.score` 关于双方反对称（所有项均为"己-对手"差 + 胜负翻转），博弈是零和的，
双方各自独立解同一矩阵 → 得到一致的均衡策略。

## 文件

| 文件 | 职责 |
|------|------|
| `battle_eval.gd` | 启发式局面评估 `score(battle, player) -> float`（己方视角，越大越好）|
| `battle_ai.gd` | 决策器 `choose_action` / `choose_death_switch`（矩阵 + regret-matching + 抽样）|
| `battle_core.gd`（引擎）| 提供 `clone()` / `legal_actions()` / `apply_choice()` 三个加法支持方法 |
| `tools/sim/run_sim.gd` | headless 自对弈批量模拟器 + 数据落盘 |

## v1 评估权重（锁定记录，单位=半点 1HP=2半点）

| 项 | 权重 | 依据 |
|----|------|------|
| 胜/负终局 | ±1,000,000 | 绝对优先 |
| 存活英雄数差 | 600/个 | 杀一人=去身体+kit，远超残血 |
| HP 总差（含替补） | 10/半点 | 1HP=20 分 |
| 能量（前 2 能）| 12/点 | 够一记大波 |
| 能量（超 2 能）| 3/点 | **边际递减**，抑制 1-ply 短视屯能不出手 |
| 护盾差 | 6/半点 | 约半 HP |
| 出战位 HP 差 | +4/半点 | 前线存活更重要 |
| 出战位燃烧 | ±30 | 易伤+禁疗 |

> 权重为 v1 经验值，按 batch 平衡数据迭代。能量边际递减是 2026-05-30 为治"AI 屯能僵局"加入。

## v2 升级（2026-05-30）：剪枝 depth-2 + 选人 AI

- **对战 AI 加深度**（默认 `search_depth=2`）：子局不再静态评估，而是再解一层 1-ply 子博弈取博弈值
  → AI 能看到"铺垫/攒→下回合收益"和"别同归于尽"，从而**会用主动技、减少换死平局、缩短对局**。
  深层用动作短名单（`_shortlist`）剪枝 + 较少迭代控成本。`depth=1` 退化为 v1 纯 1-ply。
- **`draft_ai.gd` 选人策略 AI**：对齐 bp 流程（BAN 3 → PICK 3，盲选）。结构化组队（HP 派生角色：
  坦克≥6 / 灵活5 / 脆皮≤4，按曲线均衡 + 温度探索保覆盖），BAN 偏高 HP 威胁。**无 per-hero meta
  偏见**（不硬编 combo 配对），避免污染平衡测量；深层成对协同留作后续。

## 已知局限

- **depth-2 仍看不到长尾**：能捕捉主动技的**短期**回报（h14 下回合翻倍 / h32 燃烧），但看不到
  **多回合**链（h28 契约喂 6 回合 / h03 击杀叠团队波）→ 最长 horizon 的连接件英雄仍被低估。
  ——这正是道具系统（降 combo 执行门槛）作为设计层解的价值所在。
- **drafter 偏好会影响覆盖**：择优组队会少抽弱势英雄；温度探索缓解但不消除（弱势英雄样本偏少）。
- **随机技单次采样**：评估 h13/h23 时克隆体重播种取单次独立样本（无偏有噪）；多次平均 EV 待优化。

## 运行模拟器

```bash
godot --headless --path <proj> --script res://tools/sim/run_sim.gd -- --games 200 --seed 42 --depth 2
# 参数：--games N / --seed S / --pool A-B（默认 1-34）/ --max-turns T / --out DIR
#       --depth N（AI 搜索深度，默认 2；1=快速 1-ply）/ --draft 0|1（默认 1=DraftAI 选人）
# 输出：tools/sim/out/sim_games.csv（每局明细）+ sim_summary.md（胜率/回合/动作/各英雄胜率）
```

速度：depth-1 ~1.3 s/局；**depth-2 ~6 s/局**（200 局≈21 min / 500 局≈52 min）。
