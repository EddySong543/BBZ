用户是独立游戏开发者，单人团队的像素风格小游戏项目。

**Why:** 项目的文档标准、架构决策记录、冲刺规划等流程是为中型团队设计的，对独立开发者来说是浪费时间的负担。

**How to apply:**
- 只保留必要文档：游戏概念（1页）、英雄设计（简洁的数值表）、引擎配置（已完成）
- 跳过：系统拆分文档、逐系统 GDD、ADR、正式冲刺规划、里程碑审查
- 优先级：快速原型 > 完善文档。先做可玩的，再迭代
- 技术决策：直接建议并执行，不要走多层审批流程
- 沟通风格：简短直接，减少形式化的步骤确认
