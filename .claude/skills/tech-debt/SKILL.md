当此技能被调用时：

1. **采集**：`grep` 全库 `TODO` / `FIXME` / `HACK` / `placeholder` / `占位` / `临时`；扫违反 `.claude/rules/*` 与 `coding-standards.md` 的明显处（无类型、硬编码数值、热路径分配、UI 持有状态等）；列缺测试的核心系统。

2. **分类**：按 类型（坏味道 / 缺测试 / 占位待替 / 标准违规 / 架构债）+ 影响域（战斗核心 / UI / 工具 / 美术管线）归类。

3. **评级排序**：每项给 影响（高/中/低）× 偿还成本（高/中/低），按"高影响低成本"优先排序。

4. **输出清单**：每条带 `文件:行号` + 一句话问题 + 建议动作 + 评级；先摘要计数再明细。

5. **不擅自重构**：只报告；还不还、何时还由用户定（契合"轻流程化个人项目"——别为还债打断玩法迭代）。
