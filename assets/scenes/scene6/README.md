# Scene6 素材接入说明

Scene6 正式主题为“赤炉剑谷”。场景复用成熟 UI、人物、输入、战斗交互与鼠标视差；环境由熔岩峡谷远景、左右熔流中景、剑冢近景、战斗平台与平台后方岩浆湖组成。

| 节点 | 用途 | 默认视差 |
|---|---|---:|
| `FarBackground` | 熔岩峡谷远景；原图亮裂隙内有移动热核与残留亮带 | `0.15` |
| `MidgroundLeft` | 左侧熔岩山体；原图熔流动态 | `0.55` |
| `MidgroundRight` | 右侧熔岩山体；原图熔流动态 | `0.55` |
| `ThermalAtmosphere` | 人物后方的低透明热雾与稀疏上升火星 | `0.82` |
| `MagmaLake` | 平台后方的暗红岩浆湖，由平台与左右近景自然遮挡 | `1.0` |
| `BattlePlatform` | 4 倍整数像素、中段横向平铺的石质站立平台 | `1.0` |
| `ForegroundLeft` | 左侧断剑近景 | `1.25` |
| `ForegroundRight` | 右侧断剑近景 | `1.25` |
| `ForegroundEmbers` | 近景之前的稀疏不规则像素火屑 | `1.32` |

远景和中景热流只改变原图目标裂隙的亮度与温度，不移动 UV、轮廓或 Alpha。远景因素材整体偏红，使用相对黄度和局部亮度筛选，避免整张背景同步闪烁。

火星使用不规则像素火屑：一个亮核心、一个偏移暗尾，少数带一格微弱尖端，不再使用大号统一圆团。`ThermalAtmosphere` 提供人物后方的细小火屑与淡热雾，`ForegroundEmbers` 以更低密度、更慢速度和略大的像素格覆盖左右近景之前；两层分别轻微向相反方向斜飘，并在相邻像素位置之间做时间混合，不通过加速掩盖跳帧。

`MagmaLake` 在场景树中位于 `BattlePlatform` 之前，因此遮挡来自真实绘制顺序，而不是前置矩形或屏幕阈值。平台桥腹、垂石与左右近景会直接覆盖岩浆，只从结构缝隙和底部中央露出。岩浆由连续红橙熔融底色、横向延展但自然断开的暗色熔壳漂板、少量亮缝构成；远处纹理更细更密，靠近屏幕底部逐步放大，从而保持近景湖面的透视。全部形状按场景相同的 4 倍像素格生成，熔壳使用硬像素轮廓，颜色限定为深熔岩、主体、热橙与核心四级，不以连续渐变伪造细节。底色与熔壳保持静态，局部浅弧热前沿从平台下方远端向屏幕底边推进；16 秒包裹相位首尾一致，不使用往返圆周位移、全湖呼吸、整数时间重置、纵向脊线、规则方格或蜂窝多边形。平台使用炭黑紫影、铁红中间调和局部下沿暖反光，与岩浆保持明确色温和明度分离。

角色 P1/P2 使用独立材质参数：P1 接收左下热源并提高暗部可读性，P2 接收右下热源并压缩金色高光；两者共享稳定的下半身岩浆反光与酒红接触阴影。Scene6 shader 会限制战斗动作触发的边缘光峰值，避免红色全身闪烁。世界后处理另有约 1–2 像素的上升热浪折射；HUD 位于该处理之后，不参与扭曲。
