# Scene8：天光镜湖

Scene8 定位为雪地中的开放镜面湖泊，湖面反射极光。当前已完成阶段 1 的湖岸拓扑、阶段 2 的水面/岸冰/倒影重做，以及平台接水修正。水保持主体，冰只作为远岸与近景的少量气候提示；极光造型、远山空气层和人物极光受光留给后续阶段。

## 场景层职责

- `Sky`：复刻 Scene1 的深夜夜空。
- `Stars`：复刻 Scene1 星空参数，关闭仅服务月盘的星区避让。
- `PixelAurora`：Scene8 专属程序化像素极光，固定 `320×180` 采样网格。
- `AuroraReflectionGrab`：在远山与湖面绘制前显式锁定天空和极光，避免远山、平台、人物与 UI 混入屏幕采样。
- `LakeTopology`：启动时从远山 alpha 一次生成 `320×180` RGBA 数据；R 为水域、G 为水侧岸距、B 为逐列纵深。运行期只同步远山变换参数，不重建图片。
- `MirrorLake`：先绘制的不透明开放水面；固定 `320×180` 逻辑网格，以逐列纵深做连续冷蓝过渡，以真实岸距做不规则暗岸。远岸薄冰限制在纵深 `4%` 内并半透明保留水色；近景仅放两片双椭圆并集的不规则碎冰，不使用矩形堆叠。
- `AuroraReflection`：后绘制的天空/极光倒影；最近邻采样，把 `46%` 屏高的天空源压入湖面前 `74%` 纵深（压缩比约 `0.772`），超出覆盖区后退为透明。
- `canvas_env_scene8_shared_water_wave.gdshaderinc`：湖水与倒影唯一共用的横向各向异性波场；两者使用同一拓扑坐标、时钟、分段和整数位移，倒影总横移夹在 `±2` 个逻辑格内。
- `FarSnowfield`：当前远山正式源图，使用 `6×` 等比缩放；绘制在两层水面之后，以原始 alpha 成为最终湖岸遮挡。
- `PlatformWaterContact`：位于远山和平台之间，读取平台源图 alpha，只在真实接触列绘制一格深蓝压水暗边和一格破碎共享波纹；视差系数与平台同为 `1.0`。
- `BattlePlatform`：当前平台完整源图与手调 Transform 保持不变；Scene8 专属材质仅让湖水遮住源图过深的暗侧壁，保留约 `4–5` 源像素行的浅浮冰边。
- `ForegroundLeft`：左侧雪地近景，使用 `3×` 整数缩放，有效透明边界贴齐画面左侧与底部。
- `ForegroundRight`：右侧雪地近景，使用 `3×` 整数缩放，有效透明边界贴齐画面右侧与底部。

左右近景当前的位置、矩形尺寸和 `3×` 缩放是 Eddy 手调后的受保护构图；后续湖面、光照和效果修改不得将其恢复到旧的自动贴边值。

阶段 2 的无截图验收由 `tools/scene8_lake_surface_probe.gd` 对运行时拓扑、平台源 alpha 和场景材质做逻辑像素数据分析：拒绝全宽跳色、矩形冰、过厚岸冰、全宽波纹、没有真实水下遮挡的平台、非整数或超过两格的倒影位移，以及未实际压缩的天空映射。该工具不创建或保存图像文件。

这些节点都是 `src/ui/scenes/scene8.tscn` 的直系可编辑层，不使用 `*Slot` 包装。

## 后续素材接入

1. Eddy 将待接入素材放入 `assets/import/`，并明确文件名与层职责。
2. 只移动被点名的文件及其 `.import`，正式资源归入本目录。
3. 可返工母版归入本目录的 `source/` 子目录，并用 `.gdignore` 隔离。
4. 保持完整源图比例；构图围绕 `(480, 748)`、`(1440, 748)` 双雄脚底和 `(960, 748)` 平台中心适配。
5. 极光、湖面、雪地环境光与粒子均使用 Scene8 专属材质或组件，不复用其他场景的环境效果。
6. 若后续增加人物倒影，应通过现有角色 SubViewport 另行接入；不得用当前屏幕采样把 UI 一并反射进湖面。
