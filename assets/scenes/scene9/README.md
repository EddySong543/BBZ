# Scene9：银辉草原

Scene9 定位为银色的一望无际草原，天空存在多层浮空岛屿。`src/ui/scenes/scene9.tscn` 负责环境，`src/ui/battle_screen9.tscn` 复用成熟 Battle Screen 的 UI、人物、输入、战斗反馈和鼠标视差。当前已接入 Eddy 指定的完整平台、左右近景和三个独立透明草簇；正式天空与浮空岛仍等待素材。

## 当前框架

- `FrameworkBackdrop`：中性临时天空底色，正式天空素材接入后删除。
- `SilverGrassland/PerspectiveGround`：横向延伸到画面外的单一连续地表；Scene9 专属 Shader 用银灰纵深渐变、两层随透视放大的程序草叶、低频明暗浪和地平线透明过渡形成无可见梯形边界的草原主体。细草叶与明暗浪共用同一时间和风向。
- `SilverGrassland/FarGrass`：三种完整草簇各 `4` 个实例，根部覆盖 `Y=607–643`，缩放 `0.16×–0.22×`。
- `SilverGrassland/MidGrass`：三种完整草簇各 `3` 个实例，根部覆盖 `Y=660–700`，缩放 `0.29×–0.40×`。
- `SilverGrassland/NearGrass`：三种完整草簇各 `2` 个实例，根部覆盖 `Y=735–775`，缩放 `0.48×–0.62×`。
- 三段共 `27` 个完整草簇，只作为程序草海中的轮廓强调，并以三种变体交错横跨画面、埋入平台后方，不再把大草簇复制成地平线横带。共用 `canvas_env_scene9_silver_grass.gdshader`，按源图亮度映射到银白、冷灰和极淡青蓝，原图色彩只保留 `4%`；仅在贴图最底端做极短渐隐，统一低频阵风与草尖细摆驱动。
- `BattlePlatform`：完整平台源图，使用 `6×` 整体等比缩放，视差系数 `1.0`；不拆段、不平铺、不改变内部比例。
- `ForegroundLeft`：完整左近景，使用 `3×` 整体等比缩放，视差系数 `1.18`。
- `ForegroundRight`：完整右近景，使用 `3×` 整体等比缩放，视差系数 `1.18`。
- `CompositionGuides/P1Baseline`：P1 脚底基线 `(480, 748)`。
- `CompositionGuides/P2Baseline`：P2 脚底基线 `(1440, 748)`。
- `CompositionGuides/PlatformBaseline`：战斗平台中心基线 `(960, 748)`。
- Scene9 入口显式关闭基础场景的月夜尘粒、旧接触阴影、角色月光和全屏调色；正式环境光照留给 Scene9 素材接入阶段。

当前没有 Scene9 正式天空和浮空岛图片；银色草原使用连续程序地表与三个草簇素材组合，不依赖全宽草地贴片。运行资源不引用 `assets/import/`。所有后续环境层直接放在 Scene9 根节点下，不增加 `*Slot` 包装，不移动成熟人物。

## 后续素材接入顺序

1. Eddy 将 Scene9 素材放入 `assets/import/`，并明确每个文件的层职责。
2. 只移动被点名的文件及其 `.import`；正式资源归入本目录，保留母版进入 `source/` 并由 `.gdignore` 隔离。
3. 推荐按天空、最远浮岛、远层浮岛、现有连续银色草原、完整战斗平台、近景遮挡层的顺序逐层接入。
4. 先处理尺寸、位置、遮挡和整数像素密度，再建立 Scene9 专属调色、角色银色天光和环境动效。
5. 平台与环境围绕三条成熟构图基线适配；人物、UI、输入、换人、倒计时和战斗动画保持不变。
