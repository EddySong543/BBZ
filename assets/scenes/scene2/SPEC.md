### 瀑布与山体资产边界

- 最终运行时山体素材不得烘入完整瀑布水体；带瀑布的生成图仅作为构图参考。
- 山体可以包含干燥崖口、水道凹槽、被冲刷的岩壁形状和用于遮挡水流的前缘，但水帘、泡沫、落点飞溅与水雾必须独立。
- 瀑布运行时顺序为：后山体 → 瀑布水层/蒙版 → 前山体遮挡 → 飞溅与雾。这样才能调整宽度、流速、分段位置和落点。

## 调色纪律

- 全台**低饱和**：青玉群山 + 暖纸光 + 灰粉桃瓣。**桃粉压灰压淡**——大面积艳粉/艳红会抢 P2 阵营红，艳蓝同理抢 P1（scene1 铁律延续）。
- 谷口暖光是全场唯一高亮暖点（对位 scene1 明月的冷白）。

## 后续视觉统一任务（按优先级）

1. **P0·角色落地感**：为 P1/P2 增加独立镜像角色通道，裁切在 River 内并使用与河面一致的水平切片；不要依赖 River 的屏幕采样顺序。
2. **P0·角色融光**：为 Scene2 单独调角色 `rim_color / shadow_tint / fill_color`，从 Scene1 冷月光切换为青玉环境光与暖日光补色；保留角色原始阵营色。
3. **P1·统一像素密度**：把山体、桃树、石桥先归一到同一逻辑像素网格再 Nearest 放大，减少素材的 1px 微纹理与角色 2× 粗像素之间的尺度冲突。
4. **P1·战斗可读性**：降低角色背后山门、瀑布和桃花的局部对比/细节，在双方轮廓后保留安静负形；右侧花枝继续避开 P2 头部和武器主轮廓。
5. **P1·景深重排**：远山进一步降对比、降饱和、减锐；中山保留形；桥和角色最清楚，避免所有层同时抢焦点。
6. **P2·动效同拍**：瀑布、河面、花瓣统一到 6/8/12fps 的分档节奏和同一像素格；用花瓣图集替换圆点粒子，再补克制的岸线泡沫簇。
