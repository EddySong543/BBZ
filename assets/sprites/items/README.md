# 道具图标（items sprites）

道具图标的**正式目录**。约定与代码：`src/battle/item_catalog.gd` 的 `V2_ICON_DIR`、`LEGACY_ICON_DIR` 与 `icon_path()`。

## 布局

```
assets/sprites/items/
├── README.md            ← 本文件
├── _name_id_map.md      ← 新旧池名称与 id 对照
├── v2/                  ← 当前启用的20件新版道具；Eddy直接在这里调整正式方向
│   ├── 生锈的飞镖.png
│   └── ...
└── legacy/              ← 隐藏旧池素材；只供旧代码定向复用
    ├── 生锈的暗器.png
    └── ...
```

- **正式图标文件名 = 道具中文显示名**，与目录中的显示名同步。
- 新版 UI 只从 `v2/` 读取；旧代码只从 `legacy/` 读取。即使新版暂时复用旧图，也在 `v2/` 保存一份独立副本。
- `v2/` 中 PNG 自己承担默认展示方向；图鉴、三选一、战斗道具栏和行动序列不再统一旋转图片。玩家在背包中实际旋转物件时，美术仍会跟随占格旋转。
- 缺图时 UI 回退占位文字，不会破坏界面。
- 可以把中文名 PNG 先放进 `assets/import/`，由导入工具核名并自动分仓；也可直接替换 `v2/` 中的同名文件。

## 工作流（你丢图 → 自动归位 → 游戏显示）

1. 把图标 PNG 丢进 `assets/import/`，**按道具中文名命名**（见 `assets/import/README.md`）。
2. 运行导入工具：
   ```
   <godot> --headless --path . --script res://tools/import_item_art.gd
   ```
   工具会根据当前/旧版 id 把同名 PNG 放入 `v2/` 或 `legacy/`，并打印未匹配清单。
3. 在 Godot 编辑器里让它导入一次（开编辑器或 `--import`），游戏里对应道具就显示出来了。

## 图标规格（建议）

- **透明底 · 像素图**；新版多格道具可直接按每格32×32制作，例如横2格为64×32。
- UI 节点已设 `texture_filter = NEAREST`，像素清晰、无需特意配 `.import`。
