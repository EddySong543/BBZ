# 道具图标（items sprites）

道具图标的**正式目录**。约定与代码：`src/battle/item_catalog.gd` 的 `ICON_DIR` / `icon_path()`。

## 布局

```
assets/sprites/items/
├── README.md            ← 本文件
├── 臭鸡蛋.png           ← 正式图标，文件名 = 道具中文显示名
├── 坚固的护盾.png
└── ...
```

- **正式图标文件名 = 道具中文显示名**（如 `臭鸡蛋.png`），与 `ItemCatalog._DEF[id].name` 同步。
- UI（道具芯片 + 抽取 3 选 1 卡）按 `ICON_DIR/<中文显示名>.png` 自动加载；**缺图则回退占位文字**，所以没图也不会坏画面。
- 可以把中文名 PNG 先放进 `assets/import/`（统一暂存区），由导入工具核名并归位；也可直接放入本目录。

> 得能护符、分痛木牌、候阵签、换防扣、急救铃、压阵坠、回锋鞘、续阵旗、血渡结、藤蔓陷阱、解毒药水、寻星坠，以及抵锋扣、缚影索、凝血膏、镇纹针、连心锁、分寸尺、移甲环、护阵钉、封脉针、锁泉塞、回照镜、时滞枷锁、借印佩、点将鼓、代伤伞、归营牌、行军药囊、迷雾斗篷，以及散契钟、招魂幡、连环鼓、聚宝盆、赊命券、换命契、借命灯、清囊火盆、均能斗目前均复用通用像素物件图作为**占位美术**，后续按同名文件逐件替换。

## 工作流（你丢图 → 自动归位 → 游戏显示）

1. 把图标 PNG 丢进 `assets/import/`，**按道具中文名命名**（见 `assets/import/README.md`）。
2. 运行导入工具：
   ```
   <godot> --headless --path . --script res://tools/import_item_art.gd
   ```
   工具会把 `assets/import/臭鸡蛋.png` → `t1_xiangjiaopi.png` 放到本目录，并打印未匹配清单。
3. 在 Godot 编辑器里让它导入一次（开编辑器或 `--import`），游戏里对应道具就显示出来了。

## 图标规格（建议）

- **128×128 PNG · 透明底 · 像素图**（芯片 64px、抽取卡更大，128 源图缩放都干净）。
- UI 节点已设 `texture_filter = NEAREST`，像素清晰、无需特意配 `.import`。
