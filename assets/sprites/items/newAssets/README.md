# newAssets — 道具图标暂存区

**把你做好的道具图标 PNG 丢进这个文件夹**，然后由导入工具分配到正式目录。这里是中转站，**禁止被代码/场景直接引用**。

## 怎么命名

**按道具的中文显示名命名**（就是你在 `design/items-list.md` 里看到的名字）：

```
臭鸡蛋.png
生锈的飞镖.png
坚固的护盾.png
龙息.png
```

- 不用管代码内部 id（那是历史拼音、对不上中文名，不该你记）。
- 导入工具会按「中文名 → id」自动改名（`臭鸡蛋.png` → `t1_xiangjiaopi.png`）。
- 名字对不上的（打错字 / 简写 / 该道具还没实装），工具**只报告、不瞎猜**，回头跟你核一句。
- 也支持直接用 id 命名（`t1_xiangjiaopi.png`），工具会原样放行。

## 规格

128×128 PNG，透明底，像素风。

## 跑导入

```
<godot.exe> --headless --path . --script res://tools/import_item_art.gd
```

工具会生成 `assets/sprites/items/_name_id_map.md`（最新「中文名 ↔ id」对照表，可随时查）。

> 非破坏式：工具只**复制**走匹配的图、保留这里的源文件；确认无误后你可自行清空本目录。
