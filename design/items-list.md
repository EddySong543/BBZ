# 【T1】 — 框架 20 + 趣味 4 + 中立 1 = 25 件（≈0.5 地板 · 瘦身后）

> 润滑剂 + 博弈变量。每件单看不强，垫平维度地板、给攒波/翻盘小钩子。

## 🗡️ 进攻

- **生锈的飞镖**【T1】— 对敌 0.5 伤；最便宜补刀，无脑安全选。 子鼠会祈祷战斗时别摸到这个
- **先手**【T1】— 你这次攻击 +0.5 伤（贴大波/多段前）。 先手！在波波攒里！
- **赌徒的硬币**【T1】— 抛币：正面 +1.0 伤 / 反面落空。赌自己。 会赢的 
- **最后一箭**【T1】— 0.5 伤；若你 HP 比对手低 → 改 1.0 伤（绝地走运）。 向这黑暗世界输送一丝光明！
- **银质穿甲箭**【T1】— 若对手本回合用「防」，你这次攻击穿防。  这箭是我贷款买来的！ 
## 🛡️ 防御

- **破旧的护盾**【T1】— +0.5 甲（额外血量层，先扣甲后扣血；真伤无视）。 肯定能在古董市场卖个好价钱
- **后手**【T1】— 若对手本回合「攻击」→ 你 +1.0 甲；否则无效。赌对手出招。 后发制人
- **残缺的佛像**【T1】— 若对手本回合「大波」，你这次「防」临时升级为可挡大波一次。 事到如今，这是唯一的出路了
- **圣贤书**【T1】— 本回合免疫对手对你的一次 debuff / 干扰。 一心只读圣贤书！

## ❤️ 治疗 · 续航

- **劣质生命药水**【T1】— 回 0.5 HP。 老板，这生命药水发绿是正常的吗？
- **解毒药水**【T1】— 解除你身上全部毒/灼。 别担心，发绿是因为我加了灵芝、曼德拉草、人参...总之没毒！

## ⚡ 能量 · 经济

- **劣质法力药水**【T1】— 本回合若「攒」，额外 +0.5 能。 假一赔十...前提是你还活着的话
## 🐎 节奏 · 切换

- **回马枪**【T1】— 本回合若「切换」，下回合你的攻击 +0.5 伤（不免动作）。 三十六计跑为上，三十七技——回马枪

## ☠️ 状态 — 毒 / 灼 / 易伤
- **妖火**【T1】— 敌灼烧下回合 −0.5 HP 且该回合无法回血。 这就是为什么未羊不喜欢火焰魔法

## 🔒 干扰 — 诈唬 / 信息 / 元件层锁·税·禁 / 反切换

- **臭鸡蛋**【T1】— 丢向敌，其本回合攻击 −0.5 伤。 蛋神神了
- **伪造的宝石**【T1】— 你的道具栏向对手多显示 1 个假道具（持续到你下次用道具）。 纯度百分之一百...的玻璃
- **STEAL技能卡**【T1】— 对手本回合若「攒」，少回 0.5 能。 我原本没想偷这个的
## 🔄 导出 · 转化网（跨维桥 · 反固化结构件）

- **血魔的獠牙**【T1】— 你这次攻击命中时回 0.5 HP（攻→防）。 据说原主人已经戒血了
- **盗版太极图**【T1】— 你「防御」成功时 +0.5 能（防→能）。 接，化，发！

## 🎲 博弈 · 信息 · 随机（wildcard）

- **算命先生的铜钱**【T1】— 对手攻击 → +0.5 甲，否则 → +0.5 能（自适应对冲）。 天机不可泄露，但护甲和能量可以
## ✨ 趣味 · 体系外点缀（4 · 瘦身后留最有趣）

> §7「体系外点缀 = 游戏真正的丰富内容」。**铁规：power 全压地板（≤0.5，绝不出现 1.0 payoff / 不碰动作经济 / 不照搬大件）——趣味在机制、不在数字。** 吃本作独有结构（同时盲选 yomi / 道具公开 / 低血量 / 切换）。多数需新引擎 hook（自结算 DoT / 假道具显示 / 读对手动作 / 阈值触发 等）。

- **烫手的炸弹**【T1】— 贴给对手出战，X（随机数）回合后 −1 HP，对手和我方都可以通过消耗1能甩给对方。 说明书上的倒计时那页，我怎么找不到了？
- **乌鸦嘴**【T1】— 声明对手一个动作；本回合他真做了那个 → 他 −0.5 HP（说中就灵）。 其实乌鸦一直在告诉你别这么做，但这是个颜控的世界...
- **回旋镖**【T1】🆕 — 对敌 0.5 伤；被「防/大防」挡下 → 下回合自动免费飞回再打一次。 躲得过初一，躲不过十五
- **真香定律**【T1】🆕 — 立"本回合绝不攻击"旗(对手可见)；守约 → +0.5 能；食言去攻击 → 这击 −0.5 伤(打脸税)。 我绝不攻击！……真香

# 【T2】连携件 ≈1.0 — 框架 28 + 趣味 3 = 31 件（瘦身后 · 中立待重设计）

> 大头。英雄关键词共鸣（不点名）+ 连携 + 导出 + 元件层干扰。每关键词 ≤3 件、机制铺开。

## 🗡️ 进攻

- **锋利的飞镖**【T2】— 1.0 伤（飞镖升级线）。 子鼠推荐，性价比之选
- **双生咒符**【T2】— 你这次攻击命中次数 +1（多触发一次 on-hit，伤害不变）。 据说未羊在制作第一个咒符时手抖了，才有了第二个。
- **噬铁虫**【T2】— 你这次攻击腐蚀护甲，降对手防御一级 1 回合（大防→防、防→无）。 温馨提示：不要让噬铁虫靠近您自己的护甲
- **破魔失**【T2】— 你这次「波」改为穿防。 只失手过一次,那次对面是真的清白
- **丘比特之箭**【T2】— 你这次攻击无视对手护甲层（直击本体血量，#4 穿甲）；克卯兔 +0.5 甲 / 护盾 build。 一箭穿心❤

## 🛡️ 防御

- **坚固的护盾**【T2】— +1.0 甲（护盾升级线）。 其实丑牛一直很想把他的盾改名成圣盾，但因为某种不可抗力，他最终放弃了这个想法
- **锁子连环甲**【T2】— 你「大防」后，下回合 +0.5 甲（余韵）。 一环扣一环,断一环还有九百九十九环
- **巫毒娃娃**【T2】— 放一个替身吃下你受到的**下一次**伤害：吸收上限 1.0 HP、溢出部分穿过给你，替身随即破碎（挨一下即碎）。 它替你挨这一下,唯一的要求是别让它挨第二下。
- **还魂丹**【T2】— 本局一次，你出战将死时改为保留 0.5 HP。 死神说一粒能续一命。他没说续的是半条。

## ❤️ 治疗 · 续航

## ⚡ 能量 · 经济

- **磐石卷轴**【T2】— 你这次「大防」少耗 1 能。 这绝对不是丑牛防守的诀窍，绝对不是。

## 🐎 节奏 · 切换

- **替身草人**【T2】— 你切换时下场者留个稻草替身，若本回合对手对它的攻击，落空。 巫毒娃娃常常向它抱怨

# 🔗 序列化道具（回合内编排 · 2026-06-23 🆕 · 待 Eddy 逐条审批）

> **判准**：序列化件 = 道具"**向前伸手**"改变同回合序列里**其他元素**如何结算；价值在"**怎么排**"、不在数字大小。⛔不放大自己 payoff（避渴血红玉/超充）、⛔不只读全局快照（那是普通件、非序列化）、本游戏**无相邻格、只有先后**。
> **统一概念「待结算攻击加成」**=这一回合你为这一击叠上的前置加成（先手/凶药等）之和；分流件在"叠好→落地"之间把其中一部分改道。**全部数值守 0.5 网格、整块挪**（最小单位 0.5，定死）。
> **引擎前提（诚实）**：这批都需引擎让道具能读/改"线内其他待结算元素"——现有道具只动全局状态、彼此不作用，这正是现状"只有轻微序列化"的结构根因。
> **序列标签**：〔前〕动作前结算 ／〔后〕动作后结算 ／〔窗口〕改写其后一段 ／〔拦截〕改写其后第一个某类操作。

## 子维度① 分流转化（把"待结算攻击加成"按位置改道到别资源 · 数据流）

> 产出端用现成件（先手/凶药/大波）叠高这一击；分流件插在"叠高→落地"之间把一块改道。**排太前（没叠够）就转不出 = 排法即解题。**

- **抛砖引玉**【T1·导出·序列〔前〕】— 把你在它之前已叠的攻击加成中**至多 0.5** 改落成 0.5 甲。 先扔块砖，看你接不接。 〔入门分流·教"先叠后分"〕
- **移祸江东**【T2·导出·序列〔前〕】— 把它之前已叠的攻击加成中**至多 1.0** 改落成等量护甲（攻守同源）。 这口锅，甩给护甲背。 〔combo：先手/凶药叠高后插=攻守兼顾·攻→防桥〕
- **化干戈**【T2·导出·序列〔前〕】— 把它之前已叠的攻击加成中**至多 1.0** 改落成等量能量（这拳让给法力）。 化干戈为……法力值。 〔combo：攻→能·喂超充/子鼠 ramp；能量特例=以攻为代价〕
- **以战养战**【T2·导出·序列〔前〕】— 把它之前已叠的攻击加成中**至多 1.0** 改落成回等量 HP（攻转吸血）。 边打边补，越战越勇。 〔combo：攻→续航·PvE 值钱；与扭曲的饥渴触发拉开（占序列位/免命中 vs 命中触发）〕
- **乾坤挪移**【T3·导出·序列〔前〕·一次性】— 把它之前已叠的攻击加成**全部**改落成等量护甲（这一击彻底转防）。 攻即是守，守即是攻。 〔build-around·盾狗一波转防·全转 gate=一次性〕

## 子维度② 暂存兑现 / 收割（先铺、后由收割件一次兑现 · 数据流·读上游）
