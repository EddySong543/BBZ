## 🗡️ 进攻 — 直伤 / 穿透 / 多段 / 破防 / 爆发

- **生锈的飞镖**【T1】— 对敌 0.5 伤；最便宜补刀，无脑安全选。
- **先手**【T1】— 你这次攻击 +0.5 伤（贴大波/多段前）。
- **赌徒的硬币**【T1】— 抛币：正面 +1.0 伤 / 反面落空。赌自己。
- **幸运四叶草**【T1】— 0.5 伤；若你 HP 比对手低 → 改 1.0 伤（绝地走运）。
- **破盾咒**【T1】— 若对手本回合用「防」，你这次攻击穿防。
- **闪电**【T1】— 对敌 0.5 伤，无视「防」。
- **锋利的飞镖**【T2】— 1.0 伤（飞镖升级线）。
- **连击手套**【T2】— 打 2 下各 0.5（共 1.0，算 2 次命中；被防/大防整体挡）。
- **连环咒**【T2】— 你这次攻击命中次数 +1（多触发一次 on-hit，伤害不变）。
- **酸液瓶**【T2】— 你这次攻击腐蚀护甲，降对手防御一级 1 回合（大防→防、防→无）。
- **腐朽咒**【T2】— 给敌附腐朽，其下一次「防/大防」失效。
- **魔法箭**【T2】— 你这次「波」改为穿防。
- **索魂咒**【T2】— 你这次攻击无视对手护甲层（直击本体血量，#4 穿甲）；克卯兔 +0.5 甲 / 护盾 build。
- **禁咒**【T3】— 本回合大波翻倍（4.0 穿防）；被大防挡下→下回合力竭跳过动作。
- **绝境的魔咒**【T3】— 若你 HP ≤ 2，这次攻击 +3.0 伤穿大防（背水一战）。
- **巨人的铁锤**【T3】— 你这次「大波」改为穿大防一次（砸穿一切防御）。
- **失控的巨石**【T3·〔遗物〕】— 连续攻击每回合 +0.5 累加（碾压），被打断/换动作清零。
- **狂舞之刃**【T3·〔遗物〕】— 你每次攻击额外多 1 次命中（伤害不变），3 次后散（喂鸡剑意/虎双段/全队 on-hit）。
- **狂暴药水**【T3·〔遗物〕】— 攻击 +1.0 伤，但你无法防御（→ 纯小子 / 富人思维）。

- **破旧的护盾**【T1】— +0.5 甲（额外血量层，先扣甲后扣血；真伤无视）。
- **后手**【T1】— 若对手本回合「攻击」→ 你 +1.0 甲；否则无效。赌对手出招。
- **魔法气泡**【T1】— 若对手本回合「大波」，你这次「防」临时升级为可挡大波一次。
- **护身符**【T1】— 本回合免疫对手对你的一次 debuff / 干扰。
- **坚固的护盾**【T2】— +1.0 甲（护盾升级线）。
- **残留的结界**【T2】— 你「大防」后，下回合 +0.5 甲（余韵）。
- **巫毒娃娃**【T2】— 你受到的伤害，0.5 由一个替补分担。
- **替死符**【T2】— 本局一次，你出战将死时改为保留 0.5 HP。
- **带刺的护盾**【T2】— 你「防御」成功时反弹所挡伤的 0.5（挡波反 0.5 / 挡大波反 1.0，荆棘扎手）。喂牛 + 给龟壳 build 反击面。

## 🔔 协同 · 共鸣（#8 / #5 · 同回合双 commit 触发）

> 共鸣机制：带〔共鸣〕的道具**单出弱/无效，同回合与另一〔共鸣〕元件（道具或动作）一起打出才触发强效**。单出无收益=双 commit 才放=PvP 安全（详见 `items.md §0.9`）。

- **双生星**【T2·〔共鸣〕】— 单出无效；同回合另有〔共鸣〕件 → 本回合每个〔共鸣〕件额外 +0.5（共鸣 anchor）。
- **回响的咒**【T2·〔共鸣〕】— 单出 0.5 伤；与「波/大波」同回合 → 该攻击穿防 +0.5 伤（道具+动作）。
- **应和的钟**【T2·〔共鸣〕】— 单出 +0.5 甲；与「防/大防」同回合 → +1.0 甲并反弹 0.5（道具+动作）。
- **同心结**【T2】— 持 ≥2 件同维度道具时各 +0.25（封顶，软版「同气连枝」/#5，奖励不锁死）。
