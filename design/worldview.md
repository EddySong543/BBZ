## 0. 定调 🔒

- **类型**：王道热血群像。**没有单一主角**——光十二柱集体扛旗（🔒 2026-07-11 Eddy 定：群像，无固定主角，代入靠"英雄都是从零打上来的普通生肖人，和玩家一样"）。
- **氛围（当前版本）**：**枕戈待旦、硝烟四起**——被暴政拖入长夜的战时天下。
- **调性分层**：**主线严肃**（不玩梗）；**道具 flavor text 纯搞笑**（江湖气插科打诨，独立于主线，不进叙事考量·🔒）。
- **文化底色**：偏中式奇幻，**不是修仙**——只借东方故事感与意象（生肖、化龙、柱国、山海经之名），不搞飞升练气。
- **名字只是"借来的标签"** 🔒：二十八宿名 / 山海经凶兽名都不是字面上的神，没有神魔。见 §2 名号观。

## 1. 世界底层规则 🔒

### 1.1 大一统王朝 · 天下共主 = 真龙
- 远古，**十二柱国**（十二生肖势力，见 §1.3）合力扫平乱世，共尊一位**化龙者**登「**真龙位**」，为**天下共主**。此后各柱各守一方、各司其职，天下承平。
- **化龙是「化生」的，不是继承的** 🔒（核心·锚定"非天赋、人人可参与"）：真龙位对所有人敞开——鲤鱼跃龙门的东方内核，谁有那口气、那份本事，谁都能化龙登顶。这是本作**王道的最高之梦**（相当于"我要当海贼王"）。

### 1.2 双龙结构 🔒（靠剧情讲清楚·非机制）
- **凡龙 = 生肖龙柱 h05 亢金龙**：十二柱之一，只是"龙柱"的当代扛把子，凡龙。
- **真龙 = 帝位**：化龙者所登的天下共主之位，超乎十二柱之上。当代由**暗龙 h17 烛阴**化龙坐了（然后出事，见 §3）。
- 讲法（🔒 Eddy：讲故事时点清即可）：**暗龙窃据帝位、凡龙（或任一主角）逆流化龙**——两条龙争一个真龙位，是好戏。

### 1.3 十二柱国 = 十二生肖势力 🔒
- 生肖不是一个人，是**一股势力 / 一方藩镇**（柱国=古代官职，Eddy 化用，够帅）。英雄 = 该柱的**当代扛把子**；一柱有千军万马，人人都是这柱的一员 → 坐实"人人可参与"。
- 地图落位：十二柱封地 = **四方藩镇 + 长夜边境**，直接给远征的"大地图 → 区域"骨架。
- 扩容口（🔒 非天赋、任何动物都能来）：后期变色龙、蚂蚁、蜘蛛…… = 十二柱之外的**小势力 / 某柱麾下偏师**。生肖只是最有名的起点，池子对整个动物界敞开。

### 1.4 名号观 = 打出来的，不是生出来的 🔒
- 人人生来一个生肖（普通如"你哪年生的"，不给力量）。绝大多数人一辈子是"无名的属某人"。
- 敢走出去、敢斗、敢赢 → **打出一个名号**。名号分两条**走出来的路**（非出身）：
  - **星名（光组 h01–h12）**：走上被传颂那条路，赢得响亮如星辰的名号（虚日【鼠】= 一个属鼠的人一路打成传奇）。
  - **兽名（暗组 h13–h24）**：被斗争吞掉、堕入凶戾，退回野性、捡回上古凶兽之名（穷奇 = 一只属虎的人把自己活成了猛兽）。
- **两条路对所有人敞开，且可互相转化**（星堕成兽、兽亦可被拉回）。这一条同时解释了光暗双生、干掉了天赋感、让任何人任何动物都能参与。

## 2. 反派体系 🔒

### 2.1 傀儡皇帝 · 烛阴（h17）
- 龙椅上的**烛阴变了**——目光渐冷、开始**削藩**（收兵权、废自治），暴政。
- **烛阴神话 = 烛龙**（睁眼为昼、闭眼为夜）；技能【阖眸成夜】。**他一阖眸，天就永远暗了下去**——天下陷入**不散的长夜**（= 战时暮色氛围 + 战斗场景的月亮/日食/长夜美术 + "天亮"成全剧终极胜利符号）。
- 真相（§3）：**烛阴早已是一具死尸**，龙椅是傀儡。

### 2.2 晶巢（晶体蜂巢）🔒
- 龙椅背后真正操盘者：一个**无首的晶体蜂巢意识**（🔒 2026-07-11 Eddy 定：生物晶体化方向，工作名「晶巢」；⛔ 不用会恶心的虫）。
- 无数子体，能化成遍布天下的**魔晶**。所谓暴政 = 晶巢**用死皇帝当傀儡、拿魔晶悄悄同化、改造整个天下**。

### 2.3 魔晶 = 道具的故事内来源 🔶
- 晶巢碎片 = **魔晶**（增强实力的晶体）→ 天然解释游戏里"道具 / 强化"的来龙去脉：**你手里的增益，本就是敌人的碎片**。
- 可选钩子（🔶 Eddy："无所谓"·采用为剧情设定）：**晶巢早已把「化龙」这条路本身下了毒**——当年烛阴化龙登基那一刻即被吞掉自我、成第一具傀儡。**如今谁化龙，谁就成晶巢新皮囊。** → 主角团的"化龙"之梦被反派下毒，本版目标从"抢龙椅"变成"斩断晶巢对龙位的控制、把跃龙门这条路洗干净"（本版化龙爽点延后兑现，见 ❓龙椅结局）。

## 3. 当前版本主线 🔶（五幕草案）

**一句话**：一个被暴君真龙拖入长夜的大一统天下，一群被削藩逼到墙角的小人物，一路打回帝都弑君——却发现龙椅上早没了活人。

### 序 · 盛世（背景一屏）
十二柱合力共尊化龙者登真龙位、天下承平。化龙化生、龙位对所有人敞开。当代龙位由化龙的**烛阴（h17）**所坐。

### 第一幕 · 削藩（起）
烛阴变、削藩、暴政；一阖眸天下入**长夜**。屈膝或被魔晶腐蚀的柱国成爪牙 = **暗十二柱（h13–h24）**；不肯低头的**光十二柱（h01–h12）**被逐个击破、封地沦陷、四散奔逃。**主角团从一个被打散的小柱、几个亡命之徒起步。**
> 玩法咬合：这一幕 = **远征土壤**——闯过沦为战场/荒野的四方封地，把散落的光柱盟友**招募**回来。

### 第二幕 · 结盟反攻（承）
散兵拧成**反抗军**，沿四方一路打上去。每个**暗柱 = 一场硬仗 / boss 级劲敌**（穷奇、蚩尤、相柳…）。越打越强、人越来越多。埋线：**有些暗柱是被逼的、被魔晶吞的**（非天生反派）→ 为后续"化敌为友御海洋"留伏笔。

### 第三幕 · 弑君 · 真相（转，本版最大反转）
杀进帝都、直面烛阴——**发现他早已是死尸**。背后真正操盘的是**晶巢**：无首晶体蜂巢，子体化魔晶遍布天下。暴政 = 晶巢用死皇帝当傀儡、悄悄同化改造天下。
（下毒钩子）晶巢早把**化龙之路**污染——谁化龙谁成新傀儡。本版目标 = **斩断晶巢对龙位的控制、洗净跃龙门**。

### 第四幕 · 长夜将明（合，本版高潮 + 续作引子）
决战晶巢在帝都的本体/龙脉枢纽。**胜 → 斩断它对龙位的掌控，烛阴尸身入土，长夜第一次退去、天光破晓**（月亮/日食退场 = 全剧胜利符号）。
但晶巢溃退最后一刻——**退走的魔晶全朝海的方向流去**；死皇帝口吐最后一句：*"……它们要上岸了。"* **天亮了，可潮水正在来。** → 下一版海洋入侵引子落地。

### 升华 🔒（结4 手段 vs 目的）
真相揭开后，诱惑是"让自己人化龙、重建强权备战"——主角团选**难走的那条**：不靠同化、不靠一个人的绝对权力，而是**十二柱自愿并肩**去迎那片海。**羁绊 > 强权**，前面的反抗没白费。

## 4. 与玩法的咬合 🔶
- **远征模式**：闯四方沦陷封地、招募散落光柱；怪物 = 被晶巢同化 / 彻底无名的魔晶野物；四方 + 长夜边境 = 地图分层骨架。
- **道具**：魔晶 = 道具/强化的故事内来源（敌人的碎片）；（可选）用魔晶越多越易堕成兽名——把道具·暗堕·光暗双生串成一环（🔶 待定要不要机制化）。
- **24 英雄**：光十二柱 = 主角团 / 暗十二柱 = 暗柱反派（部分可救 → 后期混队成正史）。**光暗混队、镜像纯玩法，不用剧情圆**（🔒 Eddy：无所谓）。
- **美术**：烛阴闭眸 = 不散长夜 = 战斗场景月亮/日食/夜空的故事锚；破晓 = 胜利符号。
