## 0. 定调与硬规 🔒

### 0.1 类型与氛围
- **王道热血群像。没有单一主角**——光十二柱集体扛旗。代入感来自"英雄都是从零打上来的普通人，和玩家一样"。
- **氛围（当前版本）**：**枕戈待旦、硝烟四起**——被拖入长夜的战时天下。
- **调性分层**：**主线严肃**（不玩梗）；**道具 flavor text 纯搞笑**（江湖气插科打诨，独立于主线，不进叙事考量）。
- **偏中式奇幻，不是修仙**——借东方故事感与意象（生肖、化龙、柱国、山海经之名），不搞飞升练气。
- **名字只是"借来的标签"**：二十八宿名、山海经凶兽名都不是字面上的神，**没有神魔**。

### 0.2 三条命名/叙事硬规 🔒（2026-07-11 立）

**硬规 ①｜一眼自明**
名字可以不落俗套，但**必须让玩家看一眼就懂"哦，这是那个东西/那个地方"**——不能要求玩家先查资料。
> 反面教材：「紫垣」（源自紫微垣，天帝所居的星区）——有来头，但普通玩家读不出来，**已淘汰**。
> 正面：「**天心城**」——不用解释，三个字自己会说话。
> 也解释了英雄名为什么成立：「虚日」没人懂，但后面跟着【鼠】，一眼就明白。**名字的重担压在括号上。**

**硬规 ②｜叙事禁现实映射**
**不要任何政治/历史的味道。**⛔ 削藩、收兵权、藩镇、朝廷、弑君……一律不用。这是一个**纯粹的奇幻故事**，不是历史剧。
> 见 §2.3 的词汇对照表。

**硬规 ③｜生灵用古名**
扩容任何生灵（十二生肖之外），**一律用古籍里的古名/雅称，不用现代俗名**——现代俗名太"科普"、太西式、太 low。
> 变色龙 → **避役**（《本草纲目》）｜蚂蚁 → **玄驹**（《尔雅》）｜蜘蛛 → **蠨蛸**｜壁虎 → **守宫**
> "他成的是**避役相**" ≫ "他修的是变色龙"。用到时再翻，不必一步到位。

## 1. 世界底层规则 🔒

### 1.1 龙 = 天

- **化龙不是坐上一把椅子——是与这天地合成一体。**
  他的眼睛是日月，他的呼吸是风雨，他的意是四时。
- **所以他不再是"一个人"。**
- **天下为什么必须有龙？** 因为**龙就是秩序本身**。没有龙，昼夜不分、四时错乱、山河失序。天无二日。
  （⚠ 不是"镇压着什么怪物"——那是另一个游戏的设定。这里的龙不是狱卒，**是天。**）

### 1.2 十二柱国 = 撑天的十二根柱子 🔒

- 龙是天，**十二柱国就是撑着这片天的十二根柱子**。（"柱国"这个名字 Eddy 定了，不再讨论。解释走"撑天之柱"，不走古官职。）
- 一柱 = 一股势力、千军万马。英雄 = 该柱的**当代扛把子**。
- **⛔ 十二柱不是"十二块地盘"** 🔒（2026-07-11 Eddy 定·"域"的设定整个去掉）：
  - **柱国之间分的是「差事」，不是地。** 十二根柱子各撑一角——**各司一摊事**（见 §1.6）。
  - **好处一**：不再是历史剧的味道（割据/藩镇）。
  - **好处二**：**"归一"的威胁变狠了**——他要的不是你的地，是要你**放下你司的那一摊、融进他一个人的梦里**。
- **⛔ 不必人人都有差事** 🔒：有的柱国在体系里（守将、侍卫、监天司、传令），有的**根本不进这个体系**（如猴柱）。十二柱不是"十二个官"。
- 天下**没有专名，就叫「天下」** 🔒（Eddy 定·一眼自明，零学习成本）。
- 天倦了、天要塌了——**柱子得自己扛。** 这就是本作的起点。

#### 三个重点柱（挖到东西的）

**🐲 龙 = 宰相 · 通天者 · 唯一的名门 🔥**
- **只有他听得见天。** 烛阴闭眼后天下都以为那位睡了——**只有龙柱还听得见他在说话。** 所以他最早知道出事，也**最早被侵蚀**。
- 他家**世代出龙相的顶尖人物**，是十二柱里唯一的名门。
- **🔥 反差（Eddy 采纳）**：这世界的铁律是「名号是打出来的，不是生出来的」——**而龙柱是唯一一个"生来就在高处"的人。**
  > 主角团里最容易被戳的那个：**"你那个名号，真是你自己挣的吗？"**
  > 一群从泥里爬上来的亡命之徒 + 一个天生的贵公子，还得一起打天下。

**🐍 蛇 = 医者**
- 念力向内。他医的不是身，是**念**。
- **能救你的，和能杀你的，是同一个人。** 天下人怕他，但都得求他。
- 技能咬合：毒一层层积着、某一下全爆——**那不是药性，是他在你念里埋的东西**。

**🐔 鸡 = 监天司 · 最后一剑 🔥**
- 他的差事就是管晨昏、报天亮。**烛阴一闭眼，他的历法作废了，他报不出昼夜。**
- **🔒 终局那一剑给他**（Eddy 定）——**劈开长夜，把"天亮"这件事还给天下。那本来就是他的差事。**

**🐷 猪 = 司民（+ 形象设定）**
- 🔒 形象（Eddy 定）：**本来是个潇洒的男子，走了猪这条路，人变了样——但骨子里那股潇洒还在。** 反差。
- **一心要抹掉的，正是老百姓"各有各的心"。所以十二柱里第一个觉出不对劲的，是他**——只有他天天和人打交道。

### 1.3 修行成相 🔒（v0.2 重写·取代 v0.1"生下来有个生肖"）

- **每个人都能选择自己修行的道路。** 修到深处，身上会显出一个**相**。
- **虚日 = 鼠相之顶那个人。** 穷奇 = 虎相走到了尽头的那个人。
- **⚠ 化龙 ≠ 龙相之顶。** 化龙是**所有道路共同的终点**（任何一条路走到极处，都可能化龙），不是龙这条路的专属。
  - 「亢金龙」= 龙相之顶那个**位子**（凡人的名号）。
  - 「化龙」= 超出了相，成了天。
- 扩容不受十二生肖限制：**避役相、玄驹相、蠨蛸相**……任何生灵都是一条路（用古名，见硬规③）。
- ⛔ **作废**：v0.1 的"星名/兽名两条路、可互相转化"整个删除（见 §7）。

### 1.4 名号 = 一相之顶的位子，**有限** 🔒

- 名号是**天的册子上的一个位子**（星名 = 二十八宿）。
- **位子是有数的。虚日只有一个。**
- **你想要那个名号，就得从现在坐着的那个人手里赢过来。**
- 👉 **这直接解释了游戏为什么是 1v1 对打：这天下本来就是靠夺名号运转的。**（世界观与玩法本体焊死）

### 1.5 天心城 🔒

- **龙位所在，天下正中。** 十二柱撑天，天的正中心就是龙待的地方。
- "**打上天心城**" = 本作主线的终点。
- 美术锚：战斗场景那轮**正居天心的巨月**（960,430），画的就是这个中心。

## 2. 反派体系 🔒（v0.2 结构性重写）

### 2.1 一心 🔒（历代化龙者的意识统合体）

**核心设定（Eddy 定，2026-07-11）：**

- **历代的龙不会死，会归进"它"。** 每一代共主化龙、与天地合一、不再是人，最后意识归入一个**无首的统合体**。
- **它的名字叫「一心」。**
- **它最初是善意的**：把历代的经验留下来、庇佑后来的人——"别让后人再走一遍我们走过的死路"。
- **但几十代累积下来，它变了。** 越来越极端，最后得出一个结论：
  > **失序的根源，是"人"还各有各的心。**
- 于是它要**归一**：天下该像一块干净的棋盘。凡是不齐的、有自己脾气的、各自为政的——**抹平，归于一**。
- **它叫一心。它想让天下只剩一颗心。**

> **⚠ 这是本版最重要的结构改动**：反派**不是套娃**。一心不是烛阴背后的"另一个更大的怪"——**一心就是龙位本身、就是所有的前任。** 只有一层，而且这一层是从"化龙"这个设定里长出来的，不是外面搬来的。

### 2.2 烛阴（h17）= 最新的那一个 🔒

- 烛阴化龙，坐上了龙位。**他不是傀儡，他是活的。**
- 他也曾是从最底下一路打上来的人。
- **第三幕的反转不是"他是个死人"——是"他是活的，他还认得你们，他甚至还记得自己当年，然后他平静地说：那又如何。"**
  > **他不坏。他是不再是人了。** 他正在被一心化掉。
- **他闭眼不是残暴，是倦了。** 于是天下入**不散的长夜**。
  - 神话对应：烛阴 = 烛龙（睁眼为昼、闭眼为夜）；技能【阖眸成夜】。
  - 美术锚：长夜 = 战斗场景的月亮/夜空；**破晓 = 全剧胜利符号**。
- **他是一面镜子**：你们爬上去，会不会也变成他？
- **他化龙之前是哪一条路的顶点？** ❓ **待定**——🔒 Eddy 定（2026-07-11）：**不预先锁死，写英雄故事时看哪个英雄契合就用哪个。**
  （一个备选：他曾是「亢金龙」，化龙后位子空出来，现在的 h05 补了上去——那样 h05 会是全队唯一一个天天用着龙位上那位名字的人。备选而已，不强制。）

### 2.3 "归一"怎么讲（⛔ 政治词全部替换）

| ⛔ 禁用（v0.1 遗留） | ✅ 替换成 |
|---|---|
| 削藩、收兵权 | **归一**——不是收你的兵，是要你**放下你司的那一摊、融进他的梦里** |
| 藩镇、封地、**域** | ⛔ **整个不要**——十二柱分的是**差事**，不是地（§1.2） |
| 帝都、龙椅、弑君 | **天心城** / **龙位** / "打上天心城" |
| 王朝 | 不提，就说"**天下**" |

### 2.4 暗十二柱 🔒（2026-07-11 定稿）

#### ① 兽名 = 烛阴自己的一本册子

- **天的册子**是有规矩的：一个位子只有一个人，你得**打赢**才坐得上去。名号属于**天下**。
- **烛阴另立了一本册子。上面的名字是他给的——只属于他一个人。**
  - **星名 = 位子**（有规矩、有责任、属于天下）
  - **兽名 = 力量**（无规矩、只属于他）
- 👉 这就是星名/兽名最根本的区别，且完全对上「归一」：**他不要一个有规矩的天下，他要一本只认他的名册。**

#### ② 名字就是锁 🔥

> **你叫穷奇，你就得「是」穷奇。那个名字，正在一天天把你啃成它的样子。**

- 暗柱**不是自己堕落的**——是**被那个名字啃的**。
- **怎么救？把他原来的名字还给他。**
- 接 §2.4b 的钩子：**你要把名字还给他——可那个名字，现在在你身上。**

#### ③ 暗柱**不接手**那些差事 🔥（世界观×玩法咬合）

> **烛阴要的不是让这台机器换个人继续转——是让它停下来。**
> 归一之后，天下不需要十二根柱子，**只需要一颗心。**

所以第一幕之后，**天下这台机器是坏的**：

| 缺了谁 | 天下变成什么样 |
|---|---|
| 没人报晓（监天司） | **天不亮** |
| 没人传令 | **消息断了，各柱失联**（→ 所以他们被**逐个**击破） |
| 没人管百姓（司民） | **乱世** |
| 没人守边、没人医人 | **荒** |

> **天下不是被占领了——是没人管了。**
> 👉 这一条把远征模式那片战乱荒野的来历解释干净了。

#### ④ 暗柱从哪来的：**混着来** 🔒（Eddy 定）

> **烛阴收人只有一个标准：你想不想要那个你这辈子拿不到的东西。**

- **有的是"老的"**——原本就坐着那个位子的柱国，屈从了 → 被划名、赐兽名。
- **有的是"补上来的"**——名号只有一个位子，**输的那个人一辈子没名字**。烛阴专收这种人："你差的那一口气，我给你。"
- **⛔ 不设统一说法**——**具体哪个暗柱是哪一种，落到那个人的传记里再定**（🔒 Eddy 定 2026-07-11）。
- 👉 两种人放在一起，第二幕每一场仗的味道都不一样。

### 2.4b 名号空位 🔒（叙事工具·非全局规则）

由 §1.4「名号有限」+ §2.4「夺名改籍」自动推出：

> **一个人被夺了名，天上那个位子就空出来了。而现在坐在那个位子上的，是光柱里的某个人。**
> 你打赢的那头凶兽，可能就是**你名字原来的主人**。
> 你想救他？你得**把名字还给他**——可那个名字，现在在你身上。

**🔒 Eddy 定（2026-07-11）：这是个「工具」，不是全局设定。**
- **只有部分光柱是补位上来的**（⛔ 不是全员，全员会腻）。
- **⛔ 不设统一说法**——哪个英雄是补位的、他名字原来的主人是谁，**落到那个英雄的具体小传时再逐个定**。
- 写英雄故事时，这条随时可取用。

### 2.5 怪物 = 被抹掉了心的空壳 🔒（世界观×玩法咬合）

- **归一，就是抹掉一个东西"自己的心"。**
- 被抹过的生灵不会死，会变成空壳——**只会一遍遍重复同一套动作，整整齐齐，永不改变。**
- 👉 **所以远征模式里的怪物是"明牌"的——它下一步出什么，你看得见。因为它没有心可藏了。**
  （机制与世界观完全焊死，代码一行不用改。）

### 2.6 道具的来历 🔒 = **不解释**

- Eddy 定（2026-07-11）：**奇幻道具不需要解释来历，跳过。**
- ⛔ v0.1 的"魔晶=晶巢碎片"整个作废（晶体蜂巢设计已抛弃，见 §7）。

## 3. 当前版本主线 🔶（五幕）

**一句话**：
> 天下必须有一条龙撑着，才有白昼。当代的龙撑不住了，闭上了眼，天下入夜。
> 一群被逼到墙角的人一路打上天心城，本来是要解放天下——到了最后才明白：
> **推翻他很容易。难的是，天下从此没有龙了。**

### 序 · 盛世（背景一屏）
十二柱撑天，龙居天心城，四时有序、昼夜分明。当代龙位由化龙的**烛阴（h17）**所坐。

### 第一幕 · 归一（起）
- 烛阴**阖眸**——天下陷入不散的长夜。
- **一心**借他之口要"归一"：十二柱**放下各自那一摊差事**，不许再有自己的脾气，**融进他的梦里**。
- 屈从的、被夺了名另赐兽名的 → **暗十二柱（h13–h24）**。
- 不肯低头的 **光十二柱（h01–h12）** 被逐个击破、四散奔逃。**天下这台机器，十二根柱子被拆了一多半。**
  （传令的路断了 → 各柱彼此失联 → 这就是他们为什么会被**逐个**击破。）
- **主角团从一个被打散的小柱、几个亡命之徒起步。**

> **玩法咬合**：这一幕 = **远征土壤**——闯过陷入战乱的天下，把散落的光柱盟友**招募**回来。

### 第二幕 · 结盟反攻（承）
- 散兵拧成**反抗军**，一路打上去。
- **每个暗柱 = 一场硬仗 / boss 级劲敌**（穷奇、蚩尤、相柳…）。
- 埋线：**有些暗柱是被逼的、是被夺了名的**——他们的星名，还空着。

### 第三幕 · 天心城 · 真相（转，本版最大反转）
- 打上天心城，直面烛阴——**他是活的。他认得你们。他不在乎。**
- 他背后不是"另一个怪物"，是**一心**：**历代所有的龙，全都还在里面。**
- 真正的恐怖不是"皇帝是假的"，是——**他就是终点，而终点长这样。**
- 主角团面对的不再是"打倒坏人"，是：**打倒他之后呢？天下还有龙吗？**

### 第四幕 · 长夜将明（合，本版高潮）
- 决战一心。
- **胜 → 长夜第一次退去，天光破晓。**
- **但天下从此没有龙了。**
  - 昼夜会不会乱？四时还在不在？**没有人知道——没有龙的天下，从来没有人见过。**
  - 大一统碎掉，天下将入乱世。**合久必分。**

### 升华 🔒
> **我们宁可要一个谁也不知道明天什么样的天下，也不要一个整整齐齐、装在一个人梦里的天下。**

不靠一个人的绝对权力，靠**十二柱自愿并肩**。**羁绊 > 强权**——这一版里它是打出来的，不是喊出来的。

### 长线骨架 🔒
**合久必分，分久必合。**
本版 = **分**（大一统崩塌 → 乱世）。后续数个版本 = 乱世中的挣扎 → **再度一统**。
（这是本 IP 的长期叙事骨架，取代 v0.1 的"套娃引出更大的敌人"。）

## 4. 叙事载体 · 故事模式框架 🔒（Eddy 定，2026-07-11）

### 4.1 剧情怎么送到玩家面前

- **开头一段小动画**（交代世界与起点，短）。
- **正片剧情靠碎片拼**：
  - **故事模式**：碎片化的**个人故事**。
  - **远征模式**：剧情从**事件**里透出来。
- **每个版本首尾各一段小动画**（或故事模式单独关卡），交代该版本剧情。

> **这条路子对**：群像无主角，本来就该靠碎片拼，不该塞长过场动画。

### 4.2 故事模式 = 四类关卡 🔒

**关卡形态**：**静态图（动漫过场感）+ 战斗**。

| 类型 | 数量 | 讲什么 | 调性 |
|---|---|---|---|
| **主线关卡** | 每版本几个 | 推大剧情（五幕）· 硬仗 / boss | **热血王道**（可以有搞笑调味，但总体热血王道） |
| **个人小故事** | **24（一人一个）** | 一个角色的**弧光时刻** | 同上 |
| **群像小故事** | 若干 | 几个人凑一块儿的事（结盟 / 翻脸 / 并肩） | 同上 |
| **休闲小故事** | 若干 | **放松**·补角色弧光·给角色**加小特性** | **可松弛** |

### 4.3 个人小故事的规矩 🔒

- **标题格式（玩家可见）**：**四字标题 + 换行 + 英雄全名**。（内部文档索引照旧用 `hXX`，⛔ 外部不写"某某传"。）
  ```
  天 日 昭 昭
  亢金【龙】
  ```
- **⛔ 不必写全生平** —— **只要一个小故事，能彰显角色弧光就够**。
- **⛔ 不成对** —— **一人一个**。（h01 的故事里可以出现 h13，h13 自己的故事再讲一遍同一件事——**罗生门**，一分钱设定不用加，情感重量翻倍。）
- **底线**：每关**必须有仗打**（它是个关卡）。
- **哪一刻最能照亮这个人，就写哪一刻**——不强求统一"讲长夜前还是长夜后"。

### 4.4 ⛔ 叙事的三条反面清单（2026-07-11 血泪教训）

Eddy 逐版否决 h01 剧本，否掉的是这些：

1. **⛔ 刻意煽情** —— 死一个小人物换主角觉悟 / 队友走过来抱一下 / 主角自我剖白。**廉价。**
2. **⛔ 说教式升华** —— 把主题写成一句台词讲出来（"名号不是勋章是担子"）。**主题要靠行动长出来，不能靠嘴。**
3. **⛔ 用"计谋"冒充"角色"** —— 一个聪明的招数（抹名字 / 投名状 / 以身为饵 / 叙述诡计）不等于一个人。**聪明 ≠ 深。**

**Eddy 要的**：**冷、留白、不收口、给联想空间**（他的原话：好的段落"看完之后有联想感"，把结局解释干净反而是狗尾续貂）。

### 4.5 已定的角色方向（写小传时的原料）🔶

> ⚠ **以下只是「方向」，不是剧本。** 具体故事**全部待写**（2026-07-11 h01 剧本连废 6 版，Eddy 判"还是不太对"，暂挂）。

| 角色 | 已定的方向 | 状态 |
|---|---|---|
| **h01 虚日【鼠】** | **🔥「比黑暗更黑暗的黑暗」** —— h13 是黑暗，而 h01 最后成了比黑暗更黑的东西。**⚠ 这一条是唯一保留项，剧本全部推翻重来。** | 🔴 剧本待定 |
| **h13 玄冥【鼠】** | 和 h01 **很像**，但**更强、更会正面打**（h01 只有暗器 + 一把短刀）。**"虚日"只有一个位子——那为什么坐着的是 h01？** 整条线长在这个问题上 | 🔶 |
| **h05 亢金【龙】** | **宰相 · 通天者 · 唯一的名门**。🔥 反差：世界的铁律是「名号是打出来的」——**而他是唯一"生来就在高处"的人**。主角团里最容易被戳的那个："你那个名号，真是你自己挣的吗？" | 🔒 |
