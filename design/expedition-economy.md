## 1. 货币结构（2026-07-05 Eddy 修订）

- **局内商店（行商）已拍板存在**：允许玩家局内兑换或卖出一部分战利品、购买治疗品及其他探索消耗品；整体价值**弱于局外商店**。具体收购、出售倍率随百万经济和逐件价格一起重标；结算媒介（以物易物或局内币）后续再定。
- **金币（局外主货币）**：撤离/死亡结算时金币类实物折算入局外钱包。

## 2. 金币流

**来源**：撤离折算（主）｜成就奖励（一次性）｜重复稀有品折算（英雄全解锁后的碎片等）。死亡不保留任何局内金币。
**去向（Q3 拍板：道具/英雄/皮肤外观）**：

| 商店条目 | 定价锚 | 说明 |
|----------|---------|------|
| T1/T2/T3 战斗道具 | 逐件定价 | 不按稀有度、耐久或格数套固定表；预计生命周期、稀缺性、需求、紧凑性和风险共同决定 |
| 英雄碎片包（碎片×3） | 待重标 | 旧 `1200` 金在百万经济下作废 |
| 皮肤 | 待重标 | 旧 `1500–2500` 金在百万经济下作废；仍为纯外观 |

**Demo 撤离锚**：按成功撤离时的可兑现带出总值，初始目标为 `P25=8万–12万 / P50=20万–30万 / P75=45万–65万 / P90=90万–120万 / P99=250万–400万`；极端 Jackpot 为 `800万–1000万`。入场成本和本局消耗另列为净收益。

“百万撤离”是明显大赚，“千万撤离”是设计软上限。战斗道具满价与残损曲线逐件确定；不再使用默认格数倍率、统一耐久倍率或统一残值公式。

## 3. 仓库 → PvP 战备背包

T1/T2/T3 成品都可作为真实资产进入仓库与赛前战备方案。进入 Run 时锁定对应真实实例；战斗中通过每回合一次免费真实背包三选一进入公开框，选中件锁定本回合，并在每次使用时支付自身费用。

采用 **实例制**：带入 Run 的是真实物件，使用扣耐久，归零销毁；撤离时仍持有的实例按剩余耐久回仓。远征永续、仓库回收和商店兜底由真实损耗闭环。永久解锁模型维持不采用。

**公平性如实标注**：高价值战备可以形成真实强度优势，但价格和资产风险不能补偿单场内的零信息高 roll。PvP 通过公开锁定一回合、逐次使用费、框位和候选概率提供信息与反制窗口。正常显示价值、可兑现价值与匹配战力分账；临时件正常显示估值、不可兑现，并按实际强度计入匹配。

## 4. PvE 战斗道具容器规则（对齐框架 §10/§11·摘要）

- 装备槽上限**解开**（开局 1 → 拾取扩容），⛔ PvP 锁 3 槽不变。
- **回路 e 只活 PvE**（放飞）；**导出 e 在 PvE 是刚需**（永久掉血）；系间 ≥ 系内的相对关系不变（连携主定理·PvE 只解封绝对量）。
- T3 道具 PvE 局内可用、可收藏，也可进入未来 PvP 战备候选；免费三选一、取得后锁定本回合和逐次使用费是通用规则，不再按模式分开审批。

## 5. 英雄碎片

- 获取：深层 Boss 首杀保底｜宝箱极稀有（~2%）｜商店碎片包｜（残局谜题系上线后为其专属奖励·🔶建议维持）。
- 兑换：**碎片×10 = 解锁 1 名英雄**（草稿），解锁英雄 PvP/远征通用（GDD Q2）。
- 溢出：全英雄解锁后的碎片折价待百万经济重标；旧 `100 金/片` 作废。

## 6. 宠物（🔒2026-07-05 Eddy 拍板：PvP 纯外观 + PvE 小功能）

- **PvP：纯外观**（跟随/图鉴/炫耀·零强度——守住"绝不卖强度"）。
- **PvE：允许小功能**（如探索中增加视野或嗅宝能力·数值只进 PvE）。首批宠物功能表待宠物立项时另拟。

## 7. 皮肤与成就

- 皮肤：金币商店+极稀有直掉（皮肤卷轴）双轨；纯外观，价格待百万经济重标。
- 成就：远征里程碑（首次撤离/无伤 Boss/满包撤离/发现区域秘密等）；奖励=金币+称号，不占背包、死亡不掉。
- 🔒（2026-07-05 Eddy 拍板）皮肤可重复掉落，**重复即折金币**（折率草稿=50% 商店价）。

## 8. 边界情况（Edge Cases）

- 玩家从未玩远征或仓库为空：使用系统 D1/T1 临时保底战备；不能凭空写入真实库存。
- Run 中断/掉线：以服务器最后确认的实例耐久和所有权快照结算，不能重复扣除整件或复制残损件。
- 金币来源若增加 PvP 对局奖励（供纯 PvP 玩家走商店线）：数值另立·防刷局（挂机检测/日上限）——占位登记，不在雏形范围。
- 英雄碎片指向已拥有英雄：自动折金币，具体金额待百万经济重标。

## 9. 调优旋钮（Tuning Knobs）

撤离带出总值分布（P50 20万–30万 / P90 90万–120万 / 极端 800万–1000万）｜逐件满价与残损曲线｜NPC 回收规则｜死亡时无保底金币、只保留保险槽物品｜碎片解锁数（10）｜稀有出率（2%）｜库存上限（是否封顶·防囤积）｜进场强化条目与定价。

## 10. 验收标准（Acceptance Criteria）

- [ ] 撤离结算按带出物品入账；死亡时不产生保底金币，只保留保险槽物品。
- [ ] 仓库持久化跨会话正确；真实/临时所有权、最大/剩余耐久、固定形状与满价均不丢失。
- [ ] 商店购买-入仓库-带入 PvP/PvE-残损撤离全链路可走通；T1/T2/T3 成品走同一实例规则。
- [ ] 碎片计数、解锁、溢出折算正确。
- [ ] 局内商店：兑换/卖出/购买治疗品三条链路可走通，价值弱于局外商店可量化（媒介待定后补断言）。
- [ ] 实例制：权威使用才扣 1 耐久，归零销毁；断线重发不重复扣除。
