# 英雄重设计（v2，从设计纲领自底向上）

> **性质**：2026-06-14 起，**抛弃全部旧 kit**，依 `design/build-design-framework.md` 的设计理论一只一只重建。
> **每只执行顺序（2026-07-30 重写）**：① 角色幻想（可借战斗动画 / 漫画动作发散）→ ② 从「波 / 攒 / 防 / 大波 / 大防 / 切换 / 行动」联想底层机制 → ③ 用 1~2 个共享原语写成单技能 → ④ 检查 combo、双向 yomi、简洁度与撞车 → ⑤ 机制获批后归入进攻 / 防守 / 经济 / 调度 / 控制之一 → ⑥ 最后记录 HP 与实现边界。
> **三条硬透镜，每只必过**：
> - **底层交互**：英雄是波波攒基础规则的改装件，不另造只供自己使用的关键词系统。
> - **共享原语格栅**：每只必须产出或消费可复用共享原语，不许自闭机制；连携应能自然接多名英雄和道具，不得绑定唯一搭档。
> - **博弈点**：玩家必须选择时机，对手必须能重排选择；纯后台收租、自动白值或“角色特征直接翻译成加数值”不通过。
> - **主动结构而非动作对照表（2026-07-30 h04 纠错）**：技能不能只写成一串“敌方出 X → 自己自动变 Y”的 if–else；应让玩家主动安排刺杀、进退、目标或接力路线。单纯调整既有动作的前后时序，若没有形成高影响的新决策，同样不够格成为 identity。
> - **一行小字（2026-07-30 h04 二次纠错）**：主动结构不等于同时塞入多个选择。玩家可见核心机制必须一行说清，只改变一个基础关系；若需要第二行解释目标、退路或特殊结算顺序，直接退回重做。
> **主定位只是事后描述，不是设计配额**：允许五类数量不均；0 人是缺口、1 人是薄弱警报、2 人以上即成立，绝不为凑数扭曲当前英雄。
> **强度后置**：本轮重设计不按现有胜率筛机制，也不为平衡给获批设计擅自加尾巴；按 Eddy 要求原样实装，数值另开平衡阶段。
> **旧字段兼容**：下文历史记录中的“维度”与 `.tres` 的 `dimension` 暂属道具加权技术标签，不再指导设计。当前主定位真相源见 `design/heroes-schools.md` §3。
> `design/heroes.md` = 玩家可见技能文案真相源；本文 = h01–h12 逐英雄设计理据。二者分工不同（文案 vs 设计依据），互不作废。

**🔄 h17 全面重设计（2026-08-06·Eddy 定稿·新技能名【同源万化妄真身】）**：旧【阖眸成夜·锁招】退役；新技能为占行动、消耗 2 能的永久转变——“烛阴【龙】转变为敌方当前出战英雄”。目标读取点在主动切换之后；复制英雄身份、当前与上限生命、护甲、延迟效果、局部状态和技能使用进度，但不复制团队能量、道具、遗物与团队增益。双方同时发动时先拍目标快照再同时落地，避免结算顺序改写结果。转变后原技能自然被目标技能替换，不另加局内次数限制。
**🔄 h18 全面重设计（2026-08-23·Eddy 定稿·技能名沿用【游丝引】）**：旧“均分存活队友当前生命”机制退役，但技能名【游丝引】保留；新技能为被动对称战场规则——“相柳【蛇】出战时，双方「波」与「大波」的基础伤害均视为1点。”基础值归一后再结算强化波、攻击总修正、毒素、印记与脆弱；大波仍穿「防」并被「大防」挡住，攻击型主动技、追击、反击与独立伤害不受影响。相柳退场、阵亡或被沉默时规则关闭；不新增状态、计数器或联机字段。HP 6→5，主定位由防守改为控制；旧 `dimension="状态"` / `team_role="经济"` 字段按全池兼容规则暂不逐只迁移。
**🔄 h22 全面重设计（2026-08-08·Eddy 采用方案3·技能名沿用【焚天火兆】）**：旧【蓄力获得护甲·我方下一次攻击穿大防】退役；新技能仍免费、占行动、每局 2 次——“下一回合结束时，双方失去全部能量”。发动后建立不绑定英雄的全局截止线，在下一回合全部行动、道具、死亡收益、遗物和被动产能结算后同时清空双方能量；换人、阵亡和转变不取消，同一时间不可叠加。其 combo 来自截止线前的资源倾泻与价值保留：h05 强化波、h08 保留大防、h07 免费调度及付费道具都改变下一拍选择。主定位由进攻改为控制；旧技术字段暂不逐只迁移。
**🔄 h23 全面重设计（2026-08-09·Eddy 定稿【天光长蚀】）**：旧【御凶·致死顶替承伤】及护甲 / 反击 / 次数链路退役；新被动为“天狗【狗】的「波」或「大波」造成伤害时，等量降低敌方能量上限（最低到3点）”。按实际落血量结算一次；合并进该次攻击伤害的道具加成计入，独立道具伤害不计。现有超额能量保留，但降到新上限以下前不得继续获得能量。h02 的「波升级」与 h05 的强化「波」会同时扩大伤害和削减，对手可用「防 / 大防」完全阻止。现行主定位改判为控制；旧 `team_role="防守"` / `dimension="防御"` 暂作兼容字段。
**🔄 h02 全面重设计（2026-07-30·Eddy 定稿）**：旧【山岳为屏·受伤发盾】退役，HP7 与防守主定位不变；新【玄金不动相】把成功挡招转成一次团队爆发——牛金挡下「波」或「大波」后，己方下次「波」升级为「大波」。升级不过期、不叠加，可换人交给队友兑现；这发招仍付「波」的费用并保留「波」的选招身份，伤害、有效类型和基础穿透按「大波」结算。重做目标是让牛金的价值来自玩家主动读招与后续组队接力，而不是挨打后自动发白值。

> ## 🔒 二元铁则（2026-06-16 Eddy 定死 · 后续所有设计必须遵守）
> **力量 = WHETHER（能不能），不是 HOW MUCH（多少）。** 防御是"挡不挡得住"、不是"吸收几点伤害"。
> 🔓 **护甲解禁（2026-06-22 Eddy）**：临时护甲 / 护甲（额外血量层）现为合法设计工具（当时首用 = 牛金 h02【山岳为屏】·该机制已于 2026-07-30 重做退役）；原"禁临时护甲/护甲吸收模型"条作废。但 **防/大防本身仍是二元整体挡**（挡=归零·不挡=全额），护甲与"防挡不挡"正交、只吸收落地伤、真伤无视。
> - **分级整体挡**：防 = 挡下「波」级**整个攻击**；大防 = 挡下「波 + 大波 / 穿防攻击」= **天花板**。挡 = 完全归零、不挡 = 全额落地。
> - **穿透三档**：①**穿防**（防挡不住、大防能挡，如大波 / 牛金升级后的「波」 / 鸡 2 层一闪）②**穿大防**（连大防都挡不住——**只授予"公开慢蓄 / 需铺垫"的 payoff**，如鸡满 4 层或高阶一次性道具；**禁给便宜 / 瞬发**；counter = 换核心吃 / 预防，而非挡）③**真伤**（无视一切防御**与护甲**、直接扣本体血，无敌态仍 0.5；**英雄仅娄金**；道具真伤放开准则见纲领 §4.6「真伤道具 4-gate」+ §14 判据 A）。
> - **打穿大防龟壳**靠：**破防（降防御等级，如龙）+ 资源剥夺（猴碎能 / 骗防）+ 受授权的穿大防 payoff**。**不靠"更大的数字淹没护甲"。**
> - **护甲 = 额外血量层**（当前由道具等来源提供；牛金 h02 曾为英雄首用、已于 2026-07-30 重做移除）：常驻、只吸收"**没挡住、落到身上**"的伤害（先扣甲再扣血），与"防挡不挡"正交；真伤无视它。
> - **变量伤害**（鸡一闪 / 毒爆 / 道具多段等）只在"**没被挡住**"时按数值生效；被挡 = 归零（这就是波波攒 yomi）。多段攻击的 proc 被"必须命中"gate 住——**禁止让分段绕过防御**（否则 proc 脱缰=boss）。
> - 能量允许 **0.5**（受 0.5 实例 / 等量转化用）。

- **Unique（被动·千里自在风）**：① 每回合一次，涉及星日的「切换」（顶马上场 / 切马走）**不占动作槽**，切换后新出战英雄仍可行动；② 星日**切换登场时，对敌方出战造成 0.5 冲撞伤**。冲撞是独立伤害，不算命中。
- **共享原语**：**切换 tempo / 额外动作经济** + **登场冲撞伤害**。
- **Combo / agency / 博弈**：免费 2-for-1 把对的英雄即时顶上吃 combo（顶上合适队友使用龙御极强化波、切换后继续攻击），何时换、换谁上场 = 核心决策；马 = **全池 combo 的衔接引擎**，系间乘算放大一切"出战才生效"被动。冲撞不引爆毒素、不触发命中技能。
- **cap**：免费切换为**每回合一次**（`free_switch_cap()=1`），次数按本方回合统一记录；当回合使用后，再次涉及星日的切换恢复为普通切换动作。冲撞 0.5 为小值。
- **设计依据**：马 = 疾行与冲锋陷阵；免费切换是调度 identity，登场冲撞只是进攻 rider。与 h04 的新机制须避开“无条件切换后还能行动”这一核心槽位。
- **规则裁定（2026-08-08）**：旧“不限次数”版本退役。现行只允许每回合一次免费切换，目标是让“切下星日后队友继续操作”或“切入星日后星日继续操作”成立，但不能在同回合无限循环。

## h08 鬼金「不坠神言」
- **主定位**：防守（团队后备防御）
- **HP**：6
- **Unique（被动·不坠神言）**：鬼金【羊】的「大防」未挡到攻击时，由我方保留至下一回合结束。
- **规则边界**：“攻击”只指基础「波 / 大波」；不包含道具伤害、主动技、反击、毒素或延迟伤害。保留状态属于队伍，换人后仍在且不可叠加；连续空放会刷新到再下一回合。同一次基础攻击即使多段命中也会被完整挡下。
- **结算顺序**：下一回合当前英雄选择的「防 / 大防」先结算；只有当前防御未挡住时，保留大防才补位。穿透「大防」的攻击不会消费它，但状态仍会在该回合结束时到期。
- **共享原语**：**防御延迟兑现**——允许先用大防试探，并把未兑现的防御转成下一回合的团队安全窗口。
- **Combo / agency / 博弈**：下一回合可用换人、蓄势或高风险进攻兑现安全窗口；实际挡招仍走统一成功防御钩子，可联动牛金强化等组合。对手可以暂缓一回合让神言自然消散，或用穿大防手段强行越过。
- **设计依据**：羊祭司的祷言当下落空后仍会悬留一回合，但不会成为永久保险；意象与波波攒的短期猜招窗口同时成立。
- **实装**：`assets/data/heroes/h08.tres` + `src/battle/skills/h08_buzhuishenyan.gd`；团队状态与到期回合接入 setup、clone、AI 估值与战斗快照，并复用统一防御门消费。

## h09 紫火「六爪阎罗」
- **主定位**：控制
- **HP**：4
- **Unique（被动）**：紫火对敌方造成伤害时，**移除敌方与实际伤害等量的能量**（1 点伤害移除 1 点能量；蒸发、不入己方池）。
- **共享原语**：**能量剥夺（蒸发）**——纯削对手燃料，非偷取。
- **Combo / agency / 博弈**：加伤与额外命中既扩大伤害，也同步放大削能；移除敌方能量后，对手更难使用「大波 / 大防」，为所有队友制造进攻窗口。对手则要在成功防御保住生命与能量、或省下防御节奏之间选择。
- **限制**：只有实际造成的伤害才能移除能量；成功防御、护甲吸收或敌方能量不足都会压低收益。能量只被移除，不转入我方，因此保持控制定位而非经济定位。
- **设计依据**：紫火 = 峨眉山野猴（裂佛面 / 钢爪 / 破袈裟、凶蛮掠食者，非孙悟空神猴）。钢爪 = **撕碎 / 抓毁** 而非扒窃；凶爪抓碎对手能量，直接压缩其选招自由，因此归控制。分身（孙悟空机变）已移道具层避单核固化。**不单核**：slot-in 资源压制位，不逼 build 绕它转。
- **2026-08-03 裁定**：机制保留；玩家文案保持“紫火【猴】对敌方造成伤害时，移除敌方等量的能量。”，本轮只更新旧资料并重新命名。

## h10 昴日「太初万法剑」
- **主定位**：进攻
- **HP**：5
- **Unique（主动技·以意御剑·共蓄）**：**己方每次攻击命中敌方出战英雄时，累积 +1 层「剑意」**（公开、跨回合累积、上限 4；昴日在替补席时队友命中也照常攒，换下场保留不清）。昴日出战时，其攻击可作「**拔剑一闪**」——消耗全部剑意，每层 **+0.5 伤**（满层一闪 = 波 1.0 + 2.0 ≈ 3.0；一闪那一击本身不计入累积，防自循环）。
- **共享原语**：**剑意（公开累积蓄势态，消费全队 on-hit）** + **一闪（择时收割斩）**——昴日 = 把全队攻击铺垫收束成一击的 **payoff 节点**（不再自包含）。
- **Combo / agency / 博弈**：剑意由**全队攻击喂养**，队友以「波／大波」穿过防御即可积累；双生咒符、聚鼎三花能额外触发英雄技能，加速蓄势。星日冲撞、追击、主动技和独立道具伤害不积累剑意。层数**公开** = 明牌博弈；龙御极强化波可提高命中收益，蓄好剑意后再配星日即时切入打出一闪。**一闪穿透随剑气升级：剑气 ≥2 层 → 穿防（需大防挡）；满 4 层 → 穿大防**。剑气公开 + 全队 4 次命中才满 + 择时拔剑 = 自带刹车。
- **cap**：剑意上限 4 + 一闪消耗全部 = 管理型蓄势、非无限 snowball；**满 4 层穿大防（3.0）是铁则授权的"公开慢蓄 payoff"**（counter = 换核心吃 / 预防、非挡）；+0.5/层、上限、穿防/穿大防阈值均为主旋钮。
- **设计依据**：昴日 = **黑衣长剑、红羽点缀的剑客**（Eddy 形象，保留），扣**闻鸡起舞**（拂晓练剑），以“蓄剑意 → 一闪”的状态机制完成进攻兑现。**2026-06-16 改 A（以意御剑·共蓄）**：剑意来源从"自己每回合 +1"改为"全队攻击命中喂养"，把原 v2 的自包含孤岛改成**消费全队 on-hit 原语的收束 payoff 位**——同时填补 Q3 评估指出的"无吃满铺垫的爆发位"空洞。剑意公开保留旧【啼晓】明牌博弈灵魂；区别于蛇（毒施加给对手）——昴日剑意累在**自己身上、公开**。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。
