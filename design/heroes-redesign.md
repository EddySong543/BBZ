# 英雄重设计（v2，从设计纲领自底向上）

> **性质**：2026-06-14 起，**抛弃全部旧 kit**，依 `design/build-design-framework.md` 的设计理论一只一只重建。
> **每只四层**：① 角色幻想 → ② 维度（6 选 1，单主标签）→ ③ unique（该维度最清晰表达，≤3 行、近标准值、超标带 cap/条件、有 agency、能 combo；minor 归道具）→ ④ HP（3-7：脆 3-4 / 标准 5-6 / 坦克 7）。
> **两条硬透镜（2026-06-14 Eddy 加，每只必过）**：
> - **共享原语格栅**：每只必须"产出 / 消费一个可复用共享原语"（能量 / 低血处决线 / 护盾 / DoT / debuff / 节奏…），不许自闭机制——这样未来每批 6 只能往格栅插钩子，而非各起一套新流派。**防御天生易自闭**（只产"自己活着"），必须靠团队保护或转共享资源来破。
> - **博弈点**：每个 unique 必须有玩家 / 对手要engage的决策或 yomi；纯被动白值（如"多一个防"）= 无博弈 = 废。
> **维度分布**（18=3×6）当前为**软目标**，自底向上设计完再回头对账，不预先硬分派。
> 旧 `design/heroes.md` = 历史参考，已作废。

数值基线（见纲领 §4）：波 1 能/1.0 HP · 大波 3 能/2.0 HP 穿防 · 防 0 能（挡「波」级）· 大防 2 能（挡「波 + 大波/穿防」= 天花板）· 攒 +1（A2 后另有被动 +1/回合）· 道具不占动作。

> ## 🔒 二元铁则（2026-06-16 Eddy 定死 · 后续所有设计必须遵守）
> **力量 = WHETHER（能不能），不是 HOW MUCH（多少）。** 防御是"挡不挡得住"、不是"吸收几点伤害"。**禁止把防/大防做成临时护甲 / 护甲点数吸收模型**（评估后否决：那是绝大多数卡牌游戏的套路、稀释 identity）。
> - **分级整体挡**：防 = 挡下「波」级**整个攻击**；大防 = 挡下「波 + 大波 / 穿防攻击」= **天花板**。挡 = 完全归零、不挡 = 全额落地。
> - **穿透三档**：①**穿防**（防挡不住、大防能挡，如大波 / 鸡 2 层一闪）②**穿大防**（连大防都挡不住——**只授予"公开慢蓄 / 需铺垫"的 payoff**，如鸡满 4 层；**禁给便宜 / 瞬发**；counter = 换核心吃 / 预防，而非挡）③**真伤**（无视一切防御**与护甲**、直接扣本体血，无敌态仍 0.5；目前仅戌狗）。
> - **打穿大防龟壳**靠：**破防（降防御等级，如龙）+ 资源剥夺（猴碎能 / 教皇课税 / 骗防）+ 受授权的穿大防 payoff**。**不靠"更大的数字淹没护甲"。**
> - **护甲 = 额外血量层**（卯兔 +0.5、道具）：常驻、只吸收"**没挡住、落到身上**"的伤害（先扣甲再扣血），与"防挡不挡"正交；真伤无视它。
> - **变量伤害**（虎双段 / 鸡一闪 / 毒爆等）只在"**没被挡住**"时按数值生效；被挡 = 归零（这就是波波攒 yomi）。多段攻击的 proc 被"必须命中"gate 住——**禁止让分段绕过防御**（否则 proc 脱缰=boss，见 h03）。
> - 能量允许 **0.5**（受 0.5 实例 / 等量转化用）。

## h01 子鼠「囤鼠」
- **维度**：能量
- **HP**：4
- **Unique（被动）**：子鼠出战时，「攒」额外 +1 能（攒 = +2，叠 A2 被动 +1 → 当回合 +3）。
- **Combo**：团队共享池 → 加速全队大波 / 道具 / 升级；喂任何能量饥渴 build（系间乘算）。
- **cap**：无——单英雄被动、仅出战时生效；每攒多 1 能在标准内。
- **设计依据**：鼠 = 囤积原语 → 能量维度最清晰表达；"偷 / 增殖"等其它鼠味留给后续英雄或道具。

## h02 丑牛「磐牛」
- **维度**：防御
- **HP**：7（坦克）
- **Unique（被动·卸力反震）**：丑牛**防御（防 / 大防）成功挡下攻击时**，向攻击者**反弹所挡伤害的 50%**（挡「波」反 0.5、挡「大波」反 1.0；借力打力）。
- **共享原语**：**反伤**——攻击者所受反弹可喂虎处决 / on-hit 收割端。
- **Combo / agency / 博弈**：攻牛=自伤、**大波砸牛反弹更疼** → 对手被逼"不攻 / 换人 / 绕道"，丑牛把"防"变成逼对手不敢出手的**陷阱** = 攻防双向 yomi；反弹喂虎 / processers。
- **cap**：反弹比例 50% 可调；受"防御成功"条件自限（对手不攻 = 不触发）。
- **设计依据**：牛 = 防御维度。**弃旧"+护盾"**（= 反例#1"附盾≈强化大防" + 零 agency 的"强大的无聊"，Eddy 2026-06-15 否决），改为**反震**——防御→进攻转化破自闭、填"反伤"空槽、造攻防双向博弈。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h04 卯兔「狡兔」
- **维度**：节奏
- **HP**：4
- **Unique（被动）**：卯兔**上场时**：① 你的**道具锁定 −1 回合**（**上场即触发、一次性、可反复上场反复触发**；新获取/升级即抽即用）；② 卯兔获得 **+0.5 护甲**（=额外血量层、吸收落到身上的伤；脆皮生存地板）。
- **共享原语**：节奏 / 道具部署速度——放大整个道具系统（任何道具 build 的通用加速器）。
- **Combo / agency / 博弈**：直接对冲"道具锁"的电报——压缩对手"看到你抽道具→预判"的窗口，恢复突袭性（**快兔破电报**）；道具越多它越强 = 极广 combo 钩子。
- **cap**：被动、仅出战时；强度对位道具锁（一对一抵消），可调（如只 −1 抽锁不碰开格）。
- **设计依据**：兔 = 迅捷 → 节奏维度（区别于马的登场切换）；旧"免费小动作（攒/防）"因无博弈被废，改为与道具锁正面博弈。**+0.5 护甲 = Eddy 2026-06-15 加的小生存地板**（坦诚：离维度的防御小白值 rider、非 identity，只为条件型脆皮提供"被选地板"；B"双倍道具部署"因太强被否）。
- **2026-06-16 复核**：Q3 评估指出卯兔在"无道具"语境下近乎空气（只剩 +0.5 甲），提报 A 闪避 / B 后发 / C 蓄打 / D 双模式 四个无道具修正向；**Eddy 拍板维持现状、接受其道具依赖**——节奏维度的无道具表达由午马（切换 tempo）承担，卯兔定位为**道具系统的加速器**。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h03 寅虎「猛虎」
- **维度**：进攻
- **HP**：4
- **Unique（被动·连扑）**：寅虎的「波」拆成**两段、各 0.5 结算**（总伤 1.0 不变；**被防 / 大防时整体挡下**）；**落地时每段各独立触发一次"命中时"效果**（被挡 = 不触发，proc 被"必须命中"gate 住）。
- **共享原语**：**多段命中**——meta 级 combo 放大器，把所有"命中触发"件（蛇毒 / 易伤 / on-hit 道具）翻倍。
- **Combo / agency / 博弈**：与蛇毒（+2 层）/ 龙易伤 / 破甲道具 同场时，一次行动触发两次 on-hit = **系间乘算引擎**；单独 ≈ 一个平凡波，强度全在搭配（§4.4 低标 + 好联动）；博弈点 = 你围绕"命中触发"件 build、对手提防双 proc 爆发。
- **cap**：单独平庸 = 自限；需限"每段是否都能叠毒 / 易伤"防超模。⚠ **2026-06-16 定**：防只挡一段会让 proc 脱缰（每回合保底双价值 = boss）、已否决；故**整体挡下**（proc gate 在命中）；想强化虎走**香 proc + 非对称分段**（如一段铺垫、一段收割），**不走穿防**。
- **设计依据**：虎 = 猛虎连环扑 → 进攻"更多次命中"端。**弃旧处决线**（消费端 = 单一路径"压血线上虎"、阈值 1.5/2 难调，Eddy 2026-06-15 否决），改为**产联动的上游放大器**。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h05 辰龙「裂龙」
- **维度**：进攻
- **HP**：5
- **Unique（被动·裂甲 / 破阵）**：辰龙攻击命中敌方出战英雄时，给其附「破甲」——其**下一次防御动作降一级**（大防→防、防→无）：被破甲的大防只挡得住「波」、你的大波 / 穿防一闪趁机穿过；被破甲的防形同无防（一次性）。
- **共享原语**：**破甲**——让对手"防御按钮失灵"的一次性状态，团队 combo 启动器。
- **Combo / agency / 博弈**：不是 +数值，是**让对手防御失灵** → 被破甲后"防也白防"，必须换人 / 对攻 / 硬吃；你或下一个上场的英雄趁窗口保送穿防（配马顶人进窗、虎连扑双段全落）。对手要预判破甲、改用非防御应对 = 双向 yomi。
- **cap**：仅作用于对手"下一次防御动作"、一次性（用过即失）；**只降一级、不直接归零**（比女祭司预言窗的"降至无"温和、可调）；须先命中铺设。
- **设计依据**：龙 = 君临破阵 → 进攻"更难挡"端，走**状态改写（破防）而非堆易伤数值**（过"有趣"关，Eddy 2026-06-15 选 v3-3）。与虎(乘 proc)分工：龙产 setup、虎收割。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h06 巳蛇「淬毒」
- **维度**：状态
- **HP**：4
- **Unique（被动·引爆毒）**：巳蛇攻击命中敌方出战英雄时，叠 1 层「毒」（可叠、平时不 tick）。**中毒目标每次被攻击时，引爆全部毒层**（每层 +0.5 爆发伤），随后清空。
- **共享原语**：**毒（可引爆的储存伤害）**——任意攻击都是引爆器。
- **Combo / agency / 博弈**：毒 = 储存的炸药，何时引爆 / 由谁引爆 = 时机决策；**全队攻击手都是引爆器**（虎连扑双段 / 龙 / 队友 / 道具）→ 蛇布雷、他人收割 = combo 面最广；对手抢在引爆前换人甩毒（毒留在被换下的英雄身上）。
- **cap / 规则**：叠毒的那一击本身不引爆（先叠、后续攻击才引爆）→ 单靠蛇 1 叠 1 爆滚不大，须配其他攻击手 / 多段才放大（低标 + 好联动，§4.4）；每层仅 0.5。
- **设计依据**：蛇 = 阴冷剧毒 → 状态维度，但走**"储存 → 引爆"的 combo 引擎而非每回合 tick 白值**（过"有趣"关，Eddy 2026-06-15 选）。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h07 午马「当先」
- **维度**：节奏
- **HP**：5
- **Unique（被动·当先）**：① 涉及午马的「切换」（顶马上场 / 切马走）**不占动作槽**——可在同回合再行动，**每局限 3 次**；② 午马**切换登场时，对敌方出战造成 0.5 冲撞伤**（可引爆蛇毒 / 触发 on-hit）。
- **共享原语**：**切换 tempo / 额外动作经济** + **登场冲撞（引爆 / on-hit 触发器）**。
- **Combo / agency / 博弈**：免费 2-for-1 把对的英雄即时顶上吃 combo（蛇布雷→冲撞登场引爆 / 龙破甲→切人穿防），3 次免费切换怎么花 = 核心决策；马 = **全池 combo 的衔接引擎**，系间乘算放大一切"出战才生效"被动。
- **cap**：免费切换每局 **3 次硬上限**（"免费切换+再行动"≈ +1 动作槽 = 框架最高超模，必须压住，别再叠别的免费切换源）；冲撞 0.5 为小值。
- **设计依据**：马 = 一马当先冲锋陷阵 → 节奏（切换 tempo）+ 登场冲撞进攻 rider；区别于兔（道具部署 tempo）。Eddy 2026-06-15 选 1+2 合并。
- **⚠ 核对项**：Eddy 另存一份设计；本英雄偏强（免费切换+冲撞+combo 引擎三合一），冲撞 0.5 / cap 3 留作试玩调；实装前逐项核对（本文件为基准）。

## h08 未羊「替罪」
- **维度**：防御
- **HP**：6
- **Unique（被动·致死救援）**：当出战队友将受**致死**伤害时，若未羊在替补席存活，**未羊自动顶上承受这次伤害**（救下原队友；若也致羊死则羊真死）。**每局限 2 次**。
- **共享原语**：**死亡阈值保护 / 致死救援**（团队层次，跨英雄边界）。
- **Combo / agency / 博弈**：让脆皮 carry（鼠/蛇/龙）敢压线输出无惧暴毙 = 安全网；对手必须"先耗羊 / 诱出救援 / 一次性 overkill"才能真杀 carry → 双向 yomi；羊摆替补席 = 布局 agency。
- **cap**：每局 2 次（Eddy 2026-06-15 定，从 1 次上调）；团队层次但有限次 + 形象绑 = 合规（[[hero-passive-scope-single-vs-team]] 路径 b：自限 + 形象绑）。
- **设计依据**：羊 = 替罪牺牲 → 防御维度。用反无聊正解"**致死救援（改死亡阈值，区别 flat 减免）**"避开 flat redirect 的"普通"；本作 1 人出战结构下，这是最干净的"团队防御"（替补关键时刻顶上）。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h09 申猴「裂爪」
- **维度**：干扰
- **HP**：4
- **Unique（被动·碎魄）**：申猴攻击命中敌方出战英雄时，**抓碎对手 1 能**（蒸发、不入己方池）——凶爪震碎其内力。
- **共享原语**：**能量剥夺（蒸发）**——纯削对手燃料，非偷取。
- **Combo / agency / 博弈**：对手"防（费 tempo 护能）还是挨爪 + 被碎" = defend-or-bleed yomi；碎其能量 → 对手开不起大防/大波 → 保送全队（配龙破甲、虎连扑收割）。
- **cap**：每次命中碎 1 能、占申猴动作 + 在场自限；蒸发不入己方池 = 纯干扰、维度纯（区别于"偷"的能量 rider）。
- **设计依据**：申猴 = 峨眉山野猴（裂佛面 / 钢爪 / 破袈裟、凶蛮掠食者，非孙悟空神猴）。钢爪 = **撕碎 / 抓毁** 而非扒窃 → 干扰走"凶爪抓碎对手能量（蒸发=毁、不揣兜）"扣形象。分身（孙悟空机变）已移道具层避单核固化。**不单核**：slot-in 经济搅局位，不逼 build 绕它转。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h10 酉鸡「剑意」
- **维度**：状态
- **HP**：5
- **Unique（被动·以意御剑·共蓄）**：**己方每次攻击命中敌方出战英雄时，累积 +1 层「剑意」**（公开、跨回合累积、上限 4；酉鸡在替补席时队友命中也照常攒，换下场保留不清）。酉鸡出战时，其攻击可作「**拔剑一闪**」——消耗全部剑意，每层 **+0.5 伤**（满层一闪 = 波 1.0 + 2.0 ≈ 3.0；一闪那一击本身不计入累积，防自循环）。
- **共享原语**：**剑意（公开累积蓄势态，消费全队 on-hit）** + **一闪（择时收割斩）**——酉鸡 = 把全队攻击铺垫收束成一击的 **payoff 节点**（不再自包含）。
- **Combo / agency / 博弈**：剑意由**全队攻击喂养** → 虎连扑双段 / 马登场冲撞 / 蛇引爆 / 队友普攻 每命中一次都涨剑意 → 蓄势期全队进攻越凶、一闪越重（系间乘算的收束端）；层数**公开** = 明牌博弈（对手眼看红羽剑气渐盛、算你何时拔剑 → 防 / 扰 / 抢血线 yomi）；蓄好剑意后**配马即时切入**打出一闪、吃龙破甲窗口 / 收残血。**一闪穿透随剑气升级：剑气 ≥2 层 → 穿防（需大防挡）；满 4 层 → 穿大防**（连大防都挡不住，对手只能换核心吃 / 抢在拔剑前打断）。剑气公开 + 全队 4 次命中才满 + 择时拔剑 = 自带刹车。
- **cap**：剑意上限 4 + 一闪消耗全部 = 管理型蓄势、非无限 snowball；**满 4 层穿大防（3.0）是铁则授权的"公开慢蓄 payoff"**（counter = 换核心吃 / 预防、非挡）；+0.5/层、上限、穿防/穿大防阈值均为主旋钮。
- **设计依据**：酉鸡 = **黑衣长剑、红羽点缀的剑客**（Eddy 形象，保留），扣**闻鸡起舞**（拂晓练剑）→ 状态走"蓄剑意 → 一闪"。**2026-06-16 改 A（以意御剑·共蓄）**：剑意来源从"自己每回合 +1"改为"全队攻击命中喂养"，把原 v2 的自包含孤岛改成**消费全队 on-hit 原语的收束 payoff 位**——同时填补 Q3 评估指出的"无吃满铺垫的爆发位"空洞。剑意公开保留旧【啼晓】明牌博弈灵魂；区别于蛇（毒施加给对手）——酉鸡剑意累在**自己身上、公开**。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## 大阿卡那 1 · 魔术师 The Magician「显化·超充」

## 大阿卡那 5 · 教皇 The Hierophant「颁戒·清规」
- **维度**：干扰
- **HP**：6
- **形象**：三重冠、端坐两柱间，右手祝福手势、左持三重十字杖，脚下交叉钥匙，两位信徒跪拜。传统 / 制度 / 教导 / 信仰 / 精神权威 / 既定秩序 / 逐出教门。
- **Unique（被动·颁戒·清规）**：教皇在场时，**每回合开始你指定对手一个动作类别**（大波 / 大防 / 切换 / 攒），对手本回合做该动作 **+1 能耗（或该动作 −效果）**——公开宣告戒律。

- **Combo / agency / 博弈**：每回合一次"赌对手最需要哪个动作去戒"的 yomi——命中=废其计划（戒大波则他开不起爆发 / 戒切换则困住他 / 戒攒则断他 ramp）；公开宣告 → 对手见戒改道（双向 agency）；配猴碎能 = 税 + 夺双重饿死、配狗 = 戒切换 + 罚切双锁。
