# 英雄重设计（v2，从设计纲领自底向上）

> **性质**：2026-06-14 起，**抛弃全部旧 kit**，依 `design/build-design-framework.md` 的设计理论一只一只重建。
> **每只执行顺序（2026-07-30 重写）**：① 角色幻想（可借战斗动画 / 漫画动作发散）→ ② 从「波 / 攒 / 防 / 大波 / 大防 / 切换 / 行动」联想底层机制 → ③ 用 1~2 个共享原语写成单技能 → ④ 检查 combo、双向 yomi、简洁度与撞车 → ⑤ 机制获批后归入进攻 / 防守 / 经济 / 调度 / 控制之一 → ⑥ 最后记录 HP 与实现边界。
> **三条硬透镜，每只必过**：
> - **底层交互**：英雄是波波攒基础规则的改装件，不另造只供自己使用的关键词系统。
> - **共享原语格栅**：每只必须产出或消费可复用共享原语，不许自闭机制；连携应能自然接多名英雄和道具，不得绑定唯一搭档。
> - **博弈点**：玩家必须选择时机，对手必须能重排选择；纯后台收租、自动白值或“角色特征直接翻译成加数值”不通过。
> - **主动结构而非动作对照表（2026-07-30 h04 纠错）**：技能不能只写成一串“敌方出 X → 自己自动变 Y”的 if–else；应让玩家主动安排刺杀、进退、目标或接力路线。单纯调整既有动作的前后时序，若没有形成高影响的新决策，同样不够格成为 identity。
> - **一行小字（2026-07-30 h04 二次纠错）**：主动结构不等于同时塞入多个选择。玩家可见核心机制必须一行说清，只改变一个基础关系；若需要第二行解释目标、退路或特殊结算顺序，直接退回重做。
> **主定位只是事后描述，不是设计配额**：允许五类数量不均；0 人是缺口、1 人是薄弱警报、2 人以上即成立，绝不为凑数扭曲当前英雄。
> **强度后置**：本轮重设计不按现有胜率筛机制，也不为平衡给获批设计擅自加尾巴；按 Eddy 要求原样实装，数值另开平衡阶段。
> **旧字段兼容**：下文历史记录中的“维度”与 `.tres` 的 `dimension` 暂属道具加权技术标签，不再指导设计。当前主定位真相源见 `design/heroes-schools.md` §3。
> `design/heroes.md` = 玩家可见技能文案真相源；本文 = h01–h12 逐英雄设计理据。二者分工不同（文案 vs 设计依据），互不作废。

> ## 🔒 二元铁则（2026-06-16 Eddy 定死 · 后续所有设计必须遵守）
> **力量 = WHETHER（能不能），不是 HOW MUCH（多少）。** 防御是"挡不挡得住"、不是"吸收几点伤害"。
> 🔓 **护盾解禁（2026-06-22 Eddy）**：临时护甲 / 护盾（额外血量层）现为合法设计工具（当时首用 = 牛金 h02【山岳为屏】·该机制已于 2026-07-30 重做退役）；原"禁临时护甲/护甲吸收模型"条作废。但 **防/大防本身仍是二元整体挡**（挡=归零·不挡=全额），护盾与"防挡不挡"正交、只吸收落地伤、真伤无视。
> - **分级整体挡**：防 = 挡下「波」级**整个攻击**；大防 = 挡下「波 + 大波 / 穿防攻击」= **天花板**。挡 = 完全归零、不挡 = 全额落地。
> - **穿透三档**：①**穿防**（防挡不住、大防能挡，如大波 / 牛金升级后的「波」 / 鸡 2 层一闪）②**穿大防**（连大防都挡不住——**只授予"公开慢蓄 / 需铺垫"的 payoff**，如毕方火兆后的攻击、鸡满 4 层；**禁给便宜 / 瞬发**；counter = 换核心吃 / 预防，而非挡）③**真伤**（无视一切防御**与护甲**、直接扣本体血，无敌态仍 0.5；**英雄仅娄金**；道具真伤放开准则见纲领 §4.6「真伤道具 4-gate」+ §14 判据 A）。
> - **打穿大防龟壳**靠：**破防（降防御等级，如龙）+ 资源剥夺（猴碎能 / 骗防）+ 受授权的穿大防 payoff**。**不靠"更大的数字淹没护甲"。**
> - **护甲 = 额外血量层**（当前由道具等来源提供；牛金 h02 曾为英雄首用、已于 2026-07-30 重做移除）：常驻、只吸收"**没挡住、落到身上**"的伤害（先扣甲再扣血），与"防挡不挡"正交；真伤无视它。
> - **变量伤害**（鸡一闪 / 毒爆 / 道具多段等）只在"**没被挡住**"时按数值生效；被挡 = 归零（这就是波波攒 yomi）。多段攻击的 proc 被"必须命中"gate 住——**禁止让分段绕过防御**（否则 proc 脱缰=boss）。
> - 能量允许 **0.5**（受 0.5 实例 / 等量转化用）。
