# 英雄重设计（v2，从设计纲领自底向上）

> **性质**：2026-06-14 起，**抛弃全部旧 kit**，依 `design/build-design-framework.md` 的设计理论一只一只重建。
> **每只四层**：① 角色幻想 → ② 维度（6 选 1，单主标签）→ ③ unique（该维度最清晰表达，≤3 行、近标准值、超标带 cap/条件、有 agency、能 combo；minor 归道具）→ ④ HP（3-7：脆 3-4 / 标准 5-6 / 坦克 7）。
> **两条硬透镜（2026-06-14 Eddy 加，每只必过）**：
> - **共享原语格栅**：每只必须"产出 / 消费一个可复用共享原语"（能量 / 低血处决线 / 护盾 / DoT / debuff / 节奏…），不许自闭机制——这样未来每批 6 只能往格栅插钩子，而非各起一套新流派。**防御天生易自闭**（只产"自己活着"），必须靠团队保护或转共享资源来破。

> **维度分布**（12=6 维 × 2）当前为**软目标**，自底向上设计完再回头对账，不预先硬分派。

> ## 🔒 二元铁则（2026-06-16 Eddy 定死 · 后续所有设计必须遵守）
> **力量 = WHETHER（能不能），不是 HOW MUCH（多少）。** 防御是"挡不挡得住"、不是"吸收几点伤害"。
> 🔓 **护盾解禁（2026-06-22 Eddy）**：临时护甲 / 护盾（额外血量层）现为合法设计工具（首用 = 牛金 h02【山岳为屏】·0.5HP/层·无上限累积（原封顶 1.0HP 已于 2026-07-01 废除·与代码一致））；原"禁临时护甲/护甲吸收模型"条作废。但 **防/大防本身仍是二元整体挡**（挡=归零·不挡=全额），护盾与"防挡不挡"正交、只吸收落地伤、真伤无视。
> - **分级整体挡**：防 = 挡下「波」级**整个攻击**；大防 = 挡下「波 + 大波 / 穿防攻击」= **天花板**。挡 = 完全归零、不挡 = 全额落地。
> - **穿透三档**：①**穿防**（防挡不住、大防能挡，如大波 / 鸡 2 层一闪）②**穿大防**（连大防都挡不住——**只授予"公开慢蓄 / 需铺垫"的 payoff**，如鸡满 4 层；**禁给便宜 / 瞬发**；counter = 换核心吃 / 预防，而非挡）③**真伤**（无视一切防御**与护甲**、直接扣本体血，无敌态仍 0.5；**英雄仅娄金**；道具真伤放开准则见纲领 §4.6「真伤道具 4-gate」+ §14 判据 A）。
> - **打穿大防龟壳**靠：**破防（降防御等级，如龙）+ 资源剥夺（猴碎能 / 骗防）+ 受授权的穿大防 payoff**。**不靠"更大的数字淹没护甲"。**
> - **护甲 = 额外血量层**（牛金 h02、道具；原「房日 +0.5」已随 2026-07-04 h04 重做移除）：常驻、只吸收"**没挡住、落到身上**"的伤害（先扣甲再扣血），与"防挡不挡"正交；真伤无视它。
> - **变量伤害**（虎双段 / 鸡一闪 / 毒爆等）只在"**没被挡住**"时按数值生效；被挡 = 归零（这就是波波攒 yomi）。多段攻击的 proc 被"必须命中"gate 住——**禁止让分段绕过防御**（否则 proc 脱缰=boss，见 h03）。
> - 能量允许 **0.5**（受 0.5 实例 / 等量转化用）。

## h03 尾火「银虎掠影」
- **维度**：进攻
- **HP**：4
- **Unique（被动·银虎掠影）**：尾火的「波」拆成**两段、各 0.5 结算**（总伤 1.0 不变；**被防 / 大防时整体挡下**）；**落地时每段各独立触发一次"命中时"效果**（被挡 = 不触发，proc 被"必须命中"gate 住）。
- **共享原语**：**多段命中**——meta 级 combo 放大器，把所有"命中触发"件（蛇毒 / 易伤 / on-hit 道具）翻倍。
- **Combo / agency / 博弈**：与蛇毒（+2 层）/ 龙易伤 / 破甲道具 同场时，一次行动触发两次 on-hit = **系间乘算引擎**；单独 ≈ 一个平凡波，强度全在搭配（§4.4 低标 + 好联动）；博弈点 = 你围绕"命中触发"件 build、对手提防双 proc 爆发。
- **cap**：单独平庸 = 自限；需限"每段是否都能叠毒 / 易伤"防超模。⚠ **2026-06-16 定**：防只挡一段会让 proc 脱缰（每回合保底双价值 = boss）、已否决；故**整体挡下**（proc gate 在命中）；想强化虎走**香 proc + 非对称分段**（如一段铺垫、一段收割），**不走穿防**。
- **设计依据**：虎 = 猛虎连环扑 → 进攻"更多次命中"端。**弃旧处决线**（消费端 = 单一路径"压血线上虎"、阈值 1.5/2 难调，Eddy 2026-06-15 否决），改为**产联动的上游放大器**。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h05 亢金「亢龙振九霄」
- **维度**：进攻
- **HP**：5
- **Unique（被动·裂甲 / 破阵）**：亢金攻击命中敌方出战英雄时，给其附「破甲」——其**下一次防御动作降一级**（大防→防、防→无）：被破甲的大防只挡得住「波」、你的大波 / 穿防一闪趁机穿过；被破甲的防形同无防（一次性）。
- **共享原语**：**破甲**——让对手"防御按钮失灵"的一次性状态，团队 combo 启动器。
- **Combo / agency / 博弈**：不是 +数值，是**让对手防御失灵** → 被破甲后"防也白防"，必须换人 / 对攻 / 硬吃；你或下一个上场的英雄趁窗口保送穿防（配马顶人进窗、虎连扑双段全落）。对手要预判破甲、改用非防御应对 = 双向 yomi。
- **cap**：仅作用于对手"下一次防御动作"、一次性（用过即失）；**只降一级、不直接归零**（温和、可调）；须先命中铺设。
- **设计依据**：龙 = 君临破阵 → 进攻"更难挡"端，走**状态改写（破防）而非堆易伤数值**（过"有趣"关，Eddy 2026-06-15 选 v3-3）。与虎(乘 proc)分工：龙产 setup、虎收割。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h06 翼火「灵蚀噬魂」
- **维度**：状态
- **HP**：4
- **Unique（被动·引爆毒）**：翼火攻击命中敌方出战英雄时，叠 1 层「毒」（可叠、平时不 tick）。**中毒目标每次被攻击时，引爆全部毒层**（每层 +0.5 爆发伤），随后清空。
- **共享原语**：**毒（可引爆的储存伤害）**——任意攻击都是引爆器。
- **Combo / agency / 博弈**：毒 = 储存的炸药，何时引爆 / 由谁引爆 = 时机决策；**全队攻击手都是引爆器**（虎连扑双段 / 龙 / 队友 / 道具）→ 蛇布雷、他人收割 = combo 面最广；对手抢在引爆前换人甩毒（毒留在被换下的英雄身上）。
- **cap / 规则**：叠毒的那一击本身不引爆（先叠、后续攻击才引爆）→ 单靠蛇 1 叠 1 爆滚不大，须配其他攻击手 / 多段才放大（低标 + 好联动，§4.4）；每层仅 0.5。
- **设计依据**：蛇 = 阴冷剧毒 → 状态维度，但走**"储存 → 引爆"的 combo 引擎而非每回合 tick 白值**（过"有趣"关，Eddy 2026-06-15 选）。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。

## h07 星日「一骑当先」
- **维度**：节奏
- **HP**：6（2026-07-04 平衡 5→6：510 局 36.4%(n=176) 实锤弱·疑 AI 免切误用混杂 → 保守白值续命·机制不动·AI 切换逻辑复查后再定；⚠ DraftAI 角色由灵活桶移入坦克桶）

## h10 昴日「金乌淬锋」
- **维度**：状态
- **HP**：5
- **Unique（主动技·以意御剑·共蓄）**：**己方每次攻击命中敌方出战英雄时，累积 +1 层「剑意」**（公开、跨回合累积、上限 4；昴日在替补席时队友命中也照常攒，换下场保留不清）。昴日出战时，其攻击可作「**拔剑一闪**」——消耗全部剑意，每层 **+0.5 伤**（满层一闪 = 波 1.0 + 2.0 ≈ 3.0；一闪那一击本身不计入累积，防自循环）。
- **共享原语**：**剑意（公开累积蓄势态，消费全队 on-hit）** + **一闪（择时收割斩）**——昴日 = 把全队攻击铺垫收束成一击的 **payoff 节点**（不再自包含）。
- **Combo / agency / 博弈**：剑意由**全队攻击喂养** → 虎连扑双段 / 马登场冲撞 / 蛇引爆 / 队友普攻 每命中一次都涨剑意 → 蓄势期全队进攻越凶、一闪越重（系间乘算的收束端）；层数**公开** = 明牌博弈（对手眼看红羽剑气渐盛、算你何时拔剑 → 防 / 扰 / 抢血线 yomi）；蓄好剑意后**配马即时切入**打出一闪、吃龙破甲窗口 / 收残血。**一闪穿透随剑气升级：剑气 ≥2 层 → 穿防（需大防挡）；满 4 层 → 穿大防**（连大防都挡不住，对手只能换核心吃 / 抢在拔剑前打断）。剑气公开 + 全队 4 次命中才满 + 择时拔剑 = 自带刹车。
- **cap**：剑意上限 4 + 一闪消耗全部 = 管理型蓄势、非无限 snowball；**满 4 层穿大防（3.0）是铁则授权的"公开慢蓄 payoff"**（counter = 换核心吃 / 预防、非挡）；+0.5/层、上限、穿防/穿大防阈值均为主旋钮。
- **设计依据**：昴日 = **黑衣长剑、红羽点缀的剑客**（Eddy 形象，保留），扣**闻鸡起舞**（拂晓练剑）→ 状态走"蓄剑意 → 一闪"。**2026-06-16 改 A（以意御剑·共蓄）**：剑意来源从"自己每回合 +1"改为"全队攻击命中喂养"，把原 v2 的自包含孤岛改成**消费全队 on-hit 原语的收束 payoff 位**——同时填补 Q3 评估指出的"无吃满铺垫的爆发位"空洞。剑意公开保留旧【啼晓】明牌博弈灵魂；区别于蛇（毒施加给对手）——昴日剑意累在**自己身上、公开**。
- **⚠ 核对项**：Eddy 另存一份设计，实装前逐项核对差异（本文件为基准）。
