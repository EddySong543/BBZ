> **性质**：跨系统的**设计公理与方法论**，不是单一机制的 GDD（故不放 `design/gdd/`、不套 8 段模板）。
> **来源**：2026-06-14 Eddy 与 Claude 的三段地基讨论，逐条对齐后的双方共识。
> **地位**：道具、英雄、体系的所有具体设计都应先拿本文（尤其 §6 主定理）过一遍。

## 0. 一句话定位

策略 = **资源的分配**。本作砍掉了重赛前卡组构筑，换成轻量的局内 draft；丢失的多样性由**道具系统**与**连携**接回。游戏好玩的核心 = **非固定套路化的对局**——靠英雄 + 道具的搭配选择产生变化，单人、PvP 皆然。

---

## 1. 资源框架（三层 + 动作槽）

资源分两种形态：

- **流量资源（唯一稀缺）= 动作槽**：每回合仅一个动作，不可囤积。这是策略的核心稀缺，也是一切"超模"的判据来源。
- **存量资源**：能量、血量、道具（可囤、可跨回合）。

战斗资源分三层（上游 → 下游；这是效果分析，不是英雄主定位）：

| 层 | 内容 | 说明 |
|----|------|------|
| **决胜层** | 进攻端 / 防御端 | 直接决定胜负 |
| **燃料层** | 能量 | 攻防之间的**选择权 / 元货币**，地位高于一般增益（不是普通"非决胜维度"） |
| **增益层** | 节奏(Tempo) / 状态持续 / 信息(Yomi) / 容错 / 干扰 等 | 通过放大决胜层间接取胜 |

- **运转端（能量 / 动作槽）= 放大决胜维度强度的"系数"**。
- **动作槽 = 水桶的第二块板**：未来可能推出"+1 动作槽"设计——但见 §4，它是全游戏最高级超模。
- 一切设计最终都落到两个轴：**强度**（对应攻防）× **容错率**（对应对不良事件的容纳）。效果可跨多层、也可"降一层换另一层"。

## 2. 道具系统骨架

> 🔴 **2026-07-03 经济重做（Eddy 拍板·免入场税）**：开格费废除、三格**自动解锁**（免费）。
> 根因：2026-06-24 砍被动能量后能量收入减半，道具费用未跟着重校 → 每 1 能投道具 = 少打一记波，
> 道具层被理性玩法（含搜索 AI 实测）整体定价出局、沦为累赘。修正 = **刹车从「能量」换成「时间锁」**：
> 保留部署电报（新道具出现当回合锁定、下回合可用），升级 / 补充仍各收 1 能（防无脑冲传说 / 补充永动机）。
> 本节下方标 ⛔ 的旧规仅作溯源。
>
> 🔴 **2026-08-09 普通道具基准抬升（Eddy 拍板）**：旧“0.5 润滑剂”基准在实玩中不值得占槽，
> 玩家会优先直接花 1 能打 1 伤的「波」。T1 现改为：稳定件约 **1 点有效价值**；需要对手可规避的
> 读心条件时，命中可到 **1.5–2 点**。评估必须同时检查三槽叠加、公开威胁、失败成本与英雄钩子。
>
> 🔴 **2026-08-10 稀有 / 传说道具基准抬升（Eddy 拍板）**：正式 T2 的目录估值统一为 4，承担通用连接；
> 正式 T3 的目录估值统一为 6，承担能改变后续计划的高影响一次性效果或 build-around 遗物。T3 超出稳定值时，
> 必须由次数 / 回合、残局条件、断攻反噬、对手可挡下或同回合预判等真实限制承担，不能回落到旧“小额赠品”基调。

- **分级（用 1/2/3 称呼，不叫"阶"）**：
  - **1 道具** = 简单、稳定的基础件；稳定效果约 1 点价值，硬读心命中可到 1.5–2 点。
  - **2 道具** = 通用组合与玩法连接件，目录估值基准 4；由 1 道具花 **1 能**升级而来。（⛔「升级 or 开新格」二选一已随开格废除失效，2026-07-03）
  - **3 道具** = 有真实代价、风险或反制的 build-around，目录估值基准 6，可为**次数 / 回合 / 条件型遗物**；升级同价 **1 能**（🔴 2026-07-03 统一；若 sim 出现 T3 泛滥则回调 2 能——Eddy 已同意该回调预案）。
- **使用规则**：
  - **不占动作槽**（这是道具超模的根源——任何免动作的正收益都天然超模）。
  - **使用本身免费**（用时不耗能）；**一回合使用数量不限**（→ combo 爆发靠囤积一次性甩出）。
  - **使用时点 = 揭示前**（3A 定）：道具随动作一起在盲选阶段提交 → 道具是**主动计划件**，不是揭示后的反制件；干扰 / 救场 e 因此是"**预判**"而非"反应"。
  - 槽内道具使用后即消耗；遗物件先把公开的跨回合状态登记到队伍，再清空原槽。空槽可花 **1 能**补充（T1 池 3 选 1）。
- **槽位与获取**（🔴 2026-07-03 重做）：
  - 同时持有上限 **3 槽**，第 **3 / 4 / 5 回合**依次**自动解锁**（免费·错峰摊平洪峰）：
    格 1 解锁时**自带 1 件随机 T1**（后期改为玩家从收藏自选 T1/T2 携带·PvE 沿用）；
    格 2 / 3 解锁当回合 **T1 池 3 选 1**（draft）。
  - **玩家拥有什么道具对对手公开**。
- **超模闸门（🔴 2026-07-03 重做）**：**获取端 = 时间闸门**（解锁回合 + 每件新道具锁 1 回合电报）；
  **深度端 = 能量**（升级 1 能 / 补充 1 能）——能量仍在 **大波(攻) / 防 / 升级(深度) / 补充(续航)** 间分配，
  但道具入场不再抽动作税。（⛔ 原「获取/升级/refill 全吃能量、四向分配」作废）
- **PvP 道具来源 = 掉落 / 养成（非对称），靠调爆率平衡，作为粘性钩子**——这是 Eddy 明确拍板的取舍（修订了"绝不卖强度"那条，见 [[online-pvp-and-monetization-direction]]），不再讨论。
- 对外统称“**道具**”；**遗物**只是 T3 中用于承载跨回合效果的形态，可按次数、回合或对局条件持续，不另建一套抽取系统。

> 备注：本骨架取代了旧的"药水=带3瓶/首版不碰能量"设想（[[potion-system-concept]] 已标记被取代）。

## 道具系统详设（B1，2026-06-14）

### 变强路径（D1=A）
- **只升级，不合成**：1→2、2→3 **统一各花 1 能**（🔴 2026-07-03 统一价；⛔ 原 2→3 花 2 能——sim 若现 T3 泛滥则回调）。
- 弃用"2 个 1 道具合成"（吃 2 槽换 1 级，与 3 槽经济冲突）。

### 道具的标签与设计取向（D2）
- 道具当前仍带一项**旧六维技术标签** + 必要时带元件角色（导出 / 干扰 / 泛连携 / 填隙 / 自成核 / 回路）。该标签只服务现行 3 选 1 加权 draft，不再代表英雄的玩家主定位。
- **设计取向**：道具 = 游戏的"**多而广**"内容层——**每张一句话能看懂，但总量很多、变化丰富**（类炉石 / 尖塔单卡）。英雄少而干净，**道具多而花样**（minor / 连接 / 点缀都在这一层）。

### 池子模型（D2，与共通 5 地板同构）
- **道具地板池**（稳定约 1 点价值、或带清晰读心条件的基础件，全员永远可抽）+ **养成解锁的特色道具**（进你的收藏）。
- 3 选 1 = 从（地板池 + 你的特色收藏）加权抽 → 新玩家永远凑得满，养成只加特色、不破地板。

### 获取与槽位（D3·🔴 2026-07-03 重做=自动解锁免入场税）
- 格 1 **自带 1 件**：当前随机 T1（代码 `STARTER_ITEM_IDS`）；**后期改玩家从收藏自选 T1/T2 携带**（唯一的轻构筑动作·PvE 沿用）。
- 三格第 **3 / 4 / 5 回合自动解锁**（免费·错峰）；格 2/3 解锁当回合 **T1 池 3 选 1**。
- 补充（用完的槽，1 能）→ T1 池 3 选 1。（⛔ 原「点亮新槽 1 能」作废——开格步骤/费用已删）
- **T2 加权抽卡（✅ 2026-07-04 实装）**：3 选 1 候选**互不重复**（修放回抽样重复 bug）；道具旧维度命中我方阵容英雄旧维度 → 权重 **2×**（封顶·多英雄同标签不叠加·`DRAFT_DIM_WEIGHT`）；**只认阵容标签、不认战况**（每局静态·杜绝顺风加权滚雪球）；**小保底 = 3 候选至少跨 2 个旧维度**（全同标签时末位换抽其他标签）。这里读取的 `HeroData.dimension` 是迁移期技术字段，与五种英雄主定位分离；不得因重设计单只英雄而局部改值。升级 3 选 1 不走此加权（沿用预设款 5× 偏好·B2）。

### 道具锁：部署延迟（2026-06-14 加，增博弈；🔴 2026-07-03 简化为单条统一规则）
道具**公开**，若即抽即用则公开无意义。**统一锁定规则：格里出现新道具（自带 / 抽 / 补充 / 升级）的当回合锁定（对手可见），下回合才可用。**（⛔ 原「开格→抽→可用」三步电报作废——开格步骤已删）

| 回合 | 道具事件（最快路径） | 本回合可用 |
|---|---|---|
| 1-2 | 格①自带件公开亮相（锁·纯英雄博弈热身） | — |
| 3 | 格①解锁（自带件锁定中） | — |
| 4 | **①可用**；格②解锁·3 选 1 抽（锁） | ① |
| 5 | **②可用**；格③解锁·3 选 1 抽（锁） | ①② |
| 6 | **③可用**（全开，最快） | ①②③ |

- **博弈价值**：抽道具 → 对手获得一个**预判窗口**（看到你抽了什么、有一回合应对），公开才真正产生 yomi；同时杜绝"突袭抽取即爆发"的不可反应 burst，强化"道具=主动计划件"（3A）。
- （原「h04 房日道具锁 −1 破电报」例外已随 2026-07-04 h04 重做移除——部署电报现**无英雄豁免**。）

### 回合流程 = 玩家编排的有序序列（D4，含「顺序」机制）
**核心新增（Eddy 2026-06-14）**：道具在动作**前 / 后**使用结果不同，**顺序由玩家编排**。
- 一回合提交 = 一段**有序序列** `[道具…, 动作, 道具…]`——玩家决定哪些道具在动作前、哪些在动作后，连同动作**揭示前盲选提交**（3A）。
- 这让"道具铺垫 → 动作收割"或"动作 → 道具追结算"成为玩家可控的**回合内微 combo / 链条**（接 §5/§6）。
- **操作定案（Eddy 2026-08-28）**：客户端本地记录实际施放顺序；按住左键拖出只预览，未松手不算使用；在合法区域松开左键才视为释放、播放本地动画并追加待提交步骤。最终确认时一次提交完整序列，确认前不向对手逐条公开。松手后的撤销/重排等 UI 细节另议。
- **内容护栏（Eddy 2026-08-28）**：每件道具只描述自己在结算时改变的状态，后续步骤自然读取新状态；不用“若在攻击前/后”硬造分支，也不把“一个顺序必亏、另一个必赚”当成顺序博弈。效果默认不追溯此前步骤，玩家文案不补“此后”。
- **结算模型（✅ 2026-06-14 确认）**：
  - **己方序列严格按编排顺序逐步结算**——自身 buff / 防御（甲盾）/ 读自己动作结果 的道具按序生效（故"动作前 +攻" ≠ "动作后追伤"）。
  - **跨玩家仍保持「同时独立结算」**（既有核心 B-001/2/3）：双方**无先后手**——同时出招、输出各自算好再一起落、对攻互不抵消；**可同时死亡 = 平局**（既有行为，引擎现状）。
  - **「顺序」只作用于己方回合内，不在两玩家间制造先后手**：跨玩家永远同时。
  - 一句话：**回合内顺序 = 各自管各自；两人之间 = 永远同时出、同时死**。能量经济（点亮 / 升级 / refill）在序列最前处理。
  - 平局如何处理（重赛 / 算分）= 后续 PvP 细节，不影响模型。
- **联机边界**：本地松手动画只是私有编排反馈；服务器对最终完整序列做原子校验与权威重放，随后广播事件流/快照驱动双方公开动画。当前 `{action, item_slots}` 协议尚不能表达统一步骤序列，实施前需同步升级 BattleCore、AI、协议、回放/快照和 UI。详见 [`2026-08-28-item-sequence-interaction-design.md`](../docs/superpowers/specs/2026-08-28-item-sequence-interaction-design.md)。

### 目标规则（D5=A）
- **默认自动指向**：伤 → 敌方出战 / 甲盾 → 己方出战 / debuff → 敌方出战。
- 个别特殊道具可带**特殊指向**（指定后排 / 全体等），个案开放。

### 能量预算（移交 A2；🔴 2026-07-03 已收口）
- ⛔ 原二选一（(a) 攒-only 奢侈品 / (b) 加被动能量）**均未采纳**，实际走了第三条路：**道具入场免费化**（自动解锁 + 抽免费），能量只管深度（升级 1 能）与续航（补充 1 能）。攒-only 反龟设计不动。
- 背景：被动能量已删（2026-06-24）导致道具费用被定价出局（搜索 AI 实测只刷小波）——即本节当年预警的"很紧"成真，故收口。

## 3. build 结构：浅而广，一个明确贡献 + 其余不塌

**核心问题**：与"少角色、build 绑定角色"的游戏不同（那类游戏里一个角色的各种体系各覆盖 1-2 维），本作每个英雄 = **共通 5 能力 + 1 差异化主/被动**，build = **3 英雄 unique + 最多 3 道具 ≈ 6 个元件**。

**答案（结构性）**：

1. **共通 5 = 永远在线的基础地板**。所以英雄不必覆盖所有方向，而应有**一个清楚的主要贡献，其余不塌**——"不塌"由共通 5 免费保证；设计张力上移到 unique 是否真正改变了玩家的一项基础决策。
2. **共通 5 = 通用对接口**，这一条同时撑起两件事：
   - **去流派化**之所以本作做得到、尖塔做不到：每个英雄共享同一套基础操作 = 通用插槽，任何 unique / 道具都能插进任何 build 而地板不变（尖塔的卡有颜色/角色锁，没这层地板）。
   - **"核心锁死在波波攒"**：基础 5 是地板，unique / 道具是地板上的改装件、**永不替换地板**。道具一旦强到替换基础操作，通用地板崩 → 去流派化与"核心在波波攒"一起垮。这是"不让游戏引向道具层"的**结构性理由**（不只是数值；🔴 2026-07-03 后执行手段由「抬升级费」改为「时间锁 + 升级/补充收费」，理由本身不变）。
3. **build 身份 = 浅而广**（对比角色绑定游戏的"深而窄"）：每个 build 就 6 元件的薄拼装，但英雄池大 + 道具多 → 组合空间爆炸；丰富度来自**组合广度**而非单 build 深度。
4. **代价**：6 元件每个占 ~17%，**没有容错冗余，一个废件即灾难** → 每个元件要么自身高影响、要么强联动，**不能有尖塔式凑数小料**。

详见 [[build-structure-shallow-wide]]。

## 4. 标准值（A1，2026-06-14 定）

### 4.1 五项基础操作（标准值之锚；大波→3、大防留 2）

| 操作 | 能耗 | 效果 | 端 |
|---|---|---|---|
| 攒 CHARGE | 0（占动作） | +1 能 | 能量 |
| 波 ATTACK | 1 | 1.0 HP 伤 | 进攻 |
| 防 DEFEND | 0（占动作） | 挡"波"（仅挡基础攻击，不挡大波/穿防） | 防御 |
| 大波 BIG_ATTACK | **3** | 2.0 HP 伤 + 穿"防" | 进攻 |
| 大防 BIG_DEFEND | **2** | 挡全部 | 防御 |

- **切换 SWITCH 单独算**：0 能占动作的调度动作，无攻防数值、可操作空间小，**不计入标准值**。
- **大波=3 的依据**：把"攒→波"循环算持续吞吐——波 = 0.5 HP/动作；大波=2 时 0.67 HP/动作（严格优于波 = 失衡），大波=3 时回到 0.5 HP/动作与波打平 → 大波回归"纯爆发 / 穿防"定位。
- **大防=2（Eddy 选 B）**：攻防对称被打破，防御比进攻便宜。⚠ 已知风险 = 偏苟 / 可能拖长对局（与 1-3 分钟目标反向），**接受并留待试玩观察**。
- **代码现状（2026-06-16 已实装·B/A2）**：`action_def.gd` 大波 = 6 半能（3 能）、大防 = 4 半能（2 能）；能量走半能制。✅ 已是目标态（此前此注记误记为"大波 2 能·待 D 阶段"，2026-06-18 校正）。

### 4.2 两条汇率（设计任何效果时的尺子）

| 汇率 | 值 | 来源 / 含义 |
|---|---|---|
| **占动作的操作** | 1 能 = **1.0 HP** | 波 = 1 能 / 1.0 HP |
| **T1 道具（不占动作）** | 稳定约 **1.0 HP 等价**；硬条件命中 1.5–2.0 | 以一次性、占槽、部署锁和公开反制支付强度，不再按旧半价折算 |

道具不再用统一“半价”换算。稳定值只是起点；条件收益必须由读心、规划或风险支付，并按“三份同类 + 本回合行动”的最坏组合验算。

### 4.3 标准值表

**进攻 / 防御端（占动作，1 能=1.0 HP）：**
| 费用 | 伤害基准 | 防御基准 |
|---|---|---|
| 0 | —（攒走能量端） | 挡波（条件性，=防） |
| 1 | 1.0 HP（=波） | — |
| 2 | 2.0 HP | 挡全部（=大防） |
| 3 | 2.0 HP + 穿防（=大波，含 +1 费 tempo/穿防溢价） | — |

**道具端（不占动作；2026-08-10 当前目录基准）：**
| 道具级 | 目录估值 | 基准职责 |
|---|---:|---|
| 1 | ≥2 | 稳定约 1 点有效价值；硬读心命中可到 1.5–2 点 |
| 2 | 4 | 通用组合与玩法连接，单件足以改变一次公共动作的选择 |
| 3 | 6 | 高影响一次性计划或 build-around 遗物，以真实代价、风险或反制支付突破值 |

### 4.4 偏移规则

- **超标** → 必须带负面效果或释放条件（如"血量 < x"）。
- **低标** → 必须好联动（轻 build、可选项少，故低标设计要**放宽**）。
- **3 道具单列一套基准**（它本就代表超模）。
- **灵活性税**：跨功能元件（同时攻+防）在同费用下天然强于单功能元件（第一段「灵活性溢价」的复发）。修法：各功能都压到单功能基准以下，或单独抬费。
- **能量道具特例**：+1 能 ≥ 1.0 HP 价值 + 元货币溢价 → 必须 **≥2 能成本或带条件**（避免"在伤害 / 护甲之外白多一个选择空间"的超模）。
- **铁律：不许任何操作无条件压制另一个操作**（否则玩家天然产出强度表，"抓不到强卡没法玩"）。道具是核心系统，但同样不许全方位碾压。

**核心问题**：攒-only 模型把进攻吞吐锁死在 **0.5 HP/回合**（每打一次波都得先攒一回合换能量）→ 任何 HP 下都达不到 1-3 分钟节奏（这正是现状对局 5-10 分钟的根因）。

**决议**：
- **能量收入 = 被动 +1 能/回合**（回合开始自动结算）；**攒动作额外再 +1**（攒 = **爆发加速器**，不再是每回合必做的税）。→ 基本每回合都能波（~1.0 HP/回合），攒留给蓄大波 / 道具。
- **HP 范围保持 3-7**（脆 3-4 / 标准 5-6 / 坦克 7，avg 5）。
- **节奏估算**：3 英雄 × ~5 HP，~1.0-1.5 HP/回合（含道具行动外伤害）→ **~12-20 回合 ≈ 1.5-2.5 分钟**，落进 1-3 分钟目标。**被动能量量 = 首要调速旋钮**，试玩再微调。

**「波波攒」identity 说明**：被动 +1 让攒从"强制税"变"主动加速"——大多数回合真能波（爽点），攒为大招 / 道具蓄力。重心从攒偏向波，但攒经"大波 / 道具需求"保持相关。

**不变项**：初始能量 1、默认 MAX_ENERGY 10、波 1 能 / 1.0 HP（A1 锚）、大波 3、大防 2、切换 0 能占动作。技能可改变动态上限，但不得反向删除已经持有的超额能量。

**代码现状（2026-07-03 更新）**：大波 3 能 + 半能制已落地；**被动 +1 能已恢复（`PASSIVE_ENERGY_GAIN=2`·见本节顶部 🔴🔴 修订）**。能量收入 = 被动 +1 + 攒额外 +1（鼠再额外 +0.5/次获得）。

- 🔓 **护甲解禁（2026-06-22 Eddy）**：临时护甲 / 护甲（额外血量层·吸收落地伤）现为**合法设计工具**（当时首用 = 牛金 h02【山岳为屏】；该机制已于 2026-07-30 重做退役）；下方"禁临时护甲"原条作废。但 **防 / 大防本身仍是二元整体挡**（挡=归零、不挡=全额），护甲与"防挡不挡"正交、只吸收没挡住落地的伤、真伤无视。
- ~~**禁止临时护甲 / 护甲点数吸收防御模型**~~（**已解禁·见上**）。防 / 大防 = 二元整体挡。

- **护甲 = 额外血量层**（兔 +0.5 / 道具）：只吸收"没挡住、落地"的伤、先扣甲后扣血，与"防挡不挡"正交；真伤无视。
- 能量允许 **0.5**。
- **命中边界**：只有「波／大波」穿过防御门才算命中并结算相关效果；护甲吸收仍算命中，独立主动技、追击、反击与独立道具伤害不算。

## 5. 连携：从量变到质变

- 单操作被标准值锁死；**多元件组合可超标准值，产生 1+1 > 2**。这是提升 build 的核心钥匙，PvP / PvE 皆然。
- **输入 / 输出**：道具 A 产出输入 → 英雄 A 接收并产出强化后的新效果 = 一次连携。角色不固定，输出可成为下一连携的输入 → **链条**。
- 后续可复用“效果绑定使用者英雄、跨回合保留并支持围绕其规划”的连接结构（如还魂丹），但不设为硬性配额；同一英雄只允许使用一次还魂丹，且它作为最低层保险可取消致命伤害、生命支付、失去生命与规则处决。
- **链条**：每步乘一个系数 → 总系数指数增长，但**越长越不稳**（PvP 要命）。
  - **链条天然自限**：build 仅 ~6 元件 → 链长上限 6、实战 2-3，指数跑不飞（比尖塔安全）。
  - **真正的 PvP 炸弹是回路 e**（自我连携）：它绕开"元件数量"天花板，链长无限 → **PvP 默认禁回路 e、只活 PvE**（2A 定）；**可实验性加入，但必须明确标注哪些元件是回路 e**，供测试时再定是否在 PvP 放开。
- **e（element）** = 角色 / 道具 等的统称。一对 e = 连携；一堆连携 = **体系**。轻 build 下，组成体系的**最低数量要求放宽**。

### §6 主定理（第一公理）：系内加算、系间乘算

> **单体系堆叠走加算**（线性、封顶、受标准值锁）；**跨体系配合走乘算**（放大、1+1>2）；且**任何时候 系间乘算系数 ≥ 系内乘算系数**。

这条是反固化总钥匙，同时解掉：

- **平衡（e3 单卡 = e1+e2 组合 问题）**：单卡走加算、组合走乘算 → 强单卡永远平替不了真组合 → "强单卡贬低组合"被源头禁止。
- **催化剂式排异**（参考其他卡游：体系增强卡的系内 ×系数 > 系间 ×系数 = 排异罪魁）：被本定理直接 ban。
- **配合性应 > 排异性**（暗杀神四流派两两互助为正态）：本定理保证混搭永不吃亏。
- **自洽 §3 浅而广**：广（混）≥ 深（纯）→ build 自然走浅而广。
- **自洽 回路 e 危险**：回路 e = 系内乘算的唯一例外 → 必然是 PvP 炸弹。
- **PvE 指数空间**：PvE 无对称对手，**绝对量**可解封（系内也能乘、可指数）；但**相对关系不变**（系间仍 ≥ 系内）。

详见 [[synergy-master-theorem]]。

## 7. 元件类型

### 体系内（引擎零件）
- **输入 e** / **输出 e**：连携的供给与接收端。
- **回路 e**：既是输入又是输出，触发机制后反哺强化该机制，可与自身连携 → 指数放大，**PvP 极危**（见 §6）。
- **导出 e**：把一端导向另一端（如**吸血** = 攻→防回血），补 build 缺失维度、保证整体强度。**PvE 远比 PvP 值钱**（永久掉血让"攻→防"成刚需；PvP 单局血量重置，吸血价值骤降）——是"PvP/PvE 极大区分"在元件层的具体落点。

### 体系外（点缀，可以多一些 —— 游戏真正的丰富内容）
1. **自成核（条件超标 e）**：高天花板、高方差。注意它**不是无连携**——"条件"本身就是隐藏输入，玩家会去 build"满足条件的链"，本质是"以条件为输入的微体系"。
2. **泛连携 e**：自身弱、连通度高。是**去流派化的实际执行者**（把体系彼此粘起来的结缔组织），地位高于"拓宽组合"。
3. **填隙 e**：基准 ±、无联动、无负面、补弱维（基础数值 + 1 效果）。作用 = 保证 3 选 1 **永远有一个安全无脑选**，不卡死。
4. **干扰 / 拒止 e（新增必备件）**：攻击对手的资源 / 连携（抽对手能量、锁对手道具槽、打断链条）。是**长链 / 回路在 PvP 的天然解药**，也是 PvP 反制与平均胜率的来源——与导出 e 同级，是结构件而非可选件。

## 8. 反固化设计

**目标**：玩家不应感到"走几步后必然只能玩一个流派"。手段：增加终点数 + 后移岔路口（提高路径重合度）。

- **主定理（§6）本身就是结构性解药**：系内不划算 → 玩家不会闷头钻一个方向 → 固化失去土壤。
- **导出网双解**：一套导出 e 同时"增加终点"（每维都是可达胜负手）+"后移岔路口"（抓桥接件后多条路仍开）。例：5 个导出 e（A→B/B→A/C→A/C→B/C→D）可派生 8 个等价答案，重合度高 → 选择变多。道具同理。
- **自然导出（弱于导出 e 但存在）**：快攻 = 攻够高当防；厚防 = 宽松攻磨死对方。允许玩家即便没导出 e 也能靠单体系取胜。
- **加权 draft（答 point 2，"潜在池"问题）**：**别按英雄硬锁道具池**（一选英雄就定 build = 岔路提前 = 固化）。正解 = 3 选 1 永远是全集，但**出牌概率向"能与当前 build 配合"的元件倾斜，并优先塞导出 / 泛连携 e**。英雄是**起手偏置，不是牢笼**。既有可读性（不选择瘫痪）、又什么都不锁、还主动后移岔路口。
- **变化道具困境的解（答 point 4）**：换英雄 = 离散 + 高方差（丢投资、随机塞新东西），找不到平衡点。把"变化"换成**连续 + 定向**就有解——而那东西就是**导出 e**：不丢投资的转向（乘在已有基础上、玩家主动选、低随机、高 agency）。**导出 e = 变化道具的低随机版本。** 分工：想要整队换血 → PvE 关卡间**招募/移除英雄**（安全节点）；局内变化 → 全交导出 e。
- **⚠ 反向失败模式：过度架桥 → 同质化**。导出 e 太多/太便宜 → 每个 build 都"什么都桥到" → 全收敛成一个全能大 build（固化的镜像反面）。导出 e 必须有机会成本，让你只桥得起 1-2 维。**甜点 = 够撑 2-3 个胜负手同时开着，不够让所有 build 长成一个样。** 落地数值红线。
- **多层连携（理论上限，留作参考）**：体系→攻防系数→复用 e 机制→资源级 层层相扣，选不同层构筑 = 不同答案。轻构筑难做到这么深，非本意，但多层连携是最大化收益的方法，且多层机制 e 大多能适配不同体系，理论备查。

## 9. 平衡哲学

- 平衡很重要，但**别过度平衡**：目标不是"所有选择 EV 相等"（那 = 选择不重要 = 无聊），而是 **无统治策略 + 风格可区分**。
- 不同 build 在打法 / 克制关系 / 风险曲线上不同；**用反制（干扰端）拉平胜率，不用同质化铺平强度**。
- **PvP combo 平衡看"扣除铺垫成本后的 EV"，不看 payoff**：1+1>2 是 payoff，但概率加权 + 成本调整后应回落到标准附近（高 roll vs 稳健的经典平衡）。
- **PvP 期望**：不同风格 build 大致平均地出现在对局中，并取得大致平均的胜率。

## 10. PvE × PvP：极大区分（同元件，不同容器规则）

差的不是道具本身，是**容器规则**：

| | PvE（远征） | PvP |
|---|---|---|
| 强度天花板 | 可允许**指数级**增长 | **严格限制** |
| 道具上限 | 可解开 | 锁 3 槽 |
| 对手 | 非对称 + 可设计针对性敌人 | 对称对手 + 干扰端 counterplay |
| 回路 / 长链 | 可放飞 | 必须压住 |
| 导出 e 价值 | 高（永久掉血刚需） | 低（单局血量重置） |

## 11. 单人远征骨架

> **任务8重置注记**：PvE 探索模式正式 GDD = `design/gdd/expedition-mode.md`（+四份子文档）。敌人继续按怪物系列体系落地，并允许多个地图敌人同格形成一名当前出战者加后备成员的遭遇队伍；"镜像小队"形态归入幽灵真人系与特殊遭遇。探索能量与旧版危险度成长均已作废，通用压力改由战斗间 HP 不恢复、有限治疗、敌人巡逻与死亡损失承担；"制裁特化 build"由动词考官系承担；"开局带 1 道具"=保险槽机制（expedition-backpack.md §4）。本节其余原则继续作为设计参考，但不得反向恢复已经作废的地图规则。

- 开局选 **1 名英雄** + 带 **1 道具**进场；后续可**招募 / 移除英雄**改变基础队伍；解开道具上限 → 闯关更远。
- **单英雄血量损失永久** → 对防御端形成强度要求（导出 e 因此在 PvE 成刚需）。
- **拿卡机会的路线设计**（参考尖塔地图）：路线选择 = 又一条 build 方向控制轴。
- **敌人 = 镜像小队**（与玩家形态一致；**极少 / 不存在多体同场**，区别于尖塔群怪）：
  - 可获特殊 buff（如**免费轮换** = 退一个弱动作；注意这是"+1 动作槽"的温和版，离通用 +1 槽梯度上很远）。
  - **有上限的成长**：随单局时长数值上涨但封顶 → 逼玩家重视进攻端（要打得够快），上限又保护体验不失控；**特殊 boss 可破限**，绝大多数敌人有限。
  - 应专门设计**制裁完全特化单端 build 的敌人**（反快攻只是其一，不止于此）。

## 14. 道具设计判据（撞英雄 / 撞道具 · 2026-06-20）

> 两把尺子，配套 §4.6 真伤 4-gate；memory [[item-vs-hero-design-space]] / [[item-design-catalog]]。

**判据 A —— 道具撞英雄？看「计划身份与公共接口」**

> 同一原语，英雄是每回合反复改写选择的固有能力；道具是占用三槽投资、公开部署后主动择机兑现的工具。T1/T2 通常一次性，T3 可以成为跨回合遗物，但仍必须扎根「波 / 攒 / 防 / 大波 / 大防」、能量、生命、切换、目标或公共状态，并保留次数、期限、残局条件、反噬或对手反制。

- 不能只把英雄技能装进物品；判断重点是它是否让不同英雄重新安排公共动作，而非是否出现了同一个触发词。
- 自检问句：**「这件道具是否提供一次新的计划选择；其代价、期限与反制是否仍让英雄固有能力保持独特？」**
- 真伤 4-gate（§4.6）= 本判据在「真伤」上的具体化。

**判据 B —— 道具撞道具（冗余）？看「四维是否全重合」**

> 两件道具构成**有害冗余**（死牌 / draft 注水），**当且仅当四维全部重合**：①同 tier（同入场费 / 上线时机 / 槽位累计投资）②同决策点（同一次选择里掂量）③同 payoff 维度 + 同量级 ④同触发条件。**任一维拉开 = 梯度互补（健康）。**

- **结构定理**：3 选 1 分 tier 池抽（开槽抽 T1 池 / 升级抽下一级池）→ **跨 tier 件物理上进不了同一个选择点 → 跨 tier 免疫 draft 注水**。∴ **冗余警戒只需在同 tier 内做**；跨 tier 同主题 = 健康**纵向梯队**（劣势流 `最后一箭`T1→`不死鸟的羽毛`T3；借能 `寅吃卯粮`T1→`连本带利`T2；人数 `狐假虎威`T1→`以多欺少`T2）。
- **纯数值放大何时有意义**：①跨质变阈值（血线 / 击杀线 / 防御天花板）②升级线纵深（同件随投资变强、占同槽）。只有「同 tier + 同决策点 + 同量级 + 无差异触发」才是注水。

**判据 C —— 批次覆盖是否失衡？先查公共玩法，不按已有主题继续堆件**

> 已有组合信号同时可能代表「可连接」和「已饱和」。同一批候选不能把同一种资源（尤其护甲）同时当作缺口、连接轴和收益出口；否则看似每件都有 combo，实际仍是同一套结算反复换词。

- 提案前按「公共动作 / 能量 / 生命 / 切换 / 目标 / 命中触发英雄技能 / 道具栏操作 / 反制与信息 / 队伍调度」做覆盖矩阵；同一主题原则上不超过一批候选的约四分之一，除非本轮明确补建该体系。
- 每件候选必须写明它改变的具体行动选择和具体组合；「能吃到护甲、治疗或能量」只算兼容，不自动算 combo。
- 一批方案至少覆盖：直接公共动作计划、资源或节奏转换、对手可读的反制、队伍或目标调度，以及一种不依赖已有关键词的新结算结构。
- 若候选大量呈现「若 X，则 Y」，先合并重复结构，再从选择目标、交换、封顶、延迟兑现、资源迁移或一次性规则改写中寻找更鲜明的骨架。
- 护甲既是额外生命层，也是可被转移、转伤的资源。新增护甲件前必须同时检查各 tier 的生成、搬运、转化和三件叠用上限；当本批已经覆盖入口与出口时，优先转向其他玩法轴，后续审计发现真实层级缺口时仍可补齐。

## 15. 系统操作层（中立 · meta 子维度 · 2026-06-20）

> **定位**：道具作用对象 = **游戏系统的元素本身**（道具 tier / 槽 / draft 池 / 充能 / 电报 / 规则），而非对局资源（HP / 能量 / 动作）。它与现行旧六维技术标签正交，属于中立的系统操作层（吃本作独有结构、非干净原语、无英雄拿它当招牌）。
> **已隐性存在**：`封魔锁`(锁槽) / `圣人遗体`(偷道具) / `偷天换日`(换归属) / `迷魂药`(藏操作栏) / `乱点鸳鸯`(改指向) 早是 meta 件——本节把这层正式命名，空白格即可系统补齐。

**可作用对象地图**（✅ = 空白可挖）：

| 对象 | 现状 | 空白 |
|---|---|---|
| 道具 tier | 升级经济 | ✅ **进化 / 退化一件道具**（Eddy 起点） |
| 道具形态 | — | ✅ **道具燃料化**（烧道具换能量 / 伤害；§1 第三存量「道具」首次可燃） |
| 部署电报 | 神奇口袋（加速己）（房日已于 2026-07-04 重做退出此格） | ✅ **延迟对手上线**（旧房日机制的镜像） |
| draft 池 | 加权 draft | ✅ **重抽 / 4 选 1**（己）/ **塞废牌**（对手→PvE） |
| 充能 | 3 充 + refill | ✅ **延寿遗物 / 即时 refill** |
| 基础收入 | — | ✅ **堵对手被动 +1 能**（区别猴 = 削存量、这 = 堵流量） |
| 槽 / 序列 / 指向 / 出战 | 已零散覆盖 | 多已占 → 只做一次性小版 |
| 回合数 / 结算顺序 / 动作槽 | 核心锁死 | ⛔ 禁（破 B-001）/ 至多 PvE boss |

**安全红线**：
1. **回路**：meta 件**禁自指 / 禁链式**（操作道具的道具不得作用于自己 / 同类 = 系内乘算回路 = PvP 炸弹 §6），违者标 PvE。
2. **总钥匙**（§8 固化）：强 meta 件**必带机会成本**（烧一件 / 占一槽 / 吃能量），不许变成「所有 build 都绕它」。
3. **能量闸门**（🔴 2026-07-03 修订）：meta 件正收益里**升级 / 补充仍必须吃能量**（免费升级 = 直接超模，此半条不动）；「加槽」已随经济重做改为**时间闸门**（第 3/4/5 回合自动解锁 + 新道具锁 1 回合电报），不再吃能量。
4. **核心规则**：操作结算顺序 / 回合数 / 动作槽 = 威胁 B-001 与「动作槽唯一稀缺」，基本禁、至多 PvE boss。
5. **避英雄招牌**：meta 对象上已站英雄的（出战 = 马狗羊 / 碎能 = 猴 / 基础攻击自由选敌 = 兔·2026-07-31 起；原「电报 = 房日」与“敌方重复动作产能”均已随 h04 历次重做失效），道具只做一次性小版（判据 A）。
