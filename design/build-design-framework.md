# 波波攒 — Build / 经济 / 连携 设计纲领

> **性质**：跨系统的**设计公理与方法论**，不是单一机制的 GDD（故不放 `design/gdd/`、不套 8 段模板）。
> **来源**：2026-06-14 Eddy 与 Claude 的三段地基讨论，逐条对齐后的双方共识。
> **地位**：道具、英雄、体系的所有具体设计都应先拿本文（尤其 §6 主定理）过一遍。
> **配套 memory**：[[synergy-master-theorem]] / [[build-structure-shallow-wide]] / [[item-system-skeleton]]。

## 0. 一句话定位

策略 = **资源的分配**。本作砍掉了重赛前卡组构筑，换成轻量的局内 draft；丢失的多样性由**道具系统**与**连携**接回。游戏好玩的核心 = **非固定套路化的对局**——靠英雄 + 道具的搭配选择产生变化，单人、PvP 皆然。

---

## 1. 资源框架（三层 + 动作槽）

资源分两种形态：

- **流量资源（唯一稀缺）= 动作槽**：每回合仅一个动作，不可囤积。这是策略的核心稀缺，也是一切"超模"的判据来源。
- **存量资源**：能量、血量、道具（可囤、可跨回合）。

维度分三层（上游 → 下游）：

| 层 | 内容 | 说明 |
|----|------|------|
| **决胜层** | 进攻端 / 防御端 | 直接决定胜负 |
| **燃料层** | 能量 | 攻防之间的**选择权 / 元货币**，地位高于一般增益（不是普通"非决胜维度"） |
| **增益层** | 节奏(Tempo) / 状态持续 / 信息(Yomi) / 容错 / 干扰 等 | 通过放大决胜层间接取胜 |

- **运转端（能量 / 动作槽）= 放大决胜维度强度的"系数"**。
- **动作槽 = 水桶的第二块板**：未来可能推出"+1 动作槽"设计——但见 §4，它是全游戏最高级超模。
- 一切设计最终都落到两个轴：**强度**（对应攻防）× **容错率**（对应对不良事件的容纳）。设计可跨多维、也可"降一维换另一维"。

## 2. 道具系统骨架

- **分级（用 1/2/3 称呼，不叫"阶"）**：
  - **1 道具** = 润滑剂，强度 < 基本操作（如 0.5 伤 / 0.5 甲）。
  - **2 道具** ≈ 一个动作 / 基本操作（如 1 伤 或 特殊效果）；由 1 道具花 **1 能**升级而来——**花能量时玩家自由选「升级旧道具 or 开一个新道具」**（1A 定，2026-06-14）。
  - **3 道具** ≥ 特殊技能，本身代表超模，可为**遗物（永久被动）形态**；升级费可抬到 **2 能**（防止游戏被引向道具层，见 §4）。
- **使用规则**：
  - **不占动作槽**（这是道具超模的根源——任何免动作的正收益都天然超模）。
  - **使用本身免费**（用时不耗能）；**一回合使用数量不限**（→ combo 爆发靠囤积一次性甩出）。
  - **使用时点 = 揭示前**（3A 定）：道具随动作一起在盲选阶段提交 → 道具是**主动计划件**，不是揭示后的反制件；干扰 / 救场 e 因此是"**预判**"而非"反应"。
  - **一次性消耗品**；用完后可花 **1 能** refill 一个 1 道具。
- **槽位与获取**：
  - 同时持有上限 **3 槽**：开局固定带 1（PvE 远征也带 1，降记忆成本）；第 3 / 4 回合分别解锁第 2 / 3 槽，花 **1 能点亮**；点亮后 **3 选 1**（draft），升级同理。
  - **玩家拥有什么道具对对手公开**。
- **超模总闸门 = 能量再生速率**（不是"道具个数"）：获取 / 升级 / refill 全吃能量；能量在 **大波(攻) / 防 / 点亮新槽(广度) / 升级旧道具(深度)** 之间四向分配，是全局机会成本中枢。这套使能量需求显著上升，整个能量经济（初始 1 能、大波 2 能那套）后续要重新校准。
- **PvP 道具来源 = 掉落 / 养成（非对称），靠调爆率平衡，作为粘性钩子**——这是 Eddy 明确拍板的取舍（修订了"绝不卖强度"那条，见 [[online-pvp-and-monetization-direction]]），不再讨论。
- 术语只有"**道具**"（一次性）；**遗物（永久被动）只允许出现在 3 道具层或单人模式**。

> 备注：本骨架取代了旧的"药水=带3瓶/首版不碰能量"设想（[[potion-system-concept]] 已标记被取代）。

## 3. build 结构：浅而广，一维赢 + 其余不塌

**核心问题**：与"少角色、build 绑定角色"的游戏不同（那类游戏里一个角色的各种体系各覆盖 1-2 维），本作每个英雄 = **共通 5 能力 + 1 差异化主/被动**，build = **3 英雄 unique + 最多 3 道具 ≈ 6 个元件**。

**答案（结构性）**：

1. **共通 5 = 永远在线的全维度地板**。所以维度要求不是"每维都要强"，而是 **「一维赢 + 其余不塌」**——"不塌"由共通 5 免费保证；设计张力上移到"你顶上去那一维，扛不扛得住单人的制裁"。
2. **共通 5 = 通用对接口**，这一条同时撑起两件事：
   - **去流派化**之所以本作做得到、尖塔做不到：每个英雄共享同一套基础操作 = 通用插槽，任何 unique / 道具都能插进任何 build 而地板不变（尖塔的卡有颜色/角色锁，没这层地板）。
   - **"核心锁死在波波攒"**：基础 5 是地板，unique / 道具是地板上的改装件、**永不替换地板**。道具一旦强到替换基础操作，通用地板崩 → 去流派化与"核心在波波攒"一起垮。这才是"抬 3 道具升级费、不让游戏引向道具层"的**结构性理由**（不只是数值）。
3. **build 身份 = 浅而广**（对比角色绑定游戏的"深而窄"）：每个 build 就 6 元件的薄拼装，但英雄池大 + 道具多 → 组合空间爆炸；丰富度来自**组合广度**而非单 build 深度。
4. **代价**：6 元件每个占 ~17%，**没有容错冗余，一个废件即灾难** → 每个元件要么自身高影响、要么强联动，**不能有尖塔式凑数小料**。

详见 [[build-structure-shallow-wide]]。

## 4. 标准值与灵活性税

- **每个费用档 × 每个端定一条基准线**（0 费伤/甲、1 费伤/甲、2 费伤/甲……源自基础 5 操作）。
- **超线** → 必须带负面效果或释放条件（如"血量 < x"）。
- **低线** → 必须好联动（轻 build、可选项少，故低标设计要**放宽**）。
- **3 道具单列一套基准**（它本就代表超模）。
- **灵活性税**：跨维元件（同时攻+防）在同费用下天然强于单维（第一段「灵活性溢价」的复发）。修法：跨维元件**每维都压到单维基准以下**，或单独抬费。否则"多维 e 无条件压单维 e"成立，违反下条。
- **铁律：不许任何操作无条件压制另一个操作**（否则玩家天然产出强度表，"抓不到强卡没法玩"）。道具是核心系统，但同样不许全方位碾压。

## 5. 连携：从量变到质变

- 单操作被标准值锁死；**多元件组合可超标准值，产生 1+1 > 2**。这是提升 build 的核心钥匙，PvP / PvE 皆然。
- **输入 / 输出**：道具 A 产出输入 → 英雄 A 接收并产出强化后的新效果 = 一次连携。角色不固定，输出可成为下一连携的输入 → **链条**。
- **链条**：每步乘一个系数 → 总系数指数增长，但**越长越不稳**（PvP 要命）。
  - **链条天然自限**：build 仅 ~6 元件 → 链长上限 6、实战 2-3，指数跑不飞（比尖塔安全）。
  - **真正的 PvP 炸弹是回路 e**（自我连携）：它绕开"元件数量"天花板，链长无限 → **PvP 默认禁回路 e、只活 PvE**（2A 定）；**可实验性加入，但必须明确标注哪些元件是回路 e**，供测试时再定是否在 PvP 放开。
- **e（element）** = 角色 / 道具 等的统称。一对 e = 连携；一堆连携 = **体系**。轻 build 下，组成体系的**最低数量要求放宽**。

### §6 主定理（第一公理）：系内加算、系间乘算

> **单体系堆叠走加算**（线性、封顶、受标准值锁）；**跨体系配合走乘算**（放大、1+1>2）；且**任何时候 系间乘算系数 ≥ 系内乘算系数**。

这条是反固化总钥匙，同时解掉：

- **平衡（e3 单卡 = e1+e2 组合 问题）**：单卡走加算、组合走乘算 → 强单卡永远平替不了真组合 → "强单卡贬低组合"被源头禁止。
- **催化剂式排异**（参考其他卡游：体系增强卡的系内 ×系数 > 系间 ×系数 = 排异罪魁）：被本定理直接 ban。
- **配合性应 > 排异性**（暗杀神四流派两两互助为正态）：本定理保证混搭永不吃亏。
- **自洽 §3 浅而广**：广（混）≥ 深（纯）→ build 自然走浅而广。
- **自洽 回路 e 危险**：回路 e = 系内乘算的唯一例外 → 必然是 PvP 炸弹。
- **PvE 指数空间**：PvE 无对称对手，**绝对量**可解封（系内也能乘、可指数）；但**相对关系不变**（系间仍 ≥ 系内）。

详见 [[synergy-master-theorem]]。

## 7. 元件类型

### 体系内（引擎零件）
- **输入 e** / **输出 e**：连携的供给与接收端。
- **回路 e**：既是输入又是输出，触发机制后反哺强化该机制，可与自身连携 → 指数放大，**PvP 极危**（见 §6）。
- **导出 e**：把一端导向另一端（如**吸血** = 攻→防回血），补 build 缺失维度、保证整体强度。**PvE 远比 PvP 值钱**（永久掉血让"攻→防"成刚需；PvP 单局血量重置，吸血价值骤降）——是"PvP/PvE 极大区分"在元件层的具体落点。

### 体系外（点缀，可以多一些 —— 游戏真正的丰富内容）
1. **自成核（条件超标 e）**：高天花板、高方差。注意它**不是无连携**——"条件"本身就是隐藏输入，玩家会去 build"满足条件的链"，本质是"以条件为输入的微体系"。
2. **泛连携 e**：自身弱、连通度高。是**去流派化的实际执行者**（把体系彼此粘起来的结缔组织），地位高于"拓宽组合"。
3. **填隙 e**：基准 ±、无联动、无负面、补弱维（基础数值 + 1 效果）。作用 = 保证 3 选 1 **永远有一个安全无脑选**，不卡死。
4. **干扰 / 拒止 e（新增必备件）**：攻击对手的资源 / 连携（抽对手能量、锁对手道具槽、打断链条）。是**长链 / 回路在 PvP 的天然解药**，也是 PvP 反制与平均胜率的来源——与导出 e 同级，是结构件而非可选件。

## 8. 反固化设计

**目标**：玩家不应感到"走几步后必然只能玩一个流派"。手段：增加终点数 + 后移岔路口（提高路径重合度）。

- **主定理（§6）本身就是结构性解药**：系内不划算 → 玩家不会闷头钻一个方向 → 固化失去土壤。
- **导出网双解**：一套导出 e 同时"增加终点"（每维都是可达胜负手）+"后移岔路口"（抓桥接件后多条路仍开）。例：5 个导出 e（A→B/B→A/C→A/C→B/C→D）可派生 8 个等价答案，重合度高 → 选择变多。道具同理。
- **自然导出（弱于导出 e 但存在）**：快攻 = 攻够高当防；厚防 = 宽松攻磨死对方。允许玩家即便没导出 e 也能靠单体系取胜。
- **加权 draft（答 point 2，"潜在池"问题）**：**别按英雄硬锁道具池**（一选英雄就定 build = 岔路提前 = 固化）。正解 = 3 选 1 永远是全集，但**出牌概率向"能与当前 build 配合"的元件倾斜，并优先塞导出 / 泛连携 e**。英雄是**起手偏置，不是牢笼**。既有可读性（不选择瘫痪）、又什么都不锁、还主动后移岔路口。
- **变化道具困境的解（答 point 4）**：换英雄 = 离散 + 高方差（丢投资、随机塞新东西），找不到平衡点。把"变化"换成**连续 + 定向**就有解——而那东西就是**导出 e**：不丢投资的转向（乘在已有基础上、玩家主动选、低随机、高 agency）。**导出 e = 变化道具的低随机版本。** 分工：想要整队换血 → PvE 关卡间**招募/移除英雄**（安全节点）；局内变化 → 全交导出 e。
- **⚠ 反向失败模式：过度架桥 → 同质化**。导出 e 太多/太便宜 → 每个 build 都"什么都桥到" → 全收敛成一个全能大 build（固化的镜像反面）。导出 e 必须有机会成本，让你只桥得起 1-2 维。**甜点 = 够撑 2-3 个胜负手同时开着，不够让所有 build 长成一个样。** 落地数值红线。
- **多层连携（理论上限，留作参考）**：体系→攻防系数→复用 e 机制→资源级 层层相扣，选不同层构筑 = 不同答案。轻构筑难做到这么深，非本意，但多层连携是最大化收益的方法，且多层机制 e 大多能适配不同体系，理论备查。

## 9. 平衡哲学

- 平衡很重要，但**别过度平衡**：目标不是"所有选择 EV 相等"（那 = 选择不重要 = 无聊），而是 **无统治策略 + 风格可区分**。
- 不同 build 在打法 / 克制关系 / 风险曲线上不同；**用反制（干扰端）拉平胜率，不用同质化铺平强度**。
- **PvP combo 平衡看"扣除铺垫成本后的 EV"，不看 payoff**：1+1>2 是 payoff，但概率加权 + 成本调整后应回落到标准附近（高 roll vs 稳健的经典平衡）。
- **PvP 期望**：不同风格 build 大致平均地出现在对局中，并取得大致平均的胜率。

## 10. PvE × PvP：极大区分（同元件，不同容器规则）

差的不是道具本身，是**容器规则**：

| | PvE（远征） | PvP |
|---|---|---|
| 强度天花板 | 可允许**指数级**增长 | **严格限制** |
| 道具上限 | 可解开 | 锁 3 槽 |
| 对手 | 非对称 + 可设计针对性敌人 | 对称对手 + 干扰端 counterplay |
| 回路 / 长链 | 可放飞 | 必须压住 |
| 导出 e 价值 | 高（永久掉血刚需） | 低（单局血量重置） |

## 11. 单人远征骨架

- 开局选 **1 名英雄** + 带 **1 道具**进场；后续可**招募 / 移除英雄**改变基础队伍；解开道具上限 → 闯关更远。
- **单英雄血量损失永久** → 对防御端形成强度要求（导出 e 因此在 PvE 成刚需）。
- **拿卡机会的路线设计**（参考尖塔地图）：路线选择 = 又一条 build 方向控制轴。
- **敌人 = 镜像小队**（与玩家形态一致；**极少 / 不存在多体同场**，区别于尖塔群怪）：
  - 可获特殊 buff（如**免费轮换** = 退一个弱动作；注意这是"+1 动作槽"的温和版，离通用 +1 槽梯度上很远）。
  - **有上限的成长**：随单局时长数值上涨但封顶 → 逼玩家重视进攻端（要打得够快），上限又保护体验不失控；**特殊 boss 可破限**，绝大多数敌人有限。
  - 应专门设计**制裁完全特化单端 build 的敌人**（反快攻只是其一，不止于此）。

## 12. 体系设计模板（参考，非束缚）

> 真正好玩的设计不应局限于模板，这只是参考脚手架。

1. 选定一个能力维度。
2. 在该维度上确定 build 核心机制。
3. 围绕该机制设计输入 / 输出 e。
4. 配对应的回路 e 与导出 e。

并区分：部分 e 围绕体系设计，部分 e 抛开体系单独设计（体系外点缀正是游戏真正的丰富内容）。

## 13. 决议与待办（2026-06-14 更新）

### 已定
- ✅ **2 道具升级岔路**：花能量时玩家自由选「升级旧道具 or 开新道具」（1A）。
- ✅ **回路 e**：PvP 默认禁、只活 PvE；可实验性加入但**必须标注哪些是回路 e**，供测试再定（2A）。
- ✅ **道具使用时点**：揭示前随动作盲选提交，道具 = 主动计划件（3A）。
- ✅ **英雄定位标签**：**单主标签**（5A）；且重设计后**英雄 = 对应维度最明显的表达，minor / 细枝设计下放给道具层**。
- ✅ **核心 e**：不设"无核心 e"硬规——核心 e 可存在，主定理（§6）已压住其系内乘算、不逼固化（6C）。
- ✅ **英雄规模**：新手初始开放 **6 个**，首发版本上线 **12 个**（总池 46 仍为长期目标，发行先做 12）。

### 🔴 重大方向：英雄全面重设计
现有英雄（h01-46）**全部推翻，从本纲领的设计理论重新设计**。核心原则 = 每个英雄是其**对应维度最清晰的表达**，细微 / 次要效果**归给道具层**（英雄负责"维度identity"，道具负责"minor 调味与连接"）。具体执行待 Eddy 下达任务指令。
