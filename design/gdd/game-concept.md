# 波波攒之王 — 游戏概念文档

## 1. 概述

波波攒之王（King of BoboZan）是一款像素风格 1v1 同时回合制英雄对战游戏，改编自中国广为流传的手部游戏「波波攒」。每名玩家操控 3 个英雄（全部通过 Ban/Pick 从共享池选取），在「攒→波→防→大波→大防」的心理博弈基础上搭配英雄独特技能进行对战。双方每回合同时选择动作并结算，将对方全部英雄血量归零者获胜。轻规则、重心理博弈，上手门槛极低但策略深度高。

> **数值框架**：本文采用 v4 数值框架（HP 3-7 / 大波 3 能 / 切换 0 能 / 初始 1 能 / 半点伤害制），目标对局节奏 1-3 分钟。详见 `design/heroes-schools.md §8`。

---

## 2. 玩家幻想

翻开底牌时的预判快感 — 就像猜拳赢了对方，但每回合的"猜拳"都建立在上回合的资源变化之上。玩家感受到：

- **心理压制**："我知道你知道我会出波，所以我出防"
- **资源掌控**：能量是公共资源，切换英雄占用动作，何时攒气、何时爆发需要规划
- **英雄组合**：3 个英雄的阵容选择带来策略多样性，Ban/Pick 阶段就是战斗的前奏

## 3. 详细规则

### 3.1 核心动作

| 动作 | 能量消耗 | 效果 |
|------|---------|------|
| 攒 | 0 | 获得 1 点能量 |
| 波 | 1 | 造成 1 点伤害。被「防」或「大防」格挡。**双方同时出波则各受 1 伤**（详见 §3.2 ✱） |
| 防 | 0 | 格挡「波」（不格挡「大波」） |
| 大波 | 3 | 造成 2 点伤害。穿透「防」。被「大防」格挡。**双方同时出大波则各受 2 伤**（详见 §3.2 ✱） |
| 大防 | 2 | 格挡「波」和「大波」 |
| 切换 | 0 | 换上替补英雄。不消耗能量，但**占用该回合动作**（本回合无法再做其他动作）。详见 §3.3 |

### 3.2 同时出手结算矩阵

按 P1 行动（行）× P2 行动（列）列出每个单元格内双方的能量与伤害变化（能量按 v4 框架：攒 +1 / 波 -1 / 大波 -3 / 大防 -2 / 防·攒·切换 不耗能）。

| P1 \ P2 | 攒 | 波 | 防 | 大波 | 大防 |
|---------|-----|-----|-----|------|------|
| **攒** | P1+1能, P2+1能 | P1+1能, P2-1能, P1受1伤 | P1+1能 | P1+1能, P2-3能, P1受2伤 | P1+1能, P2-2能 |
| **波** | P1-1能, P2+1能, P2受1伤 | P1-1能, P2-1能, **双方各受1伤** ✱ | P1-1能, 波被防格挡 | P1-1能, P2-3能, **P1受2伤, P2受1伤** ✱ | P1-1能, P2-2能, 大防格挡 |
| **防** | P2+1能 | P2-1能, 波被防格挡 | — | P2-3能, P1受2伤（防被穿透） | P2-2能 |
| **大波** | P1-3能, P2+1能, P2受2伤 | P1-3能, P2-1能, **P1受1伤, P2受2伤** ✱ | P1-3能, P2受2伤（穿防） | P1-3能, P2-3能, **双方各受2伤** ✱ | P1-3能, P2-2能, 大防格挡 |
| **大防** | P1-2能, P2+1能 | P1-2能, P2-1能, 大防格挡 | P1-2能 | P1-2能, P2-3能, 大防格挡 | P1-2能, P2-2能 |

> "—" 表示该组合无特殊交互（各自动作正常结算）。
>
> ✱ **重要**：波vs波、大波vs大波、波vs大波这三组同时攻击组合 **双方都独立解算伤害**，不存在"互相抵消"或"大波压制波"机制。早期设计为抵消/压制，实际游戏体验后保留为双向解算作为正式行为（增加试探代价与紧张感）。此结算逻辑在 v4 引擎中延续（见 `docs/architecture/ADR-002` 中对 B-001/2/3 的保留）。

### 3.3 对战规则

- **形式**：1v1，同时盲选动作，回合结束同时结算
- **初始能量**：1，能量为同队 3 英雄共用（团队全局池）
- **默认血量**：脆皮 3-4 / 标准 5-6 / 坦克 7（英雄各自设定；半点伤害制，最小伤害 0.5）
- **切换英雄**：**消耗 0 能量，但占用该回合的动作**（切换的回合不能再攻击/防御）。切换采用「甲时机」：切换先于伤害结算，攻击打到换上来的新英雄（切换可用作垫刀/调度的防御工具）。h07「千里自在风」是唯一例外（免费切换、不占动作）。
- **击败规则**：单个英雄血量归零后无法再切换上场；出战英雄阵亡且有存活替补时强制选择替补；一方全部英雄归零即为失败

### 3.4 选人阶段（Ban/Pick）

**2 步同时盲选**（联机正式形态）：

| 步骤 | 内容 |
|------|------|
| 第 1 步 · 禁用 | 双方**同时盲选 3 名**英雄禁用（互不可见）。双方禁到同一个时该位作废 → **取并集，有效禁用 ≤ 6** |
| 第 2 步 · 出战 | 双方从未禁用的池里**同时盲选 3 名**出战英雄。**允许双方重复**（可选同一英雄构成镜像对决） |

- 揭示双方阵容后进入战斗。
- **单机模式**：对手 3 名英雄由 AI 扮演（同时盲选）；联机时把 AI 换成网络对手即可。
- 实装位置：`src/ui/bp_screen.gd`，3 态状态机 `BAN → PICK → REVEAL`。
- 共享池：24 英雄（12 生肖 h01~h12 + 12 暗生肖 h13~h24）。

> 历史：早期为"3 轮一 Ban 一 Pick、共 12 步顺序双人"，2026-05-19 改为 2 步同时盲选（节奏更快、契合同时回合制盲选基调）。

### 3.5 英雄技能

每个英雄拥有 **1 个独特技能**，类型为以下之一：

- **主动技能**：玩家选择触发的额外动作，通常消耗能量并占用动作槽（部分有每局使用上限）
- **被动技能**：常驻加成或自动触发的规则，无需玩家选择（作用域分单英雄 / 团队层次，须明示）

> 英雄池 = 24 英雄（h01–h24：12 生肖 + 12 暗生肖）。详见 `design/heroes.md`。

### 3.6 道具系统

战斗中每名玩家有 **3 个道具槽**，对局中从掉落的道具里 **3 选 1** 装备（一次性，可补充）。道具分三档强度：

- **T1（约 0.5 地板）**：便宜的基础件，铺地板。
- **T2（约 1.0 连携）**：进阶件，支撑英雄连携。
- **T3（超模 / build-around）**：高消耗强力件，部分为〔遗物〕（充能数次后碎裂）或〔一次性〕。

关键规则：

- **道具不占动作槽**——用道具不消耗你这回合的攒 / 波 / 防。
- **能量是总闸门**：道具按档消耗能量（T1≈1 / T2≈2 / T3≈4 能），用能量节奏约束道具强度。
- 伤害类道具遵循统一的「普通 → 穿防 → 真伤」三级阶梯，每件加伤道具按级定价。

首发 **61 件**（T1 20 / T2 24 / T3 17），覆盖进攻 / 防御 / 治疗 / 能量 / 节奏 / 状态 / 干扰 / 导出 / 博弈 等维度，每维都有地板 + 升级线 + 至少一个 capstone。清单真相源见 `design/items-firstrelease.md`；后续拓展池见 `design/items-list.md`；实现细节见 `design/items.md`。实装位置 `src/battle/item_catalog.gd` + `src/battle/items/*.gd`。

### 3.7 治疗与续航

早期为纯掉血、无治疗；现已通过道具引入**轻量治疗**，给部分阵容一条有限续航轴：

- **道具层**：生命药水（回 0.5 / 1.0 / 2.0 HP）、暖玉（防御回合回 1.0HP）、续命香等。
- 治疗整体克制（防 stall），多与「防御回合」或「替补席」绑定。

### 3.8 团队后备防御

- h08 鬼金【不坠神言】使未挡到基础攻击的「大防」由队伍保留，换人后仍在，直到实际挡住一次「波 / 大波」。
- 当前回合选择的防御优先；后备大防只补位，不会在普通「防」已足够时被浪费。穿大防攻击不会消费它；多段命中的同一次基础攻击会被完整挡下。

## 4. 公式

### 伤害公式

```
实际伤害 = 基础伤害 经伤害管线各相位修正（易伤 → 减免 → 护盾 → 转移 → 落 HP）
```

内部采用半点制：1 HP = 2 半点，最小伤害 0.5（= 1 半点）。波 = 1.0 HP，大波 = 2.0 HP。

### 能量公式

```
E_回合结束 = E_回合开始 − C_本回合消耗 + G_本回合获得
```

| 动作 | C（消耗） | G（获得） |
|------|----------|----------|
| 攒 | 0 | 1 |
| 波 | 1 | 0 |
| 防 | 0 | 0 |
| 大波 | 3 | 0 |
| 大防 | 2 | 0 |
| 切换英雄 | 0（占动作槽） | 0 |

能量为同队 3 英雄共用，上限 `MAX_ENERGY`（20）。

## 5. 边界情况

| 场景 | 结果 |
|------|------|
| 双方同时出「波」 | **双方各受 1 点伤害**，各自消耗 1 能量（**不互相抵消**） ✱ |
| 双方同时出「大波」 | **双方各受 2 点伤害**，各自消耗 3 能量（**不互相抵消**） ✱ |
| 「波」vs「大波」 | **双方都解算伤害** — 波方受 2 伤（被大波满伤），大波方受 1 伤（被波满伤）；波方消耗 1 能量，大波方消耗 3 能量（**无"压制"机制**） ✱ |
| 「防」vs「大波」 | 防被穿透，防方受到 2 点伤害 |
| 「大防」vs「波」 | 波被格挡，攻击方仍消耗 1 能量 |
| 「大防」vs「大波」 | 大波被格挡，攻击方仍消耗 3 能量 |
| 能量不足时选择消耗动作 | 动作不可选择（按钮置灰），防止无效操作 |
| 切换英雄 | 占用该回合动作槽（切换回合不能再做其他动作）；切换先于伤害结算 |
| 仅剩 1 个存活英雄 | 切换不可用，必须用当前英雄继续 |
| 双方同时击杀对方最后英雄 | 平局 |
| 英雄已阵亡时尝试切换至该英雄 | 该英雄不可选择（按钮置灰或隐藏） |

> ✱ 三条同时攻击结算规则（不抵消、双向独立解算）于 2026-05-18 裁决为正式行为，并在 v4 引擎中延续。当前大波能量为 3（曾短暂改为 2、现已改回 3）。
