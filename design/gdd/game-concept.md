# 波波攒之王 — 游戏概念文档

## 1. 概述

波波攒之王（King of BoboZan）是一款像素风格 1v1 同时回合制英雄对战游戏，改编自中国广为流传的手部游戏「波波攒」。每名玩家操控 3 个英雄（1 固定 + 2 通过 Ban/Pick 选取），在「攒→波→防→大波→大防」的心理博弈基础上搭配英雄独特技能进行对战。双方每回合同时选择动作并结算，将对方全部英雄血量归零者获胜。轻规则、重心理博弈，上手门槛极低但策略深度高。

---

## 2. 玩家幻想

翻开底牌时的预判快感 — 就像猜拳赢了对方，但每回合的"猜拳"都建立在上回合的资源变化之上。玩家感受到：

- **心理压制**："我知道你知道我会出波，所以我出防"
- **资源掌控**：能量是公共资源，切换英雄消耗能量，何时攒气、何时爆发需要规划
- **英雄组合**：3 个英雄的阵容选择带来策略多样性，Ban/Pick 阶段就是战斗的前奏

---

## 3. 详细规则

### 3.1 核心动作（MVP）

| 动作 | 能量消耗 | 效果 |
|------|---------|------|
| 攒 | 0 | 获得 1 点能量 |
| 波 | 1 | 造成 1 点伤害。被「防」或「大防」格挡。双方同时出波则互相抵消 |
| 防 | 0 | 格挡「波」 |
| 大波 | 3 | 造成 2 点伤害。穿透「防」。被「大防」格挡。双方同时出大波则互相抵消 |
| 大防 | 2 | 格挡「波」和「大波」 |

### 3.2 同时出手结算矩阵

| 我方 \ 对方 | 攒 | 波 | 防 | 大波 | 大防 |
|-------------|-----|-----|-----|------|------|
| **攒** | 各+1能 | 方受伤 | — | 方受伤 | — |
| **波** | 方-1能 对方+1能 | 抵消，各-1能 | 波被格挡，各消耗 | 方受1伤 | 波被格挡，各消耗 |
| **防** | — | 防住 | — | 防被穿透，防方受2伤 | — |
| **大波** | 方-3能 对方+1能 | 方受1伤 对方-1能 | 穿透造成2伤 | 抵消，各-3能 | 大波被格挡，各消耗 |
| **大防** | — | 防住 | — | 防住 | — |

> "—" 表示该组合无特殊交互（各自动作正常结算）；"各消耗"指各自扣除对应动作的能量消耗。

### 3.3 对战规则

- **形式**：1v1，同时选择动作，回合结束同时结算
- **初始能量**：0，能量为同队英雄共用
- **默认血量**：10 点（英雄可独立设定）
- **切换英雄**：消耗 1 点能量，切换后能量保留（扣除切换费用后的剩余量）
- **击败规则**：单个英雄血量归零后无法再切换上场；一方全部英雄归零即为失败

### 3.4 选人阶段（Ban/Pick）

1. 双方各确定 1 个「必出场」英雄（固定位）
2. 从共享英雄池中进行 Ban/Pick：
   - A Ban 1 → B Ban 1 → A Pick 1 → B Pick 1
   - B Ban 1 → A Ban 1 → B Pick 1 → A Pick 1
3. 每人最终持有 3 个英雄（1 固定 + 2 选人）

> 共享池最低要求：2 固定 + 4 Ban + 4 Pick = **10 个英雄**。若 MVP 阶段英雄数量不足，降级为纯 1v1（无 BP）。

### 3.5 英雄技能

每个英雄拥有 **1 个独特技能**，类型为以下之一：

- **额外动作**：新增一个可选动作，扩展博弈维度
- **强化动作**：修改某个基础动作的数值或效果
- **被动效果**：常驻加成，改变资源获取或伤害规则

## 4. 公式

### 伤害公式

```
实际伤害 = 基础伤害 × (1 − 减伤率)
```

MVP 阶段减伤率为 0，所有伤害为固定值。

### 能量公式

```
E_回合结束 = E_回合开始 − C_本回合消耗 + G_本回合获得
```

| 动作 | C（消耗） | G（获得） |
|------|----------|----------|
| 攒 | 0 | 1 |
| 波 | 1 | 0 |
| 防 | 0 | 0 |
| 大波 | 3 | 0 |
| 大防 | 2 | 0 |
| 切换英雄 | 1 | 0 |

### 切换公式

```
E_切换后 = E_切换前 − 1
如果 E_切换前 < 1：切换不可用
```

## 5. 边界情况

| 场景 | 结果 |
|------|------|
| 双方同时出「波」 | 互相抵消，双方均不受伤害，各自消耗 1 能量 |
| 双方同时出「大波」 | 互相抵消，双方均不受伤害，各自消耗 3 能量 |
| 「波」vs「大波」 | 大波方对波方造成 1 点伤害，波方消耗 1 能量，大波方消耗 3 能量 |
| 「防」vs「大波」 | 防被穿透，防方受到 2 点伤害 |
| 「大防」vs「波」 | 波被格挡，攻击方仍消耗 1 能量 |
| 「大防」vs「大波」 | 大波被格挡，攻击方仍消耗 3 能量 |
| 能量不足时选择消耗动作 | 动作不可选择（按钮置灰），防止无效操作 |
| 剩余能量 < 1 时切换英雄 | 切换按钮不可用 |
| 仅剩 1 个存活英雄 | 切换按钮不可用，必须用当前英雄继续 |
| 双方同时击杀对方最后英雄 | 平局 |
| 英雄已阵亡时尝试切换至该英雄 | 该英雄不可选择（按钮置灰或隐藏） |

## 6. 依赖关系

- **无外部系统依赖**（MVP 阶段为独立对战逻辑）
- 后续依赖：英雄系统、UI 对战界面、音频系统、网络（如需在线 PvP）

## 7. 调优旋钮

| 参数 | 默认值 | 安全范围 | 影响 |
|------|-------|---------|------|
| 初始能量 | 0 | 0-3 | 前期节奏，越高越快进入博弈 |
| 默认血量 | 10 | 5-20 | 对局时长 |
| 波伤害 | 1 | 1-3 | 与血量挂钩的击杀回合数 |
| 大波伤害 | 2 | 2-6 | 高消耗动作的回报率 |
| 攒获得 | 1 | 1-2 | 能量积累速度 |
| 大波消耗 | 3 | 2-5 | 大波使用频率 |
| 大防消耗 | 2 | 2-4 | 大防使用频率 |
| 切换消耗 | 1 | 0-2 | 英雄切换频率 |

---

## 8. 验收标准

- [ ] 双方可在同一设备上完成完整 1v1 对局（本地对战）
- [ ] 5 个基础动作（攒/波/防/大波/大防）均按结算矩阵正确结算
- [ ] 同时出波/大波抵消逻辑正确
- [ ] 波 vs 大波结算正确（大波方造成 1 伤害）
- [ ] 防/大防格挡逻辑正确
- [ ] 能量不足时对应动作不可选择
- [ ] 英雄切换消耗 1 能量，能量不足时切换不可用
- [ ] 英雄血量归零后无法切换上场
- [ ] 一方全部英雄归零时对局结束并判定胜者
- [ ] 至少 2 个英雄拥有完整可玩的独特技能
- [ ] 选人阶段 BP 流程正确执行（需 10 个英雄）（若英雄不足则为纯 1v1）
