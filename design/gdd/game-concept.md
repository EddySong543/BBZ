# 波波攒之王 — 游戏概念文档

## 1. 概述

波波攒之王（King of BoboZan）是一款像素风格 1v1 同时回合制英雄对战游戏，改编自中国广为流传的手部游戏「波波攒」。每名玩家操控 3 个英雄（全部通过 Ban/Pick 从共享池选取），在「攒→波→防→大波→大防」的心理博弈基础上搭配英雄独特技能进行对战。双方每回合同时选择动作并结算，将对方全部英雄血量归零者获胜。轻规则、重心理博弈，上手门槛极低但策略深度高。

---

## 2. 玩家幻想

翻开底牌时的预判快感 — 就像猜拳赢了对方，但每回合的"猜拳"都建立在上回合的资源变化之上。玩家感受到：

- **心理压制**："我知道你知道我会出波，所以我出防"
- **资源掌控**：能量是公共资源，切换英雄消耗能量，何时攒气、何时爆发需要规划
- **英雄组合**：3 个英雄的阵容选择带来策略多样性，Ban/Pick 阶段就是战斗的前奏

---

## 3. 详细规则

### 3.1 核心动作

| 动作 | 能量消耗 | 效果 |
|------|---------|------|
| 攒 | 0 | 获得 1 点能量 |
| 波 | 1 | 造成 1 点伤害。被「防」或「大防」格挡。**双方同时出波则各受 1 伤**（详见 §3.2 ✱） |
| 防 | 0 | 格挡「波」（不格挡「大波」） |
| 大波 | 3 | 造成 2 点伤害。穿透「防」。被「大防」格挡。**双方同时出大波则各受 2 伤**（详见 §3.2 ✱） |
| 大防 | 2 | 格挡「波」和「大波」 |

### 3.2 同时出手结算矩阵

按 P1 行动（行） × P2 行动（列）列出每个单元格内双方的能量与伤害变化。

| P1 \ P2 | 攒 | 波 | 防 | 大波 | 大防 |
|---------|-----|-----|-----|------|------|
| **攒** | P1+1能, P2+1能 | P1+1能, P2-1能, P1受1伤 | P1+1能 | P1+1能, P2-3能, P1受2伤 | P1+1能, P2-2能 |
| **波** | P1-1能, P2+1能, P2受1伤 | P1-1能, P2-1能, **双方各受1伤** ✱ | P1-1能, 波被防格挡 | P1-1能, P2-3能, **P1受2伤, P2受1伤** ✱ | P1-1能, P2-2能, 大防格挡 |
| **防** | P2+1能 | P2-1能, 波被防格挡 | — | P2-3能, P1受2伤（防被穿透） | P2-2能 |
| **大波** | P1-3能, P2+1能, P2受2伤 | P1-3能, P2-1能, **P1受1伤, P2受2伤** ✱ | P1-3能, P2受2伤（穿防） | P1-3能, P2-3能, **双方各受2伤** ✱ | P1-3能, P2-2能, 大防格挡 |
| **大防** | P1-2能, P2+1能 | P1-2能, P2-1能, 大防格挡 | P1-2能 | P1-2能, P2-3能, 大防格挡 | P1-2能, P2-2能 |

> "—" 表示该组合无特殊交互（各自动作正常结算）。
>
> ✱ **重要**：波vs波、大波vs大波、波vs大波这三组同时攻击组合 **双方都独立解算伤害**，不存在"互相抵消"或"大波压制波"机制。早期设计为抵消/压制，
> 实际游戏体验后保留为双向解算作为正式行为（增加试探代价与紧张感）。详见 `tests/BEHAVIOR_NOTES.md` B-001 / B-002 / B-003（已 Resolved: Design Updated）。

### 3.3 对战规则

- **形式**：1v1，同时选择动作，回合结束同时结算
- **初始能量**：0，能量为同队英雄共用
- **默认血量**：10 点（英雄可独立设定）
- **切换英雄**：消耗 1 点能量，切换后能量保留（扣除切换费用后的剩余量）
- **击败规则**：单个英雄血量归零后无法再切换上场；一方全部英雄归零即为失败

### 3.4 选人阶段（Ban/Pick）

双方从共享英雄池中进行 3 轮 Ban/Pick，每轮一 Ban 一 Pick，共 12 步：

| 轮次 | 步骤 |
|------|------|
| 第 1 轮 | A Ban → B Ban → A Pick → B Pick |
| 第 2 轮 | B Ban → A Ban → B Pick → A Pick |
| 第 3 轮 | A Ban → B Ban → A Pick → B Pick |

最终每人持有 3 个英雄（全部从 BP 选出），共 6 Ban + 6 Pick。

> **共享池最低要求**：6 Ban + 6 Pick = **12 个英雄**。当前英雄池 13 个 (h01~h13) 满足。
>
> 实装位置：`src/ui/start_screen.gd` 内 `Phase` enum 共 13 个值（12 步 + DONE）。
> 后续若调整 BP 顺序，必须同步本节与 `Phase` enum。

### 3.5 英雄技能

每个英雄拥有 **1 个独特技能**，类型为以下之一：

- **主动技能**：玩家选择触发的额外动作，通常消耗能量（如百兽消耗全部能量、舍身扣 2 HP 换 3 能）
- **被动技能**：常驻加成或自动触发的规则，无需玩家选择（如龙威按能量差加伤、纳福受伤获能、午马切换附盾）

> 注：代码内部 `HeroData.SkillType` enum 当前保留 3 个值 (PASSIVE / EXTRA_ACTION / ENHANCED_ACTION)，但 ENHANCED_ACTION 未被任何英雄使用，实际只有"主动 (EXTRA_ACTION) + 被动 (PASSIVE)"两类。

## 4. 公式

### 伤害公式

```
实际伤害 = 基础伤害 × (1 − 减伤率)
```

MVP 阶段减伤率为 0，所有伤害为固定值。

### 能量公式

```
E_回合结束 = E_回合开始 − C_本回合消耗 + G_本回合获得
```

| 动作 | C（消耗） | G（获得） |
|------|----------|----------|
| 攒 | 0 | 1 |
| 波 | 1 | 0 |
| 防 | 0 | 0 |
| 大波 | 3 | 0 |
| 大防 | 2 | 0 |
| 切换英雄 | 1 | 0 |

### 切换公式

```
E_切换后 = E_切换前 − 1
如果 E_切换前 < 1：切换不可用
```

## 5. 边界情况

| 场景 | 结果 |
|------|------|
| 双方同时出「波」 | **双方各受 1 点伤害**，各自消耗 1 能量（**不互相抵消**） ✱ |
| 双方同时出「大波」 | **双方各受 2 点伤害**，各自消耗 3 能量（**不互相抵消**） ✱ |
| 「波」vs「大波」 | **双方都解算伤害** — 波方受 2 伤（被大波满伤），大波方受 1 伤（被波满伤）；波方消耗 1 能量，大波方消耗 3 能量（**无"压制"机制**） ✱ |
| 「防」vs「大波」 | 防被穿透，防方受到 2 点伤害 |
| 「大防」vs「波」 | 波被格挡，攻击方仍消耗 1 能量 |
| 「大防」vs「大波」 | 大波被格挡，攻击方仍消耗 3 能量 |
| 能量不足时选择消耗动作 | 动作不可选择（按钮置灰），防止无效操作 |
| 剩余能量 < 1 时切换英雄 | 切换按钮不可用 |
| 仅剩 1 个存活英雄 | 切换按钮不可用，必须用当前英雄继续 |
| 双方同时击杀对方最后英雄 | 平局 |
| 英雄已阵亡时尝试切换至该英雄 | 该英雄不可选择（按钮置灰或隐藏） |

> ✱ 这三条结算规则于 2026-05-18 经裁决后确定为正式行为（早期设计为"抵消/压制"已废弃）。
> 详见 `tests/BEHAVIOR_NOTES.md` B-001 / B-002 / B-003。
