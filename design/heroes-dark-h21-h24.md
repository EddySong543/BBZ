# 黑暗生肖英雄 · 申酉戌亥（h21–h24）设计

> **性质**：本文件记录暗批最后四只（h21–h24）的设计定稿与历史落地过程。
> （h13–h20 的设计正文目前活在各 skill 的 doc-comment；本文件先承载 h21–h24，待实装时转入 skill 头注。）
>
> **⚠ 2026-07-30 规则更新**：下文“6 维 × 2”“只能各填 1”的内容仅作历史溯源，**不再是设计约束**。英雄现采用进攻 / 防守 / 经济 / 调度 / 控制五种唯一主定位，机制先行、定位后判、人数不设配额；真相源见 `design/heroes-schools.md` §3。
> **当前主定位**：h21 枭阳 = 控制 / h22 毕方 = 进攻 / h23 天狗 = 防守 / h24 并封 = 经济。旧 `.tres dimension` 仍为道具加权技术标签，迁移前保留。
>
> **设计标准（Eddy 反复定调，连否多版后固化）**：
> 1. **一眼看懂** = 改一条规则的极简机制（像暗蛇"对手不能主动切换"），⛔无上限数值、⛔无 on-hit 触发链。
> 2. **有趣（首要 · 非被动光环）** = 玩家有主动 agency、能创造 combo 时刻、有来回 yomi；纯被动 debuff 光环 = 无聊 = 砍。
> 3. **广 combo** = 反制面 / 使能面广，泛连携引擎，自身平庸、强度在搭配。
> 4. **平衡（PvP）** = 有清晰对手出口、自身脆 / 有代价。
> 5. **形态新** = 不撞全 roster 已有原语。
> 6. **方法论**：产出前先推演 ① combo 够不够广 ② 好不好玩，两关都过才定稿。

## h21 枭阳【惊蛰】· 控制 · HP4 ✅定稿

- **机制（主动技）**：占动作 · 费 **1 能**（2026-07-06 批④降·原 2 能：探针实锤"被揪方下拍免费切回+切换先于伤害结算=揪几乎必被无偿撤销"·AI 在斩杀窗仍 0% 按·钉一拍案 Eddy 否·降费治标）· 每局 2 次 · **须暗猴亲自出战才能放**。强制对手换人，把对手藏在后排的英雄揪到台前（**你指定换谁上**）。
- **共享原语 = 目标选择**：当前规则下你只能打对手出战；猴让你揪出该打的那个（脆皮 carry），**使能你方整条进攻线**。
- **combo（广）**：触发光狗【影遁无门】真伤（强制切换即引爆）／揪出脆皮 + 全队 burst 秒杀／配暗蛇【困于泽国】锁切换（揪出 + 钉死）／配暗羊【罪已昭】易伤放大集火／暗系控制连环（龙锁 unique · 蛇锁机动 · 猴控位置）。
- **趣味 / yomi**：主动设局——读对手藏了谁、挑时机揪、配合集火；对手被迫纠结"还敢不敢藏脆皮"。是暗蛇的**阴阳对子**（蛇锁在原地 / 猴拽出原地）。
- **平衡**：主动技占动作 + 费能 + 每局 2 次 + 须出战（暴露 HP4 脆皮）；对手出口 = 摊平血量 / 速攻点死猴 / 换回去。**备用刹车**：揪出者只强制暴露 1 回合、下回合可自缩回（除非被锁），试玩若猴 + 蛇连环过线再启用。
- **强度评估（客观）**：中等偏强，强在"作废出战保护 + 主动精准"；最尖的角 = "你指定换谁"，用"须出战才能放"平衡，保趣味不阉割。

## h22 毕方【焚天火兆】· 进攻 · HP5 ✅定稿（🔄 2026-07-04 重做为「蓄力」两拍预告打击）

> 🔄 **2026-07-04 全面重做（Eddy 批 B 方向）**：上一版【2 能打出穿防大波】（2026-07-01~07-04）在 510 局大测试中数值健康（≈48%·主动技 1.15 次/出场局）但被 Eddy 裁定"单薄"——本质是打折大波、没有故事，且其邻居设计空间（加伤/易伤/回能尾巴）全被道具职权占死、修补无路 → 推倒。下文为现行设计。

- **机制（主动技·蓄力·🔄 2026-07-06 批④ v3 火兆共享·Eddy 批 A 案）**：占动作 · **免费** · 每局 **2 次** → **蓄力**（本回合不造成伤害·全场可见·**并获得 1.0 护盾**）；**我方下一次攻击升为穿大防**（**全队资源·不过期·兑现/落空即消·换人不熄灭**·护盾仍吸收·非真伤）。v2"下回合仅毕方本人+过期作废"废（大轮 34.6%·病根=对手能精确躲开明牌单拍窗口）；⚠ 同日推翻"保留主语/换下场熄灭"两项旧裁定（火兆=团队资源·同剑气语义）。引擎=`pierce_next_attack`。
- **🔧 2026-07-05 平衡批②（Eddy 批 A 案）**：蓄力拍 +1.0 护盾（火光护体）。验收卷 32.2%+用后率 0.71 双不及格——两拍结构最大成本项=蓄力拍白站挨打，护盾（牛金先例原语）把这拍的税付掉；预告博弈与反制链保留（垫刀/集火/沉默照旧）。
- **🔧 2026-07-05 批③第二刀（Eddy 批 B 案·蓄力免费）**：大轮 35.6%+用后率 1.83=护盾救活了机制但胜率还差 ~6pp → 成本端再砍（真代价仍在：一整拍 tempo+明牌）。窗口延长案被 Eddy 否（窗口跟人=毕方被迫站桩 2 拍或绑 h07 专线=僵化）；焚天加伤案（+0.5）留作下一刀备选。
- **两拍结构是时序标签，不是主定位**：第一拍明牌示警、第二拍火落；最终承诺是让波或大波穿大防，因此归进攻。攻击档位仍由玩家选择。
- **穿大防合法性**：走二元铁则授权通道（「只授予公开慢蓄 / 需铺垫的 payoff」·同 h10 满 4 层剑气）——蓄力拍是全场最公开的慢蓄。
- **保留主语（2026-07-04 Eddy 裁 A 案）**：蓄力只属毕方本人，换下场 / 阵亡 / 被拽即熄灭、不转移不继承——保证反制链完整（去主语的"接力开炮"= 只多一条 h07 免切专线、却砍掉集火与拽人两种拆弹，被否）。
- **反制链**：垫刀切换吃掉 / 蓄力拍集火打死毕方 / h21 拽下场 / h17 沉默掐灭 / 草人·气落空 / 趁蓄力拍抢攻。
- **生态角色**：预告拍使对手防 / 大防按钮失效一拍 → 防 32.1% 超带（大测试三旋钮）的英雄层解药之一（与 h04 十方无次第同为直接改写基础攻防决策的英雄层进攻工具）。
- **和暗兔【踏月乘风】的本质区别**：暗兔 = 同回合做两次（"多"）；暗鸡 = 跨回合两拍换一发不可挡（"准"）。
- **边界（测试锁定）**：窗口 = 次回合恰一回合·不用即失效；窗口内禁止再蓄（防误耗次数）；疾风双发两段都穿大防；道具攻击不吃 buff。
- **平衡**：真代价 = 整整一拍 tempo + 明牌 + 每局 2 次；HP 4→5（蓄力拍要站得住）。旋钮 = 费用(**0 能**·批③) / 次数(2) / 护盾量(1.0·批②) / 窗口长度(1 回合·⛔延长案已否)。用后率大轮实测 1.83 ✓（及格线 1）。
- **⚠ 溯源**：初版【空过存行动→双动作·STORE 蓄势】2026-07-01 废（与疾风同质+clunky·be38899 拆净）→ 二版【2 能穿防大波】2026-07-04 废（单薄）→ 现版蓄力两拍。技能名 2026-07-04 Eddy 定稿【焚天火兆】（第一拍点火兆·第二拍焚天·旧名「引而后发」随二版机制退役）。

## h23 天狗【御凶】· 防守 · HP6 ✅定稿（🔧 2026-07-05 批③：每局 1→2 次 + 登场反击 1.0 伤害（普通档）·Eddy 批 C 案——三轮垫底 26.8/30.2/28.6·纯保险期望太小+骗掉一次即失效 → 次数=常设威慑·反击=救场变复仇·走管线打击可喂原语）

- **机制（被动）**：暗狗在替补席存活时，我方出战英雄受到**致命伤害** → 狗立刻登场顶替并**获得 1.0 护盾垫住这一击**（2026-07-04 平衡·Eddy 批：510 局 26.8% 垫底·裸身硬接常当场阵亡=一命换一命 → 带盾登场更可能活着继续作战），原 carry 退居替补获救，剩余伤害落到狗身上（狗仍可能被打死；每局两次·批③ 1→2）。（2026-07-01 Eddy 改：旧「完全免除 + 狗自我碎掉·carry 留前线」→「顶替登场承伤·carry 退场获救」。）
- **⚠ AI 配套（2026-07-04·26.8% 的另一半病因）**：DraftAI 按 HP6 把天狗当坦克顶前排 → 御凶（须在替补席）作废。修法 = v1 评估新增「护主未用且在替补席 = 40 分资产」→ 搜索自然学会留板凳待命（battle_eval._status_assets）。
- **接手「守护」定位**：原归鬼金 h08【替罪·致死救援】，因忠犬护主比替罪羊更贴这个机制（Eddy 2026-06-25）→ 守护归天狗，**鬼金 h08 重设计**（见下）。
- **和鬼金旧救援的关系**：新天狗护主 = 「原 carry 退居替补、狗顶上承伤」——正是复用鬼金旧【致死救援】那套「顶替承伤」引擎通路（`is_lethal_guardian`）；区别仅在触发者=天狗、每局一次、狗吃这下可能阵亡。（旧版天狗是「完全免除+狗碎掉·carry 留前线」，2026-07-01 已改。）
- **共享原语 = 安全网**：使能"激进/玩命打法"这一整类——暗虎血勇（不能防御）敢压、暗鸡蓄势敢暴露、脆皮 carry 敢 over-extend。
- **趣味**：有趣的不是狗本身，是它解放出来的激进 play（同玄金不动相通过挡招把强化「波」交给队友的范式）。对手 yomi = 先点死替补席的狗破保险 / 绕开致命一击逼狗不触发。
- **平衡**：每局一次 + 狗碎掉下场 + 对手可先杀狗；HP6 让它在替补席撑得住、不被溢出轻易秒。
- **⚠ 引擎依赖迁移**：原 `is_lethal_guardian` + "致死强制换人触发狗穷追" 联动（h17/h18/暗马 doc 均引用"鬼金救援"）→ 落地时迁到天狗，相关注释同步。

## ⚠ 连带变更 · 光版鬼金 h08 重设计【不坠神言】· 防守（团队后备防御）✅定稿

- **起因**：原 h08【替罪·致死救援】与天狗护主同质，守护归天狗后鬼金曾短暂改为替补治疗；2026-08-03 再次重做，回到更贴近波波攒底层动作的防御博弈。
- **机制（被动）**：鬼金【羊】的「大防」未挡到攻击时，由我方保留，直到挡住一次攻击。
- **规则边界**：“攻击”只指基础「波 / 大波」；状态属于队伍、换人后仍在、不可叠加。当前回合的「防 / 大防」优先，后备大防只在其未挡住时补位；穿大防攻击不会消费。
- **主定位 = 防守 · 机制标签 = 延迟兑现 / 团队后备**：把一次落空的大防变成之后任一队友都可利用的防守资源，不再建立独立治疗轴。
- **共享原语 = 防御延迟兑现**：先用大防试探，再将未兑现的防御留给换人、蓄势或进攻回合；实际挡住后仍触发统一成功防御钩子，可继续喂牛金与蚩尤等组合。
- **趣味**：鬼金玩家决定何时用 2 能买一份“现在或以后”的大防；对手则决定继续不攻、用小波逼出，还是用穿大防手段越过。
- **羊祭司意象**：祭司发出的祷言即使当下未被回应也不会坠灭，直到替队伍真正挡下一次攻击。
- **和天狗对比**：狗护主处理致死伤害与强制换人；羊保留未兑现的大防。一个是替补席救急，一个是基础动作层的团队防御资源。

## h24 并封【吞尽八荒】· 经济 · HP6 ✅定稿

- **机制（被动·🔄 2026-07-04 双头分食优化·Eddy 批 A 案）**：战场上**任一英雄阵亡时（敌我皆可），并封双头对食 → 你方团队 +2.0 能（一头吞魂）+ 并封自己回复 1.0 生命（一头食肉·封顶满血·替补席也回）**。
- **🔄 优化缘由（2026-07-04）**：510 局大测试 ≈49% 平衡位，但旧版纯产能有三病——①死亡潮集中残局、能量池（上限 10）常近满 → +2 能溢出蒸发 ②首个死亡前是白板槽 ③零 agency 纯光环。A 案加食肉回血：礼包不再可能全额浪费（能满血那份还在）、并封升级为"尸山上越吃越壮的终盘兽"；**能量保持 2.0**——血那份（≈1 能等价物）即被动 +1 恢复后的通胀补偿，一次只动一根旋钮。🔧 **已批备用旋钮（Eddy 预批）**：下轮 500 局大测试若 h24 仍 <48% 或能量溢出偏高 → FEAST_ENERGY 2.0→3.0（=一记大波弹药·一行常量·免过会）。
- **共享原语 = 死亡产能**：全 roster 唯一没人碰的能量触发面。通读 20 skill 确认不撞步虚无有乡(得能加成)/纳福(受伤转能)/鼠潮(combo转能)；和尾后针(阵亡真伤)/末日火种(剩1强化)也不同。
- **combo（广·配击杀节奏）**：吃"死亡"= 所有击杀手段的共同终点——配暗羊罪已昭(易伤放大更易击杀)/暗马践踏(踏死替补)/娄金真伤/集火清场/真伤道具 → 死亡 → 暴食；暴食的能量回头喂全队大波/道具 → 再压一波。**敌我皆吃** → 己方崩盘也"废物利用"产能 = 残局破釜沉舟反转。
- **趣味 / yomi**：玩家主动推进击杀节奏(清场→能量暴涨→下一波)；对手 yomi = 不给击杀喂猪 / 抢杀猪断财路。呼应去被动后"加速对局"方向(奖励击杀、逼快攻)。
- **平衡 + 诚实**：绑"死亡"这个低频高代价事件 → 即便在能量警戒最高的维度也安全(爆发式、非稳产)。诚实短板 = 绑死亡的爆发式产能(非步虚无有乡/鼠潮那种每回合稳产)、空窗期不产能。2.0 能/死可调(1.0/1.5/2.0)。
- **暗味 / 对比**：吃尸暴食食腐、贴饕餮室火；光猪纳福 = 受难得福 / 暗猪饕餮 = 吞噬得福，触发面全异、暗味更黑。
