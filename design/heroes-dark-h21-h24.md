# 黑暗生肖英雄 · 申酉戌亥（h21–h24）设计

> **性质**：暗批 h13–h24 = 6 维 × 2。本文件记录最后四只（紫火 / 昴日 / 娄金 / 室火）的设计定稿。
> （h13–h20 的设计正文目前活在各 skill 的 doc-comment；本文件先承载 h21–h24，待实装时转入 skill 头注。）
>
> **维度配额（铁律）**：进攻[暗虎 h15 + 暗马 h19]、状态[暗蛇 h18 + 暗羊 h20]已满 → 这四只只能填 **能量 / 防御 / 节奏 / 干扰 各 1**。
> **维度分配（Eddy 授权 Claude 定）**：**紫火 = 干扰 / 昴日 = 节奏 / 娄金 = 防御 / 室火 = 能量**。
>
> **设计标准（Eddy 反复定调，连否多版后固化）**：
> 1. **一眼看懂** = 改一条规则的极简机制（像暗蛇"对手不能主动切换"），⛔无上限数值、⛔无 on-hit 触发链。
> 2. **有趣（首要 · 非被动光环）** = 玩家有主动 agency、能创造 combo 时刻、有来回 yomi；纯被动 debuff 光环 = 无聊 = 砍。
> 3. **广 combo** = 反制面 / 使能面广，泛连携引擎，自身平庸、强度在搭配。
> 4. **平衡（PvP）** = 有清晰对手出口、自身脆 / 有代价。
> 5. **形态新** = 不撞全 roster 已有原语。
> 6. **方法论**：产出前先推演 ① combo 够不够广 ② 好不好玩，两关都过才定稿。

## h21 枭阳【惊蛰】· 干扰 · HP4 ✅定稿

- **机制（主动技）**：占动作 · 费 2 能 · 每局 2 次 · **须暗猴亲自出战才能放**。强制对手换人，把对手藏在后排的英雄揪到台前（**你指定换谁上**）。
- **共享原语 = 目标选择**：当前规则下你只能打对手出战；猴让你揪出该打的那个（脆皮 carry），**使能你方整条进攻线**。
- **combo（广）**：触发光狗【影遁无门】真伤（强制切换即引爆）／揪出脆皮 + 全队 burst 秒杀／配暗蛇【困于泽国】锁切换（揪出 + 钉死）／配暗羊【罪已昭】易伤放大集火／暗系控制连环（龙锁 unique · 蛇锁机动 · 猴控位置）。
- **趣味 / yomi**：主动设局——读对手藏了谁、挑时机揪、配合集火；对手被迫纠结"还敢不敢藏脆皮"。是暗蛇的**阴阳对子**（蛇锁在原地 / 猴拽出原地）。
- **平衡**：主动技占动作 + 费能 + 每局 2 次 + 须出战（暴露 HP4 脆皮）；对手出口 = 摊平血量 / 速攻点死猴 / 换回去。**备用刹车**：揪出者只强制暴露 1 回合、下回合可自缩回（除非被锁），试玩若猴 + 蛇连环过线再启用。
- **强度评估（客观）**：中等偏强，强在"作废出战保护 + 主动精准"；最尖的角 = "你指定换谁"，用"须出战才能放"平衡，保趣味不阉割。

## h22 毕方【引而后发】· 节奏 · HP4 ✅定稿

- **机制（被动）**：暗鸡在场时，你方英雄可"空过"一回合（不行动、不拿能量），把这次行动**存起来**；之后任意回合，连同当回合行动一起打出 = **攒成一个爆发回合**。
- **和暗兔【踏月乘风】的本质区别**：暗兔 = 净多一个动作（+tempo · cap 2）；暗鸡 = **净零**（先空过一回合换之后双动作 · 总数不变 · 只是挤到同一拍）。暗兔玩"多"、暗鸡玩"准"。净零 → 不超模、无需上限。
- **共享原语 = 爆发时机**（动作集中 / 时间位移）——节奏赛道没人碰的杠杆。
- **combo（广 · 不撞暗兔）**：存一拍 →【大波 + 大波】alpha strike 凿穿肉龟（配龙息 / 至臻剑意）／关键时刻双段引爆（蛇毒 / 鹤顶红）／配猴揪出 carry 后双大波处刑／配暗羊处决择时。
- **趣味 / yomi**：空过 = 明牌电报，对手纠结冲你 / 严防爆发；你挑准爆发或假憋骗大防。蓄势 → 爆发的 setup-payoff。
- **平衡**：付出一整回合（无能量、无行动、暴露）换一次爆发 = 净零 tempo；爆发明牌可预判；HP4 脆。

## h23 天狗【御凶】· 防御 · HP6 ✅定稿

- **机制（被动）**：暗狗在替补席存活时，我方出战英雄受到**致命伤害** → 狗立刻登场顶替，原 carry 退居替补获救，这一击改落到狗身上（狗吃这下·可能被这下打死；每局一次）。（2026-07-01 Eddy 改：旧「完全免除 + 狗自我碎掉·carry 留前线」→「顶替登场承伤·carry 退场获救」。）
- **接手「守护」定位**：原归鬼金 h08【替罪·致死救援】，因忠犬护主比替罪羊更贴这个机制（Eddy 2026-06-25）→ 守护归娄金，**鬼金 h08 重设计**（见下）。
- **和鬼金旧救援的关系**：新天狗护主 = 「原 carry 退居替补、狗顶上承伤」——正是复用鬼金旧【致死救援】那套「顶替承伤」引擎通路（`is_lethal_guardian`）；区别仅在触发者=天狗、每局一次、狗吃这下可能阵亡。（旧版天狗是「完全免除+狗碎掉·carry 留前线」，2026-07-01 已改。）
- **共享原语 = 安全网**：使能"激进/玩命打法"这一整类——暗虎血勇（不能防御）敢压、暗鸡蓄势敢暴露、脆皮 carry 敢 over-extend。
- **趣味**：有趣的不是狗本身，是它解放出来的激进 play（同卸劲解放 combo 的范式）。对手 yomi = 先点死替补席的狗破保险 / 绕开致命一击逼狗不触发。
- **平衡**：每局一次 + 狗碎掉下场 + 对手可先杀狗；HP6 让它在替补席撑得住、不被溢出轻易秒。
- **⚠ 引擎依赖迁移**：原 `is_lethal_guardian` + "致死强制换人触发狗穷追" 联动（h17/h18/暗马 doc 均引用"鬼金救援"）→ 落地时迁到娄金，相关注释同步。

## ⚠ 连带变更 · 光版鬼金 h08 重设计【牧野回春】· 防御（治疗/续航子轴）✅定稿

- **起因**：原 h08【替罪·致死救援】= 替补替死，和娄金护主同质（连相似都算撞）→ 守护归娄金、鬼金重设计（Eddy 2026-06-25：忠犬护主比替罪羊更贴守护）。
- **机制（被动）**：鬼金在场时，你方退到**替补席**的英雄每回合回 **0.5 HP**（退下火线、休养生息）。
- **维度 = 防御 · 子轴 = 治疗 / 续航**：roster 唯一空白轴（仅道具暖玉/药水/续命香在做、英雄零占用）；"替补回血"触发面全 roster 没人碰。通读 20 个 skill 确认不撞护盾分发(牛)/反伤(暗牛)/守护(狗)/转能(猪)。
- **共享原语 = 轮换续航**：切换变成轮换休养——残血退后养、养好轮回。配星日免费切换 = 零成本轮换养伤引擎；roster 第一个"熬/续航"引擎。
- **趣味**：轮换管理 agency（哪个退后养、何时轮回）；对手 yomi = 趁换人抢 tempo / 集火不给休养发酵。
- **平衡 + 诚实**：0.5/回合慢、只替补回、退场=机会成本（丢前线输出+对手趁机压）；⚠ 偏"续航/熬"，和去被动反龟方向需试玩盯（克制 = 量小 + 绑退场机会成本 + 星日轮换那条 watch）。
- **和娄金对比**：狗护主 = 救急（防一次死）/ 羊休养 = 持久（慢慢养），一急一缓、互补不撞。
- **⚠ 落地影响（光版·待实装时改）**：`h08_jiuyuan.gd` → 重写为 muyang；`is_lethal_guardian` 守护逻辑迁娄金；`heroes-redesign.md` h08 条目同步；h15/h17/h18/暗马 doc 里"鬼金救援"引用改"娄金护主"。

## h24 并封【吞尽八荒】· 能量 · HP6 ✅定稿

- **机制（被动）**：战场上**任一英雄阵亡时（敌我皆可），暗猪吞噬尸身 → 你方团队 +2.0 能**（饕餮者从死亡盛宴暴食）。
- **共享原语 = 死亡产能**：全 roster 唯一没人碰的能量触发面。通读 20 skill 确认不撞囤鼠(得能加成)/纳福(受伤转能)/鼠潮(combo转能)；和尾后针(阵亡真伤)/末日火种(剩1强化)也不同。
- **combo（广·配击杀节奏）**：吃"死亡"= 所有击杀手段的共同终点——配暗羊罪已昭(易伤放大更易击杀)/暗马践踏(踏死替补)/娄金真伤/集火清场/真伤道具 → 死亡 → 暴食；暴食的能量回头喂全队大波/道具 → 再压一波。**敌我皆吃** → 己方崩盘也"废物利用"产能 = 残局破釜沉舟反转。
- **趣味 / yomi**：玩家主动推进击杀节奏(清场→能量暴涨→下一波)；对手 yomi = 不给击杀喂猪 / 抢杀猪断财路。呼应去被动后"加速对局"方向(奖励击杀、逼快攻)。
- **平衡 + 诚实**：绑"死亡"这个低频高代价事件 → 即便在能量警戒最高的维度也安全(爆发式、非稳产)。诚实短板 = 绑死亡的爆发式产能(非囤鼠/鼠潮那种每回合稳产)、空窗期不产能。2.0 能/死可调(1.0/1.5/2.0)。
- **暗味 / 对比**：吃尸暴食食腐、贴饕餮室火；光猪纳福 = 受难得福 / 暗猪饕餮 = 吞噬得福，触发面全异、暗味更黑。
