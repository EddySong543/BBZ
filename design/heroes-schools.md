# 波波攒之王 — 英雄设计框架（流派 / 原语 / 阵容定位）

> **状态**：v2 起点（2026-05-19 Eddy + Claude 协议确立）
> **作用**：所有现有及未来英雄设计的指导框架
> **关联**：`design/heroes.md`（个体英雄定义）、`design/gdd/game-concept.md`（核心机制）

---

## 1. 设计哲学

### 1.1 核心流程

```
角色形象 → 机制原语联想 → 跨流派服务能力验证 → 合格设计
```

- **角色形象先行**：每个英雄围绕主题（12 生肖）的角色形象出发
- **机制原语发散**：从形象联想 1~2 个机制原语
- **跨流派验证**：原语组合必须为至少 2 个流派提供钩子，单一服务的设计不通过

### 1.2 反模式

- ❌ **自上而下流派填空**：先定流派标签，再找英雄填 → 模板僵化
- ❌ **单一体系服务**：一张卡只在一个流派/阵容有用 → 主题轮换即报废
- ❌ **过度复杂技能**：多技能、文字超过 3 行 → 玩家心智超载

### 1.3 参照系

| 正面参照 | 设计原则 |
|----------|----------|
| MTG Lenticular Design (Mark Rosewater) | 一张卡对不同玩家呈现不同深度 |
| Slay the Spire 通用资源原语 | 用资源比例区分套牌，不用模板区分 |
| 皇室战争 Multiple Use Case | 每张卡至少 2 种用法 |
| MTG Flexibility Theory (Reid Duke) | Power = Raw Strength × Flexibility |

| 反面参照 | 警示 |
|----------|------|
| 炉石近年"主题套牌强制绑定" | 每张卡服务单一主题，版本轮换报废 |

### 1.4 关键约束：同时回合制 ≠ 信息博弈

⚠️ **波波攒的同时回合制结算意味着没有"预测对手动作再反应"的窗口**。所有玩家盲选，双方点击确认后立即结算。

因此**禁止设计以下类型的机制**（AI 设计英雄时常见的幻觉）：

- ❌ 出"假动作"误导对手
- ❌ "试探"对手下回合动作
- ❌ 强制"暴露"对手动作
- ❌ "锁定预判"双方公开

唯一合法的"信息博弈"是**结算时的目标选择**——例如"真假分身"：攻击时必须选目标，真假位置每回合随机打乱（发生在结算阶段，非动作选择阶段）。⚠️ 此机制原由 h09 申猴承载，2026-05-21 重做后腾空，目前无英雄实装，留作未来娱乐流英雄槽。

## 2. 三层结构

```
Layer 0: 机制原语字典  (开放清单，~40 个，可随新英雄扩张)
   ↓
   每个英雄 = 1~2 个原语组合，单技能呈现 ≤ 3 行
   ↓
Layer A: 主导流派  (6 个，作为"主导倾向"而非排他标签)
   每个英雄: 1 主导 + 0~2 次要倾向
   ↓
Layer B: 阵容定位  (3 种角色: 核心 / 辅助 / 独立)
   每个英雄给出"在 X 体系里担 Y / 在 Z 体系里担 W"跨档说明
```

> **衔接 / 润滑（辅助 trait，2026-05-23）**：「上一回合发生 X → 本回合得到 Y」式 delta-trigger 辅助，作各流派的润滑剂。⚠️ **从严执行——否则只服务单一/少数流派就直接废了**。**三条硬过滤器（缺一不可）**：① **触发 X 必须是通用事件**（掉血/用能/切换/出某动作等任意流派都会做的；❌ 禁"击杀/队友死/特定流派资源"等专属或近专属触发；并避开已饱和的防反 4b「掉血→获益」）② **必须留操作 agency**（不可纯 ticker 自动跳，须有玩家可塑造的节奏或选择，如"退→进"决策）③ **即时回报**（本/下回合见效，禁延迟）。**配额：全池 1-2 个封顶**——做多即成 ticker 模子聚堆（新同质化）。归类 = Layer B 辅助 + 跨流派手段，**非新流派 / 非新原语**（是 §5.4 触发器的应用方式）。
> **动作改造**（动作升级/折扣 = h10 啼晓）跨控制 + 爆发，是少数跳出"触发→数值"模子的机制，鼓励多做。剩余空白：动作替换 / 动作降级。
> **§5.5 状态附加维度已开张**：待填。剩余空白：附盾（给队友）/ 中毒/持续伤害 / 燃烧 / 不可选目标(隐身) / 嘲讽——均待填。
> **§5.1 HP 回复维度已开张**：续航 trait 现有 h12 吞噬(吸血)。剩余空白：HP 转移 / 生命链接(队友) / 能量预存 / 能量冻结。
> **§5.7 团队协同维度进展**：链式联动(羁绊)：待填。剩余空白：召唤替补（h09 化身 2026-05-21 重做迁出，腾空）/ 死亡赠礼（h06 蛇蜕 2026-05-21 重做迁出，腾空）/ 队友登场赠礼。
> **§5.3 伤害结算维度进展**：首次保护/致死阈值改写=h06 巳蛇【蛇蜕】（蜕皮重生，2026-05-21 重做启用）。剩余空白：伤害转移/反弹（4a）/延迟/固定 仍空。

### 3.2 克制关系

主三角：
```
进攻 ◄─克─ 韧性 (防反/轮转兼任韧性侧)
爆发 ◄─克─ 防反
控制 ◄─克─ 娱乐
```

辅助克制（略占优而非严格 RPS）：
- 快攻 略克 控制（不给铺垫时间）
- 爆发 略克 韧性（一次过载 vs 慢慢磨）
- 防反 略克 快攻（持续输出 = 持续被反）

**娱乐流**是变量野怪：与任何流派对战都有变数，不固定克制谁（RNG 天然干扰对手的确定性计划，尤其克控制流）。

## 4. Layer B: 阵容定位

| 定位 | 队伍中的功能 | 经典 kit 信号 |
|------|--------------|---------------|
| **核心** Core | 后期主输出，需要队友铺路 | 大量加伤 / 蓄能爆发 / 后期 Carry |
| **辅助** Support | 给队友提供资源/掩护 | 加速能量 / 切换附盾 / HP→资源 |
| **独立** Solo | 自给自足，不依赖阵容协同 | 反伤 / 受伤获能 / 高 HP 持久 |

### 阵容档案（不是英雄标签）

**阵容档案 = BP 阶段的搭配模式**，描述 3 个英雄如何组合：

- **单核体系**：1 Core + 2 Support（辅助为核心铺路）
- **双核体系**：2 Core + 1 Solo（双输出，依赖能量分配）
- **轮转体系**：3 个 Rotation 流派英雄（围绕切换打）
- **独立体系**：3 Solo（每个英雄独立作战）

### 跨档使用提示

每个英雄都应列出"在 X 档案里担 Y / 在 Z 档案里担 W"——同一英雄在不同阵容担不同角色才符合 Lenticular Design。

## 5. Layer 0: 机制原语字典

### 5.1 维度 1：资源操作

| 原语 | 含义 |
|------|------|
| 能量加速 | 增加能量获取速率 |
| 能量转换 | 用 X 资源换能量 |
| 能量盗取 | 直接扣对手能量 |
| 能量预存 | 存能量到下个英雄/下回合 |
| 能量冻结 | 让对手能量本回合不可消费 |
| 能量上限调整 | 临时改 MAX_ENERGY |
| HP 回复 | 恢复己方 HP |
| HP 转移 | 把 HP 给队友 / 抽队友 HP |
| 生命链接 | 造成伤害时回血 |
| 过载 / 透支 | 本回合 +X 能、下回合 -X 能（先享后还，非延迟回报）|

### 5.2 维度 2：动作改造

| 原语 | 含义 |
|------|------|
| 动作替换 | 选 X 实际执行 Y |
| 动作升级 | 波→大波 / 防→大防 |

| 免费切换 | 不消耗切换成本 |

### 5.3 维度 3：结算改造

| 原语 | 含义 |
|------|------|
| 加伤放大 | 普攻基于条件 +X |
| 伤害免疫 | 单回合无伤 |
| 伤害减免 | 受伤 -X（非全免）|
| 伤害反弹 | 受伤反伤攻击者 |
| 伤害延迟 | 本回合伤害下回合结算 |
| 伤害转移 | 把受伤转给队友 / 对手其他英雄 |
| 伤害固定 | 不论原数值固定为 X |
| 首次保护 | 本局第一次致死伤害不结算 |
| 致死阈值改写 | HP=0 不死，HP=负 X 才死 |
| 易伤 / 破绽 | 标记对手，其下次/本回合受攻击 +X 伤（放大队友输出）|

| 自伤换减免 | 主动扣自身 HP → 换伤害减免（预付式防御 / 卖血流闭环）⚠️ 减免非免疫·需 cap |

| 原语 | 含义 |

| 原语 | 含义 |

| 原语 | 含义 |

| 原语 | 含义 |
|------|------|

| 召唤替补 | 召唤额外作战单位 |

### 5.8 维度 8：连锁 / 节奏

| 原语 | 含义 |
|------|------|
| 连击奖励 | 连续 N 回合同动作奖励 |
| 变化奖励 | 每回合换动作时奖励 |
| 同步奖励 | 与对手出同动作奖励 |
| 错位奖励 | 与对手出不同动作奖励 |
| 镜像 | 复制对手本回合动作（结算阶段）|

### 5.9 维度 9：概率 / 随机

| 原语 | 含义 |
|------|------|
| 动作随机替换 | 自己动作随机变 |
| 概率减伤 | 50% 概率免伤 |
| 概率翻倍 | 50% 概率伤害 ×2 |

### 5.10 字典开放原则

⚠️ **以上 ~40 个原语是 v2 起点，不是上限**。

每个新英雄设计时若发现现有原语都无法描述其角色形象 → **新增原语**，字典扩张，本文档同步更新。

### 5.11 v2.5 批准新增原语（2026-05-21，关键词扫描后 Eddy 拍板）

扫炉石 / 万智牌 / 游戏王 / 杀戮尖塔 / 符文之地 → 用波波攒硬过滤（无手牌牌库随从场召唤 / 同时结算无反应窗口 / 禁偷看信息 §1.4 / 快节奏 / 小 HP / 3 英雄+切换）筛出，greenlight 进设计池：

**新增进字典**：
- **过载 / 透支**（§5.1）：本回合 +X 能、下回合 -X 能（先享后还，非延迟回报）
- **易伤 / 破绽**（§5.3）：标记对手，其受到的下次/本回合攻击 +X 伤（放大队友输出 = 真跨英雄 combo）
- **变身 / 形态切换**（新维度）：消耗高能量切换到第二形态（数值/技能整套改变）。门槛别太高防延迟回报；形态 2 宜换打法非仅加数值
- **超杀 / 溢杀**（§5.4 触发）：击杀对手且有溢出伤害 → 溢出转移给被迫登场的下个敌方英雄（穿透击杀，滚雪球）。⭐ 留给**进攻 slot**。

**已在字典、本批一并 greenlight 优先做**：中毒/持续伤害(§5.5) · 附盾给队友(§5.5) · 能量预存(§5.1) · 召唤替补(§5.7) · 节奏奖励 变化/同步/错位(§5.8)

**两个特殊注解**：
- **嘲讽 reframe（Eddy）**：原字典"强制对手攻击自己"在 1v1 单出战结构下不成立 → 改为**轮转体系英雄**机制："即使切换下场，仍能为出战队友代受/分摊伤害"（伤害转移/redirect 方向）。
- **召唤**：后期可**体系化**（如专门强化召唤物的支援英雄），非单点设计。

> **方向方针**：暂停防反 / 纯加伤；优先 **A 团队支援** · **B 控制铺垫** · **C 节奏博弈**（最"波波攒原生"、几乎全空）。

### 5.12 v2.6 补登（2026-05-23）—— 野生原语归档 + 维度 10

## 6. 设计纪律（写卡时强制遵守）

1. **单技能精简**：一个英雄只设计 1 个技能，效果描述 ≤ 3 行
2. **原语数量**：技能由 1~2 个原语合成，不允许 3+ 原语堆砌
3. **跨流派钩子**：每个原语组合必须能为至少 2 个流派提供价值
4. **角色形象先行**：从主题角色形象出发，不要从流派模板出发
5. **同时回合制约束**：禁止"预测对手动作再反应"类机制（见 §1.4）
6. **被动作用域明示**：被动技能描述必须包含主语（"自己" / "全队" / "当前出战英雄"等），杜绝"所有攻击"类歧义。默认走**单英雄层次**（仅持有者生效）；**团队层次**仅在以下三条件**同时满足**时使用——触发条件严苛（如自身死亡而非受伤）+ buff 持续短（限 N 次或 N 回合，不允许永久残留）+ 与英雄形象强绑定（非模板化）。理由：避免"开局送英雄吃 1 波激活 → 切下场永久龟 → 全队碾压"的献祭式优势。
7. **能量池视角**：能量是双方各自的**全队共享池**（`battle_core energy[2]`），非 hero-level。禁止设计"死亡传递能量"/"独享能量"/"队友死时分能量"等幻觉机制（这些原语本就跨英雄共享，无需"传递"）。

## 8. 数值框架（2026-05-19 Eddy 决议）

> **✅ 实施状态（2026-05-25）**：本节数值框架 + §8.3 的 2 步同时盲选 BP + §8.4/§8.5 的影响清单（含 `bp_screen` 重做、34 英雄重做/实装、数值落地）已随 v4 swap（S1-S3）**全部完成**。下文「§7 Step 5b」「§8.4 影响传播」「§8.5 待重做英雄」均为已落地项；实装真相源 = `src/battle/`（BattleCore v4）+ `src/ui/bp_screen.gd` + `tests/unit/battle/v4/`。

### 8.1 基础数值（7 维）

| 维度 | 旧 | 新 | 备注 |
|------|------|------|------|
| HP 范围 | 7-14（平均 10）| **3-7（平均 5）** | 脆皮 3-4 / 标准 5-6 / 坦克 7 |
| 波伤害 | 1 | 1（不变）| 占 HP 20% |
| 大波伤害 | 2 | 2（不变）| 占 HP 40% |
| 大波能量 | 3 | **2** | 提升爆发频率，与大防 2 能对称 |
| 切换 | 1 能 + 1 动作 | **0 能 + 1 动作**（方案 C）| 切换占动作但不消耗能量 |
| MAX_ENERGY | 20 | 20（保留，可后期改 10）| 暂不动 |
| 初始能量 | 0 | **1** | 第 1 回合即可博弈 |

### 8.2 节奏目标

- **标准局长**：90 秒（~11 回合）
- **最长局长**：180 秒（~22 回合）
- **每回合所需平均伤害进入**：~1.88（HP=5 × 3 英雄 / 8 打击回合）

### 8.3 BP 机制（创新设计）

**联机对战模式**：
- 双方**同时盲 Ban** 3 名英雄（互不可见，撞车时该位置视为无效，有效 Ban 总数 ≤ 6）
- 双方**同时盲 Pick** 3 名出战英雄（**允许重复** — 双方可选同一英雄构成镜像对决）
- 流程：**2 步**（Ban 1 步 + Pick 1 步）
- 估算时长：20-40 秒

**本地测试模式（临时，仅个人测试用）**：
- 跳过 Ban 阶段
- 仅保留 Pick：玩家直接选择两边阵容
- 估算时长：10-20 秒
- ⚠️ 联机功能落地后撤除本地模式
