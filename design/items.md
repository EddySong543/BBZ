## §0 道具设计规范（定稿）

### 0.1 定位（不变项）
- **一次性消耗**；用完花 **1 能 refill** 一个 1 道具。**对对手公开**。
- **揭示前随动作盲选提交** = 主动计划件（非揭示后反制）；**不占动作槽**、用时免费、一回合用量不限。
- **默认自动指向**（伤→敌出战 / 甲·盾·治疗→己出战 / debuff→敌出战）；特殊道具可特指。
- **顺序机制**：一回合 = 有序序列 `[道具…, 动作, 道具…]`，前/后玩家编排；己方按序结算，**跨玩家仍同时独立结算（无先后手、可同时死=平局）**。

### 0.2 三层 = 来源 × 强度 × 趣味（汇率 §4.2：道具 1 能 = 0.5 HP）
| 层 | 来源 | 强度带 | 性质 |
|---|---|---|---|
| **Tier 1** | 从**维度**出发 | **≈0.5 HP 当量** | 润滑剂 ∧ 博弈变量；与英雄无关、地板池、安全网 |
| **Tier 2** | 从**英雄关键词 + 共鸣关键词**（**不点名**） | **≈1.0 HP 当量** | 连携 / 导出 / 元件层干扰；1+1>2 的钱在这层（**清单大头**） |
| **Tier 3** | **强力 / build-around** | **超模或带条件/负面** | 自成核 + 遗物 + 重口干扰 + 回路(仅PvE) |

- **变强 = 只升级不合成**：1→2 花 1 能、2→3 花 2 能（升级锁 1 回合）。
- **博弈变量是跨层风味**（三层都能做变量件，强度按本层带）。**收益带守死**：每件标 EV，超标必带条件/负面（§4.4）；跨维件压到单维基准以下或抬费。
- **能量特例**：直接 +能 须 ≥2 能或带条件 → Tier-1 能量件只能是条件件。

### 0.3 护栏
- **关键词当调色盘、不当锁**：共鸣机制（毒/命中/破防/碎能/切换/惯性/治疗/课税…），**绝不点名英雄**（=固化 §8）。匹配交给加权 draft。
- **随机严控**：少量、低影响、**尽量只赌自己**；**赌对方允许但克制**；绝不让随机替代读心；重 RNG + 回路 → **PvE**。
- **干扰可达"元件层"**（道具栏 / 基础动作栏 / 信息层，本作独有结构）：PvP 放带 counterplay 的克制版；无解/重口版 → PvE 并标注。

### 0.4 潜在玩法身份（标签，非道具类别）
极端身份（纯小子 all-in / 盾狗 turtle…）**不是道具分类**，是"某道具 × 某英雄"**涌现**的标签。用途 = draft 偏置 + 玩家可读 + 设计自查"好组合存在"。详见 §5。

### 0.5 命名规范 —— 世界质感「寓言奇物」（定稿·2026-06-16）
> **总原则 = 强关联优先 + 寓言奇物味 + 适度幽默。**

**① 强关联（最高优先）**：物件的"现实功能"必须一眼对上道具的"游戏效果"——读名字就知道它干嘛。
- 反例：磁铁吸"能量"（错关联 + 科学词）/ 钥匙=穿防（太弱）/ 羽毛=护甲（无联系）。

**② 世界质感 =「寓言奇物」**：一个 **生肖 × 塔罗 × 命运** 的暖色绘本寓言世界里、会出现的**俏皮、有点活、有故事**的小物件。夹在"纯真实物件（飞镖）"与"修仙/西幻法宝"中间，往**绘本童话 + 一点命运占卜**偏。

- **✅ 这个味（正向词）**：童话 · 绘本 · 寓言 · 奇想 · 俏皮 · 命运 · 塔罗 · 占卜 · 星象 · 生肖 · 民俗 · 节庆 · 拟人 · 旧旧有故事的。
- **⛔ 红线（一踩就出戏）**：
  - 西幻套路（精灵 / 符文 / 巨剑 / 魔法书 / 龙骑士）
  - 修仙法宝（法宝 / 真气 / 丹药 / 玄X / X诀）
  - 现代 & 科学（电器 / 磁铁 / 黑洞 / 激光；**科学词 = 现代词**）
  - 纯平庸写实（没奇想加持的大白话物件）

**③ 虚构感两个旋钮**：
- **奇想名词**：拟人 / 动物 / 星象当道具（啄木鸟、风信鸡、算命先生的铜钱）。
- **故事形容词**：旧旧的 / 生锈的 / 走运的 / 倒霉的 / 命运的 / 算命先生的（顺带承担 adj 分层）。

**④ 东方平衡**：整体可俏皮、可西化点缀（啄木鸟、药水），但**适当掺东方色彩**——生肖（龟壳 / 风信鸡）、民俗（铜钱 / 纸老虎 / 红包 / 糖葫芦）、术语（先手 · 后手）。别全西、也别全国风。

**⑤ adj 分层（"xx的"）**：名词恒定、形容词分层 = 同物件越升越强。
- 升级线（分层）：**劣质 / 普通 / 上等** + 生命药水。
- 变体线（同物件不同花样）：**赌徒的 / 吸血的 / 淬毒的** + 飞镖。

**⑥ 自查三问**：① 读名一眼知道效果吗（强关联）② 踩红线了吗 ③ 好画 + 有点俏皮吗。三个都 yes 才用。

### 0.6 条目格式
> **「名」** `[维度·角色]` · Tier N · `EV≈x`
> **画面**：<好画的奇物，一句> · **效果**：<清楚一句，谁/何时/多少> · **用途**：<什么时候用、配什么>。〔序列：前/后/无关〕

### 0.7 规模与分布（初版 ~100 · 每版 +6 英雄 +≥18 道具）
| 层 | 目标数（初版） | 为何这个量 |
|---|---|---|
| Tier 1 | **~28–32** | 入门 + 安全网 + 便宜变量的广度 |
| Tier 2 | **~46–52（大头）** | 连携随英雄关键词组合爆炸，去流派化主体 |
| Tier 3 | **~18–22** | build-around / 遗物 / 炸弹 / 回路，高影响、精挑 |
| **合计** | **~100** | |

## §1 Tier-1 清单（润滑剂 ∧ 博弈变量 · ≈0.5 当量 · 与英雄无关 · 地板池）
> **基础版优化稿 = 13 件**（已按 §0.5 世界质感命名）。覆盖进攻/防御/能量/状态/干扰/导出；**节奏 tempo + 干扰"碎对手能"** 按约定推 T2 命名（T1 找不到既强关联又不踩红线的名）。**待 Eddy 微调 → 再扩到 ~30。**

### 1A 进攻
- **「生锈的飞镖」** `[进攻·填隙]` · `EV≈0.5`
  **画面**：一枚锈迹斑斑的小飞镖。 **效果**：对敌方出战造成 0.5 伤。 **用途**：最便宜的戳血/补刀；3 选 1 无脑安全选。〔无关〕〔强关联：飞镖=扎人=伤害〕
- **「先手」** `[进攻·填隙]` · `EV≈0.5`
  **画面**：一只伸出、抢先出击的手（与「后手」成对）。 **效果**：你这次攻击 +0.5 伤。 **用途**：贴在大波/多段前放大那一击。〔前〕〔强关联：先手=先发制人=进攻〕
- **「赌徒的飞镖」** `[进攻·随机]` · `EV≈0.5`
  **画面**：缠着骰子花纹的飞镖。 **效果**：你这次攻击抛币——正面 +1.0 伤、反面落空（手一抖飞偏）。 **用途**：搏一个高伤一击的赌注；赌自己、不抹对手的读。〔前〕〔强关联：飞镖=攻击 + 赌徒=赌〕
- **「啄木鸟」** `[进攻·破防]` · `EV≈0.5`
  **画面**：一只歪着头的啄木鸟。 **效果**：若对手本回合用「防」，你这次攻击**穿防**（被它啄穿了壳）。 **用途**：盲选赌对手会龟，专治缩防。〔前〕〔强关联：啄木鸟啄穿龟壳=破防〕

### 1B 防御
- **「龟壳」** `[防御·填隙]` · `EV≈0.5`
  **画面**：一只圆鼓鼓的乌龟壳。 **效果**：己方出战 +0.5 甲（额外血量层，先扣甲后扣血；真伤无视）。 **用途**：最便宜的保命垫，脆皮生存地板。〔无关〕〔强关联：缩进龟壳=护甲·生肖味〕
- **「后手」** `[防御·条件]` · `EV≈0.5`
  **画面**：一只收回、料敌待防的手（与「先手」成对）。 **效果**：若对手本回合「攻击」→ 你 +1.0 甲；否则无效（料定对手出招才严防）。 **用途**：防御版 yomi 赌——赌中对手出手就硬防；与先手（稳吃 +0.5 攻）成"稳 vs 赌"反差。〔无关·赌对手出招〕〔后手=后发制人=料敌而防〕*差异化：从纯 +0.5 甲（撞龟壳）改为条件 +1.0 甲的防御博弈*
- **「劣质生命药水」** `[防御·治疗]` · `EV≈0.5`
  **画面**：一小瓶浑浊的红药水。 **效果**：己方出战回 0.5 HP。 **用途**：续航地板；治疗维度入门件。**升级线**：劣质→普通→上等生命药水。〔无关〕〔强关联：生命药水=回血〕
- **「云朵」** `[防御·条件]` · `EV≈0.5`
  **画面**：一团软乎乎的小云。 **效果**：若对手本回合「大波」，你这次「防」临时升级为可挡大波一次（软云垫住大招）。 **用途**：盲选赌对手爆发，用便宜小防接住大招。〔无关〕〔强关联：软云=垫住大招〕
- **「算命先生的铜钱」** `[防御·对冲]` · `EV≈0.5`
  **画面**：算命先生掌中一枚卜卦铜钱。 **效果**：若对手本回合攻击 → +0.5 甲，否则 → +0.5 能（铜钱替你算到了对手下一手）。 **用途**：自适应对冲、降盲选方差，怎么读都不亏。〔无关〕〔强关联：占卜=预知=见机应变·东方味〕

### 1C 能量
- **「劣质法力药水」** `[能量·条件]` · `EV≈0.5`
  **画面**：一小瓶浑浊的蓝药水。 **效果**：本回合若你「攒」，额外 +0.5 能。 **用途**：给攒回合加速，蓄大波/道具时点。**升级线**：劣质→普通→上等法力药水。〔无关〕〔强关联：法力药水=能量〕

### 1D 状态
- **「毒蘑菇」** `[状态·填隙]` · `EV≈0.5`
  **画面**：一只红伞白点的毒蘑菇。 **效果**：敌方出战中毒，下回合 −0.5 HP（**自结算、不依赖命中**，故与任何英雄无关）。 **用途**：无条件延迟掉血，逼对手处理。〔无关〕〔强关联：吃了毒蘑菇=中毒掉血·童话经典〕

### 1E 干扰
- **「滑不溜手的香蕉皮」** `[干扰·填隙]` · `EV≈0.5`
  **画面**：一片油亮的香蕉皮。 **效果**：丢向敌方出战，其本回合攻击 −0.5 伤（脚下一滑）。 **用途**：盲选赌对手出手，削它这一击。〔无关〕〔强关联：踩香蕉皮=滑倒失手〕
- **「纸老虎」** `[干扰·诈唬]` · `EV≈0.5`
  **画面**：一只纸糊的张牙老虎。 **效果**：你的道具栏向对手**多显示 1 个假道具**，直到你下次用道具。 **用途**：污染你能控的公开信息，骗对手按不存在的道具预判。〔无关·赌自己〕〔强关联：纸老虎=虚张声势=诈唬·东方成语〕

### 1F 导出（跨维·灵活性税压到 0.5 以下）
- **「吸血的飞镖」** `[导出·进攻→防御]` · `EV≈0.5`
  **画面**：渗着红的飞镖。 **效果**：你这次攻击命中时回 0.5 HP。 **用途**：把进攻转成续航，PvE（永久掉血）远比 PvP 值钱。**飞镖变体**：赌徒的 / 吸血的 / 淬毒的。〔前〕〔强关联：飞镖=攻击 + 吸血=回血〕

### 1G 扩展批（🆕 2026-06-16 第二批 · 14 件 · 重点补东方色彩 + 试新机制）
> 红线：⚙️新机制**不抢基础操作的戏、最多与英雄持平**（都压在 ≈0.5、tame）。

**进攻**
- 🆕 **「淬毒的飞镖」** `[进攻·状态变体]` ⚙️ — **画面**：缠着绿汁的飞镖。 **效果**：命中则敌方下回合 −0.5 HP（毒），本身不直接造伤。 **用途**：把"毒"装上投掷载体；区别于毒蘑菇（这个要命中）。〔前〕〔飞镖=投掷 + 淬毒=施毒〕*新机制=飞镖载毒，毒值对位蛇之下*
- 🆕 **「走运的飞镖」** `[进攻·随机变体]` ⚙️ — **画面**：贴着红纸符的飞镖。 **效果**：0.5 伤；若你当前 HP 比对手低，改为 1.0 伤（绝地走运）。 **用途**：劣势翻盘件、鼓励搏命。〔前〕〔走运=时来运转〕*新机制=劣势加成，tame*
- 🆕 **「爆竹」** `[进攻·破防·东方]` — **画面**：一串点燃的红爆竹。 **效果**：对敌方出战 0.5 伤，**无视「防」**（炸开护体）。 **用途**：小额穿防直伤、戳龟缩；区别于生锈飞镖（这个炸穿防）。〔无关〕〔爆竹炸开=无视防御·东方〕*差异化：从纯直伤（撞生锈飞镖）改为穿防小直伤*

**防御**
- 🆕 **「糖葫芦」** `[防御·治疗·东方]` — **画面**：一串冰糖葫芦。 **效果**：回 0.5 HP，**并解除你身上全部毒/灼**（甜化苦）。 **用途**：回血 + 清自身 DoT（克毒蘑菇/灯笼/蛇毒）；区别于生命药水（这个带净化）。〔无关〕〔糖葫芦甜=化解苦涩·东方〕*差异化：从纯回血（撞生命药水）改为回血+自净化*
- 🆕 **「不倒翁」** `[防御·东方]` ⚙️ — **画面**：一只笑眯眯的不倒翁。 **效果**：本回合免疫对手对你的一次 debuff / 干扰（推不倒）。 **用途**：专克对面的干扰件，meta 反制。〔无关〕〔不倒翁=推不倒=不受扰〕*新机制=净化1次干扰，niche*
- 🆕 **「铜镜」** `[干扰·信息·东方]` ⚙️ — **画面**：一面古铜照妖镜。 **效果**：照破伪装——移除对手的假/隐藏道具效果（纸老虎·信鸽），并看清其真实道具栏 1 回合。 **用途**：专克对面的诈唬/藏牌流，恢复公开信息。〔无关〕〔照妖镜=照出原形=揭穿〕*差异化：从"蹭丑牛反弹"改为"反诈唬信息件"*

**能量**
- 🆕 **「红包」** `[能量·条件·东方]` — **画面**：一个鼓鼓的红包。 **效果**：本回合你不攻击，则回合末 +0.5 能（守成得利）。 **用途**：奖励守/过渡回合攒小钱，苟得不亏。〔无关〕〔红包=里面有钱=能量·东方〕
- 🆕 **「算盘」** `[能量·条件·东方]` ⚙️ — **画面**：一把噼啪作响的算盘。 **效果**：本回合你做一个费能动作（大波/大防），省 0.5 能。 **用途**：精打细算、卡能线时点。〔无关〕〔算盘=精打细算=省〕*新机制=单次省能0.5（条件件，不破能量特例）*

**节奏**（T1 试做：只奖励切换、**不免动作**，不抢午马/基础切换的戏）
- 🆕 **「七里靴」** `[节奏]` ⚙️ — **画面**：一双绣着云纹的快靴。 **效果**：本回合若你「切换」，下回合你的攻击 +0.5 伤（借势而上）。 **用途**：把切换接成进攻节奏；不免动作。〔无关〕〔快靴=移动=切换〕*新机制=切换→延迟进攻rider*

**状态**
- 🆕 **「灯笼」** `[状态·东方]` ⚙️ — **画面**：一盏点亮的红灯笼。 **效果**：敌方出战灼烧，下回合 −0.5 HP 且该回合无法回血（火烧着）。 **用途**：延迟掉血 + 封对面治疗；区别于毒蘑菇。〔无关〕〔灯笼火=灼烧·东方〕*新机制=DoT+封治疗，量对位皇后之下*

## §6 设计历程与决策理由（落档·2026-06-16 · 防未来重走弯路）
> 记录 **Eddy 对设计的补充**（超出/细化框架的拍板）+ **我的思考**（关键判断的 WHY）。这些是对话里的活决策，必须沉淀到文件。

### 6.1 Eddy 的设计补充（按拍板顺序）
1. **三层 = 来源 × 强度 × 趣味**：T1 从维度（润滑剂 ∧ 博弈变量）/ T2 从英雄关键词共鸣（**不点名**）/ T3 强力 build-around。**英雄相关道具 ≥ T2、强力 → T3**。
2. **命名 = 强关联优先（最高优先）**：物件现实功能 = 游戏效果、一眼对上。曾因弱关联（钥匙/骰子/磁铁）被否——原话"**这样改甚至不如第一版我否决掉的修仙命名，那个至少一眼看出作用**"。
3. **世界质感「寓言奇物」**（§0.5）：四轮收敛——v1 修仙 ✗（龙渊/玄武）→ v2 现代 ✗（创可贴/拳套）→ v3 科学+弱关联 ✗（磁铁/黑洞/钥匙；**科学词=现代词**）→ v4 寓言奇物 ✓。**锚世界（生肖×塔罗×命运绘本），不锚风格**；东方平衡（别全西/全国风）；要俏皮、好画。
4. **adj 分层**："xx 的"——名词恒定、形容词分层（劣质/普通/上等 + 生命药水），升级时名字+画面一起进化、易量产同系列。
5. **博弈变量贯穿所有 tier**；**随机严控**（尽量赌自己、赌对方克制、绝不替代读心，否则失去博弈乐趣）。
6. **干扰可达"元件层"**（对手道具栏/操作栏/信息）——本作独有结构（道具公开+动作盲选+道具锁电报）的专属玩法；重口进 PvE。
7. **玩法身份（纯小子/盾狗…）= 涌现潜在标签，非道具类别**（道具 × 英雄涌现）。
8. **遗物** = 充能制（如 3 用后碎）**或** 全局 buff（慎强）；只在 T3。
9. **🔑 广度 > 单关键词深度**：别对单一关键词（如毒）过度集中，否则 3 选 1 抽到 3 张同系列 = 死牌（违 §3 禁凑数 / §8 draft 健康）。每关键词整池 ≤4–5、铺开多机制。
10. **冗余件差异化（不砍）**：撞车的改出独特角度（后手→条件甲博弈 / 爆竹→穿防 / 糖葫芦→净化 / 铜镜→反诈唬）。
11. **D1 = 道具伤害算"命中"**（触发 on-hit，gate 在必须连接）；**D2 = 道具的毒 = 巳蛇引爆毒**（同一种）。
12. **不要限定死框架**：保留设计**创意/好玩**道具的空间（可破框架、忽视规则、不太超模但主打好玩）——**下一步专门做**。
13. （收尾期）**`on_switch_in` 开局不触发**（维持现状·马兔一致）——见 `active.md` 收尾任务。

### 6.2 我的思考（关键判断的 WHY）
- **波波攒 = yomi 游戏** → 道具最高价值是"给盲选博弈加变量"，不是 +数值棒。故 T1 不是无聊润滑剂，而是便宜的博弈变量层。
- **强关联 = 可读性 = 避免选择瘫痪**；也是 §8 加权 draft 能工作的前提（一眼读懂才选得动）。
- **广度课的结构理由**：浅而广 build（§3）无容错冗余，每槽要么高影响要么强联动；池子若窄关键词刷屏，draft 必出死牌 → "机制广度"是硬约束，不只是风味。
- **D1/D2 的取舍**：让道具接入英雄机制（命中/毒）= 泛连携成立、自检 Q1/Q3 大涨；代价 = 引擎要把道具伤害走 on-hit 管线 + gate 防 proc 脱缰。
- **T3 超模管控**：每件必带 gate（条件/代价/充能/PvE 限定），守"不许无条件压制"铁律；穿大防件只授慢蓄/公开 condition payoff（铁则）。
- **数量诚实（84/100）**：差的 ~16 留给"每版 +6 英雄 = 新关键词"自然增长，比现在硬堆同质件健康（Eddy 的广度课直接支持此选择）。
