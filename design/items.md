## §0 道具设计规范（定稿）

### 0.1 定位（不变项）
- **一次性消耗**；用完花 **1 能 refill** 一个 1 道具。**对对手公开**。
- **揭示前随动作盲选提交** = 主动计划件（非揭示后反制）；**不占动作槽**、用时免费、一回合用量不限。
- **默认自动指向**（伤→敌出战 / 甲·盾·治疗→己出战 / debuff→敌出战）；特殊道具可特指。
- **顺序机制**：一回合 = 有序序列 `[道具…, 动作, 道具…]`，前/后玩家编排；己方按序结算，**跨玩家仍同时独立结算（无先后手、可同时死=平局）**。

### 0.2 三层 = 来源 × 强度 × 趣味（汇率 §4.2：道具 1 能 = 0.5 HP）
| 层 | 来源 | 强度带 | 性质 |
|---|---|---|---|
| **Tier 1** | 从**维度**出发 | **≈0.5 HP 当量** | 润滑剂 ∧ 博弈变量；与英雄无关、地板池、安全网 |
| **Tier 2** | 从**英雄关键词 + 共鸣关键词**（**不点名**） | **≈1.0 HP 当量** | 连携 / 导出 / 元件层干扰；1+1>2 的钱在这层（**清单大头**） |
| **Tier 3** | **强力 / build-around** | **超模或带条件/负面** | 自成核 + 遗物 + 重口干扰 + 回路(仅PvE) |

- **变强 = 只升级不合成**：1→2 花 1 能、2→3 花 2 能（升级锁 1 回合）。
- **博弈变量是跨层风味**（三层都能做变量件，强度按本层带）。**收益带守死**：每件标 EV，超标必带条件/负面（§4.4）；跨维件压到单维基准以下或抬费。
- **能量特例**：直接 +能 须 ≥2 能或带条件 → Tier-1 能量件只能是条件件。

### 0.3 护栏
- **关键词当调色盘、不当锁**：共鸣机制（毒/命中/破防/碎能/切换/惯性/治疗/课税…），**绝不点名英雄**（=固化 §8）。匹配交给加权 draft。
- **随机严控**：少量、低影响、**尽量只赌自己**；**赌对方允许但克制**；绝不让随机替代读心；重 RNG + 回路 → **PvE**。
- **干扰可达"元件层"**（道具栏 / 基础动作栏 / 信息层，本作独有结构）：PvP 放带 counterplay 的克制版；无解/重口版 → PvE 并标注。

### 0.4 潜在玩法身份（标签，非道具类别）
极端身份（纯小子 all-in / 盾狗 turtle…）**不是道具分类**，是"某道具 × 某英雄"**涌现**的标签。用途 = draft 偏置 + 玩家可读 + 设计自查"好组合存在"。详见 §5。

### 0.5 命名规范 —— 奇幻调性（2026-06-17 重校准 · 取代旧「寓言奇物」执行）
> **核心 = 奇幻感。** 波波攒是 **生肖 × 命运** 的暖色绘本**奇幻**世界——道具必须有奇幻味，**绝不能掉进武侠 / 平庸写实**（这是上一版被推翻的根因）。

**必过 4 关（缺一即废）：**
1. **是一件"物件"** —— 拿得起、摆得出的小东西。⛔ 动作 / 计策 / 载具 / 抽象（顺手牵羊 · 空城计 · 战车 · 攻城槌）。
2. **常用词**（反面 = "**脱节**"）—— 大众一眼懂、打字找得到。⛔ 生僻（连珠弩 · 白蚁罐 · 毒囊 · 绷弦 · 貔貅 · 锥 · 楔）、⛔ 编造复合词（困兽符 · 孤注骰 · 百毒瓮 · 破阵箭）。
3. **强关联** —— 物件现实功能 = 游戏效果，一眼对上。⛔ 名不符效果（红绳=易伤 · 不倒翁=免疫 · 不灭灯=毒）。
4. **奇幻不出戏** —— 见调色盘。

**调色盘 = 三股混用（关键：别陷入单一风格）：**
- **RPG / 童话奇幻**：药水 · 护盾 · 魔杖 · 精灵 · 咒语 · 妖火 · 吸血鬼 · 水晶 · 宝箱 · 斗篷…（**西幻可以用，只是别全西幻**）。
- **命理 / 占卜**：铜钱 · 卦 · 签 · 纸扎 · 锦囊 · 水晶球 · 命运的…。
- **俏皮命运形容词**：走运的 · 赌徒的 · 贪婪的 · 诅咒的 · 算命先生的 · 失控的…（顺带承担 adj 分层）。

**红线（Eddy 逐条点过的）：**
- ⛔ **武侠 / 平庸写实**：匕首 · 护甲 · 铁锁 · 马鞭 · 钱袋（"太武侠、没奇幻感" = 最核心的坑）。
- ⛔ **生搬硬套东方民俗**（为东方而东方、弱关联）：糖葫芦 · 红包 · 算盘 · 灯笼 · 拨浪鼓 · 貔貅 · 黄历 · 石狮子。
- ⛔ **现实 / 现代 / 军事 / 政治**：撬棍 · 投石机 · 沙袋墙 · 攻城槌 · 关税令 · 火药桶（**世界无枪械火药**）。
- ⛔ **太普通 / 幼稚 / 无道具感**：啄木鸟 · 云朵 · 纸老虎 · 百宝箱 · 不倒翁。

**保留**：adj 分层（劣质 / 普通 / 上等 + 药水线 · 护盾线 · 飞镖线）；**同一物件名全表只出现一次**（升级线 / 同类药水例外）；跨 tier 可复用、靠画面区分。

**锚点（验收过的味道）**：算命先生的铜钱 · 赌徒的硬币 · 锦囊 · 毒蘑菇 · 吸血鬼的獠牙 · 破旧的护盾 · 狂暴药水 · 妖火 · 水晶球 · 贪财的小精灵。

### 0.9 共鸣机制（顺序机制专属 · 🆕 2026-06-17 · #8）
> 源自 Eddy #8 草案，落地为本作**独有结构**（顺序序列 §D4 + 系间乘算 §6）的招牌玩法。
> **规则**：带〔共鸣〕标记的道具，**单独打出 = 基础（弱/无）效果**；同一回合序列里**与另一个〔共鸣〕元件一起打出 → 触发共鸣（强效果）**。两种触发：① **道具+道具**（≥2 件〔共鸣〕同回合）② **道具+动作**（〔共鸣〕道具 + 指定基础动作同回合）。
> **为何 PvP 安全**：单出无收益 → 必须**双 commit**（占两个序列位 / 两份资源）才放 = 成本真实、非免费 burst；且揭示前盲选提交（对手可预判）。是"1+1>2"的显式化。
> 首版 3 件见 §2L；待实装验证手感再扩。

## §1 Tier-1 清单（润滑剂 ∧ 博弈变量 · ≈0.5 当量 · 与英雄无关 · 地板池）
> **26 件**（铜镜删 + 毒刺撞蛇删 · 奇幻调性命名）。覆盖进攻/防御/能量/节奏/状态/干扰/导出/随机。名字已按 §0.5 奇幻调性 + §0.8 映射更新（2026-06-17）。

### 1A 进攻
- **「生锈的飞镖」** `[进攻·填隙]` · `EV≈0.5`
  **画面**：一枚锈迹斑斑的小飞镖。 **效果**：对敌方出战造成 0.5 伤。 **用途**：最便宜的戳血/补刀；3 选 1 无脑安全选。〔无关〕〔强关联：飞镖=扎人=伤害〕
- **「先手」** `[进攻·填隙]` · `EV≈0.5`
  **画面**：一只伸出、抢先出击的手（与「后手」成对）。 **效果**：你这次攻击 +0.5 伤。 **用途**：贴在大波/多段前放大那一击。〔前〕〔强关联：先手=先发制人=进攻〕
- **「赌徒的硬币」** `[进攻·随机]` · `EV≈0.5`
  **画面**：一枚边缘磨亮的赌运硬币。 **效果**：你这次攻击抛币——正面 +1.0 伤、反面落空（手一抖偏了）。 **用途**：搏一个高伤一击的赌注；赌自己、不抹对手的读。〔前〕〔强关联：硬币=抛币 + 赌徒=赌〕
- **「破盾咒」** `[进攻·破防]` · `EV≈0.5`
  **画面**：一道嗤嗤灼蚀的破盾咒文。 **效果**：若对手本回合用「防」，你这次攻击**穿防**（咒文蚀穿其护盾）。 **用途**：盲选赌对手会龟，专治缩防。〔前〕〔强关联：破盾咒=对手举盾时蚀穿=破防〕

### 1B 防御
- **「破旧的护盾」** `[防御·填隙]` · `EV≈0.5`
  **画面**：一面磨损卷边的旧护盾。 **效果**：己方出战 +0.5 甲（额外血量层，先扣甲后扣血；真伤无视）。 **用途**：最便宜的保命垫，脆皮生存地板。**升级线**：破旧→坚固护盾。〔无关〕〔强关联：护盾=挡伤·RPG〕

## §6 设计历程与决策理由（落档·2026-06-16 · 防未来重走弯路）
> 记录 **Eddy 对设计的补充**（超出/细化框架的拍板）+ **我的思考**（关键判断的 WHY）。这些是对话里的活决策，必须沉淀到文件。

### 6.1 Eddy 的设计补充（按拍板顺序）
1. **三层 = 来源 × 强度 × 趣味**：T1 从维度（润滑剂 ∧ 博弈变量）/ T2 从英雄关键词共鸣（**不点名**）/ T3 强力 build-around。**英雄相关道具 ≥ T2、强力 → T3**。
2. **命名 = 强关联优先（最高优先）**：物件现实功能 = 游戏效果、一眼对上。曾因弱关联（钥匙/骰子/磁铁）被否——原话"**这样改甚至不如第一版我否决掉的修仙命名，那个至少一眼看出作用**"。
3. **世界质感「寓言奇物」**（§0.5）：四轮收敛——v1 修仙 ✗（龙渊/玄武）→ v2 现代 ✗（创可贴/拳套）→ v3 科学+弱关联 ✗（磁铁/黑洞/钥匙；**科学词=现代词**）→ v4 寓言奇物 ✓。**锚世界（生肖×命运绘本），不锚风格**；东方平衡（别全西/全国风）；要俏皮、好画。
4. **adj 分层**："xx 的"——名词恒定、形容词分层（劣质/普通/上等 + 生命药水），升级时名字+画面一起进化、易量产同系列。
5. **博弈变量贯穿所有 tier**；**随机严控**（尽量赌自己、赌对方克制、绝不替代读心，否则失去博弈乐趣）。
6. **干扰可达"元件层"**（对手道具栏/操作栏/信息）——本作独有结构（道具公开+动作盲选+道具锁电报）的专属玩法；重口进 PvE。
7. **玩法身份（纯小子/盾狗…）= 涌现潜在标签，非道具类别**（道具 × 英雄涌现）。
8. **遗物** = 充能制（如 3 用后碎）**或** 全局 buff（慎强）；只在 T3。
9. **🔑 广度 > 单关键词深度**：别对单一关键词（如毒）过度集中，否则 3 选 1 抽到 3 张同系列 = 死牌（违 §3 禁凑数 / §8 draft 健康）。每关键词整池 ≤4–5、铺开多机制。
10. **冗余件差异化（不砍）**：撞车的改出独特角度（后手→条件甲博弈 / 闪电(原爆竹)→穿防 / 解毒药水(原糖葫芦)→净化；铜镜后删=伪装只1回合价值低）。
11. **D1 = 道具伤害算"命中"**（触发 on-hit，gate 在必须连接）；**D2 = 道具的毒 = 翼火引爆毒**（同一种）。
12. **不要限定死框架**：保留设计**创意/好玩**道具的空间（可破框架、忽视规则、不太超模但主打好玩）——**下一步专门做**。
13. （收尾期）**`on_switch_in` 开局不触发**（维持现状·马兔一致）——见 `active.md` 收尾任务。

### 6.2 我的思考（关键判断的 WHY）
- **波波攒 = yomi 游戏** → 道具最高价值是"给盲选博弈加变量"，不是 +数值棒。故 T1 不是无聊润滑剂，而是便宜的博弈变量层。
- **强关联 = 可读性 = 避免选择瘫痪**；也是 §8 加权 draft 能工作的前提（一眼读懂才选得动）。
- **广度课的结构理由**：浅而广 build（§3）无容错冗余，每槽要么高影响要么强联动；池子若窄关键词刷屏，draft 必出死牌 → "机制广度"是硬约束，不只是风味。

## §7 平衡检查（2026-06-17 · 设计阶段结构核对）
> 方法 = 拿 §4 标准值 + §4.2 汇率 + §4.4 偏移/能量特例/"不许无条件压制" + §4.6 二元铁则 逐项过 91 件。**实际数值校准待实装试玩（§4.5）**，本节只做"规则层结构核对 + 待观察清单"。

**✅ 结构核对：无违规。**
- **能量特例（§4.4）**：所有直接产能件都带条件或 T3≥2 能（魔力水晶=不攻击 / 省力咒=费能动作 / 淬炼的魔石=受伤 / 汲魔符·魔力源泉=命中·防御成功 / 上等法力药水 T3 升级费 2 能 / 火球术·天雷=弃能）。
- **二元铁则（§4.6）**：反弹件（带刺的护盾 / 应和的钟）= 反弹伤害、非"吸收点数"；护盾/护甲 = 额外血量层；索魂咒穿甲 = 无视护甲层但仍受"挡不挡"约束（挡住=归零）。**无临时护甲吸收模型**。
- **跨维件压基准（§4.4）**：导出网（吸血鬼的獠牙 / 汲魔符 / 魔力屏障 / 蓄力符 / 血祭 / 带刺的护盾）均"命中或弃资源"为条件，压在汇率内。
- **不许无条件压制**：锋利的飞镖 1.0 伤 = 累计 2 能道具（汇率 1.0 HP），不强于波（1 能占动作）；无任何免费碾压件。

**🟡 待实装观察清单（规则内，手感/数值待试玩）：**
1. **应和的钟**（共鸣 +1.0 甲 + 反弹 0.5 = 1.5 防御价值/防御回合）——共鸣 payoff 偏厚，若试玩偏强 → 反弹砍到"按所挡级别"或去掉。
2. **回响的咒**（共鸣 → 波穿防 +0.5 ≈ 1.5 穿防/回合）——给波低价穿防，盯是否过度替代大波。
3. **双生星**（共鸣 anchor·占一槽只给别的共鸣件 +0.5）——可能偏弱；且回响的咒(需攻)/应和的钟(需防)**同回合互斥**（一动作槽）→ 共鸣最多 2 件生效 = 自限健康，但 anchor 价值待观察。
4. **索魂咒**（穿甲）——情境件：对无护甲目标 ≈ 白板、对堆甲对手值钱；EV 方差大，draft 偏置需标"反甲"。
5. **狂舞之刃**（T3 遗物·每攻 +1 命中 ×3）= 连环咒×3，喂 on-hit 翻倍；盯毒/破甲 build 的爆发上限。
6. **驱逐令**（强制切换）——强干扰，已圈"偏 PvE / 限定模式"，PvP 慎放。
7. **幸运四叶草 / 绝境的魔咒**——同为"劣势加成"主题，同队抽到略撞（非平衡问题，记一笔）。
8. **命名待微调**（关联偏弱，Eddy 逐个改）：幸运四叶草(攻击) / 省力咒 / 分神的铃铛 / 魔力源泉 等"经济·抽象修正"类。

**结论**：91 件在框架规则内自洽——无超模、无违二元铁则、无无条件压制；数值微调全部留实装试玩（§4.5 主旋钮：被动能量量 / 各 +0.5 增量 / 共鸣 payoff 厚度）。
