# 英雄动画方案（波波攒 · 46 英雄 · 个人项目）

> **状态**：方向探讨（2026-05-24，Eddy + Claude brainstorm 产出）。主推=剪纸绑定，待 MVP 单英雄试装验证后转为正式管线。
> **关联**：`design/heroes.md`（46 英雄设计）、`src/battle/hero_data.gd`（现有 per-hero spritesheet 字段）。

## 0. 约束前提
- 个人开发者，英雄池最终 46 个；**已完成 46 张全身静态立绘**
- 每英雄**独立武器** → 攻击/技能动作无法简单复用同一套位移
- 观感目标：理想是《杀戮尖塔》级独立动画；现实底线 = **能做完**
- 品类：同时回合制 1v1 对拼 + 3 英雄切换
- 终局可能上**手机端、prefer 竖屏**

## 1. 核心认知（先纠正问题定义）
- 真正瓶颈不是"缺场景"，是 **per-hero 逐帧 spritesheet 模型**（46 × idle/attack/hit/defend/defeat/技能 ≈ 276 套），solo 做不完，且本品类不需要。
- 参照：**StS 自己也没全做**——玩家 5 角色才有逐帧，敌人多为少帧 + 程序化位移。
- **打击感 = juice**（顿帧 / 震屏 / 闪白 / 粒子 / 数字 / 音效），写一次全员复用，比逐帧更划算。
- **同时结算是省力红利**：双方"向中心对冲 → clash 闪光"的演出**只编排一次**，不分先后手，省一半动画。

## 2. 五个方案（从重到轻）

**方案 1 · 全员逐帧手绘动画（理想 / StS 级）**
- 做法：每英雄手绘 idle/attack/技能等帧序列。
- 每英雄工作量：极高（美术活，画功门槛高）。
- 短板：**46 个 solo 基本做不完**（StS 才 5 个玩家角色，你是 9 倍）。→ 理想但否决。

**方案 2 · 剪纸 / 骨骼绑定（Cutout Rig）← 推荐**
- 做法：把**已有静态立绘切块**（重点切出"持武器手臂 + 武器"），Godot 里搭简单骨架，用 **~5 套通用动作模板**摆动骨架。**武器是绑在手臂块上的 → 同一套挥击，刀劈/枪刺/杖砸各不相同，差异化由武器免费提供**。
- 每英雄工作量：低-中（切图 + 补绘遮挡 + 套模板 ≈ 15-30 分钟装配，**不画新帧**）。
- 短板：转身/夸张形变弱于逐帧；切图补绘有体力活；需学一次骨架（技术活，程序员主场）。
- 评价：**唯一兼顾"能做完 + 独立武器观感 + 侧视对决台演出 + 朝向无关"的方案**。

**方案 3 · 静态立绘 + 通用 tween/VFX（无 rig）**
- 做法：立绘整体做前冲/击退 tween + 共享 VFX + juice，不切块不绑定。
- 每英雄工作量：极低（用现成立绘，0 额外美术）。
- 短板：**攻击不区分武器动作**（人在台上但"不挥武器"略假）——已指出不可接受。
- 用途：可作 **MVP 占位档 / 验证好玩用**，或最终的退路。

**方案 4 · 卡牌对决桌**
- 做法：英雄=卡牌对摆，攻击=卡前顷/发光/数字飞出。每英雄 1 卡面（=立绘）。
- 每英雄工作量：极低；天然适配竖屏。
- 短板：**改变了"舞台上两人对打"的构想，缺人物演出**——想避免。

**方案 5 · 极简头像 + UI 演出**
- 纯头像 + 大数字 + VFX。最省，但最不"游戏场景"。→ 排除。

| **2 剪纸绑定** ✅推荐 | 低-中 ★★★★ | ✅★★★★★ | ★★★★ | ★★★★ | ★★★★ | ★★★★★ | 中 |
| 3 静态+juice | 极低 ★★★★★ | ✅★★★★★ | ★★★ | ★★★ | ★★★(略假) | ★★★★★ | 低 |
| 4 卡牌桌 | 极低 ★★★★★ | ✅★★★★★ | ★★★ | ★★★ | ★(改构想) | ★★★★★ | 低 |

## 4. 支撑系统（任何方案都该叠加的省力杠杆）
1. **通用 juice 层**：顿帧/震屏/闪白/击退/粒子/数字——写一次，46 全员复用。
2. **风味标签 VFX**：46 技能各打 1 标签（火/雷/圣光/暗/毒/物理斩/能量/治疗/buff/debuff，~10 种），**只做 ~10 套 VFX**，同标签复用。
3. **idle = 呼吸 shader / 2 骨微晃**：0 额外美术，静态立绘也"活"。
4. **hit / 防 / 阵亡 / 攒 = tween + 共享 VFX**：0 额外英雄美术。
5. **武器动作模板 5 套**（见附录 A）：46 武器归类，狮子 1 个开小灶。
6. **AI 当加速器**：切图分割 / 补绘遮挡 / 分块（能帮）；全自动出战斗 rig（截至 2026 初还不能，出的是视频非可控 rig）。
7. **分级投入**：全员廉价档；最多 0-3 招牌英雄开小灶。
8. **MVP 先 8-12 英雄**走通管线、验证好玩，美术后置。
9. **rig 朝向无关**：绑定一次，横屏(PC) / 竖屏(手机) 都能用，只重排舞台与 UI。

## 5. 推荐结论
**主推方案 2（剪纸绑定）+ 第 4 节全套支撑系统。**
- 取舍：非逐帧，转身/夸张形变逊于手绘，但**90% 观感、20% 成本，且能做完**。
- 路线：先用 1 个普通英雄（非狮子）走通"切块→绑骨→套模板→上对决台"管线，亲手验证工作量与观感 → 再 MVP 子集 → 批量 46。
