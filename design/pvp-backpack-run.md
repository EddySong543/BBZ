# PvP 背包构筑与连续对战 Run

> ⏸ **状态覆盖（2026-08-31）：**当前 PvP 产品线与入口已冻结。本文保留为未来好友对战参考，不约束当前 PvE Demo。
> **状态：局内取得与使用费已通过；Run 经济仍为候选骨架。** 当前目标规则为手动免费三选一、公开锁定一回合、逐件 `0–4` 能使用费；战备方案、连续 PvP Run、搜刮、临时战备、撤离、匹配和 Rank 的具体数值仍待验证。
> **用途：**记录 PvP 背包与连续对战规则。当前代码的旧 1 能补充、免费使用与旧槽位生命周期只代表迁移前现状，不再代表目标设计。
> **2026-08-30 当前标准：**取得、公开、锁定、使用费和冲突裁定以 [`2026-08-30-item-system-current-standard.md`](../docs/superpowers/specs/2026-08-30-item-system-current-standard.md) 为准；取得与实例边界见 [`2026-08-30-pvp-item-acquisition-instance-boundaries.md`](../docs/superpowers/specs/2026-08-30-pvp-item-acquisition-instance-boundaries.md)；五维平衡见 [`2026-08-30-item-four-axis-balance-design.md`](../docs/superpowers/specs/2026-08-30-item-four-axis-balance-design.md)。

## 1. 设计目标

- 把道具从纯局内随机奖励提升为赛前构筑，使玩家能够围绕英雄、公共动作和道具组合建立稳定计划。
- 背包形状承担道具的构筑价格；玩家通过空间取舍决定能够携带哪些道具，而不是额外建立邻接或朝向系统。
- 保留同时选招与读招核心；免费随机候选提供组合宽度，公开锁定一回合与逐次使用费提供预判和能量取舍。
- 用连续对战、完整搜刮和主动撤离形成“穷装入场、战后补给、搜到即走或继续冲高胜”的 PvP Run。
- 胜者必须能通过搜刮补回多场战斗中的真实道具消耗；败者可以损失局外资产，但前两次失败不能因此立刻失去当前 Run 的构筑与操作空间。

## 2. 赛前战备方案

- PvP 开始前选择一套已保存的**战备方案**。方案保存：英雄队伍、背包内容、道具摆放位置和保险格内容。
- 不要求每场匹配前重新摆包；后续界面支持多个方案槽、沿用上次方案、复制、改名、自动整理和分享。
- 匹配成功后锁定方案，不能看见对手信息后再修改。
- 道具形状会大量复用；形状只承担空间价格，不增加邻接、朝向、连线或图案奖励。
- 每一种完全相同的道具最多携带 2 件。
- 保险格沿用 PvE 的独立保险位思路；其中的真实道具不参与对手搜刮。保险格具体尺寸继续与 PvE 规则统一校准。

## 3. 稀有度、成品与占格

- T1、T2、T3 成品都可以作为真实资产进入仓库与赛前战备方案，不依赖通用图纸或隐藏合成配方。
- 稀有度不决定固定耐久、固定形状或默认格数。每件道具根据物件形态与预期密度身份单独确定耐久和占格。
- 可以存在大型廉价 T1，也可以存在单格、高强、高价 T3；高单格价值是允许存在的搜打撤奖励。
- 三档成品都通过同一套真实背包免费三选一进入公开框；稀有度不决定候选资格，也不设通用升级准入。

## 4. 局内取得、信息与可用时机（已批准基线）

- 双方以 3 个空公开框开局，不预置可用道具。每回合行动规划前先经过同步抽取门；每人至多手动免费抽取一次，机会不累计。
- 候选从自己的真实战斗背包按 UID 无放回展示 `min(3, N)` 件。玩家选 1 件或放弃；同名不同 UID 可以同时出现，不足 3 件不补假道具。
- 候选固定，关闭重开或重连不刷新。选中实例进入编号最小的空框；未选实例继续留在背包。双方最终结果在同一权威节拍公开，然后才开始完整行动规划。
- 第 `R` 回合取得的道具锁定本回合，第 `R+1` 回合规划阶段才可使用。有剩余耐久的占框道具不能免费替换。
- 耐久归零的道具到本回合最终清理时才腾框，下一回合重新提供抽取资格；抽取超时放弃，行动超时提交“攒”，断线不暂停阶段时钟。
- 每件道具每次使用支付自身 `0–4` 能费用，大部分为 `1–2`；随后扣 1 耐久再结算。前件产能可支付后件，多耐久件每次都重新付费。
- T1/T2/T3 均可进入同一候选系统；旧“固定 1 能抽取、使用免费、抽后即用、指定起手、通用升金”全部废止。
- 真实、Run 临时和本场临时实例分开记录；战斗内交换只改控制权，不直接改变永久资产归属。复制效果不生成实例，复制实体必须使用新 UID。

## 5. 连续对战 Run

- 一次 PvP Run 采用最多 12 场对战、最多承受 3 次败场的结构；第 3 次失败后强制出局。
- 每场结束后，玩家都可以选择继续匹配或立即撤离。
- 每次胜利获得：
  1. 一次 Run 临时道具三选一；
  2. 一次完整搜索败者背包的机会。
- 系统三选一所得不能带出、出售或转成真实资产；永久道具只从真实搜刮或另设的少量里程碑产生，避免 12 胜凭空铸造 12 件资产。
- 每次失败增加 1 次败场。前 2 次败场启用临时战备保护；第 3 次失败不再生成临时道具，按失败出局结算。

## 6. 完整搜刮

- 胜者可以查看败者背包中全部可搜刮真实道具，而不是从随机候选中选择。
- 胜者可以拿走任意件可搜刮道具，不设人为件数上限；实际携带量只受胜者当前背包形状与容量限制。
- 搜刮所得只能装入当前 Run 的背包，不能把装不下的道具直接传送到局外仓库。
- 保险格中的道具不参与搜刮。
- 每场结束先把仍有耐久的道具按原归属退回背包或保险格，再进行搜刮。除保险格外，本场曾进入公开框的真实道具也属于搜索对象，不能提前抽出贵重物规避损失。
- 胜者看见并拿走实例的当前/最大耐久，搜刮不会把残损件补满。快速击败对手通常会留下更多耐久；拖入长局则双方消耗更多，可搜刮总价值自然下降。
- 搜刮到的真实道具在当前 Run 内可以继续使用；成功撤离后才正式进入胜者局外仓库。没有交易行，入库后只允许自用或交给 NPC 固定回收。

## 7. 前两次败场：同名临时战备件

核心规则：

> 胜者拿走真实道具；败者在原位置获得一件仅限本次 Run 使用的同名临时道具。

- 第 1、2 次败场中，被对手搜刮走的每件真实道具都会在败者原位置生成一件同名临时战备件。
- 临时战备件的形状、效果、最大耐久与**被拿走时的剩余耐久**都与原实例一致，可以正常抽取、使用并维持原有英雄与道具 combo，不能借失败补满。
- 临时战备件不代表所有权，不能再次被搜刮、不能放入保险格、不能进入局外仓库、不能出售给 NPC。
- 临时道具产生的任何临时产物继续保留临时属性，不能洗成真实资产。
- 临时道具按同一耐久规则扣减，归零后销毁且不会再次补发。
- 玩家在后续胜利中获得的真实道具可以替换临时战备件；只有真实道具可以随撤离入库。
- 主动撤离、完成 12 场或第 3 次失败出局时，所有临时战备件消失。
- 第 3 次失败不生成同名临时战备件：失败即出局，不再为下一场保留构筑。

这条规则把两种后果拆开：失败会造成真实资产损失，但前两次失败不会立即摧毁当前 Run 的战术和操作能力。

## 8. 系统临时补给

- 同名临时战备件只补回“被对手拿走”的道具；玩家自己在战斗中消耗的道具不会按原样返还。
- 每场结算后检查下一场所需的**战备下限**。若可抽取道具不足，系统自动用固定基础池中的 D1/T1 临时普通道具补齐。
- 系统临时补给可以正常抽取和使用，但不能入库、保险或出售；Run 结束时消失。
- 这层补给只保证玩家仍能使用完整道具系统，不保证原组合与高稀有度强度。
- 战备下限、补给池内容和自动整理规则待实测单场平均消耗量后确定。

## 9. 撤离、结算与 Rank

- 玩家每胜或每败一场后都可以撤离；主动撤离不增加额外罚金。
- Rank 在 Run 结算时按最终胜场与败场关系计算，不把单场失败立即重复扣分。
- 当胜场等于败场时，Rank 变化为 0。
- 当胜场比败场多 1 场时开始获得少量 Rank；之后随胜差和深入程度曲线上升，鼓励玩家继续战斗并尝试把败局打回来。
- 当胜场少于败场时的具体扣分曲线、12 场完成奖励和第三败结算数值另立平衡表。
- Rank 不直接按搜刮价值或击败速度计算，避免竞技目标退化为刷装备。
- 前两次败场的同名临时战备件降低即时挫败感；玩家可以继续使用原计划争取真实战利品，再决定何时撤离。

## 10. 匹配规则

匹配按以下优先级逐级放宽：

1. 相同胜场且相同败场；
2. 相同胜场；
3. 邻近战绩，再结合隐藏实力分扩大范围。

- 同一次 Run 内避免重复匹配同一对手。
- 背包价值只能作为极端差距保护或末级参考，不能完全抹平穷装入场与高价值战备的差异。
- 正常显示价值、可兑现价值与匹配战力分账：临时件正常显示同名真实件及当前耐久的估值，可兑现价值为 0，并按实际战斗能力计入匹配。
- 对手背包仅显示黑色轮廓；匹配阶段不能泄露具体构筑。

## 11. 藏品、产出与回收

- 增加极稀有、无法携带的永久藏品。每件藏品绑定一种固定道具并挂机生产该道具。
- 藏品拥有储存上限；达到上限后停止生产，领取产物后恢复计时。
- 藏品本身不能进入背包、不能被搜刮、不能交易。
- 不设置玩家交易行；多余真实道具只能自用或交给 NPC 按固定价格回收。
- 满耐久价格和残损价值逐件确定，统一见五维平衡基准；不能再按稀有度、耐久或格数套固定公式。
- 藏品负责长期定向恢复常用构筑，系统临时补给负责当前 Run 不断档，两者不能相互替代。
- 普通基础道具仍需保留低门槛来源，不能要求玩家必须先获得极稀有藏品才能正常参战。

## 12. 设计护栏

- 局外构筑增强了组合确定性，但不能替代同时选招与能量决策；公开锁定一回合必须保留为可读、可防的信息窗口。
- 不增加邻接、连线、朝向和专属形状奖励，避免背包层压过战斗层。
- 新英雄与新道具可以利用“构筑形状、抽取顺序、临时所有权、搜刮与撤离”扩展设计，但优先继续作用于公共动作、能量、生命、切换、目标、状态和结算顺序。
- 不大量增加需要战斗中长期记忆的常驻状态；背包与 Run 状态主要在局外/战后界面查询。
- 胜者获得的是真实资产与后续选择，败者前两败保留的是临时使用权；不得把临时战备件误写成永久复制，避免经济通胀。
