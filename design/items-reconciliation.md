# 道具三方对账（items.md ↔ items-list.md ↔ 代码）

> **性质**：道具系统三个真相源之间分叉的**对账底稿 + 归一建议**。一次性除尘产物（2026-06-20），供后续「三方归一」决策与实装参考。
> **结论一句话**：**机制层基本对齐**（代码 70 件框架件已实装、删除纪律零残留），**烂账全在命名层**（`items.md` 落后一代旧奇幻名 / 代码 `id` 拼音化石化 / 同一件三个名）。
> **当前定位**：`design/items-list.md` = **当前清单真相源**（Eddy 维护·98 件 + 系统操作层待筛）；`src/battle/item_catalog.gd` = 实装真相源（70 件，显示名已对齐 items-list）；`design/items.md` = **历史快照·已被取代**（见其文首状态章，仅作溯源）。
