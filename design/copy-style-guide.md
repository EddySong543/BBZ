# 玩家可见文案风格规范

> 适用范围：英雄技能描述、道具描述、所有玩家可见的效果文本（tooltip / 图鉴）。
> 目标优先级：**① 风格一致 > ② 一句话让玩家一眼看懂 > ③ 关键词可复用。**

## 一、写法规则

1. **主语用「该英雄」**（英雄技能描述），不写具体英雄名、也不用「它 / 他 / 其」。取了技能名后用「该英雄」指代当前卡上的英雄，玩家一眼明了、不用记人名对应谁。（道具描述不写「你」，主语用效果的作用对象，如「己方 / 己方出战英雄 / 敌方 / 敌方出战英雄 / 这次攻击 / 本回合」。）
2. **句式 / 时机词**（三种状态各用一词，互不混用）：
   - 出战期间持续生效 =「**该英雄出战时，……**」。
   - 登场瞬间触发一次 =「**该英雄登场时，……**」。
   - 未出战（在场下待命）时生效 =「**该英雄未出战……时，……**」。
   - 其他触发型 =「**该英雄……时，……**」——**句首不写「当」**。
3. **数值带单位、统一用「点」**：0.5 点能量 / 1 点伤害 / 0.5 点护盾 / 0.5 点生命。
4. **一句话**说清「谁、什么时候、发生什么」；复杂的可用分号，但尽量短。
5. **用大白话**，不用耍帅但难懂的词（震碎 / 卸劲 / 红温 / 吞噬…）。
6. **主动技**：描述只写效果，**不写能量 / 次数 / cap**（游戏 UI 会单独显示）。

## 二、统一术语

| 概念 | 用 | 不用 |
|---|---|---|
| 额外血量层 | **护盾** | 护甲 |
| 血量 | **生命** | HP / 血 |
| 一回合的行动 | **行动** | 动作槽 |
| 我方 | **己方** | 你方 / 全队 |
| 攻击附带的额外效果 | **附加效果** | 连携 / combo |
| 当前上场作战的英雄 | **出战（英雄）** | 在场 |
| 没上场的己方英雄 | **未出战（英雄）** | 替补 / 替补席 |
| 切换上场那一刻 | **登场** | 上场 |
| 对面那一方 | **敌方** | 对手 |

## 三、关键词

> 只给**会反复出现**的机制立关键词（帮助里统一解释一次）；只出现一次的机制用大白话、不立关键词。

- **附加效果**：一次攻击除了造成伤害，还额外触发的效果（下毒 / 破甲 / 碎能 / 易伤 / 剑意 等）。
- **真实伤害**：无视防御和护盾的伤害。
- **穿防 / 穿大防**：攻击穿透「防」/「大防」。
- **护盾**：额外血量层，先扣护盾后扣生命，真实伤害无视。
- **中毒**：可叠加；中毒目标再次被攻击时引爆全部毒层造成伤害。
- ⛔ 不立关键词（只一个英雄用、用大白话）：剑气、断罪标记 等。

## 四、范例

- 该英雄出战时，己方获得的所有能量增加 0.5 点。（常驻被动 · 主语用「该英雄」· 出战）
- 该英雄对敌方造成伤害时，移除敌方等量的能量。（触发型 · 去「当」· 统一「敌方」）
- 该英雄攻击命中时，使目标中毒（可叠加）；中毒目标再次被攻击时，引爆全部毒层造成伤害。（关键词 + 分号短句）
- 己方出战英雄获得 0.5 点护盾。（道具 · 主语用作用对象「己方出战英雄」· 不写「你」· 护盾不写「甲」）
- 这次攻击命中时，己方出战英雄回复 0.5 点生命。（道具 · 「这次攻击」作主语 + 触发型 · 生命不写「HP」）
