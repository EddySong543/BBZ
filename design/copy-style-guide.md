# 玩家可见文案风格规范

> 适用范围：英雄技能描述、道具描述、所有玩家可见的效果文本（tooltip / 图鉴）。
> 目标优先级：**① 风格一致 > ② 一句话让玩家一眼看懂 > ③ 关键词可复用。**

## 一、写法规则

1. **主语用英雄的完整名**（英雄技能描述），即该卡英雄的 `hero_name`（含生肖括号，如「虚日【鼠】」），不用「该英雄 / 它 / 他 / 其」。玩家一眼看清是谁的技能、与战斗格 / 图鉴显示的名字一致。（道具描述不写「你」，主语用效果的作用对象，如「我方 / 我方出战英雄 / 敌方 / 敌方出战英雄 / 这次攻击 / 本回合」。）
2. **句式 / 时机词**（各状态各用一词，互不混用；下方「〔名〕」= 该卡英雄的完整名，如「虚日【鼠】」。🔄 2026-07-04 Eddy 修订：原「出战时」易误读为"在队伍里"，状态词改「在场时」、新增「在队时」）：
   - 站在场上作战位期间持续生效 =「**〔名〕在场时，……**」（原「出战时」·2026-07-04 起弃用）。
   - 在队伍里（含替补·存活）即持续生效 =「**〔名〕在队时，……**」（2026-07-04 新增·全队光环用）。
   - 登场瞬间触发一次 =「**〔名〕登场时，……**」。
   - 未出战（在场下待命）时生效 =「**〔名〕未出战……时，……**」。
   - 其他触发型 =「**〔名〕……时，……**」——**句首不写「当」**。
3. **数值带单位、统一用「点」**：0.5 点能量 / 1 点伤害 / 0.5 点护盾 / 0.5 点生命。
4. **一句话**说清「谁、什么时候、发生什么」；复杂的可用分号，但尽量短。
5. **用大白话**，不用耍帅但难懂的词（震碎 / 卸劲 / 红温 / 吞噬…）。
6. **主动技**：描述只写效果，**不写能量 / 次数 / cap**（游戏 UI 会单独显示）。
7. **归属显而易见时省略「我方」**：英雄技能默认作用于自己一方，效果落在我方时不写「我方」；仅在需要与敌方对比 / 消歧时才写「我方 / 敌方」。（如「获得的能量增加 0.5 点」不写「我方获得」；但「对**敌方**造成伤害」不能省。）
8. **本英雄之外的己方英雄用「队友」**：比「其他我方英雄 / 我方未出战英雄」更短，「队友」天然不含本英雄自己。（如「队友获得 0.5 点护盾」「存活队友回复生命」。）
9. **去掉可省的修饰词**：能省则省（如去「所有」；用「换下的英雄」而非「被换下的英雄」）。

## 二、统一术语

| 概念 | 用 | 不用 |
|---|---|---|
| 技能描述的主语 | **英雄完整名**（如虚日【鼠】） | 该英雄 / 它 / 他 / 其 |
| 额外血量层 | **护盾** | 护甲 |
| 血量 | **生命** | HP / 血 |
| 一回合的行动 | **行动** | 动作槽 |
| 英雄使用「波」或「大波」 | **攻击** | 用“攻击”泛指独立主动技、独立道具伤害、反击或持续伤害 |
| 「防」或「大防」完整挡下一次攻击 | **成功防御** | 用“成功防御”描述仅减伤、护盾吸收或挡下独立道具伤害 |
| 生命或护盾减少的结果 | **伤害** | 用“攻击”代替所有伤害来源 |
| 我方 | **我方** | 你方 / 全队 / 己方 |
| 本英雄之外的我方英雄 | **队友** | 其他我方英雄 / 我方未出战英雄 |
| 攻击附带的额外效果 | **附加效果** | 连携 / combo |
| 站在作战位（状态词） | **在场时**（2026-07-04 起） | 出战时 / 存活时 |
| 在队伍里含替补（状态词） | **在队时**（2026-07-04 新增） | 在场（易混）/ 存活时 |
| 当前上场作战的英雄（名词） | **出战英雄**（⚠ 是否随状态词改「在场英雄」待 Eddy 裁·道具 60 条在用） | — |
| 没上场的我方英雄 | **未出战（英雄）** | 替补 / 替补席 |
| 切换上场那一刻 | **登场** | 上场 |
| 对面那一方 | **敌方** | 对手 |

### 战斗术语边界（2026-07-31 起）

- **攻击**只指英雄使用基础动作「波」或「大波」。附在该次攻击上的加伤、额外命中、中毒、破甲等附加效果仍随攻击结算。
- 独立主动技能、独立道具伤害、反击、中毒引爆和延迟伤害都不叫“攻击”；需要概括这些来源时统一写“伤害”。
- **命中**只指「波」或「大波」穿过防御门；护盾吸收仍算命中。独立主动技能、追击、反击和独立道具伤害都不算命中，也不结算命中相关效果。
- **额外触发**只重复由命中触发的英雄技能；附在攻击上的道具效果每次攻击最多结算一次。
- 若技能以“本次造成的伤害数值”为计算依据，且必须区分攻击附加伤害与独立伤害，则在小字中直接写「波」和「大波」，不再用“攻击”缩写该边界。
- **成功防御**只指「防」或「大防」完整挡下一次攻击。护盾吸收伤害、免疫伤害或挡下独立道具伤害不使用该词。
- 该边界优先服务短文案：英雄小字只写核心规则，目标锁定、同拍换位、落空、主动技和道具例外留在完整机制说明与测试中。
- h01–h06 已按本规则统一；尚未重设计的英雄随逐英雄流程更新，不以文案改写擅自改变旧机制。

## 三、关键词

> 只给**会反复出现**的机制立关键词（帮助里统一解释一次）；只出现一次的机制用大白话、不立关键词。

- **基础动作加「」（2026-07-05 Eddy 定·硬规）**：文案中出现五个基础动作名词——**「波」「攒」「大波」「防」「大防」**——一律加「」（例：敌方「防」的能量增加 1 点）。固定穿透术语**「穿防」「穿大防」按伤害等级词处理、不拆开加括号**（例：的「波」穿防）；「防御」「攻击」等泛称不加。切换不在此列。
- **附加效果**：一次攻击除了造成伤害，还额外触发的效果（下毒 / 破甲 / 碎能 / 脆弱 / 剑意 等）。额外触发只重复英雄技能，道具附带效果每次攻击最多结算一次。
- **反制**：使该道具的效果无效；道具仍照常消耗。
- **真实伤害**：无视防御和护盾的伤害。
- **穿防 / 穿大防**：攻击穿透「防」/「大防」。
- **护盾**：额外血量层，先扣护盾后扣生命，真实伤害无视。
- **毒素**：可叠加。中毒英雄再次被「波」或「大波」命中时，引爆并清除全部毒素，每层造成0.5点伤害。
- **脆弱**：受到的伤害增加0.5点。
- ⛔ 不立关键词（只一个英雄用、用大白话）：剑气、罪已昭印 等。

## 四、范例

- 虚日【鼠】在场时，获得的能量增加 0.5 点（回合被动能量除外）。（常驻被动 · 归属明显省「我方」· 在场=作战位）
- 牛金【牛】成功防御时，我方下一次的「波」升级为「大波」。（“成功防御”已统一包含用「防」或「大防」挡下攻击）
- 双方同时攻击时，尾火【虎】的攻击优先结算。（“攻击”已统一包含「波」与「大波」，不在小字重复枚举）
- 房日【兔】的攻击可以指定任意一名敌方英雄。（只写被改写的基础关系；不把目标锁定、换位与落空等引擎边界塞进小字）
- 亢金【龙】在队时，我方的「波」可以额外消耗1点能量，使伤害增加1点。（“可以”表示由玩家选择，不自动扣能；“波”排除大波、主动技与道具）
- 紫火【猴】对敌方造成伤害时，移除敌方等量的能量。（触发型 · 去「当」· 统一「敌方」）
- 翼火【蛇】命中敌方英雄时，使其获得1层毒素。<br>毒素：可叠加。中毒英雄再次被「波」或「大波」命中时，引爆并清除全部毒素，每层造成0.5点伤害。（技能句 + 关键词解释分行）
- 触邪【羊】攻击命中敌方英雄时，使其获得脆弱，直到其下场。（关键词效果由帮助统一解释，技能句只说明施加条件与持续时间）
- 并封【猪】在队时，我方可以降低1点能量上限，使本回合的行动少消耗1点能量（下限最低3点）。（“在队”包含存活的未出战英雄；“可以”表示由玩家选择，不自动支付上限）
- 我方出战英雄获得 0.5 点护盾。（道具 · 主语用作用对象「我方出战英雄」· 不写「你」· 护盾不写「甲」）
- 本回合的下次攻击命中时，我方出战英雄回复等同于伤害的生命。（道具 · 明确限于本回合下次攻击；回复量取实际伤害，不写「HP」）
