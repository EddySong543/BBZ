# 玩家可见文案风格规范

> 适用范围：英雄技能描述、道具描述、所有玩家可见的效果文本（tooltip / 图鉴）。
> 目标优先级：**① 风格一致 > ② 一句话让玩家一眼看懂 > ③ 关键词可复用。**

## 一、写法规则

1. **主语用英雄的完整名**（英雄技能描述），即该卡英雄的 `hero_name`（含生肖括号，如「虚日【鼠】」），不用「该英雄 / 它 / 他 / 其」。玩家一眼看清是谁的技能、与战斗格 / 图鉴显示的名字一致。（道具描述不写「你」，主语用效果的作用对象，如「我方 / 我方出战英雄 / 敌方 / 敌方出战英雄 / 这次攻击 / 本回合」。）
2. **句式 / 时机词**（各状态各用一词，互不混用；下方「〔名〕」= 该卡英雄的完整名，如「虚日【鼠】」。🔄 2026-07-04 Eddy 修订：原「出战时」易误读为"在队伍里"，状态词改「在场时」、新增「在队时」）：
   - 站在场上作战位期间持续生效 =「**〔名〕在场时，……**」（原「出战时」·2026-07-04 起弃用）。
   - 在队伍里（含替补·存活）即持续生效 =「**〔名〕在队时，……**」（2026-07-04 新增·全队光环用；若触发本身归属显而易见、可按规则 7 精神省略前提——先例 = h13 玄冥直接写触发句、Eddy 裁定不加前缀）。
   - 登场瞬间触发一次 =「**〔名〕登场时，……**」。
   - 未出战（在场下待命）时生效 =「**〔名〕未出战……时，……**」。
   - 其他触发型 =「**〔名〕……时，……**」——**句首不写「当」**。
3. **数值带单位、统一用「点」**：0.5 点能量 / 1 点伤害 / 0.5 点护盾 / 0.5 点生命。
4. **一句话**说清「谁、什么时候、发生什么」；复杂的可用分号，但尽量短。
5. **用大白话**，不用耍帅但难懂的词（震碎 / 卸劲 / 红温 / 吞噬…）。
6. **主动技**：描述只写效果，**不写能量 / 次数 / cap**（游戏 UI 会单独显示）。
7. **归属显而易见时省略「我方」**：英雄技能默认作用于自己一方，效果落在我方时不写「我方」；仅在需要与敌方对比 / 消歧时才写「我方 / 敌方」。（如「获得的能量增加 0.5 点」不写「我方获得」；但「对**敌方**造成伤害」不能省。）
8. **本英雄之外的己方英雄用「队友」**：比「其他我方英雄 / 我方未出战英雄」更短，「队友」天然不含本英雄自己。（如「队友获得 0.5 点护盾」「存活队友回复生命」。）
9. **去掉可省的修饰词**：能省则省（如去「所有」；用「换下的英雄」而非「被换下的英雄」）。

## 二、统一术语

| 概念 | 用 | 不用 |
|---|---|---|
| 技能描述的主语 | **英雄完整名**（如虚日【鼠】） | 该英雄 / 它 / 他 / 其 |
| 额外血量层 | **护盾** | 护甲 |
| 血量 | **生命** | HP / 血 |
| 一回合的行动 | **行动** | 动作槽 |
| 我方 | **我方** | 你方 / 全队 / 己方 |
| 本英雄之外的我方英雄 | **队友** | 其他我方英雄 / 我方未出战英雄 |
| 攻击附带的额外效果 | **附加效果** | 连携 / combo |
| 站在作战位（状态词） | **在场时**（2026-07-04 起） | 出战时 / 存活时 |
| 在队伍里含替补（状态词） | **在队时**（2026-07-04 新增） | 在场（易混）/ 存活时 |
| 当前上场作战的英雄（名词） | **出战英雄**（⚠ 是否随状态词改「在场英雄」待 Eddy 裁·道具 61 条在用） | — |
| 没上场的我方英雄 | **未出战（英雄）** | 替补 / 替补席 |
| 切换上场那一刻 | **登场** | 上场 |
| 对面那一方 | **敌方** | 对手 |

## 三、关键词

> 只给**会反复出现**的机制立关键词（帮助里统一解释一次）；只出现一次的机制用大白话、不立关键词。

- **基础动作加「」（2026-07-05 Eddy 定·硬规）**：文案中出现五个基础动作名词——**「波」「攒」「大波」「防」「大防」**——一律加「」（例：敌方「防」的能量增加 1 点）。固定穿透术语**「穿防」「穿大防」按伤害等级词处理、不拆开加括号**（例：的「波」穿防）；「防御」「攻击」等泛称不加。切换不在此列。
- **附加效果**：一次攻击除了造成伤害，还额外触发的效果（下毒 / 破甲 / 碎能 / 易伤 / 剑意 等）。
- **真实伤害**：无视防御和护盾的伤害。
- **穿防 / 穿大防**：攻击穿透「防」/「大防」。
- **护盾**：额外血量层，先扣护盾后扣生命，真实伤害无视。
- **中毒**：可叠加；中毒目标再次被攻击时引爆全部毒层造成伤害。
- ⛔ 不立关键词（只一个英雄用、用大白话）：剑气、罪已昭印 等。

## 四、范例

- 虚日【鼠】在场时，获得的能量增加 0.5 点（回合被动能量除外）。（常驻被动 · 归属明显省「我方」· 在场=作战位）
- 房日【兔】的「波」和「大波」可以指定任一敌方英雄。（只写被改写的基础关系；不把目标锁定、换位与落空等引擎边界塞进小字）
- 牛金【牛】挡下「波」或「大波」后，我方下次「波」升级为「大波」。（同一触发与收益合并成一句；基础动作统一加「」）
- 紫火【猴】对敌方造成伤害时，移除敌方等量的能量。（触发型 · 去「当」· 统一「敌方」）
- 翼火【蛇】攻击命中时，使目标中毒（可叠加）；中毒目标再次被攻击时，引爆全部毒层造成伤害。（关键词 + 分号短句）
- 我方出战英雄获得 0.5 点护盾。（道具 · 主语用作用对象「我方出战英雄」· 不写「你」· 护盾不写「甲」）
- 这次攻击命中时，我方出战英雄回复 0.5 点生命。（道具 · 「这次攻击」作主语 + 触发型 · 生命不写「HP」）

## 五、参考

- 英雄技能文案全量见 `design/heroes.md`（真相源 = 各 `assets/data/heroes/hXX.tres` 的 `skill_detail`）。
- 道具机制文案全量见 `src/battle/item_catalog.gd` 的 `_DEF[].desc`（游戏内展示真相源，已按本规范统一）；`design/items-firstrelease.md` 等设计文档保留开发简述与设计注解、不逐条对齐游戏内措辞。
- 道具描述禁用设计术语，另见纪律「道具描述只用大白话」。
