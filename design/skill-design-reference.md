# 相似游戏技能结构研究记录（内部）

> 更新：2026-08-17
> 用途：为英雄与道具设计提供外部结构参照与撞车检查，不作为玩家文案，不直接移植、改写或仿写任何现成技能。
> 使用原则：只抽取“一个决定如何改变另一个决定”的结构，再用波波攒的「波 / 攒 / 防 / 大波 / 大防 / 切换 / 共享能量」重新推导。

---

## 1. 波波攒过滤器

外部技能必须依次通过以下过滤，才允许进入候选池：

1. **不依赖速度、命中率、属性克制和回合外响应**：这些系统不是波波攒的地基。
2. **能压成一个明显规则变化**：不能要求玩家记多个状态、阶段、例外或技能表。
3. **改变行动选择**：仅自动增伤、自动回血、后台产能不算合格身份。
4. **生成共享接口**：至少能让两名不同队友改变出牌，而非只让本英雄数值上涨。
5. **对手能重排选择**：必须有看得懂的反制、绕行或兑现时机。
6. **通过内部撞车检查**：不能只是把现有英雄的波、攒、防、切换换成另一组词。
7. **通过外部撞车检查**：若核心句读起来仍像某个现成技能，即使数值、角色和尾巴不同，也判高风险。

---

## 2. 扫描记录

### 2.1 洛克王国：世界

**全量审阅口径（2026-08-17）**：以 BWIKI 更新至 S3 的当前公开目录为玩家真相源，逐项审阅 594 条精灵 / 形态记录与 553 个正式技能。技能表包含物攻 190、魔攻 155、防御 52、状态 156；公开标签中，应对 73、连击 65、印记 40、异常 31、回能 30、回血 28、选择 21、离场 20、驱散 15、传动 13、巧变 11、奉献 10、打断 8。结构化数据模块另有 4 条未进入公开索引的占位技能，只用于发现数据口径差异，不纳入设计样本。第三方导出出现的 1065 精灵、1511 技能包含首领、资源占位和未实装内容，同样不当作玩家可用真相。

道具图鉴也已遍历，但其中主体是捕捉球、材料、任务物和技能石；技能石的战斗意义是改变赛前技能池，不是战斗中使用的一次性工具。因此本轮以技能、特性、精灵配招为机制主体，只把技能石的“公共技能跨精灵分发”视为构筑经验。

#### 最重要的设计结论

1. **能量是每个技能自己的价格，不只是大招条。** 约七成非特性技能集中在 1—3 能，0 能动作维持循环，4—10 能动作负责兑现；因此同一只精灵要在低费周转、高费压制与当前剩余能量间持续取舍。BBZ 最该学习的是“价值和支付时机绑定”，不是把「波」改成零费回能攻击。
2. **“应对”有效，是因为大部分技能先有可用的基础效果。** 防御本来就减伤，攻击本来就造成伤害，状态本来就建立计划；猜中对方类别后再升级效果。若只拿走“猜中翻倍”，就会退化成 BBZ 已多次否决的纯白板 `if / else`。未来道具应让失败也推进另一条计划，或把代价公开给对手，而不是继续堆动作对照表。
3. **成长不只加数值，也会改变技能未来价格。** `重击` 用高威力换每次使用后永久加费，`冲撞 / 蓄能轰击` 通过回合或先前行动逐步降费，`无畏之心` 用强防守与转化收益换永久加费。BBZ 可转译为“现在透支、以后为同一选择还债”或“工具可重复，但再次上线更慢”；价格变化应显示在行动钮或道具框上，不能藏在头像状态里。
4. **精确资源比单纯多给一点资源更能制造计划。** `触底强击` 奖励一次行动正好耗尽能量，`莫比乌斯` 奖励回合末精确归零。它们的价值在于玩家要先计算如何花到临界点。BBZ 旧余烬灯式“0→1”确实不足；值得学习的是有分量的精确归零回报，并让锁泉塞、毕方截止线等现有规则自然反制。
5. **团队组合依靠公共产物，不要求指定搭档。** `奉献`由多个技能生产共享的后续强化，其他技能再消费；部分特性把回复或能量转送给队友。BBZ 不应新建“奉献点”，但可以继续让生命回复、能量、命中产生的英雄效果、已生效道具和背包补充成为跨英雄 / 跨道具接口。
6. **技能卡自身承担了大量记忆。** 永久能耗、位置、选择分支和剩余规划都显示在技能槽上，所以复杂体系仍可追踪。BBZ 的对应承载面是公开的道具框、锁定回合和未来行动按钮；跨回合效果若无法挂在这些既有位置，就不应继续新增。
7. **完整体系才能托住小众标签。** `传动`依赖技能槽位置，`天气`依赖属性生态，`引电 / 迸发 / 巧变`依赖成组技能。它们在原作能成立，不代表拆出一件 BBZ 道具也能成立。背包形状只负责构筑价格，绝不转化为邻接、朝向或位置战斗效果。

#### 具体结构的 BBZ 判断

| 原作结构 | 真正价值 | BBZ 判断 |
|---|---|---|
| 0 能攻击并回 1 能 | 提供循环底板，使高费技能有稳定前置 | 不移植；会同时削弱「波」和「攒」的地基身份 |
| 攻击 / 防御 / 状态“应对” | 基础用途之上奖励正确读招 | 只学“基础用途 + 命中奖励”；不批量生产纯条件白板 |
| `重击 / 无畏之心`式永久加费 | 强效果把成本推给未来选择 | 可转成行动债务或道具重新锁定，必须公开显示 |
| `冲撞 / 蓄能轰击`式逐步降费 | 先完成若干动作，再兑现高费终结技 | 已有牛金、至臻剑意、爆裂卷轴等大量降费入口；只从新支付结构进入 |
| `触底强击 / 莫比乌斯`式精确归零 | 奖励资源计算而非无脑攒能 | 高价值空位；回报必须明显高于旧“回到1能” |
| `奉献 / 系统发育`式团队转送 | 生产者与消费者可以是不同精灵 | 转译为既有生命、能量、命中英雄效果或道具经济，不新增奉献资源 |
| 防御后离场 / 攻击后离场 | 把本次应对接到下一名队友 | 结构有价值，但星日、候阵签、归营牌等已使切换区拥挤，本轮不立项 |
| `连击`与额外段数 | 让次数型技能与触发型能力相互放大 | BBZ 已锁定“额外触发只重复英雄技能，道具附效每次攻击一次”，不得恢复乘算漏洞 |
| `传动`与技能位置 | 排列本身成为构筑成本与效果来源 | 拒绝；BBZ 形状 / 摆放只定背包价格，不参与战斗结算 |
| `巧变 / 借用 / 取念 / 复写` | 用不确定技能池扩大临场选择 | 会撞烛阴与技能复制边界，也会把道具变成英雄技能，拒绝 |
| 天气、属性异常与印记小包 | 大型技能池内的主题生态 | 不移植；围绕通用命中英雄效果设计，不为毒素或单属性另建封闭牌组 |

#### 对 BBZ 后续设计的约束

- 优先补“精确支付、未来债务、持续效果时机、团队转送、道具可重复但越来越慢”五类接口；其中可重复物最好把状态留在道具框，避免新增头像记忆。
- 应对型道具必须先回答失败时是否仍推动计划；若答案只是“什么也不发生”，除非读中收益足够高且对手能明确绕行，否则不进入高推荐区。
- 现有 96 件正式道具已经覆盖大量攻击、防御、切换、命中、治疗和能量白值。洛克带来的新价值应是重新安排支付与兑现，不是再造一瓶更大的药或一个属性版状态。
- 本对话仍不重做英雄；精灵与特性只用于检验一件道具能否连接两名以上英雄、以及组合是否真的改变行动选择。

**明确禁止移植**：零费攻击回能、技能位置 / 邻接、属性克制、天气队、速度与先手竞速、随机技能复制、成套专属印记、长异常、永久多维强化，以及把洛克技能石直接当成战斗道具。它们依赖原作完整技能栏与属性生态，在 BBZ 中会压过「波 / 攒 / 防 / 大波 / 大防」。

### 2.2 宝可梦系列

**全量审阅口径（2026-08-17）**：以主系列九个世代的 1025 个全国图鉴编号、934 个历史招式和 308 个特性为稳定目录，逐项归入伤害、强化、异常、保护、回复、切换、束缚、场地、代价、复制等结算骨架；另用 Pokémon Showdown 当前结构化数据核对形态、特性分布与可学习招式池。`Legends: Z-A` 的实时距离、范围与冷却规则不与传统回合制混算。

#### 最重要的设计结论

1. **精灵身份不是一条独占技能，而是多层组合。** 外形与生态先建立角色幻想；种族值决定速度、耐久和输出轮廓；属性决定基础关系；特性提供一个被动偏折；可学习招式决定具体用途。大量精灵共享招式和特性，仍可因组合位置不同而成立。BBZ 应继续用“形象 + HP / 阵位 + 一条技能 + 公共动作关系”建立英雄，不要求每名英雄拥有专属资源或完整小系统。
2. **公共招式池是组合密度的主要来源。** 结构化目录中，单个形态可学习招式的中位数约为 75，且有大量招式被上百个形态共享；真正稀有的签名招式只是提纯身份。玩家从宽招式池中只带 4 招，强度因此必须支付槽位机会成本。BBZ 的对应物不是给英雄加四个技能，而是让同一名英雄与公共的「波 / 攒 / 防 / 大波 / 大防 / 切换」及三格道具产生不同路线。
3. **切换本身是一级行动。** `U-turn / Volt Switch` 把攻击接到换位，`Baton Pass` 把准备成果交给下一名精灵，`Regenerator / Intimidate` 等特性让登退场成为阵容计划。BBZ 可学习“这一名铺垫、下一名兑现”的调度关系，但星日、广寒、候阵签、归营牌等已覆盖不少切换槽位；后续不能再用“切换后自动得一点数值”冒充新身份。
4. **优秀签名机制是一条强规则例外，并带真实限制。** `Truant` 用不能连续行动换取异常身板，`Stance Change` 让攻防动作改变形态，`Zero to Hero` 要求离场再登场，`Wonder Guard` 则极度依赖完整属性克制作为反制。可学的是“强例外 + 可见代价 + 队伍安排”，不是复制其文本；没有对应反制地基的例外不能移植。
5. **组合由生产端、连接端与兑现端组成。** 中毒与其增伤招式、天气开启者与天气受益者、空间规则与慢速精灵、钉场与强制换位，都让不同成员承担不同职责。BBZ 应把这类关系压回已有公共接口，例如一名英雄产出命中、升级波、能量或安全回合，另一名英雄决定目标、加价、收割或调度；禁止建立只服务两三张牌的天气、地形或属性小包。
6. **隐藏信息是有边界的。** 对手看见精灵种类后能推测其常见招式、特性与道具，但无法确认四招具体配置；深度来自“已知候选范围内猜选择”，不是任意未知。BBZ 的背包黑色轮廓与公开道具框可以承担相似职责，但候选必须能由形状、稀有度和构筑规则推理，不能变成纯猜答案。
7. **复杂度逐层开放，而非首回合全压给玩家。** 基础战斗始终是出招、换位和道具；属性、特性、招式副作用与队伍构筑逐步叠加。BBZ 应保持玩家第一眼只读公共动作和一条英雄技能，长期状态、图纸与背包经济放在需要时查询，不把全部结算例外写进英雄小字。

#### 具体结构的 BBZ 判断

| 原作结构 | 真正价值 | BBZ 判断 |
|---|---|---|
| `Protect` 与攻击读招 | 用一次行动换取对攻击的确定防守 | 已由「防 / 大防」承担，不再设计同义英雄技能 |
| `Swords Dance` 等强化 | 当前回合放弃伤害，为后续爆发铺垫 | 已由「攒」、剑意、升级波与能量储备覆盖 |
| `U-turn / Volt Switch` | 攻击同时把下一名队友送上场 | 调度结构有价值，但与星日 / 广寒高度拥挤，只能从新的公共代价或目标关系进入 |
| `Baton Pass` | 把自己建立的成果交给下一名成员 | 很适合检验跨英雄 combo；BBZ 只应转移现有短期成果，不复制整包状态 |
| `Choice Band` 类 | 大幅增益换取动作锁定 | 很适合道具构筑：强度以公开承诺和选项损失付款；需避免撞烛阴的动作锁定 |
| `Belly Drum` | 大额生命支付换极端输出 | 已被天不葬、力量的代价、借命灯等覆盖，不再换数值重做 |
| `Destiny Bond / Innards Out` | 用死亡威胁改变对手是否补刀 | 已被尾后针、换命契等覆盖 |
| 天气 / 场地 / `Trick Room` | 一条全场规则让整队重新估值 | 结构强，但 BBZ 没有速度 / 属性地基；只可学习“短期公共规则”，不得引入天气包 |
| 中毒 + `Hex / Venoshock` | 一名成员施加，另一名成员消费 | 生产—消费关系可学；BBZ 应围绕通用命中附加效果，不建立毒素专属牌组 |
| `Future Sight` 等延迟招式 | 预定未来压力，再用换位控制兑现 | BBZ 跨回合状态已接近记忆上限，除非无需新增常驻标记，否则不采用 |

#### 对未来英雄设计的约束

- 新英雄可以拥有宝可梦式“一个鲜明特性”，但必须落在 BBZ 的公共动作上，并明确改变哪一个回合选择。
- 签名技能应是少数高辨识度例外；普通英雄不需要为了显得独特而增加形态、层数、专属状态和第二技能。
- 设计必须同时检查本英雄的数值轮廓、出战 / 未出战位置、队友生产物、道具入口和对手绕行方式，不能只审一句技能文案。
- 现有 24 人已经覆盖能量放大、挡招转攻、指定目标、攻击加价、命中生产、免费切换、后备防御、伤害碎能、全队蓄势、切换惩罚、受伤转能、生命支付、变身、生命均分、强制登场、能量截止线与上限削减等大量骨架；未来优先找新的连接方式，不重复这些身份。

**明确禁止移植**：18 属性克制表、速度线、命中 / 闪避、暴击与概率异常、PP、睡眠 / 麻痹 / 混乱等长状态包、场地钉与清场套件、每代再叠一层 Mega / Z / 极巨 / 太晶式战斗变身，以及“只有指定属性队友才能启动”的封闭阵容。它们在宝可梦中有完整生态承托，在 BBZ 中只会增加记忆和 UI 负担。

### 2.3 Temtem

其技能通过耐力消耗、过度消耗、休息、入场后等待回合和双人协同形成节奏：

- 资源不足仍可强行施放，但以生命和下一拍行动权偿还；
- 主动休息会放弃当前动作，换取更高的资源恢复；
- 强技能需在场若干回合后才能使用，形成公开的部署时机；
- 同一技能因场上队友满足公共条件而获得额外用途。

**可学结构**：透支、公开等待、当前行动换未来资源都能制造真实代价。
**禁止移植**：固定属性搭档是指定体系；等待若只换来更大的数字，会重演旧 h22 的空过一拍问题。

### 2.4 赛尔号

精灵通常用有限技能次数、先制、状态与专属特性组织战斗。它提供了大量触发时点、资源消耗和状态绑定案例，但系统层数远高于 BBZ。

**可学结构**：持续效果必须明确绑定对象、持续时间和清除节点；主动技能与被动特性应承担不同职责。
**禁止移植**：先制竞速、PP 消耗、长状态链和多条专属被动会增加记忆负担，不适合作为单技能英雄模板。

### 2.5 Cassette Beasts

每名单位按回合获得行动点，在低费行动与积攒高费行动之间选择；主动贴纸占用行动，被动贴纸在特定事件自动触发；融合会合并双方的主动池与被动池。

**可学结构**：

- “现在花少一点还是为下一拍保留”必须始终是可见选择；
- 被动的价值来自与主动池组合，而不是单条被动自动收租；
- 两个组件结合后应扩大可用动作，而不是只把同一数值相加。

**禁止移植**：随机词条、庞大技能槽和被动堆叠会把英雄设计变成装备构筑，超出 BBZ 单技能边界。

### 2.6 Monster Sanctuary

其核心是团队光环、公共状态与回合内连击：支援者先行动建立命中或状态，终结者在同一回合消费连击；普通光环可叠加，独特光环不可叠加。

**可学结构**：

- 生产端和消费端可以由不同角色承担；
- 合格的团队被动应改变队友技能的用途，而不只是统一加百分比；
- “本回合不用就消失”的公共资源天然形成行动顺序和兑现压力。

**禁止移植**：多层 Buff、Debuff、光环和额外命中链过于复杂；BBZ 只能保留一层生产—消费关系。

### 2.7 Coromon

每个技能消耗耐力，无法支付时最终会被迫休息；特性与技能分离，接触类攻击还能作为其他效果的公共触发接口。

**可学结构**：资源耗尽不必只表现为“不能按按钮”，也可以改变下一拍可选行动；公共动作标签可以成为技能间的连接口。
**禁止移植**：被迫休息若缺少玩家提前规划，只会成为惩罚；物理、特殊、接触等多层分类不应引入 BBZ。

### 2.8 Beastieball

角色关系会解锁新能力和组合行动，连携被表现为双方共同获得的新选择，而不是单个角色旁边多一个自动数字。

**可学结构**：combo 的验收对象应是“组合后新增什么行动路线”。
**禁止移植**：按指定角色关系解锁技能会把 BBZ 固化成配对体系。

### 2.9 Yomi / Yomi 2

其双盲同时选择与波波攒最接近：攻击、防御、投技和闪避构成底层胜负关系，角色能力主要改变如何准备、覆盖或兑现这些公共动作；超级资源来自连续攻击或主动舍弃其他资源。

**可学结构**：

- 双盲博弈的深度来自同一动作拥有多种用途，而非结算后再猜对手；
- 公共资源需要至少两种获取方式和两种消费方式，才会形成规划；
- 连段成立的关键是“铺垫者—连接者—终结者”职责，而不是命中后自动追加白值。

**禁止移植**：手牌、弃牌堆和牌面双用途不能直接搬入；只保留“双盲承诺与后续兑现”的结构。

### 2.10 游戏王 OCG / TCG

**全量审阅口径（2026-08-17）**：以 Konami 官方卡片数据库核对现行规则、卡片详情与禁限口径，再读取 YGOPRODeck 数据库版本 146.67 的无参数全卡接口，逐条按 `type / race / archetype / desc` 归类。接口共有 14515 条记录；排除 124 张 Skill Card 与 106 张 Token 后，审阅主体为 14285 张通常卡片，其中效果怪兽 5119、魔法 2870、陷阱 2080，其余为通常怪兽及融合、同调、超量、连接、仪式、灵摆等额外类型。

8703 张卡带有 652 种实际使用中的系列标签，约占主体的 61%。效果文本的英文长度中位数为 315 字符，四分之三分位为 449，九十分位为 521。以下为允许同一卡重复归类的全文关键词粗扫：`一回合一次` 6415、从卡组加入手牌 1469、从卡组特殊召唤 1252、从卡组盖放 214、丢弃 989、解放 1681、除外 2904、无效 1579、效果替代 602、结束阶段 1196、快速效果 1183。数字说明其组合密度主要来自检索、区域流转、支付与系列共享，而不是 14000 多条互不相关的新规则。

#### 最重要的设计结论

1. **检索是降低构筑随机性的主要工具，但越精确越需要公开代价。** `Gold Sarcophagus / Different Dimension Capsule` 让玩家指定想要的卡，却必须公开等待；`Sangan` 检索后又限制同名卡当回合发动。BBZ 可以让玩家从背包精确找连接件，但目标应直接进入公开道具框并锁定，不能再建一个随时可访问的备用区。
2. **卡牌可以先作成本，再从另一位置产生价值。** 丢弃、解放、送墓、自毁与除外并非只扣数字，而会改变后续可用资源。BBZ 只吸收“正常使用 / 被烧掉”两种用途和死亡后的资源接替，不建立墓地、除外区、苏生链与第二套卡片区域。
3. **稳定组合依赖共享检索词与公共接口。** 约六成卡片属于系列；大量卡通过系列名、种族、属性、等级与卡种互找，从而让同一组件接入多条路线。BBZ 不建立具名道具家族，只复用「波 / 大波、攒、防 / 大防、切换、能量、生命、命中英雄效果、道具框」；一件连接件必须能改写多个现有英雄或行动的选择。
4. **强效果的成本、目标和结算结果必须严格分开。** 游戏王的 PSCT 用标点和固定句式区分发动条件、支付、指定对象与结算。BBZ 的玩家文案仍应是一句大白话，但内部规则与测试必须明确：道具被反制时已经支付的生命、能量或被烧道具不退回；目标失效与效果无效也不是同一件事。
5. **连锁、手坑与盖卡是原作的核心，却不是 BBZ 的接口。** 它们依赖回合中途的响应优先权、速度分层与隐藏身份。BBZ 已经用揭示前盲选和公开三格道具建立读心，不新增“看到结果后再打断”的连锁窗口，也不把道具框改成暗置陷阱区。
6. **硬封锁很容易把构筑强度变成不让对方玩。** `Summon Limit / Skill Drain / Droll & Lock Bird` 等能把一整类选择关掉；现行官方禁限表中也长期存在大量泛用检索、展开器、多次无效与封锁终端。BBZ 只考虑双方可见、持续一回合、允许停手或换线的软成本，不设计永久禁用基础行动、抽取或英雄技能的 T3 场地。
7. **“一回合一次”主要用于给可重复卡与连锁降速。** 6415 条相关文本证明原作必须靠频率限制管理循环；BBZ 的 T1 / T2 多为一次性消耗品，本身已经付出槽位与库存，不应机械追加同样的限次小字。只有会留在道具框的遗物或可重复工具才需要公开次数 / 锁定。
8. **额外卡组的价值是公开配方与稳定工具箱。** 融合、同调、超量和连接用不同材料规则换取特定成品；可学的是“传说图纸继承材料路线”，不是常驻可查的额外道具区。现有合契卷已覆盖该方向，后续只补兼容候选池，不再另建召唤法。
9. **同一张牌承担两种身份能显著提高构筑密度。** 灵摆、墓地效果和材料效果让卡既是当前手段也是未来成本。BBZ 最适合的轻量转译，是道具在“直接使用”和“被另一件道具烧掉”时分别提供清晰用途；不能把形状、相邻位置或朝向带入战斗。
10. **胜利替代与无限循环不适配。** 特殊胜利、削空卡组、无限回收和多层召唤链会把胜负从三英雄与五种公共行动上移走，全部淘汰。

#### 具体结构的 BBZ 判断

| 原作结构 | 真正价值 | BBZ 判断 |
|---|---|---|
| `Gold Sarcophagus / Different Dimension Capsule` 精确检索后延迟 | 用等待换确定性，对手提前知道未来关键件 | 高价值；转为“背包精确找一件，公开锁定后上线” |
| `Sangan / Mystic Tomato` 离场后补充 | 当前组件被消耗后把计划交给下一组件 | 高价值；转为英雄死亡或道具被反制后的标准抽取，不复制怪兽条件表 |
| `Chain Energy / Summon Limit` 连用税与次数上限 | 抑制一回合堆满资源的爆发展开 | 只采用可停手绕开的软生命成本；硬限制第几件无效只保留为二选一备案 |
| `Forbidden Droplet` 用己方资源换目标失效 | 支付越多，临时压制越广 | 可缩成烧一件道具、沉默当前出战英雄；必须允许切换逃离，且属高风险候选 |
| `Waking the Dragon` 被清除后浮出收益 | 让对手处理卡片时承担信息风险 | 可转为公开的反制诱饵；不做暗置陷阱或超规格召唤 |
| `Pot of Prosperity / Card of Demise` 大量找牌换限制 | 用未来选项、伤害或手牌换当前稳定性 | 付费三选一与锁定已经承担大部分功能，不额外制造大批免费抽取 |
| 灵摆 / 墓地效果 / 材料效果的双用途 | 单卡既能现在使用，也能充当另一计划的成本 | 转为“直接使用 / 被烧掉”二选一，状态不离开现有道具框与背包 |
| 融合 / 同调 / 超量 / 连接 | 可见材料规则换稳定的高阶产物 | 已由传说图纸与合契卷覆盖；背包形状只定价格，不当召唤条件 |
| 反击陷阱、手坑、连锁速度 | 结算途中保留响应权 | 拒绝；会破坏同时盲选并引入新响应 UI |
| 墓地、除外、回卡组与苏生链 | 同一卡多次跨区利用 | 拒绝建立新区域；仅复用烧掉、随机放回背包与现有复活英雄规则 |
| 场地、永续陷阱与全局封锁 | 长期重估整副卡组 | BBZ 长期状态已接近记忆上限，只允许极少数有期限 / 次数 / 反噬的 T3 遗物 |
| 系列专名、属性、种族与等级检索 | 用大量共享词构成封闭高密度牌组 | 不移植专名卡组；继续用公共行动和现有状态连接全队 |

#### 对 BBZ 后续设计的约束

- 精准检索必须把确定性付在**公开锁定时间、占格与真实道具消耗**上，不能同时兼得立即使用、隐藏信息和零能量成本。
- 反制类设计优先做“对手可以少用、换位或改顺序”的软约束；禁用整类基础行动、整回合抽取或全部技能的方案直接淘汰。
- 道具支付先于效果。被反制时仍消耗本物及其明确成本；只有文案写明的保价 / 替代效果可以例外。
- 不为“送墓、除外、素材、计数物”分别建立词条。烧掉是唯一道具牺牲口，标准抽取是 1 能 3 选 1，所有转译都必须复用这两条。
- 游戏王证明搜索会快速把构筑变成稳定展开。正式加入精确检索前，必须用两份同名上限、三格公开道具框和两回合锁定做最坏组合测试，确保构筑没有变成每局固定脚本。

**明确禁止移植**：盖卡身份、连锁速度与结算后响应、手坑、墓地 / 除外区、额外卡组常驻工具箱、专名系列检索、属性 / 种族 / 等级条件表、Token 与计数物小包、无限回收、削卡胜利、特殊胜利，以及让对手长期不能行动 / 抽取 / 使用英雄技能的封锁场。

## 3. 可参考的结构原语

以下条目不是技能方案，只是未来构思时可调用的结构：

| 结构 | 真正改变的决定 | BBZ 适配要点 | 主要风险 |
|---|---|---|---|
| 改写资源来源 | 玩家为了获得能量而改用另一类行动 | 必须与「攒」形成取舍，并让对手能阻断 | 洛克世界已有“攻击回能”，直接采用撞车 |
| 公开资源截止线 | 玩家必须在指定回合前花掉、保存或转换资源 | 双方提前知道，至少留一拍重排 | 若没有保存/转换接口，只是清空数字 |
| 透支 | 现在获得行动或能量，下一拍用生命、能量或行动权偿还 | 代价必须公开且能被阵容利用 | 容易与 h14 的生命支付重合 |
| 公共一回合规则 | 双方在一拍内重新估值波、攒、防 | 规则必须对称、可见、只改一件事 | 容易让某个动作成为唯一正确答案 |
| 资源保值 | 把即将浪费的资源变成下回合仍有效的防御、攻击或部署 | 产物须为全队可消费的现有原语 | 容易复刻 h08 的后备大防 |
| 行动双用途 | 同一按钮可服务当前与后续两种目的 | 两种用途必须共享一个直观动作逻辑 | UI 分支与解释成本可能过高 |
| 部署式成长 | 通过在场、离场或换位完成准备 | 换位本身要带来新选择 | 易撞 h07、h16、h17、h21 |
| 生产—消费桥 | 一名英雄制造公共产物，多名英雄用不同方式兑现 | 至少列出两种会改变出牌的消费者 | 只说“大家都能受益”是假 combo |
| 本回合即逝资源 | 迫使玩家决定现在兑现还是放弃 | 适合制造大波 / 大防 / 道具之间的竞争 | 需要清晰 UI，不宜再造专属计数物 |
| 条件升级 | 已使用的动作改变后续动作，而非只加数值 | 条件应来自玩家主动路线 | 易退化成“出 X 则 Y”的 if–else |

## 4. H22 当前撞车记录

### 方案1：无法「攒」；攻击命中获得能量

- **内部**：与 h01 的能量放大、h10 的攻击蓄积并非完全同构，但主要接口仍只是产出共享能量；大多数所谓连携不会改变队友原本的动作，只会让其更容易支付费用。
- **外部**：洛克王国：世界已经把“零费攻击同时回复能量”作为基础技能样式，且火系也存在同类结构。追加“无法攒”虽形成限制，仍不足以消除核心体验重合。
- **裁定**：高撞车风险，不再作为 h22 推荐方向。

### 方案3：下一回合结束时，双方失去全部能量

- **稳定接口**：制造一个公开的资源截止线，双方必须决定花掉、保值还是放弃剩余能量。
- **具体组合**：h05 可把即将消失的能量投入强化「波」；h08 可提前购买「大防」，未挡到攻击时把价值保存到截止线之后；h07 可免费调整出战位，把行动交给更适合消耗能量的英雄；付费道具也获得明确的提前兑现窗口。
- **对手选择**：对手同样可以用「大波」「大防」或道具花掉能量，也可以接受损失而选择免费行动；效果并非单方面收益。
- **外部**：扫描范围内存在耐力、行动点、回合内即逝连击与过度消耗，但未发现“提前预告、下一回合结束时同时清空双方共享能量”的同构实现。
- **裁定**：2026-08-08 已获批并实装。沿用免费、占行动、每局 2 次；同一时间只有一个全局火兆，不叠加或刷新。结算时通过双方“能量归零”反馈公开结果，暂不新增独立倒计时 HUD。
