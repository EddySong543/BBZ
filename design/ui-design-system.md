## 0. 定位 + 设计铁律（最先看·别看错方向）

**视觉风格 = 奇幻**（不是经典西式奇幻，就是**奇幻感**）。落地路线 = **B 手绘绘本暖调 × C 复古像素工艺** 融合：温暖手绘绘本奇幻的味道（厚涂插画感、华丽描金边框，像翻一本魔法书）+ 八位机 JRPG 怀旧像素（木纹/宝石钉/暖光）。
游戏底子：像素风 1v1 同时回合制，**轻规则、重心理博弈，单局 1–3 分钟**。UI 的脸面要求：**简单、干净、好读** —— 信息少而清、留白充足。

### 🔴 设计铁律（Eddy 反复强调·违反必废）

- **设计 UI 时脑子里只有「奇幻」。** 不想 furry、不想动物、不想兽化 —— **奇幻，奇幻，奇幻**。
- **「主角是拥有生肖动物能力的人」只是世界观设定**（人，**非 furry/兽人**；后期英雄泛动物：鹤/海洋/远古/虫…不限生肖）。设定在设计时**次要、需要时**才考虑，**⛔ 绝不把它做成 UI 视觉母题**（不做动物图腾/兽印/兽谱/兽化纹样）。
- **⛔ 不给 UI 元素安主题噱头名**：「兽印纹章 / 插画兽谱」这类命名套路作废。框就是**好看的奇幻框**，图鉴就是**奇幻质感的图鉴**，别强行套主题。
- **⛔ 彻底抛弃且不再回来的旧母题**：塔罗 / 大阿卡那 / 星盘星座 / 符文 / 流光宝石 / 「命运牌」/ 印章（作塔罗印）。主题已转向，这些不再是任何 UI/美术母题。

**⛔ 参照系纪律**：炉石/皇室战争**只能作机制/数值参考，不作视觉参考**（CR 玻璃流光卡通风与本作不匹配）。视觉参考 = ref12 / ref13（见 §1 末 + `ref/`）+ 本作已有语法。

## 0.5 动手前先判断（Design Read）+ 三拨杆（借鉴 Taste Skill·2026-06-27）

> **背景**：AI 做 UI 最大的坑不是"做不出"，而是"一上来就套默认审美 → 模板味"。破法不是更长的 prompt，是动手前先判断 + 把"做高级点"这种虚话拆成可执行的拨杆。本节即我们项目的"审美刹车"。

**铁律：写任何界面前，先一句话做 Design Read，别直接套默认审美。** 自问：
- 这是什么界面、面向什么状态的玩家？（大厅长停留 vs 过场 3 秒；对战 vs 浏览）
- 有没有现成参考锚？（ref12/ref13 / 战斗界面 / §2 已定令牌）
- 有哪些不能乱来的约束？（§6 硬规）

**三拨杆**——每个界面动手前先定这三个值，比"做高级点"好执行：

| 拨杆 | 含义 | 低 ↔ 高 |
|------|------|---------|
| 布局变化 LAYOUT | 构图打破常规的程度 | 规整网格 ↔ 大胆错落 |
| 动效强度 MOTION | 动画的多少与张扬 | 几乎静止 ↔ 频繁醒目 |
| 信息密度 DENSITY | 一屏信息的多少 | 极简留白 ↔ 密集 |

各界面参考值（🟡 可调）：
- **主菜单大厅**：布局 中（左大右双栈已错落）/ 动效 中（波流+临战升温）/ 密度 低（留白）
- **战斗 HUD**：布局 低（功能优先·规整）/ 动效 中（镜头/飘字·但 UI 永不动）/ 密度 中（一屏读完）
- **图鉴**：布局 低（网格+详情·规整）/ 动效 低（入场+选中+格底云纹微动）/ 密度 中

**审美 ≠ 设计系统（别把风格包装成正式规范）**：本作的"暗金奇幻"是**审美方向**，锚在 ref12/ref13 + §2 已定令牌，**不是**一套要逐条硬编的设计系统。参考图给的是"手感方向"，不是逐像素的法律——**照其神、按本项目令牌落地**。⛔ 别把一个风格词讲成正式规范去硬编。

## 1. 材质语言（地基·先看这条）

🟢 **定案 =「木骨纸芯」（2026-07-09 Eddy 批·取代 6-27「华丽描金」方向）**——中式语汇里木与纸天然一体（匾额=木框字芯 / 画轴=木轴纸卷 / 灯笼=木骨纸罩），据此分工：

- **结构承重 = 深漆木**（外框 / 书脊 / 底座 / 收纳条）——"厚"由木来给，纸永远不裸奔（Eddy 硬要求：纸质感**不能薄**）。
- **内容面 = 暖黄白宣纸**（墨字所在）——厚纸配方：毛边/撕边 + 微叠页（边缘露第二层纸）+ 纸纹 + 落在场景上的柔投影。
- **点睛 = 鎏金 + 朱印**（克制用量·与 title 金冠一脉相承）。
- **分寸规则（两层用法）**：**文书层**（弹窗/卡片/图鉴/设置="拿在手里看的"）偏纸，允许大面积亮底墨字；**战场悬浮层**（战斗 HUD 小件="贴在场景上的"）偏木，暗调小面积，不抢战场。
- **底部战斗按钮**：jelly 彩色框架**保留**（Eddy：配色+外框舒服），改法限于降一档饱和/亮度 + 收进木框条——从"六颗糖"到"嵌在木案上的一排印章"。
- 🔴 **反花哨 = 铁律**（Eddy 2026-07-09）：全游戏元素统一风格；⛔宝石铆钉堆砌类华丽路线弃用。

**暗可以，但必须"富"不能"脏"**：高饱和深色 + 高对比 + 连续质感撑住。⛔ 仍禁**低饱和、中明度的浑浊棕 + 抖动颗粒**（那才是"脏/泥"）。

⛔ **已废的旧语言**：① 「板岩冷金属」（grimdark/魂系）。② 「命运典籍/塔罗印」框架（主题转向）。③ 旧 ui-brief §4「冷蓝玻璃 UI」。④ 「华丽描金·宝石点缀」（2026-06-27 B+C 方向·被 7-09 反花哨铁律取代；ref12 随之降级为质感手感参考、不再是转正候选锚）。

## 2. 配色令牌（Design Token · 核心）

> 取色铁律（🟢）：① 颜色按**功能/语义**分，同义同色、全局一套语言（按钮色 = 道具维度色 = 飘字色）。② UI **场景无关**——自带对比（亮填充 + 暗轮廓 + 暗描边），浅底/深底都成立，不靠背景。③ 颜色**不可作唯一信号**（无障碍）：确认/危险等必须配**图标+形状**，不只靠红绿。

## 3. 字体（🟢）

- 字体 = **Ark Pixel（方舟像素）**，OFL 许可、免费商用（**不是** Fusion Pixel，**无需买 Zpix**）。
- 文件：`assets/font/ark-pixel-{12,16}px-proportional-zh_cn.ttf`，由 autoload `FontManager`（`src/core/font_manager.gd`）加载，**关抗锯齿**。
- **清晰度规则（硬）**：显示号必须是变体网格的**整数倍**——12px → 12/24/36/48…；16px → 16/32/48…。混用非整数倍会糊。
- 缺 10px 变体（Eddy 觉 12px 偏宽）；要更窄需补 `ark-pixel-10px-...ttf` 并接 FontManager。
- ⚠ Ark 像素汉字无下伸部，Label 垂直居中视觉偏下 2–4px，大字号标题需手动 y 上提补正。

| 远征 | `RIDGES` | `canvas_ui_mountain_ridges.gdshader` | 多层山脊纵深；`warm` uniform 切冷夜蓝(0)/暖日金(1) |

其他常用：`hit_flash`（受击白闪）、`canvas_button_jelly`（按钮）、`canvas_ui_pixel_frame`（框）、`canvas_ui_round_mask`/`rounded_fill`/`inner_fx`/`portrait_pixelate`/`soft_shadow`、`canvas_ui_title_glyph`（标题字效）。

**像素粗格法（🟢 铁律）**：shader 把屏幕切 `cells_x` 列正方格，每片元吸附到格心采样、整格填纯色，**全程无上采样/无平滑/无抖动**。粗细 = 改 `cells_x`。⛔ **别用"低分辨率缓冲再放大"**（上采样把方块糊成渐变）。文字层走原生高分辨率，不进网格（否则中文糊）。旋钮在各 `.gdshader` 顶部。

## 6. craft 原则 + 硬规禁忌（违反必被否）

### craft 原则（🟢 2026-06-27 Eddy 反馈）
- **设计前先拆解参考真实游戏的同类 UI**（别闭门造车）；本作的质感锚 = ref12 + 战斗界面。
- **纹理用连续内阴影/渐变，不用随机离散噪点**（我那种 Bayer 离散暗点 = 廉价感）。**例外**：沿边等距的**装饰铆钉/宝石钉**（规则、有意）是 OK 的（ref12）。
- 多层斜面鎏金浮雕 + 宝石点缀 + 切角 = 暖色奇幻像素的可用手法。

### 硬规（🟢）
- **UI 独立**：UI 永远满饱和、清晰、跳出场景，**绝不加 PostFX / 月夜分级 / 任何全屏滤镜**。提质感走飘字/pop/投影/浮雕/排版/动效，**不碰颜色滤镜**。（角色立绘在 PostFX 之下吃分级，那是"世界"不是 UI。）
- **UI 不被游戏状态污染**：UI 只展示，用命令/事件请求变更。所有面向用户文本走本地化系统，禁硬编码字符串。
- **战斗镜头铁规**：① UI 永远不动（HUD/按钮不进舞台容器）② 建筑完全静止，只在受击 shake / 触发推近时动，禁 idle 漂移 ③ 一切克制、只**触发**。
- **无障碍底线**：颜色非唯一信号、禁低对比、禁小字；动画必须可跳过、尊重运动偏好；交互同时支持键鼠 + 手柄。

### 禁忌（⛔）
- ⛔ **设计 UI 时想动物/furry/兽化/图腾**（见 §0 铁律）。
- ⛔ **塔罗/星盘/符文/宝石/命运牌**作母题。
- ⛔ **暗 = 脏**：低饱和中明度浑浊棕 + 抖动颗粒。降疲劳走 UI 覆盖率/动效平息，**不靠压暗**；亮主调或高饱和深色二选一，别落中间浑浊区。
- ⛔ **美术克制**：AI 痕迹素材不向玩家主推（菜单中心立绘橱窗）；中心展示物用百分百自有语言（shader 母题/像素框/金字）。
- ⛔ **主菜单中心禁大型单体装饰**（板/立绘/徽章/台面）。**例外**：功能性主 CTA（放大的「匹配对战」横卡）。

## 8. 工作流（怎么落地·谁把关）

1. **Claude 能自检的**（🟢 截图回路已通）：布局/构图/主次/比例/大色块配色/明显瑕疵。
   做法：**带窗口**跑 shot-runner（**不加 `--headless`**，headless 卡 `frame_post_draw`）：主菜单 `tools/menu_shot_runner.tscn` / 图鉴 `gallery_shot_runner.tscn`·`item_gallery_shot.tscn` / 战斗 `battle_shot.tscn` → 存 PNG（项目外或 res/ gitignore）→ `Read` PNG → 改→截→再看。
2. **Claude 仍弱、必走 AI-gen/美术 + Eddy 把关**：自定义像素字形、从零画 logo、像素级笔形精修。
3. **终审永远是 Eddy F6**（截图自检只减往返，不替代）。⛔ 别把预览截图堆进 BoBoZan 目录。
4. **美术友好（🟢）**：UI 默认完整 `.tscn` 化，节点命名表意带类型后缀；颜色/StyleBox 长期抽 `.tres`；未来换美术的位置加注释。美术替换 = Inspector 换资源，**不该回头改 .gd**。
5. ⚠ Eddy 常在编辑器手改 `.tscn`/Inspector → **改场景前先 grep 重读磁盘真实版本**，别用旧缓存覆盖他的参数。

**Godot 渲染踩坑（🟢 实测）**：① `clip_children` 裁剪 mask **不执行**父节点自定义 shader → 圆角必须**每层自己 shader 切**。② `TextureRect` 小于纹理的 size 必须 `expand_mode = EXPAND_IGNORE_SIZE`。③ 像素台阶圆角要"边框沿弧重算"（径向 `edge_dist`），非方形必须传 `aspect`。
