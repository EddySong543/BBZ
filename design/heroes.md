## 1. 十二生肖（h01–h12）

> h01~h12 严格对应十二地支生肖（子鼠 / 丑牛 / 寅虎 / 卯兔 / 辰龙 / 巳蛇 / 午马 / 未羊 / 申猴 / 酉鸡 / 戌狗 / 亥猪）。

### h01 子鼠 ｜【囤鼠】

| 字段 | 值 |
|------|-----|
| HP | 4 |
| 技能类型 | 被动 |
| 技能说明 | 子鼠在场时，己方获得的所有能量 +0.5。 |

### h02 丑牛 ｜【卸劲】

| 字段 | 值 |
|------|-----|
| HP | 7 |
| 技能类型 | 被动 |
| 技能说明 | 丑牛挨打时把冲击卸给全队——每名其他队友获得 0.5HP 护盾（上限 1.0HP）。 |

### h03 寅虎 ｜【连扑】

| 字段 | 值 |
|------|-----|
| HP | 4 |
| 技能类型 | 被动 |
| 技能说明 | 寅虎的攻击拆为两段、各自独立结算（命中触发效果翻倍）。 |

### h04 卯兔 ｜【狡兔】

| HP | 4 |
| 技能类型 | 被动 |

| 技能类型 | 被动 |

### h06 巳蛇 ｜【淬毒】

### h07 午马 ｜【当先】

## 2. 黑暗生肖（h13–h20）

> 黑暗子鼠 … 黑暗未羊，对应 h13–h20。暗批不守「镜维度」铁律——可从规则自由设计（单维度主标签仍守）。
> 概览与维度配额见 `design/heroes-dark-h21-h24.md`。

### h13 黑暗子鼠 ｜【鼠潮】

| 字段 | 值 |
|------|-----|
| HP | 4 |
| 技能类型 | 被动 |
| 技能说明 | 黑暗子鼠在场时，己方每触发一次连携效果，团队能量 +0.5（每回合最多 +1.5）。战场越乱、鼠群越肥。 |

### h14 黑暗丑牛 ｜【卸力反震】

| 字段 | 值 |
|------|-----|
| HP | 6 |
| 技能类型 | 被动 |
| 技能说明 | 黑暗丑牛防御成功挡下攻击时，向攻击者反弹所挡伤害的 50%。 |

### h15 黑暗寅虎 ｜【血勇】

| 字段 | 值 |
|------|-----|
| HP | 7 |
| 技能类型 | 被动 |
| 技能说明 | 黑暗寅虎无法使用「防 / 大防」（嗜杀红温·有进无退）；作为补偿，其「波」穿防——对手须用「大防」才挡得下（大波仍穿防）。 |

### h16 黑暗卯兔 ｜【疾风】

| 字段 | 值 |
|------|-----|
| HP | 4 |
| 技能类型 | 被动 |
| 技能说明 | 黑暗卯兔在场时，己方每局 2 次可把同一个动作再做一次（波/大波/攒/防）。 |

### h17 黑暗辰龙 ｜【镇压】

| 字段 | 值 |
|------|-----|
| HP | 6 |
| 技能类型 | **主动技** |
| 技能说明 | 主动技（占动作·耗 2 能·每局 2 次）：沉默对手当前出战英雄 2 回合——其技能完全失效（被动不触发、主动技不可用）。 |

### h18 黑暗巳蛇 ｜【缠绕】

| 字段 | 值 |
|------|-----|
| HP | 4 |
| 技能类型 | 被动 |
| 技能说明 | 黑暗巳蛇出战时，对手无法主动切换（被死死缠住）。 |

### h19 黑暗午马 ｜【践踏】

| 字段 | 值 |
|------|-----|
| HP | 5 |
| 技能类型 | 被动 |
| 技能说明 | 黑暗午马攻击命中敌方出战时，这一击超过 1.0HP 的溢出部分碾到一名敌方替补（最高血那个），封顶 1.0HP。 |

### h20 黑暗未羊 ｜【断罪】

| 字段 | 值 |
|------|-----|
| HP | 5 |
| 技能类型 | **主动技** |
| 技能说明 | 黑暗未羊主动挥圣剑给敌方出战烙下『断罪印』（占动作·费 2 能·每局 2 次）：被烙印者出战时血量 ≤ 1.0HP 即被斩杀（处决）。印记跟身不消，换下场可暂避、换回来又悬着。 |
