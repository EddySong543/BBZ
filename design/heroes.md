## 1. v4 重做决议（Step 2 — 单英雄重做）

按 `heroes-schools.md` §6 设计纪律（命名 B 格风 / 被动作用域明示 / 十二生肖映射）与 §8 数值框架（HP 3-7 / 大波 2 能 / 切换 0 能 / 初始 1 能）拍板。

### h01 子鼠 ｜【窃运】

| 字段 | 值 |
|------|-----|
| HP | 4（脆皮，经济流先锋） |
| 技能类型 | 主动 |
| 描述 | 消耗 0 能立即偷对手 1 能（对手 -1 / 自己 +1），每局最多 3 次 |
| 原语 | 能量盗取 |
| 作用域 | 单英雄主动 |
| 跨流派钩子 | 控制 / 快攻 / 经济 |

**设计思路**：

- **描述**：消耗 0 能立即偷对手 1 能（对手 -1 / 自己 +1），每局最多 3 次
- **原语**：能量盗取（团队池间转移）
- **作用域**：单英雄主动
- **跨流派钩子**：控制（卡对手节奏）/ 快攻（破对手大波蓄能）/ 经济（自我积累）
- **数值**：
  - 单次 1 能 ≈ 半个大波，cap 3 累计 3 能影响
  - 11 回合内预期每 3-4 回合用一次
  - 高节奏下"时机选择"= 决策密度强
- **Lenticular**：新手 = 看见就偷 / 进阶 = 卡对手攒到 1 能（差 1 即可大波）时偷
- **风险**：cap 3 可能不够爽快，需 playtest
- **备选名**：【鼠窃】【夜行】【穿墉】【掠粟】（最终选【窃运】= 偷取气运，比"偷食"更抽象有 B 格）

### h02 丑牛 ｜【怒目】

| 字段 | 值 |
|------|-----|
| HP | 6（标准偏坦克） |
| 技能类型 | 被动 |
| 描述 | 丑牛 HP < 满血时，**丑牛自己**攻击 +1 伤 |
| 原语 | 阈值切换 + 加伤放大 |
| 作用域 | **单英雄**（下场即失效，规避献祭式优势） |
| 跨流派钩子 | 防反 / 快攻 / 爆发 |

**设计思路**：

- **描述**：被动 — 丑牛 HP < 满血时，**丑牛自己**攻击 +1 伤
- **原语**：阈值切换 + 加伤放大
- **作用域**：**单英雄**（A1 版本；下场即失效，规避献祭式优势）
- **跨流派钩子**：防反（受伤获益）/ 快攻（短期内激活越打越猛）/ 爆发（叠加大波伤害）
- **数值**：
  - HP=6 → 第 1 次受伤后激活，触发后持续到下场/死亡
  - 触发面积 ~80% 局长（基本一受伤就有 buff）
  - 阈值清晰（"满血 vs 非满血"），不再有 HP≤50% 向下取整的歧义
- **Lenticular**：新手 = 受伤反而更猛 / 进阶 = BP 后故意先吃 1 波激活全局
- **风险**：与 h11 戌狗"队友死亡 +1 伤"功能定位略重叠，但触发条件不同（自伤 vs 队友死），可共存
- **备选名**：【赤目】【怒角】【逆鳞】（最终选【怒目】= 双目赤红古风感强，与"受伤激活"机制视觉对应）

### h03 寅虎 ｜【渴血】

| 字段 | 值 |
|------|-----|
| HP | 5（标准） |
| 技能类型 | 被动 |
| 描述 | 寅虎击杀对手英雄后，**全队**波伤害 +1（永久叠加，无上限，寅虎死亡后清零） |
| 原语 | 击杀触发 + 加伤放大（团队向） |
| 作用域 | **团队层次**（全队波 +1，由寅虎击杀驱动、寅虎死亡即清零） |
| 跨流派钩子 | 爆发 / Carry / 团队 |

**设计思路**：

- **描述**：被动 — 寅虎击杀对手英雄后，**全队波伤害 +1**（永久叠加，无上限；**寅虎死亡后清零**；仅加"波"、不加大波）
- **【2026-05-24 校准】**：原单英雄自 buff → 改为**团队 buff**（全队波 +1）= 把寅虎变成连接件（击杀 → 带动全队波，呼应 combo 审计要更多连接件）
- **原语**：击杀触发 + 加伤放大（团队向）
- **作用域**：**团队层次被动**（§6 合规 = 寅虎死亡即清零，非永久白嫖、与寅虎存活强绑，属"自限"路径；与 h30 星星同为合规团队层次被动）
- **跨流派钩子**：爆发 / Carry 后期 / 独立（自给自足型）
- **数值**：
  - 11 回合内击杀 1-2 个对手英雄（每方 3 个），最多 +2 伤
  - 后期波伤 = 1 + 2 = 3 伤，比基础大波（2 伤）还猛
  - 寅虎死亡清零 = 派生"保护寅虎"的阵容需求
- **Lenticular**：新手 = 杀人变强 / 进阶 = BP 队友选脆皮辅助送人头，让寅虎拿击杀点
- **风险**：寅虎死亡清零 = 强保护派生需求，平衡上需 playtest
- **备选名**：【啖魂】【饕餮】【噬魂】（最终选【渴血】= 古风凶威感，对应"击杀越多越渴望血"的叠加机制）

### h06 巳蛇 ｜【蛇蜕】

> 🔁 **2026-05-21 重做**：团队死亡赠能（活着零贡献、太弱）→ **蜕皮重生（首次保护）**。保留"蛇蜕"名 + 重生形象内核，机制从"舍命喂队友"翻转为"打不死的自保"。**作用域 团队→单英雄**——此后全员暂无被动团队层次案例（§6 第 6 条规则仍有效，只是当前 0 实例）。

| 字段 | 值 |
|------|-----|
| HP | 4（脆皮，但内置一条命，等效 ~6） |
| 技能类型 | 被动 |
| 描述 | 本局巳蛇首次受到致死伤害时不死，蜕皮重生为 **2 HP** 并清除自身全部 debuff（每局 1 次） |
| 原语 | 首次保护 + 净化（自身） |
| 作用域 | **单英雄**（重生与净化只作用巳蛇自己） |
| 跨流派钩子 | 韧性（凭空多一条命）/ 防反（越被斩越触发）/ 独立（自给生存） |

**设计思路**：

- **描述**：被动 — 本局巳蛇首次受到致死伤害时不死亡，蜕皮重生为 2 HP，并清除自身全部 debuff（每局 1 次）
- **原语**：首次保护（致死阈值改写）+ 净化（自身）
- **作用域**：**单英雄**（§6 被动默认单英雄；重生与净化只作用巳蛇本人）
- **跨流派钩子**：韧性（凭空多一条命）/ 防反（对手越想斩杀越触发蜕皮，斩杀资源打空）/ 独立（不依赖队友的自保）
- **填补**：**§5.3 首次保护 / 致死阈值改写维度全空，首启用**
- **数值**：
  - HP 4 + 重生 2 = 等效 ~6 HP；但重生后仅 2 HP **极脆**（一记大波/孤注即清）→ 是"多撑一回合/一动作"的保命，非持续坦
  - **每局 1 次**硬 cap
  - 致死保护挡下所有致死伤（大波 2 / 天威 4 / 孤注 4）→ 重生 2 HP；非致死伤不触发
  - **蜕皮净化** = 解自身全部 debuff（未来的毒/中毒/沉默等）→ **前瞻性净化位**，随 §5.5 状态附加维度填满而增值
  - 重生 HP 由方案初稿 3 压到 **2**（Eddy 调弱）：降低过肉 + 收敛与皇后奶叠加
- **Lenticular**：新手 = 死一次还能爬起来 / 进阶 = 故意推巳蛇上前线吃对手的致死大波/孤注，把对手"以为秒了"的斩杀资源作废，重生后再用 2 HP 换 1-2 个动作；BP 配激进/弃子流
- **风险**：
  - 重生后 2 HP 极脆，对手有连续输出可立即补刀 → 蜕皮价值依赖时机（挡大斩杀才赚、挡小波亏）
  - **Combo★** 与 h16 皇后【泽被苍生】：重生后皇后回血续命 → 需 playtest 是否过黏（2 HP 起点已比 3 HP 收敛）
  - 重做移除了旧"自杀喂能"链（旧版与 h08 替罪的无脑经济自杀链就此消解）
- **备选名**：【重蜕】【蜕骨】（最终仍选【蛇蜕】= 保留旧 kit 经典名，机制回归"蜕皮重生"字面本义，比旧"死亡赠能"更贴形象）

### h33 审判 ｜【最后审判】

> ⚖️ 塔罗 XX 号 Judgement。牌意 = 最终审判·清算 / 复活·觉醒 / 号角召唤 / 救赎 / 升华（天使吹号、亡者从棺中升起受审）。**取"最终审判·定生死"的一面——给团队一个确定的残血处决按钮，补快攻 2b 斩杀收割。**（复活那一面【起死回生】保留，留世界 h34 / 后续定夺）

| 字段 | 值 |
|------|-----|
| HP | 5（标准，执裁者） |
| 技能类型 | 主动 |
| 描述 | 消耗 2 能：审判对手出战英雄——若其 **HP ≤ 2**，直接处决（无视防御/护盾，不可减免）；否则无效（每局限 2 次） |
| 原语 | 斩杀/处决（致死阈值·反向） |
| 作用域 | 单英雄主动（占动作槽，效果作用于对手出战英雄） |
| 跨流派钩子 | 快攻（收割）/ 控制（斩杀威慑）/ 爆发 |

**设计思路**：

- **描述**：主动 — 消耗 2 能：对对手当前出战英雄宣判——若其 **HP ≤ 2**，立即处决（HP 归零，无视防/大防/护盾，不可被任何方式减免）；HP > 2 则本次审判无效（仍消耗能量与动作）。**每局最多 2 次**
- **原语**：斩杀/处决（致死阈值·反向——h06 蛇蜕把致死阈值改写"向上"求生，本技反向"处决"低血）
- **作用域**：单英雄主动（占动作槽，效果作用于对手出战英雄）
- **跨流派钩子**：快攻（保证收割残血）/ 控制（残血处决威慑、逼对手保血或频繁切换/回血）/ 爆发（团队铺血后的终结锤）
- **填补**：**快攻 2b 斩杀收割**——此前仅穷追(切换 chip)/塔(击杀 splash)，本技是**首个主动保证处决**；区别于普通伤害=它是"不可阻挡的判决"
- **数值**：
  - 阈值 HP ≤ 2（HP 范围 3-7 下，1-2 血即真残血）；2 能 + 占槽 + cap 2 三重制衡
  - **不可阻挡**（无视防/大防/盾/减免）= 判决不是"伤害"故挡不住；但**有明确解法**（见下）→ 非无脑必杀
  - **counterplay（关键平衡支点）**：审判在结算阶段检定"对手**出战**英雄"的 HP → 对手可**把残血英雄切下场**（换上的健康英雄不满足 ≤2 = 审判空打）/ 或**回血到 3+**（皇后）躲过 → 你打的是"赌他这回合保不保得住残血位"的盲选 yomi（§1.4 合法：基于公开 HP 状态，非预读其动作）
  - **旋钮**：阈值 2→1（更苛）或 →3（更宽）/ 是否允许大防格挡（默认否）/ cap
- **Lenticular**：新手 = 残血就处决 / 进阶 = 读对手"会不会切走/奶起残血位"来决定砸不砸审判；配铺血队友把目标压到 ≤2 再宣判；用威慑逼对手不敢留残血英雄在前
- **真跨英雄 combo**（对手 debuff / 铺血→补刀·真跨边界）：
  - ✅ **队友铺血 → 审判收头**（**补审计最薄的"铺血→补刀"轴**）：太阳易伤 / 穷追 chip / 任意波削到 ≤2 → 审判处决
  - ✅ **配穷追 h11**：对手切走残血躲审判 → 穷追对其下场英雄再 chip 1（切也疼、不切被斩的两难）
  - ✅ 团队斩杀链：把对手压到处决线，审判保证终结，不给回血/苟活机会
- **风险**：
  - **条件性**：无 ≤2 目标 / 对手切走 / 被奶起 → 空打浪费能量与动作（有意取舍：是终结器非通用输出）
  - **execute feel-bad**：被无视防御处决方挫败 → 靠"有切换/回血解法 + 仅 ≤2 + cap 2"缓解
  - **不可阻挡处决**若阈值过高会过强 → 旋钮收阈值
  - **实现旗标（Step 5b）**：结算阶段检定对手出战 HP ≤ 阈值 → 置 HP 0 触发死亡相位、绕过防御/护盾/减免管线；与切换/回血的相位先后需明确（处决在对手切换/回血结算**之后**判定当前出战位）
- **备选名**：【最后审判】（选定，4 字塔罗 = 牌名直译，"最终审判定生死"对应残血处决）；曾考虑【末日审判】【生死判决】【天谴处决】

- **真跨英雄 combo**（全场效果·真跨边界）：
  - ✅ **铺血→补刀轴**：队友把对手全队削残 → 寰宇同寂一键推过斩杀线 → 配审判处决 / 塔 splash 连锁团灭
  - ✅ **弃子流·配 h22 隐者**：主动炸死自己残血队友 → 隐者获 +攻/-受伤（队友阵亡叠加，真跨英雄）；与"最后一人 carry"打法咬合

  - **连锁死亡**：一次可能同时杀多个角色 → 触发多个死亡相位（隐者叠加 / 塔 splash / 穷追等）需明确结算顺序，避免无限连锁
  - **强度**：无视防御的全场保证 chip + 够到替补 → 若偏强，旋钮（cap 1 / 对己方减半 / 仅伤出战不及替补）
  - **实现旗标（Step 5b）**：全场遍历除施法者外所有角色（含双方 bench）施 1 伤、绕过防御/护盾管线、**批量死亡判定 + 死亡触发相位排序**（本作首个多目标连锁死亡场景）
- **备选名**：【寰宇同寂】（选定，4 字塔罗；寰宇同寂 = 天地万物同归寂静，独留中心舞者，最贴世界"圆满/万物归一/周期完结"的收官分量）；曾考虑【天倾地裂】【万物归墟】【世界寂灭】
