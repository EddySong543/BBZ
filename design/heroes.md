> **状态**：当前为**过渡版本**，与 `HeroData._hero_defs()` 代码现状对齐。

> **未来**：流派与定位将由 Eddy + Claude 协作重新设计（h14~h46 槽位），届时本文档会再次重写。

## 当前实装：13 个英雄（h01~h13）

主题：**12 生肖 + 愚者**。
代码位置：`src/battle/hero_data.gd::_hero_defs()`、`src/battle/skills/*.gd`。

### 定位说明

英雄定位仅为**临时分类**，会在流派重设计时全面调整。

| 标签 | 含义 |
|------|------|
| 进攻型 | 持续施加血量压力 |
| 防御型 | 吸收伤害、降低对手进攻效率 |
| 反制型 | 惩罚特定动作 |
| 经济型 | 改变能量获取/消耗 |
| 爆发型 | 一次性倾泻资源造成大量伤害 |
| 赌博型 | 高风险高回报 |
| 娱乐型 | 随机/有趣机制 |

## h01 子鼠 ｜ 财源广进

| 项 | 值 |
|----|----|
| HP | 8 |
| 技能类型 | 主动 |
| 临时定位 | 经济型 / 首发 |

**技能**：消耗 0 能量。标记一次"双倍攒"机会，下一次"攒"获得的能量翻倍（+2 而非 +1）。使用后下回合 cooldown 不可再次使用。

**实装细节**：`extra_action_id = Action.CAI_JIN`，状态 `_caijin_buff[p]` 与 `_caijin_cooldown[p]`。

---

## h02 丑牛 ｜ 反戈

| 项 | 值 |
|----|----|
| HP | 11 |
| 技能类型 | 主动 |
| 临时定位 | 防御型 / 中核 |

**技能**：消耗 2 能量。本回合若受到伤害，对对手造成等量反伤（无视防御）。无法击穿"狡兔三窟"的无敌状态。

**实装细节**：`extra_action_id = Action.FAN_GE`，读取 `_raw_dmg_to[p]`（防御前的原始伤害）。反伤在 phase 2 末尾结算。

---

## h03 寅虎 ｜ 百兽

| 项 | 值 |
|----|----|
| HP | 9 |
| 技能类型 | 主动 |
| 临时定位 | 爆发型 / 后期 |

**技能**：消耗当前全部能量（最少 1，最多 6），造成等量次数的 1 点伤害。每次 hit 随机选择目标（含申猴分身）。"大防"可全格挡所有 hit。

**实装细节**：`extra_action_id = Action.BAI_SHOU`，cost = `clampi(energy, 1, BAI_SHOU_DAMAGE_CAP=6)`。

---

## h04 卯兔 ｜ 狡兔三窟

| 项 | 值 |
|----|----|
| HP | 8 |
| 技能类型 | 主动 |
| 临时定位 | 防御型 / 轮转 |

**技能**：消耗 3 能量。本回合免疫所有伤害（含反戈反弹）。下回合获得 1 次免费切换（cost=0）。每局最多使用 3 次。

**实装细节**：`extra_action_id = Action.JIAO_TU`，状态 `_jiaotu_immune` / `_jiaotu_free_switch` / `_jiaotu_used_count`（cap=3）。

## h09 申猴 ｜ 身外化身

| 项 | 值 |
|----|----|
| HP | 8 |
| 技能类型 | 主动 |
| 临时定位 | 赌博型 / 中核 |

**技能**：消耗 3 能量，创建 1 个分身（1 HP）。上限 2 个分身。对手攻击时必须选目标，真假位置每次随机打乱（shuffle）。切换离场时所有分身清空。

**实装细节**：`extra_action_id = Action.SHEN_WAI`，状态 `clone_count` / `clone_hp` / `clone_order`（shuffle 后的索引）。`select_switch_target` 内 hardcoded 清分身。

## h13 愚者 ｜ 不可知之权柄

| 项 | 值 |
|----|----|
| HP | 8~14 随机 |
| 技能类型 | 主动 |
| 临时定位 | 娱乐型 / 灵活 |

**技能**：消耗 0 能量。随机执行"波/大波/防/大防/攒"之一（5 种基础动作等概率）。

**特殊**：开局前 HP 在 [8, 14] 范围内随机。

**实装细节**：`extra_action_id = Action.YU_ZHE`，phase 1 内 `selected_action[p]` 被随机替换。`setup()` 内 hero_id == "h13" 触发 `randi_range(8, 14)` HP 随机。
