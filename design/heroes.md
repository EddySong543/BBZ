## 1. v4 重做决议（Step 2 — 单英雄重做）

按 `heroes-schools.md` §6 设计纪律（命名 B 格风 / 被动作用域明示 / 十二生肖映射）与 §8 数值框架（HP 3-7 / 大波 2 能 / 切换 0 能 / 初始 1 能）拍板。

### h01 子鼠 ｜【窃运】

| 字段 | 值 |
|------|-----|
| HP | 4（脆皮，经济流先锋） |
| 技能类型 | 主动 |
| 描述 | 消耗 0 能立即偷对手 1 能（对手 -1 / 自己 +1），每局最多 3 次 |
| 原语 | 能量盗取 |
| 作用域 | 单英雄主动 |
| 跨流派钩子 | 控制 / 快攻 / 经济 |

**设计思路**：

- **描述**：消耗 0 能立即偷对手 1 能（对手 -1 / 自己 +1），每局最多 3 次
- **原语**：能量盗取（团队池间转移）
- **作用域**：单英雄主动
- **跨流派钩子**：控制（卡对手节奏）/ 快攻（破对手大波蓄能）/ 经济（自我积累）
- **数值**：
  - 单次 1 能 ≈ 半个大波，cap 3 累计 3 能影响
  - 11 回合内预期每 3-4 回合用一次
  - 高节奏下"时机选择"= 决策密度强
- **Lenticular**：新手 = 看见就偷 / 进阶 = 卡对手攒到 1 能（差 1 即可大波）时偷
- **风险**：cap 3 可能不够爽快，需 playtest
- **备选名**：【鼠窃】【夜行】【穿墉】【掠粟】（最终选【窃运】= 偷取气运，比"偷食"更抽象有 B 格）

### h02 丑牛 ｜【怒目】

| 字段 | 值 |
|------|-----|
| HP | 6（标准偏坦克） |
| 技能类型 | 被动 |
| 描述 | 丑牛 HP < 满血时，**丑牛自己**攻击 +1 伤 |
| 原语 | 阈值切换 + 加伤放大 |
| 作用域 | **单英雄**（下场即失效，规避献祭式优势） |
| 跨流派钩子 | 防反 / 快攻 / 爆发 |

**设计思路**：

- **描述**：被动 — 丑牛 HP < 满血时，**丑牛自己**攻击 +1 伤
- **原语**：阈值切换 + 加伤放大
- **作用域**：**单英雄**（A1 版本；下场即失效，规避献祭式优势）
- **跨流派钩子**：防反（受伤获益）/ 快攻（短期内激活越打越猛）/ 爆发（叠加大波伤害）
- **数值**：
  - HP=6 → 第 1 次受伤后激活，触发后持续到下场/死亡
  - 触发面积 ~80% 局长（基本一受伤就有 buff）
  - 阈值清晰（"满血 vs 非满血"），不再有 HP≤50% 向下取整的歧义
- **Lenticular**：新手 = 受伤反而更猛 / 进阶 = BP 后故意先吃 1 波激活全局
- **风险**：与 h11 戌狗"队友死亡 +1 伤"功能定位略重叠，但触发条件不同（自伤 vs 队友死），可共存
- **备选名**：【赤目】【怒角】【逆鳞】（最终选【怒目】= 双目赤红古风感强，与"受伤激活"机制视觉对应）

### h03 寅虎 ｜【渴血】

| 字段 | 值 |
|------|-----|
| HP | 5（标准） |
| 技能类型 | 被动 |
| 描述 | 寅虎击杀对手英雄后，**全队**波伤害 +1（永久叠加，无上限，寅虎死亡后清零） |
| 原语 | 击杀触发 + 加伤放大（团队向） |
| 作用域 | **团队层次**（全队波 +1，由寅虎击杀驱动、寅虎死亡即清零） |
| 跨流派钩子 | 爆发 / Carry / 团队 |

**设计思路**：

- **描述**：被动 — 寅虎击杀对手英雄后，**全队波伤害 +1**（永久叠加，无上限；**寅虎死亡后清零**；仅加"波"、不加大波）
- **【2026-05-24 校准】**：原单英雄自 buff → 改为**团队 buff**（全队波 +1）= 把寅虎变成连接件（击杀 → 带动全队波，呼应 combo 审计要更多连接件）
- **原语**：击杀触发 + 加伤放大（团队向）
- **作用域**：**团队层次被动**（§6 合规 = 寅虎死亡即清零，非永久白嫖、与寅虎存活强绑，属"自限"路径）
- **跨流派钩子**：爆发 / Carry 后期 / 独立（自给自足型）
- **数值**：
  - 11 回合内击杀 1-2 个对手英雄（每方 3 个），最多 +2 伤
  - 后期波伤 = 1 + 2 = 3 伤，比基础大波（2 伤）还猛
  - 寅虎死亡清零 = 派生"保护寅虎"的阵容需求
- **Lenticular**：新手 = 杀人变强 / 进阶 = BP 队友选脆皮辅助送人头，让寅虎拿击杀点
- **风险**：寅虎死亡清零 = 强保护派生需求，平衡上需 playtest
- **备选名**：【啖魂】【饕餮】【噬魂】（最终选【渴血】= 古风凶威感，对应"击杀越多越渴望血"的叠加机制）

- **风险**：与 §3 轮转流派绑定深，BP 选轮转体系几乎必拿；但其他流派下卯兔价值低
- **备选名**：【兔窟】【月隐】（最终选【三窟】= 保留"狡兔三窟"典故的核心字，3 字与机制层数 3 对应，比 4 字版更简练）

### h06 巳蛇 ｜【蛇蜕】

> 🔁 **2026-05-21 重做**：团队死亡赠能（活着零贡献、太弱）→ **蜕皮重生（首次保护）**。保留"蛇蜕"名 + 重生形象内核，机制从"舍命喂队友"翻转为"打不死的自保"。**作用域 团队→单英雄**——此后全员暂无被动团队层次案例（§6 第 6 条规则仍有效，只是当前 0 实例）。

| 字段 | 值 |
|------|-----|
| HP | 4（脆皮，但内置一条命，等效 ~6） |
| 技能类型 | 被动 |
| 描述 | 本局巳蛇首次受到致死伤害时不死，蜕皮重生为 **2 HP** 并清除自身全部 debuff（每局 1 次） |
| 原语 | 首次保护 + 净化（自身） |
| 作用域 | **单英雄**（重生与净化只作用巳蛇自己） |
| 跨流派钩子 | 韧性（凭空多一条命）/ 防反（越被斩越触发）/ 独立（自给生存） |

**设计思路**：

- **描述**：被动 — 本局巳蛇首次受到致死伤害时不死亡，蜕皮重生为 2 HP，并清除自身全部 debuff（每局 1 次）
- **原语**：首次保护（致死阈值改写）+ 净化（自身）
- **作用域**：**单英雄**（§6 被动默认单英雄；重生与净化只作用巳蛇本人）
- **跨流派钩子**：韧性（凭空多一条命）/ 防反（对手越想斩杀越触发蜕皮，斩杀资源打空）/ 独立（不依赖队友的自保）
- **填补**：**§5.3 首次保护 / 致死阈值改写维度全空，首启用**
- **数值**：
  - HP 4 + 重生 2 = 等效 ~6 HP；但重生后仅 2 HP **极脆**（一记大波即清）→ 是"多撑一回合/一动作"的保命，非持续坦
  - **每局 1 次**硬 cap
  - 致死保护挡下所有致死伤（大波 2 / 天威 4）→ 重生 2 HP；非致死伤不触发
  - **蜕皮净化** = 解自身全部 debuff（未来的毒/中毒/沉默等）→ **前瞻性净化位**，随 §5.5 状态附加维度填满而增值
  - 重生 HP 由方案初稿 3 压到 **2**（Eddy 调弱）：降低过肉 + 收敛回血叠加
- **Lenticular**：新手 = 死一次还能爬起来 / 进阶 = 故意推巳蛇上前线吃对手的致死大波，把对手"以为秒了"的斩杀资源作废，重生后再用 2 HP 换 1-2 个动作；BP 配激进/弃子流
- **风险**：
  - 重生后 2 HP 极脆，对手有连续输出可立即补刀 → 蜕皮价值依赖时机（挡大斩杀才赚、挡小波亏）
  - 重做移除了旧"自杀喂能"链（旧版与 h08 替罪的无脑经济自杀链就此消解）
- **备选名**：【重蜕】【蜕骨】（最终仍选【蛇蜕】= 保留旧 kit 经典名，机制回归"蜕皮重生"字面本义，比旧"死亡赠能"更贴形象）

### h09 申猴 ｜【凶兽】

> 🔁 **2026-05-21 重做**：身外化身/分身（费高 2 能、切换即清无联动、机制围绕"联想"非成功设计）→ **钢爪连段递增**。形象重定义：孙悟空神猴 → **峨眉山野猴（裂佛面 / 钢爪 / 破袈裟）= 披着破碎佛门皮相的凶蛮掠食者**。代价：娱乐流跌回 1 件+ §3.1 6a 假目标/分身、召唤替补维度腾空（后续英雄补）。

| 字段 | 值 |
|------|-----|
| HP | 4（脆皮快攻刺客，钢爪近战凶兽） |
| 技能类型 | 被动 |
| 描述 | 申猴连续出"波"，伤害逐段递增：第 1 段 1 伤 → 第 2 段 2 伤 → 第 3 段封顶 3 伤（撕裂三段）。出任何非"波"动作或被迫切换则连段归零；被"防/大防"格挡的波仍计入连段 |
| 原语 | 连击奖励 |
| 作用域 | 单英雄被动（仅申猴自己的波递增） |
| 跨流派钩子 | 快攻（核心）/ 爆发（第 3 段 3 伤斩杀）/ 控制（明牌压制逼对手防） |

**设计思路**：

- **形象**：峨眉山野猴 —— 裂佛面（破碎佛门皮相的凶悖）/ 手持钢爪（撕裂连段）/ 身穿破袈裟（堕落佛徒）。凶蛮掠食者，非孙悟空神猴
- **描述**：被动 — 申猴连续出"波"，伤害逐段递增：1 段 1 伤 → 2 段 2 伤 → **3 段封顶 3 伤**（撕裂三段）。出非"波"动作 / 被迫切换 → 连段归零重来；被"防/大防"挡住的波**仍计入连段**
- **原语**：连击奖励（§5.8 连击维度首启用）
- **作用域**：单英雄被动（仅申猴自己的波递增）
- **跨流派钩子**：快攻（核心，越撕越深的持续高压）/ 爆发（3 段 3 伤可斩杀）/ 控制（明牌递增逼对手每回合考虑防）
- **填补**：**§5.8 连击维度首启用**
- **数值**：
  - 每记波**费用 1 能不变**（治旧版"2 能费高"批评）；第 3 段 = 3 伤 / 1 能 = 大波（2 伤 / 2 能）的 3 倍能效
  - **硬封顶 3**：不封顶则"持续叠加"破坏能量经济（1 能秒杀跑飞），故到第 3 段不再涨
  - **被防/大防挡住的波仍计入连段（处理 A）** → 对手防得住伤害拦不住递增 → 逼出"波 vs 大波"心理战（升大波穿防惩罚对手的防）
  - **天然自限**：HP4 + 波vs波互伤（GDD §3.2）→ 递增着打自己也在挨打，攒到 3 段时申猴往往已残血
- **Lenticular**：新手 = 连续抓越打越疼 / 进阶 = 明牌博弈——对手必在第 2、3 段考虑防/大防，故升大波穿防钓他的防、或卡他没能量大防时把连段打满；HP4 要算"撕到第几段前会被反杀"
- **跨英雄 combo（有限，单英雄自引擎）**：当先 h07 免费切换把申猴顶上场续段。**不与渴血/天威/啼晓等单英雄自 buff 叠加**（见 memory `cross-hero-combo-reality`）
- **风险**：
  - 单英雄自引擎，跨英雄 combo 弱（与"孤立"批评同源，但有意取舍：换纯快攻刺客身份 + 明牌博弈深度）
  - 处理 A"防仍计连段"可能让对手 feel-bad（防了还涨）→ playtest 旗标：必要时改"被挡的波暂停不涨也不归零"
  - 封顶 3 的 3 伤/1 能能效仍高 → 若过强，旋钮 = 封顶降 2 / 或递增改"每 2 回合 +1"
- **备选名**：【连爪】【裂创】【急爪】【撕裂】（最终选【凶兽】= 峨眉山野猴凶蛮掠食者形象直给，沿用怒目/吞噬式具象命名，比"连爪"更扣形象而非机制）

### h10 酉鸡 ｜【啼晓】

> 🔁 **2026-05-21 重做**：主动 0 能 cap3 → **被动明牌博弈**。区别于初版"我偷偷选时机"，改为双方共知的固定窗口，差异化于 h07 同质模板 + 增 yomi 深度 + 主动转被动（合 5主8被倾向）。

**设计思路**：

- **核心 = 明牌博弈**：3/6/9 是**公开确定**的窗口（回合数双方可见），博弈来自双方对一个**已知威胁**的同时盲选 yomi——酉鸡方"砸不砸这记免费大波"、对手"防不防这记必来的波"，互相算计。**合法性核对**：§1.4 禁的是"假动作 / 试探 / 暴露 / 看对手选择再反应"；本设计基于双方共享的公开信息，无人偷看对方动作，属格斗游戏式健康 yomi，不触红线

- **数值**：
  - **折扣是机制必然非旋钮**：升级后仍付波的 1 能（而非大波 2 能）——否则收满 2 能直接选大波即可，升级形同虚设。老 kit（司晨）亦同
  - **回合数自限、无需 cap**：11 回合标准局触发约 3 次（第 3/6/9），与旧 cap3 等价；长局（22 回合）最多 7 次。被动 = 白拿，不套主动技"每局上限"习惯
  - 每次升级 = 1 能换 2 伤（vs 大波 2 能 2 伤），单次省 1 能

- **Lenticular**：新手 = 到点波更猛 / 进阶 = 围绕公开窗口反向操作——对手必然在 3/6/9 考虑防，故钓对手防空时改去攒/切换；或确保酉鸡在窗口回合在场吃节奏
- **风险**：
  - 单英雄作用域要求酉鸡在 3/6/9 出战才生效 → 对手可逼其下场/集火，酉鸡方需轮转保场，增深度也增门槛
  - 被动收益恒定、低操作 → 对新手偏"自动"；明牌窗口的 yomi 是留给进阶的深度补偿
- **备选名**：【闻鸡起舞】【晨歌】【天明】（最终选【啼晓】= 保留旧 kit"司晨"古风内核 + 主动转回被动，鸡啼报晓的视觉感对应"明牌窗口"——到点必鸣，谁都听得见）
