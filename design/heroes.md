# 波波攒之王 — 英雄设计文档

> 20 英雄完整设计，按定位分组。

---

## 英雄定位与位置说明

### 定位（Role）
| 定位 | 说明 |
|------|------|
| 进攻型 | 持续施加血量压力，迫使对手防守 |
| 防御型 | 吸收伤害、降低对手进攻效率 |
| 反制型 | 惩罚特定动作，打断对手计划 |
| 经济型 | 改变能量获取/消耗，滚雪球 |
| 骗招型 | 制造信息不对称，误导对手判断 |
| 爆发型 | 一次性倾泻资源造成大量伤害 |
| 赌博型 | 高风险高回报，概率/读牌决定收益 |
| 切换型 | 围绕英雄切换机制产生价值 |
| 蓄势型 | 随时间累积优势，后期发力 |

### 推荐位置
| 位置 | 说明 |
|------|------|
| 首发/先锋 | 对局开场，试探对手习惯 |
| 中核 | 中期核心，稳定输出或控场 |
| 后手 | 中后期登场，利用前期积累的资源 |
| 终结 | 残局收割，斩杀残血英雄 |
| 轮转 | 灵活切换，配合换人体系 |
| 灵活 | 多位置适用 |

## 英雄详设

---

### 1. 藏锋 — 经济型 / 后手

| 项目 | 内容 |
|------|------|
| **血量** | 12 |
| **技能类型** | 被动 |
| **技能** | 每在场上度过 2 个完整回合，结束时额外获得 1 点能量（切换英雄后计数重置） |

**打法风格**：后期滚雪球。越拖越有能量优势，能更频繁使用大波/大防或切换。12 血高血量确保能活到发力期。

**结算细节**：
- 回合计数器绑定英雄实例，切换离场后清零
- 第 2、4、6... 回合结束时触发
- 触发时机在回合结算末尾、伤害结算之后

---

### 2. 穿云 — 反制型 / 首发、中核

| 项目 | 内容 |
|------|------|
| **血量** | 8 |
| **技能类型** | 额外动作 |
| **技能** | **惊燕**（消耗 1 能量）：本回合若对手出「波」，则格挡并反伤对手 1 点。对「大波」无效 |

**打法风格**：专门惩罚试探性出波的对手，逼迫对方减少基础攻击。8 血较脆，需要精准读牌。

**结算细节**：
- vs 波：格挡伤害 + 反伤 1 点，穿云方消耗 1 能量
- vs 大波：无效，穿云方仍受到 2 点伤害并消耗 1 能量
- vs 攒/防/大防：无效果，仅消耗 1 能量
- 若双方都出惊燕：各自消耗 1 能量，无其他效果

---

### 3. 镇山 — 防守型 / 先锋

| 项目 | 内容 |
|------|------|
| **血量** | 10 |
| **技能类型** | 强化动作 |
| **技能** | 你的「防」额外维持一回合（即使用「防」后，下回合自动拥有防的效果，但你仍可选择其他动作） |

**打法风格**：铁壁防守反击。能长时间耗住对手能量，适合拖入后期给藏锋等蓄势型英雄发育。

**结算细节**：
- 使用「防」后，本回合和下回合均有防的格挡效果
- 维持防的回合，镇山可以同时执行其他动作（如攒/波）
- 维持防不额外消耗能量
- 连续使用「防」不会叠加（刷新维持回合数）
- 维持防只格挡「波」，不格挡「大波」

---

### 4. 虚浪 — 骗招型 / 先锋

| 项目 | 内容 |
|------|------|
| **血量** | 9 |
| **技能类型** | 额外动作 |
| **技能** | **虚浪**（消耗 0 能量）：本回合伪装成「波」出手。若对手使用「防」或「大防」，则造成 1 点伤害（不消耗能量），且对手无法反制。若对手出「波」则虚浪被抵消。若对手出「大波」则虚浪被压制，虚浪方受到 1 点伤害。 |

**打法风格**：心理骗招大师。专门针对爱防的对手，制造"我出波了"的假象穿透防御。

**结算细节**：
- vs 防：穿透造成 1 伤害（无视防御）
- vs 大防：穿透造成 1 伤害（无视大防）
- vs 波：互相抵消（虚浪和波都无效）
- vs 大波：虚浪被压制，虚浪方受 1 伤害
- vs 攒/其他：虚浪无效果
- 虚浪本身不造成伤害（vs 攒时不会造成伤害）

---

### 5. 惊涛 — 进攻型 / 中核

| 项目 | 内容 |
|------|------|
| **血量** | 9 |
| **技能类型** | 强化动作 |
| **技能** | 你的「波」造成伤害时，额外附加 1 点溅射伤害（无视防御，作用于对手当前英雄） |

**打法风格**：持续压迫流。即使波被防住，溅射伤害依然穿透。对手被迫必须大防或主动出击。

**结算细节**：
- 波命中（对手未防）：1（波基础）+ 1（溅射）= 2 伤害
- 波被防格挡：0（波被挡）+ 1（溅射）= 1 伤害
- 波被大防格挡：0（波被挡）+ 1（溅射）= 1 伤害
- 溅射伤害无视所有防御类型
- 波被抵消（双方同时出波）：溅射仍触发，对手受 1 伤害

---

### 6. 鬼步 — 切换型 / 灵活

| 项目 | 内容 |
|------|------|
| **血量** | 10 |
| **技能类型** | 被动 + 强化 |
| **技能** | 切换英雄消耗降为 0（无需消耗能量），但切换后本回合无法使用「大波」或「大防」 |

**打法风格**：多英雄轮换专家。快速根据局势切出最合适的英雄应对，牺牲高费动作为代价。

**结算细节**：
- 鬼步在场时，切换按钮消耗显示为 0
- 切换后鬼步离场，新英雄当回合不可选大波/大防
- 若鬼步是切换目标（从其他英雄切到鬼步），切换消耗为 0，但鬼步当回合也不可用大波/大防
- 能量不足时也可切换（消耗为 0）

---

### 7. 灵息 — 防守型+蓄势型 / 后手

| 项目 | 内容 |
|------|------|
| **血量** | 11 |
| **技能类型** | 额外动作 |
| **技能** | **灵息**（消耗 2 能量）：下一个上场的英雄恢复 2 点生命（不可超过上限）。若本回合被「大波」命中，则恢复失效但仍消耗能量 |

**打法风格**：续航磨血。适合把对局拖得很长，配合镇山或藏锋使用。

**结算细节**：
- 使用灵息后，标记"下一个切换上场的英雄"回复 2 HP
- 若灵息方本回合受到大波伤害 → 标记失效，2 能量白费
- 标记持续有效直到切换发生或灵息阵亡
- 灵息自身不享受此回复（仅限下一个上场英雄）

---

### 8. 余烬 — 爆发型+赌博型 / 终结

| 项目 | 内容 |
|------|------|
| **血量** | 8 |
| **技能类型** | 额外动作 |
| **技能** | **焚命**（消耗全部能量）：造成等同于消耗能量数值的伤害（最低 1 点，最高 5 点）。若被对手「防」或「大防」格挡 X 点伤害，则自身受到 2X 点反噬伤害 |

**打法风格**：高风险终结者。能量越多伤害越高，但一旦被猜到就瞬间崩盘。

**结算细节**：
- 消耗当前全部能量，至少消耗 1 点才能使用
- 伤害 = 消耗量，上限 5（即使消耗超过 5 也只造成 5 伤害）
- vs 防：防方受到伤害（防不格挡焚命），无额外反噬
- vs 大防：假设焚命造成 N 伤害，大防格挡全部 N → 余烬受 2N 反噬
- vs 其他：正常造成 N 伤害
- 焚命后能量归零

---

### 9. 空蝉 — 骗招型+反制型 / 先锋

| 项目 | 内容 |
|------|------|
| **血量** | 9 |
| **技能类型** | 额外动作 |
| **技能** | **空蝉**（消耗 1 能量）：本回合若对手使用「大波」，则完全闪避该伤害，并使对手额外损失 1 点能量。对其他动作无效果 |

**打法风格**：专门狩猎大波玩家。强行打断对手爆发节奏，让对手不敢轻易交大波。

**结算细节**：
- vs 大波：闪避全部 2 伤害 + 对手额外损失 1 能量
- vs 其他动作（攒/波/防/大防/其他）：空蝉无效果，纯亏 1 能量
- 双方都出空蝉：各自消耗 1 能量，无效果
- 空蝉不闪避「波」，仅闪避「大波」

---

### 10. 雷切 — 赌博型+爆发型 / 终结

| 项目 | 内容 |
|------|------|
| **血量** | 7 |
| **技能类型** | 强化动作 |
| **技能** | 你的「波」有 50% 概率造成 2 点伤害（否则为正常的 1 点） |

**打法风格**：极端高压。低能量就能打出爆炸收益，但伤害完全不稳定。7 血极脆。

**结算细节**：
- 每次使用「波」时独立判定 50% 概率
- 波被防格挡 → 无伤害（概率不触发）
- 波被大防格挡 → 无伤害
- 波命中（无防）：50% 造成 1 伤害 / 50% 造成 2 伤害
- 波 vs 波抵消：无伤害，概率不触发

---

### 11. 铁衣 — 防御型 / 先锋、轮转

| 项目 | 内容 |
|------|------|
| **血量** | 13 |
| **技能类型** | 额外动作 |
| **技能** | **铁衣**（消耗 1 能量）：本回合受到伤害减半（向下取整）。若减半后伤害 < 1（即原伤害 ≤ 1），则你获得 1 点能量 |

**打法风格**：稳定前排。13 血 + 减伤技能，能硬吃大波不死，适合吸收关键爆发。

**结算细节**：
- 使用铁衣后，本回合所有受到的伤害减半，向下取整
- 2 伤害 → 1 伤害（减半后 < 原值）
- 1 伤害 → 0 伤害（减半后 0.5 向下取整 = 0，且 < 1 → 获得 1 能量）
- 铁衣不格挡伤害，仅减少数值
- 铁衣 vs 大波（2 伤）→ 受到 1 伤害

### 12. 逆鳞 — 反制型 / 中核

| 项目 | 内容 |
|------|------|
| **血量** | 9 |
| **技能类型** | 被动 |
| **技能** | 每次受到伤害后，额外获得 1 点能量 |

**打法风格**：受击反打。对手越主动进攻，你越容易进入大波节奏。

**结算细节**：
- 每受到 ≥ 1 伤害时，获得 1 能量
- 一回合内受到多次伤害（如波+溅射），每次受伤分别触发
- 伤害被完全格挡（0 伤害）不触发
- 回合结算中触发，能量立即到账

### 13. 逐月 — 切换型+经济型 / 轮转

| 项目 | 内容 |
|------|------|
| **血量** | 10 |
| **技能类型** | 被动 |
| **技能** | 每次成功切换上场时，获得 1 点能量 |

**打法风格**：资源轮转核心。配合鬼步能形成高速换人体系，不断赚取能量优势。

**结算细节**：
- 任何英雄切换到逐月时触发（不限于特定来源）
- 切换消耗照常扣除后再获得 1 能量（净效果取决于切换消耗）
- 逐月被强制切换（原英雄阵亡）上场时也触发

### 14. 天衡 — 防御型+经济型 / 后手

| 项目 | 内容 |
|------|------|
| **血量** | 11 |
| **技能类型** | 被动 |
| **技能** | 若本回合双方均未造成伤害，则回合结束时获得 1 点能量 |

**打法风格**：和平运营流。擅长在防守与博弈中慢慢积累资源优势。

**结算细节**：
- 判定时机：回合结算末尾，伤害结算完成之后
- 条件：双方当前英雄均未受到伤害（包括溅射、反伤等）
- 双方都出防/大防/攒等非伤害动作 → 触发
- 任一方受到 ≥ 1 伤害 → 不触发

### 15. 血狩 — 进攻型+赌博型 / 终结

| 项目 | 内容 |
|------|------|
| **血量** | 8 |
| **技能类型** | 强化动作 |
| **技能** | 你的「波」若成功造成伤害，则恢复自身 1 点生命（不超过上限） |

**打法风格**：吸血压制。只要连续猜中对手，就能边压血边回血，形成强烈滚雪球。

**结算细节**：
- 波命中对手且造成 ≥ 1 伤害 → 血狩回复 1 HP
- 波被防/大防格挡 → 无回复
- 波被抵消 → 无回复
- 回复不超过血狩最大血量（10）

### 16. 破军 — 爆发型 / 终结

| 项目 | 内容 |
|------|------|
| **血量** | 9 |
| **技能类型** | 强化动作 |
| **技能** | 你的「大波」伤害提升至 3 点，但消耗增加至 4 点 |

**打法风格**：超重炮台。一旦命中几乎直接奠定胜局，但能量压力极大。

**结算细节**：
- 大波消耗 4 能量（原 3），造成 3 伤害（原 2）
- 大波 vs 大波抵消：各自消耗 4 能量，无伤害
- 大波被大防格挡：消耗 4 能量，无伤害
- 穿透防：造成 3 伤害
- 大波 vs 波：破军方受 1 伤害（对方波），对方受 1 伤害（破军大波压制）

### 17. 狂战 — 进攻型+爆发型 / 中核

| 项目 | 内容 |
|------|------|
| **血量** | 10 |
| **技能类型** | 被动 |
| **技能** | **血怒**：每当此英雄累计失去 5 点血量，你的「波」伤害永久 +1（叠加上限 2 层） |

**打法风格**：卖血换输出。对手如果不尽快击杀狂战，狂战的常规"波"将变成不消耗额外能量的"小核弹"。

**结算细节**：
- 追踪狂战累计失去的血量（含治疗后的净损失）
- 累计失去 5 血 → 波伤害 +1（变为 2）
- 累计失去 10 血 → 波伤害 +1（变为 3）
- 上限 2 层（波最多 3 伤害）
- 切换离场后层数保留
- 波被格挡不造成伤害，但层数不影响消耗

### 18. 影卫 — 防御型+反制型 / 轮转

| 项目 | 内容 |
|------|------|
| **血量** | 8 |
| **技能类型** | 强化动作 |
| **技能** | 你的「大防」消耗降低为 1 点 |

**打法风格**：低成本防御。影卫是完美的"挡箭牌"，专门用来切换上场抵挡对手的高费「大波」。

**结算细节**：
- 大防消耗从 2 降为 1
- 格挡效果不变（格挡「波」和「大波」）
- 注意：8 血身板脆，虽然大防便宜但扛不住穿透

---

### 19. 幻瞳 — 骗招型 / 中核

| 项目 | 内容 |
|------|------|
| **血量** | 9 |
| **技能类型** | 额外动作 |
| **技能** | **镜像**（消耗 1 能量）：本回合镜像对手上一个回合使用的动作。若对手上回合切换英雄，则此技能失效 |

**打法风格**：复读机博弈。通过复制对手的动作来强行拉平资源差或造成抵消。

**结算细节**：
- 复制对手上回合的动作（攒/波/防/大波/大防/特殊动作）
- 消耗镜像本身的 1 能量 + 被复制动作的能量消耗
- 若能量不足以支付被复制动作，镜像不可使用
- 对手上回合切换 → 镜像失效（按钮不可用或使用后无效果）
- 不能复制对手的镜像（若对手上回合出镜像，则复制镜像所复制的动作）
- 复制的大波/波享受幻瞳自身的英雄加成（非对手的）

---

### 20. 瞬岚 — 切换型 / 中核、后期

| 项目 | 内容 |
|------|------|
| **血量** | 9 |
| **技能类型** | 被动 |
| **技能** | 切换英雄后，本回合可立即使用一次「波」（不消耗能量）。但此英雄无法使用「大波」和「大防」 |

**打法风格**：快速切换突袭。利用切换后的免费波打对手一个措手不及。

**结算细节**：
- 从其他英雄切到瞬岚的当回合：获得一次免费用「波」的机会（自动触发，也可选择不使用）
- 瞬岚永远不能使用大波和大防（按钮始终不可用）
- 免费波享受英雄自身的强化（但瞬岚无强化）
- 若切换后对手当回合也出波 → 正常抵消（但瞬岚的波是免费的）
- 切换消耗照常支付

## 阵容搭配思路

| 体系 | 英雄组合 | 核心思路 |
|------|---------|---------|
| **拖后体系** | 镇山 + 藏锋 + 天衡 | 前排耗住，后排滚雪球 |
| **轮转体系** | 鬼步 + 逐月 + 瞬岚 | 高速换人赚能量 |
| **爆发体系** | 破军 + 余烬 + 狂战 | 攒能量一波带走 |
| **骗招体系** | 虚浪 + 空蝉 + 幻瞳 | 信息战，让对手猜不透 |
| **反制体系** | 穿云 + 逆鳞 + 影卫 | 对手出什么就被罚什么 |
| **压迫体系** | 惊涛 + 雷切 + 血狩 | 持续施压，不让对手喘息 |
