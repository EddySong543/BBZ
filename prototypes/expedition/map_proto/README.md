# 远征地图探索原型（任务 A·占位美术）

> 设计真相源：`design/expedition-map.md`（子文档 B）。原型代码·可丢弃·不进 src/。

## 验证假设

1. "搜打撤"循环在 12×12 网格上是否成立：迷雾探索 → 遭遇取舍（打/逃）→ 贪与撤的张力。
2. 三压力源（补给步数 / 危险度时钟 / 撤离点关窗）叠加后，单局节奏是否落在 60-100 刻带（≈15-25 分钟目标的刻代理）。
3. 分层大地图 fallback 前，单张中型地图作为一层的可玩性。

## 怎么跑

- **试玩**：编辑器打开 `MapProto.tscn` → F6。

## 原型简化（与正式版的差距·判读时注意）

- **战斗=自动结算占位**：先知效率 0.7-0.9 伤/拍（校准 v6 研究发现），受伤按 tier 带随机——没有真打拍，节奏数据里"战斗刻"是估算的。
- 背包=计数器（拼图在 backpack_proto）；保险槽不在本原型。
- 逃跑简化为"进战前选逃"（正式=战斗中任意拍）；挨一拍伤害=0.5×tier 占位。
- 行商媒介=金币占位（Eddy 待定）；修补匠折干粮×2（扩容在背包原型）。
- 事件为一次性（行商回访例外·库存不刷新未实现）。
