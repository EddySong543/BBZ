# 远征背包拼图原型（任务 B·占位美术）

> 设计真相源：`design/expedition-backpack.md`（子文档 C）。原型代码·可丢弃·不进 src/。

## 验证假设

1. 形状拼图背包的核心乐趣：拾取→旋转→拼放的取舍是否好玩（尤其"大件值不值得腾格子"）。
2. **战斗力 vs 运力**张力：装备栏（不占格·撤离不带出）与背包（占格·带得走）的换装决策是否成立。
3. 保险槽（≤2×2·死亡保留）+ 死亡 30% 金币保底的痛感/安心感配比。

## 怎么跑

- **试玩**：编辑器打开 `BackpackProto.tscn` → F6。
  - 顶部按钮模拟击杀 T1/T2/T3/开宝箱 → 掉落区出货
  - 拾起=左键点物品 ｜ 放下=点背包格 ｜ R=旋转 ｜ 右键=放回掉落区 ｜ X=丢弃
  - 点背包内物品=拾回手上；保险槽/装备栏按钮=放入或取回
  - 修补匠按钮=+1 行/列（封顶 6×6）；撤离/死亡结算按钮=看两种结算文案
- **逻辑自检**（headless·16 项）：
  `godot --headless --path <项目根> --script res://prototypes/expedition/backpack_proto/selfcheck_backpack.gd`

## 已实现（按子文档 C）

4×4→6×6 网格｜首发 7 形状（1×1/1×2/1×3/2×1/2×2/L/2×3）拾放旋转无重叠越界｜
金币类价值密度递增（碎宝石 20 → 蟠龙冠 67/格）｜装备栏上限解开·仅战斗道具·撤离不带出｜
保险槽 ≤2×2 单件｜撤离=背包+保险槽全带出·死亡=保险槽+金币 30% 保底其余消失｜
掉落表（T1/T2/T3/宝箱·件数带与权重=子文档 C §7）。

## 原型简化

- 「鎏金屏风 2×3」「1×3 战斗道具」=为补齐形状库加的**原型占位物品**（非正典·正典化需 Eddy 点头）。
- 丢弃即消失（正式版=留在原格可回捡）；撤离/死亡结算只出文案不落仓库。
- 拼放交互=点击式（拾起跟随鼠标），非拖拽——手感验证够用，正式版再定交互。
