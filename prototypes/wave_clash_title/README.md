# 原型：对波加载界面（wave_clash_title）

## 假设（Hypothesis）

游戏点开后的加载/进入界面 —— 左蓝、右红两道冲击波从屏幕两侧向中央**连续推进**，相遇后进入**中央僵持**（持续涌动），玩家点击屏幕后随机一方盖过另一方，再进入游戏。

验证：能否仅用一个 canvas_item shader（无贴图）实现这种"对波 → 僵持 → 盖过"的卡通像素发光质感，且观感足够带感、节奏连续无卡顿。

## 如何运行

- **Godot 编辑器**：打开 `wave_clash_title.tscn`，按 `F6`（运行当前场景）。
  - 推进 ~0.85s → 撞击 ~0.2s → 中央僵持（持续涌入小波 + 中心白柱微脉动 + 边界小幅游走）→ 提示「点击屏幕进入游戏」→ 鼠标/任意键点击 → 随机一方盖过 → 控制台打印（**不切场景**）。
- **命令行运行**：
  ```
  godot --path <PROJ> res://prototypes/wave_clash_title/wave_clash_title.tscn
  ```
- **重新截图**（非 headless，会短暂弹窗）：
  ```
  godot --path <PROJ> -s res://prototypes/wave_clash_title/_screenshot.gd
  ```
  输出 7 帧：`shot_1_start` / `shot_2_advance_25` / `shot_3_advance_70` / `shot_4_impact` / `shot_5_settle_a` / `shot_6_settle_b` / `shot_7_sweep`。

## 像素风机制（核心：大格子 + 多档颜色）

**认知纠偏**：像素风 ≠ 颜色少。颗粒感由"格子大"实现，渐变感由"颜色档位多"实现，两件事不冲突，绝不绑死。

- 背景 `Wave` 是**原生分辨率** ColorRect。shader 把屏幕切成 **`cells_x`(默认 64) 列正方形格**（格高 = `cells_x/aspect`）。
- 每个片元先 `cuv = (floor(UV*grid)+0.5)/grid` **吸附到格心**，整格只用该中心点算一次颜色、填纯色。**同格所有片元颜色完全相同 → 一格 = 一块纯色**。
- 亮度量化 **`levels`(默认 40) 档**：蓝/红各 40 个由暗到亮的层次（不是 5 色简笔画）。
- 颜色 ramp 在 5 个关键色（最暗 → 最亮 → 白）之间用 `mix` 插值，L 量化后查 ramp → **40 种蓝 + 40 种红 + 白**。
- 相邻格 cuv 差 1/64 → energy 差 0.01-0.03 → 跨多档 → **相邻格自然显色差**。**不需要任何黑缝/描边**——前几版试过都失败（暗缝雪花感、白描边 HOT 糊片）。
- 文字层不走网格：原生高分辨率 Label，经 **FontManager**（Ark Pixel 像素字体，关抗锯齿），字号 12 整数倍：标题 96=8× / 提示 36=3×。

## 时间轴（脚本 tween chain，全程连续无 sleep/timer/wait）

```
t=0     ─┐
推进 0.85s│  pulse_l_x 0→0.5, pulse_r_x 1→0.5（平滑平行 tween）
         │  pulse_amp = 1.0（大波振幅恒定）
         │  小波 wave_amp = 0.10（背景纹理让方格颗粒可见）
t=0.85  ─┤
撞击 0.2s │  pulse_amp 1→0  +  center_amp 0→1
         │  wave_amp 0.10→0.25（小波涌动加强）
         │  intensity 1.0→1.25→1.0 短促闪
         │  title alpha 0→1
t=1.05  ─┘
僵持      │  _process 每帧：
         │    · wave_time += delta*6  → 小波相位推进（永不静止）
         │    · clash_pos 在 0.5±0.025 双频游走（边界挤压）
         │    · center_amp = 1.0 + sin(t*3.2)*0.10（中央白柱局部微脉动 0.9~1.1）
         │  ⚠ intensity 不再全屏脉动（删 _breathe，避免"黑白闪"）
点击     │  clash_pos tween 到 0/1（盖过）
         │  base_L = mix(0.35, 0.72, flood) 自动让整屏"逐渐高亮"
```

## shader uniforms（可调旋钮）

- `cells_x = 64`：格数。越大格子越细颗粒。
- `levels = 40`：颜色档数。越大渐变越细腻。32~48 都合理。
- `pulse_l_x / pulse_r_x / pulse_amp`：大波位置 + 振幅（脚本驱动）。
- `center_amp`：中央白柱权重（撞击后起，僵持期微脉动）。
- `wave_amp / wave_time / wave_freq`：持续涌入的小波振幅 + 相位 + 频率（默认 freq=60，每屏 ~5 道竖直波）。
- 颜色 ramp（蓝/红/白）写死在 shader 里，未做 uniform。

## 研究发现（迭代历史血泪教训）

- **【认知纠偏】像素风 ≠ 颜色少**。前几版试 5 档量化 → 简笔画 → 5 色拼不出渐变 → 相邻同色看不到格子 → 用黑缝/白描边硬补结构 → 失败。正解：大格子 + 多档颜色。
- **【删 fbm】fbm 平滑噪声调制是 "老电视雪花糊感" 的元凶**。所有 fbm 项已全删。
- **【删暗角 vig】暗角衰减让边缘暗下来形成 CRT 球面感**。已删。
- **【辉光按 side 切】**蓝辉光只能在蓝半屏出现，红辉光只能在红半屏 → 永不串色出紫雾。
- **【冲击波是竖直波列】** Eddy 硬要求。波峰竖直，水平方向推进。小波相位加 `cuv.y * 6.0` 偏移让纵向相邻格 L 跨档（波峰倾斜仅 ~0.4°，肉眼仍是竖直）。
- **【删 INTRO_HOLD 死帧】** 早期 `await create_timer(0.8).timeout` 是 "卡死 1 秒" 元凶。
- **【wave 加在 base 上而非 max】** max(base, wave) 时 wave < base 不显，加法让 base 区每格 L 都不同 → 颜色丰富。
- **【删 _breathe 全屏 intensity 脉动】** 全屏乘整体亮度 → 量化档大幅跳变 → "黑白闪"。改成 center_amp 局部脉动。
