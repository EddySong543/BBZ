# 原型：对波加载界面（wave_clash_title）

## 假设（Hypothesis）

游戏点开后的加载/进入界面 —— 左蓝、右红两道冲击波从屏幕两侧向中央**连续推进**，相遇后进入**中央僵持**（持续涌动），玩家点击屏幕后**胜方波加速冲锋、连击撞过边界、最终崩溃盖过**另一方，再进入游戏。

验证：能否仅用一个 canvas_item shader（无贴图、纯代码）实现"对波 → 僵持 → 连击盖过"的卡通像素发光质感，且观感足够带感、风格化（非数据条纹图）、节奏连续无卡顿。

## 如何运行

- **Godot 编辑器**：打开 `wave_clash_title.tscn`，按 `F6`（运行当前场景）。
  - 推进 ~0.85s → 撞击 ~0.2s → 中央僵持（持续涌入小波 + 中心白柱微脉动）→ 提示「点击屏幕进入游戏」→ 鼠标/任意键点击 → **连击盖过（C 型）** → 控制台打印（**不切场景**）。
- **重新截图**（非 headless，会短暂弹窗）：
  ```
  godot --path <PROJ> -s res://prototypes/wave_clash_title/_screenshot.gd
  ```
  输出 9 帧：`shot_1_start` / `shot_2_advance_25` / `shot_3_advance_70` / `shot_4_impact` /
  `shot_5_settle_a` / `shot_6_settle_b` / `shot_7_combo_hit` / `shot_8_burst` / `shot_9_swept`。
  > ⚠ 截图只能验证**静态**特征（颗粒/dither/撞击闪/扩散环/末态色）。波的生命周期淡入淡出、
  > 非对称浪头推进、连击节奏这些**动态**效果必须 F6 实跑才能确认。

## 风格化机制（v2 · 2026-05-29）

在「大格像素 + 多档颜色」正确路线之上做了 5 项风格化：

1. **非对称浪头波形**：陡前缘（K=520，~2.3 格）+ 长拖尾（K=70，~6 格），替代旧版对称高斯软斑 →
   波"有形"而非亮斑。`wave_head(s)`：s>0（中央侧/波前）陡，s<0（边缘侧/波尾）缓。
2. **生命周期振幅包络**：每道波 `c=fract(phase)`，振幅乘 `smoothstep(0,0.12,c)·(1-smoothstep(0.80,1.0,c))`，
   并从**屏外**（origin=-0.12/1.12）推进到中央侧（target=0.58/0.42）→ 波从屏外淡入、到中央淡出，
   **消除旧版"波直接冒出来"**（旧版 `fract()` 归零瞬间波包位置突变回边缘满振幅显形）。
3. **2D 格点 hash 颗粒**：`fract(sin(dot(ci, vec2(12.9898,78.233)))*43758.5453)`，替代旧"整行 hash"。
   **旧版每行一个亮度值 → 水平长条 = 数据条纹图感的元凶**；改 2D 后颗粒是随机格点，像素质感。
4. **Bayer 4x4 有序抖动 dithering**：量化前按格子索引加 `(BAYER-0.5)/levels` 偏移 → 档位边界棋盘交错，
   复古像素渐变质感（中央过渡带最明显）。
5. **连击盖过（C 型）**：见下方时间轴。

保留的正确路线：大格 64 列每格中心采样纯色 / 多档颜色 ramp（蓝40+红40+白）/ 相邻格 cuv 差自然显色差
（无描边无暗缝）/ 蓝红按 side 切永不串色出紫。配色维持蓝 vs 红。

## 时间轴（脚本 tween chain，全程连续无 sleep/timer 死帧）

```
t=0     ─┐
推进 0.85s│  pulse_l_x 0→0.5, pulse_r_x 1→0.5（平滑平行 tween）
t=0.85  ─┤
撞击 0.2s │  pulse_amp 1→0 + center_amp 0→1 + wave_amp 0.10→0.18 + intensity 短促闪
t=1.05  ─┘
僵持      │  _process 每帧：phase_l/phase_r 持续累加（波涌入）/ clash_pos 双频游走 /
         │  center_amp 微脉动 0.9~1.1（局部，不全屏闪）
点击 → 连击盖过（C 型）：
  · 胜方 phase 速度拉到 CHARGE(2.4)，败方压到 LOSER(0.18) → 胜方波加速冲锋、败方变疏弱
  · 4 击蓄力：中线 clash_pos **阻尼震颤**（被撞后阻尼正弦来回摆动衰减，丝滑）+ hit_flash 每击 1→0 局部闪 + 每击轻微 shake
  · 第 5 下崩溃决堤：clash_pos 从中央一鼓作气冲到 0/1（CUBIC）+ **全屏光 glow**（burst 0→1.3 中央光晕扩展到全屏再自然衰落，取代旧窄环+白闪）+ 强 shake
  · base_L flood = mix(0.35, 0.62, |clash-0.5|*2) 让胜方色随盖过铺满（上限 0.62 = 饱和色不糊白）
```

## shader uniforms（可调旋钮）

- `cells_x = 64` / `levels = 40`：格数 / 颜色档数。
- `pulse_l_x / pulse_r_x / pulse_amp`：大波位置 + 振幅（推进期）。
- `center_amp`：中央白柱权重（僵持期微脉动）。
- `wave_amp`：持续涌入小波振幅（稳态 0.18）。
- `phase_l / phase_r`：蓝/红侧小波累积相位（脚本每帧累加；红侧初始偏移 0.25 让左右不同步）。
- `wave_time`：仅用于波纹纵向漂浮（与推进相位解耦）。
- `dither_amt = 1.0`：Bayer 抖动强度（×1 档）。
- `hit_flash`：连击撞击局部闪（每击 0→1→0）。
- `burst`：崩溃全屏光爆发 0→1.3（中央光晕向外散发；fade=smoothstep(0,0.15)·(1-smoothstep(0.55,1.25))，**burst=0 时无 glow**）。
- `shake`：受击屏幕抖动（UV 偏移；脚本驱动衰减）。
- 颜色 ramp（蓝/红/白）写死在 shader 里。

## 脚本旋钮（wave_clash_title.gd）

- `BASE_PHASE_SPEED=0.45`：僵持期波相位速度。
- `CHARGE_PHASE_SPEED=2.4` / `LOSER_PHASE_SPEED=0.18`：盖过期胜方加速 / 败方压制。
- `SHAKE_HIT=0.0045` / `SHAKE_BURST=0.016` / `SHAKE_DECAY=0.05`：连击轻 shake / 崩溃强 shake / 衰减速度。
- `_run_combo()` 的 `strikes`/`kick`：连击蓄力击数（4 击）与每击震幅（中线 `_apply_kick` **阻尼正弦震颤** kick≈0.024→0.039）；崩溃段 clash 从中央冲到 0/1 + burst 全屏光。

## 研究发现（迭代历史血泪教训）

- **【认知纠偏】像素风 ≠ 颜色少**。前几版试 5 档量化 → 简笔画拼不出渐变 → 黑缝/白描边硬补 → 失败。正解：大格子 + 多档颜色。
- **【删 fbm】**fbm 平滑噪声是"老电视雪花糊感"元凶，已全删。
- **【删暗角 vig】**暗角衰减形成 CRT 球面感，已删。
- **【辉光按 side 切】**蓝/红辉光各自半屏，永不串色出紫雾。
- **【冲击波是竖直波列】** Eddy 硬要求。波峰竖直、水平推进。
- **【删 INTRO_HOLD 死帧】** 早期 `await create_timer(0.8)` 是"卡死 1 秒"元凶。
- **【删 _breathe 全屏 intensity 脉动】** 全屏乘亮度 → 量化档大幅跳变 → "黑白闪"。改 center_amp 局部脉动。
- **【v2 · "波冒出来"根因】** 旧版波位置 `fract(t)*0.55`，`fract()` 归零瞬间波包从 0.55 突变回 0 边缘满振幅显形。
  正解：生命周期振幅包络（淡入淡出）+ 起点设屏外。
- **【v2 · "数据条纹图感"根因】** 旧版"整行一个 hash 亮度"形成水平长条。正解：2D 格点 hash → 随机颗粒。
- **【v2 · 崩溃过曝】** `intensity 1.4 + flood 提亮`叠加把整屏推到顶档糊白、扩散环不可见。
  正解：白闪峰值降到 1.30 且短促（0.07s）+ flood 上限降到 0.62（饱和色不泛白）+ 扩散环在白闪回落后才扩张。
- **【v2b · 扩散环→全屏光 glow】** 窄环不够"全屏散发"。改成以中央为心的宽光晕(glow_w 随 burst 0.12→1.6 扩到全屏)，
  并去掉 intensity 白闪(全屏乘法是糊白元凶)、全靠 glow 加法提供光。震颤改阻尼正弦(丝滑)、加 shake(连击轻/崩溃强)。
- **【v2b · glow 污染僵持期 bug】** burst=0 时 `(1-smoothstep(0.55,1.25,0))=1`，glow 在平时仍激活、中央挂亮斑(verify 色块 15→9)。
  正解：fade 乘 `smoothstep(0,0.15,burst)` 淡入因子 → burst=0 完全无 glow，仅崩溃时爆发。
