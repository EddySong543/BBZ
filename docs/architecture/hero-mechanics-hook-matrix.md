> **用途**：Battle Core v4 重写的实装参照表。逐个英雄列出机制 + 引擎需求（触发时机 + 读写状态）。
> **来源**：`design/heroes.md §1`（v4 / Step 3 拍板版 + 2026-05-24 Eddy 手记对齐）。§2 旧 kit 已废弃。
> **配套**：`ADR-002-battle-core-v4-architecture.md`（据本表做出的架构决策）。
> **状态**：2026-05-25 初版，随实装修订。

## 4. 新基建需求（按类别）

**① 半血 / 0.5 HP 增量**：h18、h24（首个）、h30、h31 → 横切需求，数值层优先统一支持。

**② 挂英雄身上、随切换保留的状态（buff/debuff）**：h04(窟)、h09(连段)、h14(待发)、h25(蓄势)、h23(在场型 buff)、h32(燃烧·禁疗+易伤·附对手)。

**③ 变身 / 双形态**：h26（唯一，需 form 状态机 + battle_core 首次引入"变身"概念，标注为最大代码新增）。

**④ 延迟 / 转移伤害**：h27(延迟队列)、h30(转移到后排)、h19(挚爱死→反噬)、h24(HP 平衡，改写结算)。

**⑤ 替补席参战（板凳位影响战斗）**：h30（首个"后排参与结算"）、h28(恶魔替补仍供养)、h16(回血含替补)、h34(AOE 命中替补)、h29(溢出波及替补)。

**⑥ 全场 AOE / 多目标 + 批量死亡**：h34（首个群体 + 打到双方替补 + 多目标连锁死亡）、h29(击杀溢出连锁)。

**⑦ 无视防御的处决/斩杀**：h33(处决)、h11(追击)、h34(AOE)、h19(殉情)。→ 伤害需携带 pierce_defense / pierce_shield 标志。

**⑧ 契约 / 绑定（效果挂到另一英雄）**：h28(首个缔约)、h19(挚爱绑定)。→ link state。

**⑨ 复活**：当前 34 个**无**已落地复活；h06 蛇蜕=自身重生（致死改写）。审判复活面【起死回生】保留未实装。

**⑩ 团队层共享 buff**：h03(全队波+1)、h28(契约队友+攻/恶魔付血)、h30(后排分担)。

**额外（文档点名）**：动作槽例外(h07)、沉默/净化(h15)、动作禁用(h17)、动作复制(h14)、资源倾泻(h20)、结算时机选择元机制(h24)。

## 5. 作用域 = 团队层的被动（区分清楚）

| 英雄 | 类型 | 说明 |
|------|------|------|
| h03 渴血 | 团队层**被动** | 全队波 +1，寅虎击杀驱动、死清零（自限合规） |
| h30 北辰守望 | 团队层**被动** | 首个合规团队层被动；替补分担前排伤（付费+自限） |
| h28 灵魂契约 | 团队层（开局缔约的绑定，效果团队向） | 契约队友 +攻，恶魔付血 |

> ⚠️ 区分：h18 教皇 / h22 隐者**强度由团队存活/阵亡驱动，但归类单英雄被动**（团队状态驱动单英雄收益，非团队层 buff）。h16 皇后 / h34 世界是**单英雄主动、效果作用全队/全场**，非团队层被动。
