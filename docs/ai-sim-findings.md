# AI 自对弈模拟 — 平衡发现汇总（2026-05-30）

用 AI 自对弈批量模拟积累平衡数据。本文记录四次关键运行与结论，作平衡决策溯源。
工具：`tools/sim/run_sim.gd`（headless 批量）｜ AI：`src/battle/ai/`（详见该目录 README）。

> ⚠️ 数据可信度边界：**聚合量**（胜负分布/回合数/动作频率）即使少局也可信（按决策数聚合）；
> **各英雄胜率**需大样本（n≥130/英雄）才稳。各英雄梯队**以 v3 1200 局为准**，其余轮次仅看聚合。

## 1. 四次运行对照

|------|------|------|------|------|------|------|------|

## 2. 核心结论

### ① 平局是"同时结算 + 弱 AI"的产物，depth-2 根治
v1 的 62% 平局（双方全队同回合换死）随 depth-2 降到 ~5%。深一层 AI 会"防一手活下来下回合赢"而非对拼送死。**对称自对弈的平局是最坏情况，真人不对称会更低。**

### ② 对局长度是**结构性**的，AI 已到极限 → 要缩短得调经济
depth-1→depth-2 把回合中位从 46 压到 31，但**到此为止**。粗算：一队 ~15 HP ÷ 最优 ~0.6 HP/回合输出 ≈ 25+ 回合是经济下限。
- **1 分钟(≈6 回合)结构性不可达**；3 分钟(≈18 回合)需**降血/升伤/波 0 费**等经济改动。
- wall-clock 另一杠杆 = 每回合限时 + "双方按结束提前结束"（真人节奏，不改回合数）。

### ③ 主动技偏弱 → 最优play 不偏向使用（**已被 depth-3 实验证明非"AI 深度不够"**）
两代评估（基础/牌感）+ depth-2/depth-3 都停在 ~2-3% 主动技。**关键实验**：depth-3（看更深）主动技不升反降（3.1%→2.2%），且更龟缩（防 9%→24%、大波 17%→9%、13.6% 局达回合上限、均值回合 35→51）。
- **结论**：主动技少用**不是看得不够深，是当前数值下多数主动技不如基础动作（大波/防）划算**。
- **杠杆**：强化主动技（降费/提效）或削弱大波的"默认最优"地位。
- 注：**即时型**主动技（h20 倾力/h13 孤注/h32 灼烧）有被用；**慢/铺垫型**（h14 梅开/h26 死神变身/h16 回血）被跳过。

### ④ depth-3 不是"更强"，是"更偏执" → 生产用 v3 depth-2
深 AI 过度保守、龟缩、拖长对局，且仍不用主动技。**v3 depth-2 = "果断、牌感好的优秀玩家"甜点，生产定型。**

### ⑤ 牌感评估(v3)修正了"叠层型"英雄的低估
v3 给叠层/buff 状态加分，使对应英雄从 v2→v3 明显回升（更接近真实强度）：h03 渴血 21.7%→39.9%、h04 三窟 41.7%→51.9%、h23 轮 56.4%→66.2%。**证明这些英雄之前的低分有一半是"AI 不会用"。**

## 3. 英雄梯队（v3 1200 局，n=135-300，差异>10% 才算实）

- **强（>60%，OP 嫌疑）**：h25 倒吊 71.2 ｜ h19 恋人 69.9 ｜ h13 愚者 69.6 ｜ h06 蛇蜕 69.3 ｜ h18 教皇 67.5 ｜ h23 轮 66.2 ｜ h21 力量 61.4
- **弱（<35%）**：h28 恶魔 22.5 ｜ h17 皇帝 28.6 ｜ h24 正义 29.2 ｜ h08 替罪 32.0 ｜ h33 审判 34.2 ｜ h34 世界 35.8
- **弱簇分类**：
  - h17 皇帝 / h24 正义 = **无 UI 占位人为偏弱**（"二选一/时机"默认值，非真弱，不算数）。
  - h28 恶魔 = **连接件**（喂 carry 但自损血），v3 未加契约价值项 + drafter 不会刻意配对 → 仍可能被低估（道具系统/协同的设计理由）。
  - h08/h33/h34 = 可能真偏弱/niche，可纳入平衡候选。

## 4. 方法论与已知偏置

- **选人**：`DraftAI` 结构化组队（HP 派生角色坦/灵/脆 + 温度覆盖），无 per-hero meta 偏见；但择优会少抽弱势英雄 → 尾部样本偏少。
- **评估档**：profile 0=基础（HP/能量/存活/护盾/燃烧）｜ profile 1=v3 牌感（+铺垫叠层/变身/致命威胁/延迟伤害）。
- **随机技**：评估时克隆重播种独立采样（无偏有噪），不预知真实 rng。
- **未建模**：h28 契约价值、跨英雄具体 combo 配对（避免注入 meta 偏见）、长尾多回合链（depth-2 看不到）。

## 5. 下一步候选（待定）

1. **主动技数值强化** → 重测主动技率是否上升（验证 ③）。
2. **OP 簇试削**（h25/h19/h13/h06/h18，剔除 UI 占位的 h17/h24）→ 重测梯队。
3. **经济改动试缩短对局**（波 0 费 / 降大波费 / 降血）→ 重测回合数 + 攒%。
4. 给 v3 加契约价值项重测 h28，或认定其需道具/协同。
