# 图鉴界面重构复盘：从英雄/道具分立到统一图鉴

本文总结 2026-08-06 至 2026-08-27 的图鉴重构过程。它是后续英雄、道具、效果图鉴视觉与工程修改的权威入口；历史方案和计划只用于追溯，不得覆盖本文记录的最终合同。

## 一、最终结论

### 1. 一个图鉴，而不是多个相似实现

- `src/ui/codex_screen.tscn` 是图鉴外壳、书本构图、章节侧签、背景、动效和公共导航的唯一视觉源。
- 英雄、道具、效果分别保留自己的页面信息结构，但都作为同一 `CodexScreen` 的章节运行。
- 主菜单、战斗及其他场景入口只能实例化同一个 `codex_screen.tscn`。外层浮窗只负责打开、关闭、输入停用和层级，不得重建标签、书本或页面。
- 新增章节时扩展统一章节表、统一侧签和测试，不得复制出新的“某某图鉴浮层”。

这一边界解决了本轮最严重的工程问题：主菜单图鉴更新后，战斗场景仍显示旧版。相同产品只要存在两套 UI 树，就一定会继续漂移。

### 2. 书本与页面合同

- 设计画布为 `1920×1080`。
- 书本保持 `0.84` 显示比例，即约 `1612.8×907.2`，位置由画布与显示尺寸计算得到，严格全局居中；不得再为侧签把书本整体右移。
- 英雄、道具、效果页面仍在各自的 `1920×1080` 设计坐标中制作，统一外壳负责缩放，页面内部不二次缩放。
- 书本、固定排版、分页、详情组等稳定节点应落在 `.tscn`，保证编辑器预览与 F6 使用同一几何数据。脚本只更新数据、显隐和动效。

### 3. 通过版本的美术语言

- 正面二维羊皮纸书，不使用伪 3D、单张纸、竹简或大理石质感。
- 页面是克制的暖米色纸张；外部背景为低饱和暖烟褐，中心略亮、边缘略暗，但不得接近纯黑或偏灰蓝。
- 背景底图必须在无 shader 时仍可见；微动效放在独立透明层。材质失效不能把背景变黑。
- 内饰保持简约，不混入西式雕花、复杂中式纹样、金属包角或重复标题。
- 已通过的英雄页是受保护基线：4×3、每页 12 个头像；返回、分页、生命、技能类型和详情轴只在用户点名区域内修改。
- 道具页复用书本、导航和像素对齐方法，但保持自身的信息层级；每页 12 件，底部分页可连续跨越普通、稀有、传说，快速导航状态随分页同步。

## 二、素材与代码的职责边界

### 1. 外部素材负责不可伪造的质感

书本、纸张、笔刷背景、侧签轮廓和纸张质感应由外部美术素材提供。程序化矩形、纯色板和临时描边无法替代这些内容，容易产生“太光滑、太假、像草稿、像 UI 方块”的结果。

当前侧签只保留两张权威母版：

- `bookmark_chapter_idle.png`
- `bookmark_chapter_selected.png`

两张均为 `150×82 RGBA`、硬 Alpha、Lossless、无 mipmap、Nearest。`tools/prepare_codex_bookmarks.py` 只允许校验和原样安装，不得重新生成、重采样或“优化”通过资产。文件哈希是回归合同的一部分。

### 2. Godot 负责可变语义

- 文字不烘焙进图片；章节名、稀有度名由 Godot 原生文字层绘制。
- 阴影在 Godot 中复用素材 Alpha 并偏移生成，不烘焙第三张带影资产。
- 普通、稀有、传说复用同一套侧签形状；蓝、紫、金读取共享稀有度色板，并用侧签纹理/专用 shader 精确限制在轮廓内，不能裸画长方形色条。
- 章节图标不是必要信息，不得为了“更有设计感”擅自添加。

### 3. 参考图通过后的处理规则

通过的预览栅格就是受保护母版，不是“灵感图”。必须保留：

- 轮廓与朝向；
- 物件数量与相对比例；
- 明暗关系、纸张颗粒和状态差异；
- 书本与背景占比；
- 选中/未选中的外露长度。

正确流程是从通过图中确定性裁切或使用已经批准的源 PNG，逐像素修边，去除应由 Godot 负责的投影，然后锁定尺寸与哈希。重新调用生图、凭印象重画或用代码“做一个类似的”都不是一比一复刻。

## 三、侧签几何与交互合同

- 主章节签使用 `150×82` 母版一比一显示；稀有度签约为 `100×54`，视觉层级必须明显低于主签。
- 侧签层使用最终画布坐标，不用父 `Control.scale` 承担静态布局。父级缩放会同时改变文字、点击区和子节点坐标，难以保证真像素与输入一致。
- 侧签右缘与书封接缝是固定轴。悬停不得横向拉开侧签与书本；只允许克制的明暗反馈。
- 按压和折页动效只作用于视觉子节点或 visual-only offset，按钮点击矩形与接缝保持不动。
- 选中和未选中使用不同素材，但文字必须分别居中于各自实际可见纸面。不能把文字简单居中于共用的 150px 点击框，否则未选中文字会明显偏左。
- 道具二级签从主签后展开；展开/收起期间要管理 `mouse_filter`，隐藏页面和关闭浮层必须停止输入，避免 ESC、方向键或点击穿透。
- “效果”等后续主章节应作为同级正式侧签加入；道具稀有度展开时，只移动新增下游签，不改已经通过的英雄、道具和稀有度坐标。

## 四、本轮主要失败及根因

### 1. 风格判断失焦

早期方案先后出现过度国风、深色、过亮大理石感、西式花纹、伪 3D 和装饰堆叠。根因不是缺少细节，而是没有先锁定项目的基本语义：二维、像素、羊皮纸书、简约、暖色、低饱和。

以后先用一行不可违反的风格约束筛选方向，再讨论装饰。违反基本语义的方案不进入精修。

### 2. 把“预览通过”误解为“方向通过”

多次实装与预览差距过大，侧签连续三次复刻失败。根因是把通过图当作参考，再次生成或手工推测形状；每次都改变了弧度、削角、状态宽度、颗粒和阴影。

以后预览一旦通过，立即建立资产合同：源文件、裁切框、透明区、显示尺寸、状态数量、阴影职责和哈希。没有这些数据，不得进入实装。

### 3. 一次修改过多区域

部分预览为了改标题、返回或选中框，连书本、纸张和其他已通过资产一起改掉。这样既无法判断单点修改是否有效，也破坏了成熟基线。

以后严格使用最小编辑范围：用户点名返回键，就只改返回键；点名选中箭头，就只改箭头。完整页面重做必须由用户明确授权。

### 4. 用代码替代美术轮廓

纯色正方形、直接矩形色条、程序化纸纹和临时描边都曾造成“脏、假、像草稿”。代码适合表达状态，不适合凭空制造已经要求外部美术完成的纸张轮廓与质感。

以后先判断元素属于“稳定外形”还是“可变语义”：稳定外形进资产，可变文字/颜色/投影进 Godot。

### 5. 编辑器与运行态不一致

早期固定 UI 由脚本创建或运行时补偿，导致 Godot 预览中看不到书本、笔刷、头像框，或 F6 与编辑器位置不同。

以后固定视觉节点必须场景化；如需运行时生成，必须提供 editor-safe 预览节点或独立预览场景，且运行时不得覆盖手动坐标。

### 6. 独立实现导致全局漂移

战斗图鉴曾自己维护英雄/道具页签和两套页面实例，主图鉴改版后战斗仍是旧版。

以后任何图鉴入口都必须做路径审计：入口 → 生命周期容器 → 同一个 `codex_screen.tscn`。测试必须断言不存在旧页签和独立页面引用。

### 7. 动效改变了结构关系

悬停曾把侧签向左拉，造成书本与侧签之间出现空隙；按压位移也可能改变真实点击矩形。根因是把结构坐标当作动画参数。

以后结构位置、点击矩形、视觉 offset 三者分离。动画只能改视觉 offset、调制色或视觉子节点折叠比例。

### 8. 交付细节降低可验证性

曾多次给出反斜杠本地图片路径，用户无法查看。当前 BBZ 工作也已明确不主动生成、读取或返回截图。

以后默认用 Godot 日志、几何断言、像素数据分析和不保存图片的运行探针验收；如用户明确要求图片，使用绝对路径和正斜杠，并先确认文件可读。

## 五、以后执行图鉴修改的固定流程

1. **确认唯一入口**：扫描主菜单、战斗及其他入口是否都实例化 `codex_screen.tscn`。
2. **声明保护区**：列出本次可改节点与不可改的已通过区域。
3. **参考先行**：涉及新视觉方向时先研究同类成熟实现，但只提取信息层级、状态对比和交互规律，不照抄装饰。
4. **资产合同先行**：明确源图、状态数、尺寸、Alpha、阴影、文字和颜色分别由谁负责。
5. **先几何后装饰**：先验证书本中心、边界、页码轴、点击区和接缝，再做色彩、纹理与动效。
6. **固定节点场景化**：稳定布局写进 `.tscn`；脚本只更新数据、显隐和动画。
7. **小步验收**：复杂返工拆成素材、接入、几何、交互、全局入口五个任务；上一项通过后再进入下一项。
8. **建立回归合同**：GUT 覆盖场景路径、几何、状态、输入和共享入口；素材测试覆盖尺寸、哈希和硬 Alpha。
9. **运行态验证**：使用 `tools/run_godot.ps1` 执行聚焦测试、全量测试和非保存图鉴探针；源代码检查不能替代运行验证。
10. **区分无关失败**：全量测试存在并行任务失败时，记录精确测试名和证据，不修改无关文件。

## 六、后续修改的验收清单

- [ ] 书本仍为 0.84 且全局居中。
- [ ] 页面内部没有二次缩放或被外壳脚本重排。
- [ ] 主菜单、战斗和新增入口加载同一个 `codex_screen.tscn`。
- [ ] 修改仅影响用户点名区域，没有重做已通过资产。
- [ ] 侧签右缘始终贴合书封，悬停和按压不改变点击矩形。
- [ ] 选中/未选中文字分别按实际可见纸面居中。
- [ ] 稀有度颜色受侧签轮廓限制，不出现裸矩形或越界色块。
- [ ] 正式素材保持硬 Alpha、Nearest、Lossless、无 mipmap；通过母版哈希未漂移。
- [ ] 编辑器可见的固定节点与 F6 运行态坐标一致。
- [ ] 隐藏章节、收起标签和关闭浮层不再接收输入。
- [ ] 聚焦 GUT、图鉴探针、`git diff --check` 已运行并读取结果。
