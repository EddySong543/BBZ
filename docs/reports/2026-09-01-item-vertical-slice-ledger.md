## 3. 已通过的五件基础标尺

### F-01 磨刀石

- 五维：T1，价值 `0 / 1.5 / 2.5`，`C1`，`D2`，横向2格，满价2.4万、剩1次1.2万，单格1.2万。
- 资源冲突：磨刀石加「波」共2费；配「大防」共3费、配「大波」共4费，但两者不会消费强化。
- 空间：占主背包2.86%、保险箱22.22%、总运力2.53%，`D/S=1`；三件占6格并提供6次使用。
- 独立用途与顺序：2能时，`磨刀石→波`强化本轮攻击；`波→磨刀石`先打普通波，把强化留给下一轮。需要立即击杀时选前者，预计本轮会被「防」挡住时可选后者。
- Combo：`银币→磨刀石→波`只需1能；亢金【龙】在队时，3能可完成`磨刀石→强化波`，造成3点伤害。
- 反制与边界：只强化下一次实际结算的「波」，持续到兑现或战斗结束；普通「大波」与牛金升级后按「大波」结算的攻击不消费。玄冥拆分出的第一波会消费并获得强化，第二波不重复。攻击被挡或落空仍消费。三件同轮可令下一次「波」多3伤，总费连同「波」为4，仍被「防」完整挡住。

### F-02 裂纹小盾

- 五维：T1，价值 `0 / 2 / 3`，`C1`，`D1`，竖向2格，满价2.0万，单格1.0万。
- 资源冲突：小盾加「波」共2费、加「大防」共3费、加「大波」共4费；支付1能购买的是保留基础行动的即时2甲。
- 耐久与物件：已有裂纹的小盾展开一次后破碎；避免多耐久工具在两轮内稳定堆出大量永久护甲。
- 空间：占主背包2.86%、保险箱22.22%、总运力2.53%，`D/S=0.5`；三件占6格。
- 独立用途与顺序：A出战、B为队友时，`小盾→传送卷轴(B)`把2甲留给A；`传送卷轴(B)→小盾`把2甲给B。保护撤下者或登场者都有用途。
- Combo：与传送卷轴形成直接站位组合；穷奇【虎】可用2能完成`小盾→波`，在不能使用「防 / 大防」时带甲进攻。
- 反制与边界：护甲立即给使用时的出战英雄，不追溯抵挡同一行动位已经开始的攻击。三件同轮共花3能获得6甲；敌人可用清甲、穿甲或持续进攻消耗。

### F-03 血药

- 五维：T1，价值 `0 / 1.8 / 3`，`C2`，`D1`，单格，满价1.4万。
- 资源冲突：费用等同「大防」；血药加「波」共3费、加「大防」共4费、加「大波」共5费。
- 耐久与物件：一瓶一次喝完；满血时收益为0，过量恢复损失。
- 空间：占主背包1.43%、保险箱11.11%、总运力1.27%，`D/S=1`；三件只占3格，但共需6能。
- 独立用途与顺序：A、B都受伤时，`血药→传送卷轴(B)`治疗A后换B登场；`传送卷轴(B)→血药`治疗B。顺序由当前需要保住谁决定。
- Combo：与传送卷轴共同改变治疗对象；蚩尤【牛】可先用生命支付本轮行动，再用团队能量支付血药恢复生命，道具费不转为生命支付。
- 反制与边界：锁定使用时的出战英雄，不能超过生命上限；目标在血药步骤前阵亡则效果落空。三件最多恢复6点生命，全部溢出照常损失。

### F-04 银币

- 五维：T1，价值 `0 / 1.3 / 2`，`C0`，`D1`，单格，满价1.6万。
- 资源冲突：本身不花能量，只降低下一件道具1费，最低降到0；不影响基础行动。
- 耐久与物件：银币在支付一次道具费用后消失。
- 空间：占主背包1.43%、保险箱11.11%、总运力1.27%，`D/S=1`；三件占3格。
- 独立用途与顺序：`银币→传送卷轴`让本次卷轴0费；`传送卷轴→银币`先按1费换位，把折扣留给下一件道具。当前换位是否急迫决定顺序。
- Combo：`银币→磨刀石→波`只需1能；亢金【龙】在队时，2能可完成`银币→磨刀石→强化波`。
- 反制与边界：持续到下一件道具或战斗结束。连续使用银币时，后一枚也是“下一件道具”，会先消费前一枚折扣，再建立自己的折扣，因此三枚不会叠成减3费。

### F-05 传送卷轴

- 耐久与物件：卷轴施放一次后焚毁。
- 空间：占主背包2.86%、保险箱22.22%、总运力2.53%，`D/S=0.5`；三件占6格。

- 反制与边界：目标必须是存活队友，交换立即生效并计为切换；同一行动位已经开始的步骤不被取消。三件同轮共花3能完成三次切换，全部正常触发切换收益与惩罚；敌方娄金【狗】出战时，换下者仍受2点真实伤害。

- 历史索引：接近旧「龙息」和多种攻击增伤件，但当前效果只有一次大波加1伤。

## 7. 阶段四裁定

### B4-01 酸液陶罐

玩家文案：双方出战英雄失去全部护甲。

- 五维：T3，价值 `0 / 3.5 / 7`，`C2`，`D1`，固定`2×2`四格；满价4.0万，单格1.0万。

- 边界与三件同名：即时结算，锁定该行动位开始时双方的出战英雄，不影响后备。三件占12格、共需6能；第一件清甲后，后两件只有在中间重新产生或转移护甲时才有收益，不能叠加清除量。

### B4-02 破魔铃

玩家文案：双方尚未触发的道具效果全部消失。

- 五维：T3，价值 `0 / 3.5 / 7`，`C3`，`D2`，竖向2格；满耐久4.0万、剩1次2.0万，满耐久单格2.0万。

- 物件与独立用途：破魔铃可以敲响两次，每次重新支付3能；用于清除磨刀石、战争号角、烟雾瓶、护心镜等正在等待后续触发的道具效果。没有待清效果时收益为0。
- 顺序与Combo：`破魔铃→磨刀石→波`先清场再建立己方强化；`磨刀石→波→破魔铃`先兑现己方强化，再尝试清除敌方较早行动位建立的效果。`银币→破魔铃→战争号角→波`共5费，银币先把铃降为2费，铃清场后再建立号角。
- 英雄Combo与反制：敌方烟雾瓶效果尚未触发时，穷奇【虎】可用`破魔铃→波`清除减伤后进攻；敌方仍可使用「大防」。对手也可先兑现效果、改用即时道具，或把新效果排在铃之后。
- 边界与三件同名：即时结算且不选目标；只清除等待后续触发的道具效果，不撤销已经发生的生命、护甲、能量变化，也不清除英雄技能。三件占6格、共有6次使用；同轮三响共需9能，且必须有新效果在铃声之间产生才有意义。

### B4-03 复苏石

玩家文案：选择我方一名阵亡队友，使其以1点生命复活。
