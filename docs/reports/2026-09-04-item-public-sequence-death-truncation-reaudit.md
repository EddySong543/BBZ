# 公开敌方序列与死亡截断下的20件道具重审

> 日期：2026-09-04
> 状态：阶段一审计完成；荆棘护腕调整已审批并写入运行数据。
> 范围：现行20件新版道具、三件同名上限及 H02 / H08 / H10 / H21 交互。英雄保持冻结。

## 1. 判定口径

公开敌方序列的目的就是让玩家能准确使用工具，因此“看到一种威胁后，道具有明确用途”不等于设计失败。只有同时满足以下条件才判为危险：

1. 对多类常见敌方序列都是同一个最优答案；
2. 使用后仍能保留完整基础行动，却没有足够的能量、耐久、占格或局面代价；
3. 旧设计所依赖的反制必须发生在敌方锁招之后，而新 PvE 已不允许敌方临时改招；
4. 三件同名会把上述问题放大为连续多轮的稳定压制。

本轮同时固定三条新审计边界：

- 同拍双方道具读取同一开拍快照。破魔铃、短柄铁钩等不能清除同拍刚建立的效果或护甲。
- 双方基础行动固定在共同 `0` 拍。敌方 `-1` 拍建立、`0` 拍兑现的效果，中间不存在可插入的新拍位。
- 任一出战英雄在一拍结束后阵亡，双方后续步骤一起取消。取消的道具不收费、不耗耐久；只死后备不截断。

## 2. 总结论

- 保留：19件。
- 已调整：1件，荆棘护腕。
- 暂缓：0件。
- 死亡截断没有让任何道具失去核心用途，也没有产生新的复活循环。
- 旧报告中“敌人可以临时停止攻击或改用小攻击来烧掉效果”不再是有效反制。袋装石灰粉靠一次性、逐点付费和只影响首段攻击成立；荆棘护腕已降低重复次数。

已执行荆棘护腕调整：

| 属性 | 调整前 | 当前 |
|---|---:|---:|
| 使用费 | 1 | 1 |
| 最大耐久 | 2 | 1 |
| 占格 | 2 | 2 |
| 满耐久价格 | 2.8万 | 2.4万 |
| 残损价格 | 1.4万 | 无 |
| 稀有度与文案 | T1，现文案 | 不变 |

原因：敌方攻击已经锁定时，触发条件由风险变成已知事实。它还能与「攒」、切换、主动技或我方攻击并用，相当于在保留基础行动的同时增加一个伤害结算点。改为一耐久后仍是清楚有力的战术反击，但不再由一件两格 T1 工具连续复制两轮。三件同名的最坏结果变为：占6格、付3费，在一次确定命中的攻击后反击3点，随后三件全部耗尽。

调整后20件耐久暂为 `12 / 6 / 2`，即 `60% / 30% / 10%`。这仍接近目录目标；扩池时优先补二耐久工具，恢复长期 `55% / 35% / 10%`，不为守住20件的整数比例保留危险重复次数。

## 4. 三件同名复核

公开序列使“是否能兑现”更容易计算，但没有改变以下硬上限：

- 瓶装能量、银鳞甲和猎鹰羽毛在前一份待触发效果尚未消费时，不能叠成更高等级效果。
- 破魔铃不能清同拍新状态；连续三响必须在中间真的出现新状态，否则后响空转。
- 复苏石只能选择规划时已经阵亡的后备，且出战位死亡会截断后响。
- 袋装石灰粉三件只削弱下一次实际攻击的首段，需3费、6格和三件消耗品。
- 荆棘护腕已改为一耐久，三件只形成一次3伤反击，不再跨两轮重复。

除荆棘护腕的重复次数外，没有发现无费用循环、无限资源、无限行动、复活循环或跨轮稳定封锁。
