# H23 Energy-Cap Reduction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `verification-before-completion` before claiming this plan complete.

**Goal:** Replace H23's retired lethal-guardian ability with a basic-attack effect that lowers the opposing team's energy maximum by the actual HP damage dealt, down to 3 energy.

**Architecture:** Add a serialized per-team `energy_max` state to `BattleCore`, route all energy gains through that dynamic ceiling while preserving existing over-cap energy, and give `HeroSkill` a once-per-basic-attack damage hook for H23. Remove the old guardian interception path rather than leaving two H23 identities active.

**Tech Stack:** Godot 4, typed GDScript, GUT, project Godot wrapper.

---

### Task 1: Lock the mechanic with tests

- Replace the old H23 guardian tests in `tests/unit/battle/v4/test_heroes_dark_v4.gd` with coverage for Wave, Big Wave, defense, actual HP damage, the 3-energy floor, preserved over-cap energy, and resumed energy gain below the cap.
- Extend `tests/unit/battle/v4/test_battle_snapshot.gd` and AI tests for `energy_max`.
- Rewrite the guardian-dependent attribution regression so source-slot attribution remains covered without the retired mechanic.

### Task 2: Implement dynamic energy maximum and H23

- Update `src/battle/battle_core.gd` with `energy_max`, setup/clone/snapshot support, a centralized cap reducer, dynamic energy gain clamping, and a once-per-basic-attack callback.
- Update `src/battle/hero_skill.gd` with the new callback and remove the retired guardian capability.
- Retire `src/battle/skills/h23_huzhu.gd` and register the final skill file `src/battle/skills/h23_tianguangchangshi.gd`, preserving the original H23 script UID.
- Route H12 and any direct energy-gain sources through the centralized gain rule.

### Task 3: Remove stale behavior and expose the state

- Remove guardian constants, interception, AI valuation, events, and UI tags.
- Add AI valuation for persistent energy-cap advantage and ensure cloned simulations see the same cap.
- Show the reduced cap in the battle HUD without changing the approved baseline when both caps are normal.

### Task 4: Synchronize current truth

- Apply the exact approved name 【天光长蚀】 and copy to `assets/data/heroes/h23.tres`; item bonuses merged into a Wave / Big Wave count, while independent item hits do not.
- Update current hero tables, H21-H24 design truth, architecture notes, AI documentation, and localization references while retaining clearly labeled historical records only where they remain useful.

### Task 5: Verify and hand off naming

- Run Godot import, targeted H23/snapshot/AI/UI tests, then the full test suite through `tools/run_godot.ps1`.
- Run a 1920x1080 battle probe if the HUD changes.
