# Boot 标题 B 实施计划

1. 保留现有三个标题文件路径、节点结构和透视 Shader，只替换标题生成逻辑与 PNG。
2. 在 `tools/prepare_boot_title.py` 中使用 Noto Sans SC 900 字重建立高可读中文字形骨架。
3. 将字形硬阈值像素化到 `63×63`，加入单向结构暗面、统一斜向断层和少量朱红能量边。
4. 对“波、波、攒”分别做安全区、字腔、色卡、透明角、重复生成一致性和两“波”差异检查。
5. 生成三张 `252×252` RGBA PNG，运行 Godot 导入。
6. 通过 Boot 截图探针检查字形、透视、角色关系和点击跳转；只在标题范围内迭代。
