# 英雄文案、H10 机制与道具框 UI 修复计划

**目标：** 完成 h17/h21 文案修改，把 h10 从独立攻击主动技改为可选的基础攻击穿透强化，并统一图鉴与战斗中的道具框视觉。

## 任务 1：英雄数据与 H10 规则

- 先补/改测试，覆盖 h10 不再拥有独立主动技、2 点剑气强化波穿防、4 点强化波或大波穿大防、无收益选择非法、打断不消耗、落空会消耗。
- 在 BattleCore 的选择、快照、AI/协议与结算链中加入显式 `jianqi_attack` 选择标记。
- 更新 h10/h17/h21 资源、图鉴文案、技能提示与相关设计记录。

## 任务 2：共用道具框视觉

- 建立共用的道具图案布局：按透明像素边界光学归一、由源 PNG 承担默认朝向、始终限制在框内；背包仅跟随玩家实际旋转。
- 费用与耐久徽章按同一可见尺寸归一，并相对道具框计算左右对称位置。
- 图鉴卡片、图鉴详情、战斗道具栏、战斗行动序列和三选一共用该布局。

## 任务 3：图鉴排版与占格样式

- 右页稀有度与属性条上移，给说明留出间距。
- 占格改成不规则双层棕色手绘方格，删除占格文字和“可旋转”文字。

## 任务 4：验证

- 运行英雄、图鉴、战斗道具栏与行动序列定向测试。
- 用无截图运行探针断言普通框零旋转、背包实际方向跟随、可见边界、徽章位置和框内约束。
- 最后运行完整测试并区分既有失败与本次回归。
