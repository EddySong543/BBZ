# 公开敌方序列后的道具设计分阶段任务

> **目标：** 先证明“公开敌方序列 + 玩家编排”确实把胜负重心从猜拳转向规划，再继续把新版道具池从20件扩到100件。英雄维持冻结，只做交互审计，不擅自修改。

## 阶段一：重审现有20件

按新信息规则和死亡截断逐件复核：

- 敌方行动公开后，道具是形成选择，还是变成见招必出的标准答案；
- 前置、同拍、后置位置是否都存在合理用途，死亡截断会不会让后置用途失效；
- 费用、耐久与三件同名上限是否因确定命中或确定反制而升值；
- 重点复核银鳞甲、袋装石灰粉、荆棘护腕、破魔铃、复苏石，以及 H02 / H08 / H10 / H21 的交互风险。

**交付：** 20件“保留 / 调整 / 暂缓”清单；英雄只报告风险。全部处理完才进入新道具设计。

## 阶段二：建立 PvE 敌方序列语法

先设计敌人怎样出题，不先堆新道具：

- 敌方只读取回合开始时的公开战局，从多个合法候选序列中按状态生成并锁定；
- 不用固定循环让玩家背板，也不在玩家规划后改招；
- 难度来自同一序列里的多目标压力、能量限制、站位和后续风险，而不是隐藏答案；
- 普通敌人保持一句话可懂，精英再加入两段威胁，Boss 才使用较长序列和阶段规则。

**交付：** 3个普通敌人、2个精英、1个Boss的纸面序列包；每个敌人至少有3种状态驱动的候选序列和2种可行玩家解法。

## 阶段三：策略纵切验证

用冻结英雄、现有20件道具和阶段二的6个敌人建立代表局面：

- 分别测试无道具、单件、两件链和三件链；
- 对同一公开序列至少找出两条有真实代价差异的可行方案；
- 检查改变道具顺序、目标或能量分配能否改变结果；
- 检查基础“波 / 防”是否仍单独压过整套道具规划。

**通过标准：** 代表局面不能长期退化为唯一正确基础动作；道具与顺序必须稳定改变生存、击杀、资源或下一回合局面。未通过时先修敌人出题和现有20件，不扩池掩盖问题。

## 阶段四：20件扩到35件

仍按每批5件审批，共3批：

1. 公开序列应对件：改变目标、站位、资源分配或步骤价值，不做简单“看见攻击就减伤”；
2. 非银币桥接件：补费用、目标和即时状态连接，降低瓶装能量的万能枢纽地位；
3. 队伍与持续作战件：补后备、跨战续航和战斗 / 非战斗背包配比。

同步补齐猎鹰羽毛的严格搭档，并继续限制“下一次……”模板比例。每件仍走完整五维与真实顺序验算。

## 阶段五：35件扩到50件，并接入远征背包

- 增加食物、补给和可撤离经济物，正式验证79格中战斗件与非战斗件的取舍；
- 验证1 / 2 / 3耐久分布在连续战斗中的真实价值；
- 实测最低6件、最低9件和不设最低UID三种战备规则；
- 把敌人掉落、商店与事件来源和道具职责对应起来。

**交付：** 50件Demo核心池、战备规则、掉落来源与一轮全池碰撞报告。

## 阶段六：50件闸门

集中清理重复身份、必胜链、无脑公开反制、三件同名、复活循环、护甲循环和单格价值异常。只有50件池仍存在明确结构缺口，才继续扩到75 / 100件。

## 阶段七：50件扩到75件，再扩到100件

- 51–75：精英 / Boss 环境件、稀有构筑核心和替代路线；
- 76–100：长期远征、收藏经济、特殊来源与低频高价值道具；
- 始终每5件一批审批，每批必须说明填补的真实缺口，禁止为了数字补同义件。

最终验收仍以策略选择、跨战背包取舍和全池碰撞为准；100件只是目录目标，不是自动通过条件。
