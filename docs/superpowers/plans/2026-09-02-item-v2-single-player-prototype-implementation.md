# 新版20件道具单机原型实施计划

> 日期：2026-09-02
>
> 状态：已获授权，按七步连续实施；旧道具保留但从新版生产入口隔离。2026-09-03 起，本文原“左对齐”步骤已由行动锚点规则取代。

## 目标

让冻结的20件道具在当前单机战斗中完整走通：每回合一次免费三选一、取得结果公开、锁定一回合、道具与公共行动统一排序、逐步骤付费和扣耐久、AI合法使用、结算事件与动作记录。旧目录、脚本、资产和旧测试不删除。

## 七步施工与验收

1. **目录隔离**
   - 在 `ItemCatalog` 建立唯一的20件启用名单与新版定义。
   - 旧 `make(id)`、旧目录和旧测试继续可按ID读取；新版抽取、图鉴和战斗生产入口只读启用名单。

2. **公共运行时基础**
   - `ItemData` 补齐逐次使用费、最大耐久、固定形状、价格、合法目标和新版效果键。
   - 背包实例保存 UID、当前/最大耐久和生命周期；三框保存真实实例而非只有道具ID。
   - 建立每回合一次的固定免费候选、放弃、最小空框放入、锁定一回合和耗尽后回合末清框。
   - 建立整段原子预验、同实例每回合最多一次、双方主行动固定在共同 `0` 拍的逐拍结算和权威事件记录。

3. **五件地基件**
   - 磨刀石、裂纹小盾、血药、银币、传送卷轴。

4. **九件基础件**
   - 火蜥蜴油、护心镜、魔力药水、破甲锤、疗伤药膏、战争号角、烟雾瓶、猎鹰羽毛、荆棘护腕。

5. **三件连接件**
   - 连心结、炼金坩埚、食铁虫。

6. **三件局势件**
   - 酸液陶罐、破魔铃、复苏石。

7. **单机切换与回归**
   - 玩家与AI均使用新版抽取和同一序列校验入口。
   - 三框继续复用现有视觉，隐藏旧补充和升阶入口；提示补充费用、耐久和锁定信息。
   - 结算结果保存双方公开序列、逐列结果、付费、耐久、效果和反制事件。
   - 覆盖最低0/6/9合法UID的A/B配置、20件数据、目标、费用前缀、耐久、换位、复活、H02/H13身份与代表Combo测试。

## 兼容边界

- 当前只切换本地PvE生产入口；休眠网络逻辑不作为本次阻塞项。
- 不修改英雄定义。新版行动结算只读取现有英雄接口；H02和H13按冻结规则专项验证。
- 旧道具代码和测试继续保留在“legacy”路径，便于以后按ID重新评审后恢复。
- 本轮使用现有图标作临时映射；正式资产和显示名由后续导入替换。
