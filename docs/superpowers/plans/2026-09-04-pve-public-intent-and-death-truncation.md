# PvE 敌方公开序列与死亡截断实施计划

> **状态：已完成。** 本轮只改 PvE 新版道具序列和通用逐拍死亡边界，未改英雄机制与数值。

## 目标

- PvE 每回合先由敌方生成、提交并锁定完整序列，再向玩家公开；玩家随后规划，敌方不得根据玩家选择重算。
- 双方主行动继续固定在共同 `0` 拍，主行动前后步骤保持原相对顺序。
- 每拍双方已启动步骤全部完成后检查死亡；任一出战英雄确认阵亡，就取消双方所有尚未开始的后续步骤并进入既有死亡换人流程。
- 被取消的道具不扣能量、不扣耐久、不写入使用历史；替补单独阵亡不截断序列。

2. 给时间线增加只允许在列间调用的 `cancel_remaining()`；保留原始提交序列，只清空未执行游标与 BattleCore 等待。

2. 在延迟伤害后和每个已完成列后调用既有死亡 hook 链；仅在最终存在出战阵亡时截断。
3. 防止同一出战死亡重复写入强制换人提示。
4. 跑死亡截断与既有新版道具序列测试。
