# Scene6 桥下熔炉与角色光影实施计划

## 目标

- P0：移除被平台遮住的旧深渊/炉芯/接触条，改为与平台同变换、仅显示在平台透明镂空中的桥下熔炉。
- P1：保持角色位置与尺寸不变，为 P1/P2 分别建立来自左下/右下的环境光、熔火反射与酒红接触阴影。

## 实施

1. 先更新 Scene6 契约测试：锁定平台与熔炉的同纹理、同几何、正确层级和透明孔洞遮罩；锁定角色独立曝光、镜像受光与阴影色。
2. 新增 `canvas_env_scene6_underbridge_forge.gdshader`，以平台源纹理 alpha 为精确遮罩，只在桥身透明孔洞内绘制破碎的纵向熔火通道。
3. 在 `scene6.tscn` 中以与 `BattlePlatform` 完全一致的 NinePatchRect 接入 `UnderbridgeForge`，放在平台之后、近景之前；删除旧生产节点及资源引用。
4. 调整 Scene6 角色 shader 与 `battle_screen6.tscn` 参数，分别校准 P1/P2 曝光、高光压缩、左下/右下光源、下半身量化反光和接触阴影。
5. 更新探针与 Scene6 说明，执行导入、GUT、1920×1080 探针，并依据运行截图微调可读性。

## 保护项

- 不改平台、近景、角色节点的现有位置和尺寸。
- 不以加速掩盖慢速动画卡顿；桥下熔火使用连续时间与空间羽化。
- 不让桥下效果覆盖平台不透明像素、人物或 UI。
