# h05「龙御极」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 h05 亢金【龙】重做为“攻击被成功防御后给目标留下破绽”的团队进攻启动器，并将技能名统一为「龙御极」。

**Architecture:** 继续复用 `BattleCore.statuses[player][slot]` 保存逐英雄持久状态；新增通用的“基础攻击被成功防御”技能钩子，由 h05 写入不叠加的 `opening` 状态。伤害管线只在下一次基础攻击到达该英雄时把穿透档提升到 `PIERCE_DEF` 并消费状态；道具伤害、攻击型主动技与反击不触发也不消费。

**Tech Stack:** Godot 4、GDScript、GUT、`.tres` 英雄资源、CSV i18n。

## Global Constraints

- 技能名固定为「龙御极」，HP 保持 5，类型保持被动，定位保持进攻。
- 玩家短文案固定为「亢金【龙】的攻击被成功防御时，使目标获得破绽。」
- 「成功防御」只指「防」或「大防」完整挡下基础「波」或「大波」。
- 「破绽」默认挂在单个英雄身上、持续到兑现、换下场不清除、不可叠加。
- 带有破绽的英雄下一次受到基础攻击时，该攻击至少为穿防；「防」挡不住、「大防」仍能挡住，随后破绽消耗。
- 独立道具伤害、攻击型主动技、反击和持续伤害既不触发 h05，也不消费破绽。
- 保留现有 `broken_armor` 给噬铁虫等旧机制使用，不借本次重做修改无关道具。
- 保留工作树中 h02 文案、Scene4 与 Boot Title 等其他任务的未提交改动。

- [ ] **Step 2: 让伤害管线显式区分基础攻击**

`_apply_resolve_hit()` 以 `hit.action && !hit.active` 生成 `is_base_attack`，作为 `_apply_damage()` 的末尾参数。直接 `strike()` 与道具 hit 沿用默认 `false`。

- [ ] **Step 3: 在防御门应用并消费破绽**

```gdscript
if is_base_attack and int(get_status(target_player, slot, "opening", 0)) > 0:
	statuses[target_player][slot].erase("opening")
	pen = maxi(pen, ActionDef.Pen.PIERCE_DEF)
	events.append({id = "opening_used", player = target_player, slot = slot})
```

逻辑必须在计算 `blocked` 之前运行；目标不存在或伤害免疫时不消费。

- [ ] **Step 4: 在基础攻击被完整挡下后通知攻击者技能**

从 hit 快照取得攻击者槽位并调用 `on_base_attack_blocked()`；防守方原有 `on_block()` 保持不变。

- [ ] **Step 5: 将 h05 组件改为施加不叠加破绽**

```gdscript
func on_base_attack_blocked(battle: BattleCore, player: int, _slot: int,
		target_player: int, target_slot: int, _attack_action: int,
		_defense_action: int, _raw: int) -> void:
	battle.set_status(target_player, target_slot, "opening", 1)
	battle.note_combo_proc(player)
```

- [ ] **Step 6: 将破绽纳入 AI 状态资产**
