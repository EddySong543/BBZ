# 新版道具分阶段设计计划

> 日期：2026-09-01
>
> 目标：从五件已通过基础标尺扩展到15–20件纵切池，再进入独立的原型规划。
>
> 当前状态：阶段一至五全部完成；20件初始纸面池已冻结，下一步为独立单机原型。

## 固定边界

- 英雄不修改。
- 当前只做 PvE 纸面道具设计，不实装，不让未启用的扩展系统阻塞。
- 历史重合只作资料索引；只要符合当前标准，可以重新提交同构机制。
- 每件第一版同时提交机制价值、费用、耐久、固定占格、金币和完整顺序边界。
- 名称和玩家文案保持自然、具体、一句话可读；复杂度来自简单道具之间的组合。

## 阶段一：冻结五件基础标尺

状态：已完成。

工作内容：

- 通过池只保留磨刀石、裂纹小盾、血药、银币、传送卷轴。
- 此前其他提案全部移出新版候选池。
- 补齐五件的稀有度、价值、费用、耐久、占格、价格、顺序、Combo和边界。
- 把碰撞表改为“历史相似机制索引”，取消高、中、低风险和撞车淘汰逻辑。

完成结果：五件已作为后续费用、空间和价格比较标尺写入唯一账本。

## 阶段二：补齐基础单功能道具

状态：已完成；两批原有10件通过，飞刀在2026-09-02后续反制审计中退出，当前保留9件。

工作内容：

- 每批约5件，同时覆盖进攻、防守、恢复、经济、能量、站位或基础反制中的不同用途。
- 单件只保留一个主效果，玩家文案原则上一句话。
- 优先复用现有公共接口，不新增封闭系统。
- 每批审批后只把通过件计入总池；修改项不阻塞其他通过项。

第一批提交：

- 火蜥蜴油：大波加伤。
- 护心镜：把下一次「防」改为「大防」。
- 魔力药水：即时获得能量。
- 破甲锤：移除敌方当前护甲。
- 疗伤药膏：治疗队友。

第一批结果：5件全部通过，通过池增至10件。

第二批提交：

- 战争号角：下一次攻击加伤。
- 烟雾瓶：降低敌方下一次攻击伤害。
- 飞刀：对敌方出战英雄造成独立伤害。
- 猎鹰羽毛：给下一次攻击一次指定目标权。
- 荆棘护腕：敌方下一次攻击命中后反击。

第二批初审结果：5件全部通过，通过池一度增至15件。后续审计确认飞刀的独立伤害无法被「防 / 大防」反制，并绕过唯一基础行动，当前版本退出通过池。

阶段出口：已达到。基础进攻、防守、恢复、能量、站位、目标与反击接口均有独立样本；独立直伤不再作为基础池必备接口。

## 阶段二后研究门：三款参考游戏

状态：已完成。

工作内容：

- 研究《杀戮尖塔》的小牌池成长、能量曲线、抽取质量、消耗与遗物联动。
- 研究《炉石传说》的单卡可读性、费用曲线、职业边界、节奏与组合反制。
- 研究《宝可梦》的出战位 / 后备位、换位、共享招式池、队伍分工与公开信息。
- 分开记录可直接吸收的原则、需要转译的结构和不适合BBZ的系统，禁止直接换皮复制。
- 当前15件中8件使用“下一次……”状态；下一批默认不再用该模板构造顺序。

研究结论：

- 三款游戏的共同优势不是单卡文字复杂，而是简单效果共同读写少量公共状态，组合由状态变化自然形成。
- 后续优先建立“产生资源或状态→转移或转换→兑现结果”的开放链条；每件道具仍需独立可用，不做固定套件或专属关键词包。
- 费用、三道具框、耐久、背包空间、出战位和行动位应承担主要限制；能用公共规则解决时，不在单件文案继续添加条件。
- 敌方先公开完整行动序列，玩家随后规划；完整序列按共同节拍逐行动位播放。部分 Boss 可以在规划前额外公开意图。基础道具不得依赖不可见的敌方顺序；“可见反制”主要来自已公开的道具框、通用防御与下一轮调整。
- 不引入抽牌区、弃牌区、部族、属性克制表、命中率、暴击、天气、场地、秘密反应和大量新状态等依赖其他游戏生态的系统。
- “下一次……”不是禁用词，但属于稀缺结构；现有8件保留，下一批不再默认增加。

阶段出口：向用户提交研究简报，得到下一批设计方向反馈后再进入阶段三。

## 阶段三：建立基础顺序玩法

状态：已完成。

工作内容：

- 只从阶段一、二的通过件暴露出的接口缺口设计少量连接件。
- 验证两件道具的真实先后、道具与基础行动交错，以及0费连接件的必要性。
- 优先使用即时状态变化、资源前缀、站位、目标和行动位产生顺序，不把“下一次”当作默认发动机。
- 反转顺序后若一边永远更优，就只承认固定用法，不计顺序博弈。
- 每条Combo走完费用前缀、持续时间、站位、合法目标和敌方应对。
- 当前基础池不提交无条件执行完整「波 / 防」的道具，也不提交无法被通用攻防体系阻止的独立直伤。护身符与魔法箭袋保留为后期复审方向，是否成立取决于怪物设计能否提供清楚、普遍且可读的应对。

完成结果：连心结、炼金坩埚、食铁虫通过；飞刀退出后通过池达到17件。炼金坩埚按T1连接件定位，食铁虫按T2双轴转移件定位。护身符、魔法箭袋未通过当前基础池审批，但不永久否决，转入怪物体系成形后的条件复审。

阶段出口：通过池达到约16–18件，并形成数条真实两件Combo。

## 阶段四：补充高费局势道具

状态：已完成。

工作内容：

- 增加少量3–4费道具，承担整轮计划或局势改变，而不是单纯放大数字。
- 补齐至少一件D3+远征续航样本和必要的大体积样本。
- 完成一条真实三件Combo，并验证公开准备、失败窗口和可见反制。

阶段出口：形成15–20件通过池，覆盖0费、1–2费和3–4费。

完成结果：酸液陶罐、破魔铃、复苏石通过；酸液陶罐最终为2费，复苏石最终为3费，破魔铃保持3费。通过池达到20件，具备0费连接、1–2费主力和3费局势件；当前没有4费件，不为覆盖费用表强行保留不合格道具。

## 阶段五：全池审计与冻结

状态：已完成。

工作内容：

- 审查费用、耐久、格数、价格密度和机制维度分布。
- 测试70格主背包、9格保险箱，以及战斗道具与未来食物、探索用品和战利品的空间竞争。
- 测试三件同名、两件链、三件链和不同英雄组合。
- 删除或修改离群件，不为凑比例保留不合格机制。

阶段出口：冻结一版可进入单独原型规划的15–20件纸面池；是否实装另行授权。

完成结果：20件全部保留并冻结，没有数值修改或淘汰。三件同名、47条两件关系、5个三件链模板、24名英雄交互和`n=2–5`极小战备均已复核；完整证据见[`2026-09-02-item-stage5-full-pool-audit-and-freeze.md`](../../reports/2026-09-02-item-stage5-full-pool-audit-and-freeze.md)。纸面版暂不新增最低合法UID，最低6件 / 9件方案进入单机原型A/B测试。
