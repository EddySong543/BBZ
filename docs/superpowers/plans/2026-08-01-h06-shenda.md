# h06「神打」Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 将 h06 翼火【蛇】的技能正式定名为「神打」，并把已确认的毒素文案同步到所有玩家可见数据、实现标识、测试与设计文档。

**Tech Stack:** Godot 4、GDScript、GUT、Godot `.tres` 资源、CSV 本地化、Markdown 设计文档。

## Global Constraints

- 技能名逐字使用「神打」。
- h06 生命保持 4，技能机制不变。
- 玩家文案逐字使用两行定稿：
  - `翼火【蛇】命中敌方英雄时，使其获得1层毒素。`
  - `毒素：可叠加。中毒英雄再次被命中时，引爆并清除全部毒素，每层造成0.5点伤害。`
- 内部状态键继续使用 `poison`，不做存档协议或战斗事件迁移。
- 保留工作区内 h02、h05、Boot、Scene4 等其他任务的未提交改动。
- 本任务不执行 commit 或 push。
