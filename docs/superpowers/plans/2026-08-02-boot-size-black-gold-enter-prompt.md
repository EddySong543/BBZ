# Boot Screen 尺寸、黑金标题与进入提示实施计划

**目标：** 保留当前手动调整后的视觉大小和位置，移除标题与人物实例上的 `scale`，改由 `size` 表达；将标题改成黑金配色；加入融入画面的进入提示。

## 任务 1：把视觉缩放转换为尺寸

- 标题三个字与阴影保持当前屏幕位置，节点 `scale` 恢复为 `Vector2.ONE`，尺寸由 252×252 改为 302.4×302.4。
- 重整 `TitleColumn` 的边界，使它覆盖当前标题的真实视觉范围。
- 人物实例改为当前实际显示尺寸；人物组件根据根 `Control.size` 同步内部 `Rig` 的位置和缩放。

## 任务 2：黑金标题

- 主体：炭黑。
- 结构暗部：近黑。
- 压力切口：古金。
- 能量峰值：浅金。
- 外轮廓：克制的暖金细边，保证标题跨越米色、金色和蓝色背景时仍可辨认。

## 任务 3：进入提示

- 文案使用“点击任意位置进入”，与现有整屏点击行为一致。
- 放在标题下方，以深色像素字、左右短金线构成。
- 只做慢速透明度呼吸，不加入额外粒子或位移。

## 任务 4：验证

- 更新 Boot Screen 单元测试，验证无遗留 `scale`、尺寸驱动人物骨架、黑金材质与提示文案。
- 使用项目规定的 Godot 启动脚本运行测试和 Boot Screen 截图探针。
- 对照修改前后截图，确认构图大小和位置没有意外漂移。
