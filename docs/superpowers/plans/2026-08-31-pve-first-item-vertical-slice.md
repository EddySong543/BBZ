# PvE 优先：道具系统后续分阶段验收任务

> **当前状态（2026-09-04）：阶段 0–2 已完成。** 20件纵切道具已经完成纸面复核并冻结，下一步为阶段3单机原型。当前产品只开发 PvE 单机；旧入口、源码、测试和专用素材已在后续清理中移除。
> **通用规则已经定稿：**每回合主动免费三选一，取得后公开并锁定本回合，从下一回合开始可用；每次使用支付该件 `0–4` 能费用。当前只按 PvE 单机验证，未来模式若恢复需另立审批。
> **既有基线不重开：**行动序列、行动位、延后、五维平衡、`0–4` 费曲线和真实背包检索模型均已确认。

## 阶段 0：清理旧未启用入口（已完成）

- 主菜单只显示远征入口，不再显示未启用的模式切换、取消入口和段位。
- 个人资料只保留当前身份信息，不再展示未启用模式战绩；旧存档无关字段不进入当前 UI。
- 旧选人或大厅场景、入口脚本和对应测试已删除；旧路径不再参与工程加载。
- PvE 建局只保留本地 BattleCore / BattleAI 与远征会话适配。

**验收：**入口隔离测试、主菜单测试和无截图运行探针已经通过；清理后继续执行导入与定向 GUT。

## 阶段 1：设计 15–20 件跨档纵切样本（已完成）

总量为 15–20 件。为了便于逐件审批，每次提交约 5 件，但不能因此缩减最终数量：

- 0 费连接件；
- 1–2 费主力件；
- 3–4 费局势件。

每件同时提交：名称、单句玩家文案、稀有度、机制价值、逐次使用费、耐久、固定占格、金币价格、独立用途、真实顺序例、英雄 Combo、道具 Combo 与反制方式。

**验收：**不得出现英雄专属空道具、假顺序、唯一正确顺序、依赖解释才能成立的名称 / 文案，或用“最多 X 点”等附加句硬压强度。最终通过件数达到 15–20 件。

## 阶段 2：纸面组合复核（已完成）

把通过的 15–20 件放进前期、中期、后期场景，覆盖不同英雄、两件 Combo、三件 Combo，以及极小背包 `n=2–5` 对照。

**验收：**确认能量曲线、成型率、卡手率、通用性、反制空间和五维平衡成立，输出保留、修改、淘汰清单；同时决定是否需要最低合法可抽 UID 数。这个决定来自内容实测，不改动免费三选一基线。

## 阶段 3：最小可玩原型

只实装已通过的纵切样本，并完成统一行动序列、动作列表、道具动画、免费三选一、锁定一回合、逐次使用付费和耐久扣除。AI 与玩家走同一套本地规则；本阶段不恢复已退役的旧分支。

**验收：**完整走通“取得 → 公开锁定 → 下一回合排序 → 结算 → 动画 / 动作记录 → 扣费与耐久”的单机回合。

## 阶段 4：扩充 Demo 池

纵切通过后先扩到 50 件；实测仍有结构缺口时再扩至 75 或 100 件。随后接入远征掉落、背包、商店、临时件与百万级撤离经济。

**验收：**每批扩充都复查 Combo 覆盖、替代件、单格价值、取得概率和前中后期体验。50 / 75 / 100 是目录规模，不直接决定单场 Combo 成型率。

## 更后面的任务

核心道具纵切成立后，再设计正式 PvE 敌人、精英、Boss 和单区域搜打撤闭环。

依赖顺序为：

`阶段 0 旧入口清理（已完成）→ 阶段 1 纵切道具（已完成）→ 阶段 2 纸面复核（已完成）→ 阶段 3 原型（下一步）→ 阶段 4 Demo 扩池与经济`
