# 晴风稻田单格资产设计

## 最终三层结构（2026-08-09 确认）

- **地表层**：草地、泥土。允许把低矮草叶、土点、小碎石等不承担玩法功能的自然装饰合并进地表。
- **物体层**：金色稻穗、田界、搜索补给等独立透明 PNG。物体不得烘焙草地、泥地、格子边框或功能描边，因此能放在任意地表上复用。
- **标识层**：搜索金框、选中提示等由运行时状态绘制，不制作固定在物体图片里的第六张资产。
- 绘制顺序为地表 → 迷雾 → 已探明物体 → 已探明标识 → 动态图签；未探明物体不参与绘制，避免透过半透明迷雾泄露。
- 稻田格的数据语义保留，但运行时先绘制普通草地，再叠加独立稻穗；稻穗拥有单独绘制层，后续可增加摆动或角色拨开效果。
- 首轮仍只保留五张 PNG：两张地表、三张透明物体。搜索完成后只移除物体和标识，底层地表保持不变。

## 已确认方向

- 采用方案 A「像素软边方块」，以 `ref/block1.png` 至 `ref/block6.png` 的简洁色块、柔和轮廓与选择性描边为参考，不复制其图标。
- 格子始终保持 1:1 正方形，使用像素切角，不使用光滑矢量圆角、等距透视、立方体侧面或程序化噪点。
- 普通地形使用本地色暗边、轻微内侧亮边和少量纹理；只有交互或特殊格使用更强的对比描边。
- 晴风稻田整体明亮、温暖、适合新手区；奇幻感来自色彩与少量辉光细节，不堆砌魔法装饰。

## 首批正式资产

1. `grass_01.png`：清爽草地，低纹理密度。
2. `rice_01.png`：独立透明的成熟金色稻穗，不包含草地、格子轮廓或方块厚度；放置时叠加于 `grass_01.png` 上。
3. `dirt_path_01.png`：暖色土路，少量石子和草边，不形成方向性车辙。
4. `field_boundary_01.png`：不可通行的低矮田界，轮廓清楚但不做高耸墙体。
5. `search_supply_01.png`：特殊搜索格，容器放在草土基底上；禁止使用水面、荷叶或无法解释的蓝绿色池塘。

## 资产与运行契约

- 每张源资产为独立正方形 PNG，透明切角，无文字、人物、UI、投影背景或水印。
- 最终运行版统一缩放到 `128x128`，最近邻过滤、无 mipmap、Lossless 导入。
- 1920x1080 下使用 `15x9` 个 `128x128` 格的裁切视窗；纵向额外 72 像素由屏幕上下各裁掉 36 像素。
- 镜头采用中央 `5x3` 格死区：玩家在死区内移动时地图不动，越界后镜头只追到最近死区边缘，并用约 0.28 秒缓动；首次进入直接定位，所有中间位置取整像素。
- 正式提示词与资产同目录保存。
- 普通地形和特殊交互资产分开；后续允许搜索容器变化、打开或消失，而不影响底层地形。
- 验收同时检查放大单格、`3x3` 拼接和 1920x1080 实机画面。
