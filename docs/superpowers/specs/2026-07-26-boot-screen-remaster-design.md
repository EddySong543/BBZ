# Boot Screen「聚气成攒」重制设计

## 目标

把现有红蓝对波 Boot Screen 重制为以“攒”为核心意象的 H01 聚气片头：

1. 前 5.8 秒为不可交互的连续运镜。
2. 镜头从黑暗中的金球近景逐渐拉远，先显露上下掌，再猛速抽离到 H01 全身。
3. 5.8 秒后镜头完全停止，进入无限待机；只有头发、围巾、衣摆、金球、流水和微粒循环。
4. 玩家只能在最终待机状态点击进入主菜单。

## 已锁定的画面规则

- 最终机位为约 10–15° 轻仰视广角，不使用极端低机位。
- 人物以 H01 为唯一造型参考。
- 保留 H01 的不对称黑发、遮眼刘海、紫黑围巾、胸前交叉背带、深紫分层武服、宽袖、绑腿与手套。
- 弱化腰间武器和大量挂件，保持胸口、双手与金球区域清楚。
- H01 的脸大部分藏在暗处，只露一只紫色眼睛和少量金色轮廓光。
- 球体悬浮在胸口中央，不由手掌托举。
- 上掌水平位于球体正上方、掌心向下；下掌水平位于球体正下方、掌心向上。
- 上下掌垂直对齐、不接触球体、不斜置、不推向镜头。
- 分镜 2 起出现少量外溢线；分镜 3 起流线逐渐增多。
- 流线只从球体赤道附近与下半球溢出，可以向左右、弧形斜下和缓慢下流，禁止从顶部垂直向上。
- 首版标题只显示“波波攒”；标题由 Godot 渲染，不烘焙进角色或背景。

## 时间线

| 时间 | 画面 |
|---|---|
| 0.0–0.5 秒 | 全黑；中央出现微弱金色光点。 |
| 0.5–1.8 秒 | 金球近景逐渐显现；内部液态光缓慢循环；赤道和下半球出现极少短流线。 |
| 1.8–3.6 秒 | 缓慢拉远；上掌、下掌和少量小臂进入画面；流线开始向左右和斜下流动。 |
| 3.6–4.2 秒 | 手位保持不变；亮度、流线数量、长度和速度连续抬升。 |
| 4.2–5.0 秒 | 一次连续的猛速抽离式拉远；已有流线被拉成长拖线；首次揭示完整人物。 |
| 5.0–5.8 秒 | 镜头落稳为轻仰视全身构图；标题显现；能量转入可循环状态。 |
| 5.8 秒后 | 无限待机；镜头不再移动，开放点击进入。 |

## 制作架构

采用“高分辨率角色源图 + Godot 实时合成”的 HD-2D 混合路线：

1. 图像模型生成一张透明背景的 H01 最终姿势主图。
2. 主图通过同图编辑拆出刘海、后发、围巾尾、袖口和衣摆。
3. 角色素材保留高清源档，再通过 PixelLab 或等价工具进行整数倍降采样、调色板量化和清边。
4. 金球、球体照明、流线、粒子、标题、镜头和输入门控全部由 Godot 实现。
5. 视频模型只用于运镜、头发和衣摆动态参考，不直接作为最终可交互 Boot 视频。

## 图层顺序

从后到前：

1. 黑色背景与微弱雾光。
2. “波波攒”标题。
3. H01 后层头发与后衣摆。
4. H01 主体。
5. H01 前层刘海、围巾尾、袖口与前衣摆。
6. 金球、角色受光和后景流线。
7. 前景流线与金色微粒。
8. 最终待机才出现的“点击进入”。

## 输入与跳过

- 0.0–5.8 秒完全禁止输入，点击不会跳过、加速或进入主菜单。
- 5.8 秒后才允许鼠标左键进入主菜单。
- 不增加键盘、触摸或其他按键入口，除非后续另行扩展。

## 验收

- 分镜 2 没有任何垂直向上的能量线。
- 分镜 3、4 只露手掌与少量小臂。
- 分镜 3–6 上下掌始终正对齐，球体位于胸口而非丹田。
- 猛速拉远保持空间连续，不使用硬切镜头。
- 最终待机无镜头漂移。
- 最终循环首尾无跳变，标题和手势不被流线遮挡。
- H01 在暗处仍可由发型、围巾、交叉背带和紫色眼睛辨认。
- 改标题文字不要求重新生成任何美术资产。
- 运行验证必须使用 `tools/run_godot.ps1` 的截图探针，不关闭任何已存在的 Godot 进程。
