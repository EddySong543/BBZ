# 新版道具图鉴属性与首批正式美术设计

> 日期：2026-09-03
> 状态：已由 Eddy 批准，直接实施。

## 目标

在不改变已通过羊皮纸图鉴整体结构的前提下，为新版20件道具补齐可扫读的使用费、最大耐久、初始占格和满耐久价格，并接入当前已提供的首批正式道具美术。图鉴展示初始形状；正式 PNG 自己承担默认朝向，Godot 不再追加统一的装饰旋转。远征背包中的物品美术仍随玩家实际旋转后的占格一起转向。

## 图鉴信息结构

- 左页继续保持每页4列×3行。每张道具卡左上角显示使用费，右上角显示最大耐久；0费也显示。
- 右页继续使用居中主轴：名称、大图、稀有度、属性条、效果文案、风味文字。
- 右页大图的左上和右上角重复显示使用费与最大耐久，方便放大查看。
- 使用费复用战斗行动按钮的 `energy_idle.png` 与 `IconBadge` 数字样式。
- 耐久使用 Eddy 最新提供的 `耐久.png`，正式归档为 `assets/ui/icons/item_durability.png`。
- 属性条左侧只显示由不规则双线方框组成的初始占格图，不附“占格”“N格”或“可旋转”文字；右侧显示带千位分隔符的满耐久金币价。
- 费用与耐久数据现已覆盖图鉴、三选一、战斗道具栏和行动序列；角标最终视觉语言待单独审批，耐久位置固定为右上角。

## 文案

- 生锈的飞镖：`我方下一次「波」增加1点伤害。`
- 锋利的飞镖：`我方下一次「大波」额外增加1点伤害。`
- 其他道具只按批准内容改名，不改变效果数值或结算逻辑。

## 背包旋转表现

- `ItemData.shape_cells` 继续表示道具初始形状，不额外产生朝向玩法或相邻加成。
- 背包 placement 的 `shape` 表示当前旋转态。
- 图鉴、三选一、战斗道具栏和行动序列不在 Godot 内给道具图追加固定角度；美术默认姿态直接写入 `assets/sprites/items/v2/` 中的 PNG。
- 绘制时根据道具初始形状与 placement 当前形状推导四分之一圈旋转数。
- 非方形美术按原始宽高比装入整件道具的占格包围盒，不再压入中央正方形。
- 旋转后的美术围绕占格中心旋转；阴影使用同一旋转和尺寸。

## 验收

- 目录数据准确反映11件改名/形状/文案与既有费用、耐久、价格。
- 图鉴左页与右页均显示费用/耐久角标；右页属性条显示价格和手绘方格组成的初始形状，不显示占格文字或旋转说明。
- 64×32、32×64和96×32美术保持源 PNG 自带的初始朝向，不在普通道具框中二次旋转。
- 背包长条美术使用完整占格范围，旋转形状后美术同步转向。
- 正式资源不引用 `assets/import/`；已接入源文件及其旧路径 `.import` 不残留在收件箱。
- 使用 Godot Import、定向GUT、全量GUT和无截图几何/数据断言验证。
