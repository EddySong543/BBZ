# 公开序列困境门

> 阶段1验收规则；只用于筛选纸面敌人方向，不授权敌人、英雄或公共规则实装。

## 1. 判定对象

判定对象是完整公开的一个战局及其可达后果，不是“敌人有两个技能”，也不是一张玩家方案列表。

每个压力样本必须给出：回合号，双方团队能量/上限，每个角色生命/上限/护甲/站位，全部可用框UID及剩余耐久，已生效状态，敌方每一步的身份/目标/拍位，玩家方案的费用前缀，以及最终能量、队伍、耐久与截断记录。

普通敌人只有一句核心规则；脚注只解释触发时点、目标和失效条件，不能暗藏第二个技能。名称采用普通身份或外形，不为一场测试新建派系。

## 2. 五个闸门

1. **双重压力**：玩家至少要在两项不可同时免费保全的价值之间选择。当前HP与后续攻击强度、保命与敌甲、当前击杀与后备恢复都可计入；同一伤害的两个说法不计两项。
2. **非支配方案**：至少两条完整合法方案。在生命、能量、敌方剩余威胁、己方耐久与位置等已说明维度上，一条不能处处不差并至少一处更好。不得凭随意给分宣布两条都理性。
3. **优先级可翻转**：指出相邻战局里哪个具体阈值令优先级互换。不能以“有些玩家爱冒险”替代；也不能仅凭卡齐却付不起费的方案过关。
4. **道具有不同代价**：至少一条当前二十件池的道具解能保留不同资源、选择不同目标、保住队友或改变尾段；如果只是给唯一正确基础行动加数字，该样本未证明道具选择。
5. **重复仍有代价**：继续检查反复“波就防、防就攒、大波就大防”。一轮看似丢了未来收益，若敌人恢复很快封顶、玩家却能无伤蓄满再处理，不计持续困境。

终局斩杀、没有能量、没有队友等局部强制解可以存在，但不能拿它们当“两种解”的通过证据。喘息回合可以简单，不能用喘息回合撑起普通敌人的全部语法。

## 3. 必做反证

- 基础答案表，必须看实际攻击身份，不能把1费升级大波当普通波防。
- H21：亲自出战、2费、每战两次、存在敌方存活后备；取消0拍普通行动不退其费，不能删除已完成的前置或自动取消后置道具。
- 银鳞甲及H08：1费升级防仍占唯一主行动，不能当作免费额外防御；H08仅空大防能留到下一回合结束。
- 石灰粉：减下一次实际攻击的首段1伤；攻击降到0仍可能算命中。检查是否有同费更优护甲解，不能故意漏掉支配项。
- 抢杀：同拍攻击已启动仍完成；仅杀后备不截断。不能把“杀了敌方”写成“所以本拍无伤”。
- 三件同名、低UID开局、非攻击回合蓄能，以及无道具时是否仍有选择。

本回合意图、目标、前后步骤和所有条件分支完整公开；敌方锁定后不改招。若玩家改变状态使公开步骤无效，就按原步骤正常失败，不能让AI临场挑另一个目标。未来候选只可由公开个性与局面推断，不泄漏未来随机种子，也不固定整场循环。

## 4. 出口

当前通过状态统一维护在 `design/gdd/expedition-mode.md` §3.2；整体深度与边界验收以该文§3.1.1—§3.1.2为准，初期供应轨迹维护在 `design/expedition-economy.md` §3.1。初期要求覆盖前十场持续缺道具，可以跨多次远征，不能缩成第一回合或第一场。单回合非支配端点必须继续检查跨回合结果；强制残局不要求硬凑两解，但正常早期体验不能长期只有固定答案。用户已通过收割人偶与持盾匪徒，不重复提交同一机制审批；继续计算与补样本不需要另行许可。新增状态不能批量复制人偶的触发—强化—解除结构。

输出“样本通过 / 敌人方向暂留 / 方向退回”，分开记录。本轮六个样本不代表完整敌人生成语法或24英雄全局平衡通过。

优先修失败敌人的压力结构。只有连续三种不同结构经过修正仍失败，才提交独立公共规则A/B；第一候选是防/大防回合不获得回合末被动能量。此规则当前未批准，不能代入样本悄悄使用，更不能修改冻结英雄救题。

## 5. 参考与转译

[Into the Breach 官方说明](https://subsetgames.com/itb.html)同时公开攻击并要求保护供能城市；本文据此取“公开以后仍有多个要保的对象”，不引入BBZ没有的战术棋盘。

[Slay the Robot 开源框架](https://github.com/DesirePathGames/Slay-The-Robot)说明意图、描述和合法性共用实际动作逻辑；本文据此要求公开文本与结算用同一份序列。该工程参考不能证明BBZ现有敌人已经有取舍。
