# Scene1 竹林景深融合设计

## 目标

在保留用户手动调整形成的“两侧高大竹影框景”意图下，把竹子从孤立贴图改造成 Scene1 夜间屋顶环境的一部分。仅调整 Scene1 竹子相关节点、材质与验证契约，不修改角色、HUD、Scene2 或战斗逻辑。

## 当前问题

- 两张竹子素材被非等比放大，源像素成为宽高不同的矩形，和场景像素网格不一致。
- 主竹接近纯黑且轮廓锐利，缺少 Scene1 山体、屋顶共有的靛蓝阴影与空气透视。
- 巨大而清晰的轮廓暗示极近景，但现有遮挡关系又更像中景，空间语义矛盾。
- 左右竹子形成连续竖直“帷幕”，并与顶部头像区域竞争。
- 只有一对竹子，没有中远层竹影建立竹林环境，复制感和后贴感明显。

## 采用方案

采用“专属远竹林、主竹”两级结构，全场共四个竹子节点：

- `BambooFarLeft`、`BambooFarRight`：分别使用专属
  `scene1_bamboo_far_left.png` 和 `scene1_bamboo_far_right.png` 竹林簇，
  位于山体之后、地平雾之前；低对比、低饱和、轻度离散失焦；视差 `0.34`。
- `BambooLeft`、`BambooRight`：保留两侧框景职责，恢复源素材宽高比并进一步向屏幕外裁切；视差维持 `1.25`。

旧方案中所有复用主竹素材生成的远景和中景副本均被删除，不隐藏、不覆盖。
两张专属远竹素材各自只实例化一次，通过屏幕外裁切把有效竹林放在左右边缘。
竹子根部由屋顶、雾和画面边缘遮挡，不额外制造独立地面。两株主竹保持
`alpha_scale = 1.0`，不参与背景层的透明度衰减。

## 材质

扩展现有 `canvas_env_night_foliage.gdshader`，让同一 Shader 支持：

- alpha-aware 九点离散采样失焦，透明边缘不产生黑边；
- 可选的高亮中性背景剔除，用于移除两张专属远竹 PNG 内烘焙的白色棋盘格；
- 夜景去饱和和靛蓝色相统一；
- 暗部蓝紫补色，减轻纯黑剪影感；
- 根据左右月光方向产生克制的单侧边缘光；
- 每层独立控制亮度、透明度和失焦半径。

主竹保持 `blur_amount = 0`、`background_key_strength = 0` 和最近邻采样；
专属远竹使用 `blur_amount = 1.2`、`background_key_strength = 1`。
不会引入全屏后处理或持续动画。

## 构图与安全区

- 主竹可见区域继续贴边，不进入角色主体与中央月亮区域。
- 顶部枝叶避开左右头像、血条的主要识读轮廓。
- 远层透明度最低，中层次之，主竹对比最高，但主竹暗部仍服从 Scene1 冷色环境光。
- 不追求左右严格对称，保留自然框景和视觉重量差。

## 验收

- 两张主竹保持各自源宽高比，像素块不发生横纵变形。
- Scene1 运行图能读出专属远竹林与清晰主竹的前后关系，背景竹不抢角色、月亮和 HUD。
- 主竹不再呈现纯黑贴纸感，边缘不存在白边或模糊黑边。
- Scene2 运行图不出现竹子或 Scene1 材质。
- 全套 GUT 通过，并以 Scene1、Scene2 两张运行截图完成必要视觉回归。
