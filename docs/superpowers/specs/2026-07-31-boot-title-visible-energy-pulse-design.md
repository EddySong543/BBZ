# Boot 标题可见能量脉冲设计

## 问题

当前标题脉冲只在细窄的能量色区域内混入 `22%` 浅色，单轮有效变化
约半秒，随后静止约四秒。即使逐帧对比可以测得差值，在完整 Boot Screen
中也难以察觉，不满足 idle 动效需要在正常观看中可见的要求。

## 目标

保留现有“波 / 波 / 攒”字形、纵向布局、朝角色内旋的透视和三张 PNG，
将能量刻印改为一眼可见但不刺眼的向上传递脉冲。

## 已批准方案

- 顺序保持为 `攒 → 中间波 → 顶部波`。
- 相邻字延迟由 `0.10s` 调整为 `0.12s`。
- 总周期由 `4.8s` 缩短为 `3.6s`。
- 单字脉冲包含 `0.12s` 升亮、`0.08s` 峰值停留和 `0.55s` 消散。
- 能量核心从常态红色向暖金白峰值色混合，峰值强度由 `0.22` 提高到
  `0.70`。
- 能量核心周围增加约 `2px` 的像素柔光。柔光只在脉冲期间出现，
  跟随同一包络自然生成和消散。
- 柔光使用纹理相邻采样产生，不新增可见节点，不移动文字，也不改变
  字体主体、结构暗面或透视 UV。

## Shader 结构

标题 Shader 继续先执行现有透视映射，再对源纹理颜色分类。

1. 使用独立函数计算当前字的 rise / hold / fall 脉冲包络。
2. 当前像素属于能量色时，按包络把 `energy_color` 混向
   `energy_peak_color`。
3. 在当前源 UV 周围采样一圈 `1px` 和 `2px` 邻域，只识别能量色。
4. 邻域能量产生的光圈在透明像素上以较低 alpha 显示，在不透明字形上只
   产生轻微暖色照亮。
5. 包络为零时，输出必须与当前静态标题一致。

新增统一参数：

- `pulse_hold`
- `glow_strength = 0.65`
- `glow_radius_texels = 2.0`

## 范围保护

- 不修改三张标题 PNG。
- 不修改 TitleColumn 和三个字的尺寸、位置、间距、旋转感或透视强度。
- 不修改角色、角色 idle、腰部动画、后手星芒、背景或输入逻辑。
- 不增加扫光、位移、缩放、整字透明度动画或新的场景节点。
- 不提交或推送 Git，除非 Eddy 明确要求。

## 验收

1. 完整 Boot Screen 正常观看时，不需要逐帧对比即可看到能量由下向上传递。
2. 峰值时红色核心明显变为暖金白，周围存在约 `2px` 的像素柔光。
3. 常态能量红线始终存在；柔光消散后标题恢复当前静态外观。
4. 三个字的起始顺序为 `0.00s / 0.12s / 0.24s`。
5. 渲染探针必须基于能量像素 mask 验证核心变化覆盖率、平均色差和柔光
   邻域，而不能只检查 Shader uniform。
6. 三张标题 PNG 哈希保持不变，点击仍能进入 Main Menu。
