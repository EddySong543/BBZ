# 战斗 Buff 玩家名后挂载设计

## 目标

把毒素、脆弱、剑气从角色脚底移到双方玩家名之后，避免持续状态污染战场画面，同时完整展示全部 Buff。

## 布局

- P1 状态栏位于玩家名右侧，默认锚点对齐第四个能量点的起始位置。
- P2 使用镜像布局，状态栏从对应锚点向左展开。
- 状态栏与玩家名使用同一垂直中心线；道具栏、血条、能量条和角色区域均不移动。
- 状态栏定位只使用图标联合边界，`x + 数字` 不参与左右锚点计算。
- P1、P2 的静态锚点作为 `.tscn` 节点保留，便于在 Godot Inspector 中直接微调。

## 保留契约

- 保留当前毒素、脆弱、剑气素材、光学缩放、数字偏移、小写 `x`、数字间距、阴影和入场动效。
- Buff 数量变化仍只播放数字反馈；新增 Buff 才播放整枚图标入场。
- 出战英雄死亡时隐藏状态栏；主动角色切换后刷新为新角色的完整状态。

## 验证

- 几何测试验证 P1 从锚点向右、P2 从锚点向左展开。
- 改变角色演出偏移不得移动状态栏。
- 一个、两个、三个 Buff 时都只按图标边界锚定。
- 使用项目统一 Godot 启动器运行定向 GUT 与全量测试。
