## 1. 本轮定稿结论

1. 「切换」为 `0` 费，但占用本回合唯一基础行动。
2. 道具把一次免费但占行动的切换变成额外步骤时，`1` 费是正常基准；传送卷轴按此为 `1` 费。
3. 新版道具目录耐久比例按 `D1=55% / D2=35% / D3及以上=10%` 控制；15–20 件纵切池按此比例取最接近的整数样本。
4. PvE 运力分为 `70` 格主背包与独立 `9` 格保险箱；成功撤离总容量为 `79` 格，但风险属性不同，不能只记一笔账。
5. 常规物品以 `2–4` 格为主；首发最大单品为 `9` 格。`12` 格仅保留为未来无法放入保险箱的任务级战利品空间，不进入当前基础战斗道具池。
6. 金币密度继续采用 `0.2万–2.5万/格` 的常规分层；首批 15–20 件不使用 Jackpot 定价。
7. 百万撤离需要接近满载且整体质量较好，不由两三件普通基础道具轻易达到。

## 2. 公共行动费用锚

### 2.1 固定费用

| 行动 | 费用 | 基础结果 |
|---|---:|---|
| 攒 | `0` | 行动步骤发生时立即获得 `1` 能量 |
| 防 | `0` | 挡住「波」 |
| 波 | `1` | 造成 `1` 点伤害 |
| 切换 | `0` | 更换出战英雄，并占用本回合基础行动 |
| 大防 | `2` | 挡住「波」和「大波」 |
| 大波 | `3` | 造成 `2` 点伤害并穿过「防」 |

回合末被动获得 `1` 能量，供下一回合使用。忽略道具自身产能时，公共行动造成的回合净变化为：

| 行动 | 回合后净能量变化 |
|---|---:|
| 攒 | `+2` |
| 防 / 切换 | `+1` |
| 波 | `0` |
| 大防 | `-1` |
| 大波 | `-2` |

### 2.2 道具费用职责

| 逐次使用费 | 主要职责 | 准入门槛 |
|---:|---|---|
| `0` | 连接、改目标、搬运、严格受限的减费 | 单独使用没有稳定正收益；必须依赖后续合法步骤；费用最低降到 `0` |
| `1` | 单轴基础收益；把免费但占行动的效果变成额外道具步骤 | 能清楚说明与「波」并用后为什么仍合理 |
| `2` | 强基础收益、广目标、明显的额外行动价值 | 必须与「大防」争夺资源仍值得使用 |
| `3` | 改变整轮攻防计划的局势件 | 不能只是更大的治疗、护甲、切换或普通增伤 |
| `4` | 专门蓄能的构筑核心 | 必须有公开准备、可见反制和真实失败窗口 |

定费顺序固定为：

1. 找到效果最接近的公共行动或已通过道具；
2. 区分效果价值与“保留基础行动”的额外行动价值；
3. 计算与「波 / 大防 / 大波」共同使用时的总费用；
4. 检查前缀能量是否合法，不能只看回合总账；
5. 检查三件同名、两件链和三件链；
6. 不用大占格、低耐久或高金币替错误费用免责。

### 2.3 当前五件基础校准件

以下五件已经完成整卡审批；本表只摘录费用锚，完整五维、价格、顺序和边界以 [`2026-09-01-item-vertical-slice-ledger.md`](../../reports/2026-09-01-item-vertical-slice-ledger.md) 为准：

| 名称 | 玩家效果 | 费用 |
|---|---|---:|
| 磨刀石 | 我方下一次「波」多造成 `1` 点伤害 | `1` |
| 裂纹小盾 | 我方出战英雄获得 `2` 点护甲 | `1` |
| 银币 | 下一件道具少花 `1` 点能量 | `0` |
| 血药 | 我方出战英雄恢复 `2` 点生命 | `2` |
| 传送卷轴 | 选择我方一名队友，与出战英雄交换位置 | `1` |

磨刀石与 H05【龙御极】存在表层输出重合，但允许作为有限次数的道具接口：英雄提供在队期间反复可选的强化；道具需要取得、公开、锁定、占框、付费并消耗耐久。磨刀石不得升级为持续授权。两者允许叠加，但强化后的「波」仍被「防」完整挡住。

旧机制与新版道具重合不再视为风险。历史内容只用于说明相似接口；只要完整卡符合当前标准，即可重新提交或通过。

## 3. 耐久目录基线

### 3.1 目录比例

| 最大耐久 | 目录目标 | 主要身份 |
|---:|---:|---|
| `1` | `55%` | 药水、卷轴、爆发件、强减费、强位移和一次性规则改变 |
| `2` | `35%` | 简单工具、主力辅具、两次使用都仍有正常选择的器物 |
| `3+` | `10%` | 远征续航资产；通常具有更高等级倾向 |

若纵切池为 `20` 件，对应 `11 / 7 / 2` 件。若总量为 `15–19` 件，按最接近比例取整，同时至少保留一件 `D3+` 样本验证远征续航风险。

高耐久不与稀有度机械绑定，但会减少携带替代品所需的格数和补充次数，因此天然提高远征空间效率。低稀有度高耐久只有在单次价值低、重复不滚雪球、公开后仍可反制时才成立。

### 3.2 耐久审查

逐件必须回答：

1. 第二次及后续使用是否仍值得再次付费；
2. 后续使用是否只是无脑复制第一次收益；
3. 三件同名满耐久一共提供多少次功能；
4. 高耐久是否长期堵住三个公开框；
5. 高耐久是否明显减少 PvE 途中寻找补给的需要；
6. 名称与物理形态是否自然支持重复使用。

新增诊断指标：

`远征续航密度 = 最大耐久 D ÷ 占格 S`

它只用于发现离群件，不自动决定稀有度或价格。

### 3.3 残损价格审查带

残损价格仍按边际用途逐件决定，以下只作异常检测：

- `D2` 剩 `1` 次：满耐久价的 `45%–60%`；
- `D3` 剩 `2` 次：满耐久价的 `65%–80%`；
- `D3` 剩 `1` 次：满耐久价的 `30%–45%`；
- 耐久归零：实体销毁，可兑现价值为 `0`。

偏离区间时必须说明剩余使用为什么具有不同的边际价值，不能直接套统一耐久倍率。

## 4. PvE 运力与空间价格

### 4.1 三本容量账

| 容器 | 格数 | 风险与用途 |
|---|---:|---|
| 主背包 | `70` | 战斗道具、食物、恢复品、探索用品与战利品共同争夺；死亡时失去 |
| 保险箱 | `9` | 受保护的高价值物、关键消耗品或战备；死亡时保留 |
| 成功撤离总容量 | `79` | 只用于成功撤离时的总运力与总值压力测试 |

保险箱不是九个普通免费格。它的保护属性会促使玩家优先放入高价值密度或关键功能物，因此必须与主背包分开评估。

每件候选都必须填写：

- 主背包占比：`S ÷ 70`；
- 保险箱占比：`S ÷ 9`；
- 成功撤离总运力占比：`S ÷ 79`；
- 远征续航密度：`D ÷ S`；
- 满耐久金币密度：`满耐久价格 ÷ S`。

例如 `4` 格物品占主背包 `5.71%`、占保险箱 `44.44%`、占成功撤离总运力 `5.06%`。四格本身可以成立，但低收益基础件不能把这部分空间价格当成无意义装饰。

### 4.2 PvE 参考装包

主背包不设置硬分区；下表只用于平衡测试：

| 类别 | 入场参考占格 |
|---|---:|
| 战斗道具 | `14–20` |
| 食物、恢复与探索用品 | `8–14` |
| 入场时预留空间 | `36–48` |
| 保险箱 | 独立 `9` |

正常入场时主背包占用约 `31%–49%`。远征节奏应允许形成：

`携带战备入场 → 消耗 D1 物品释放空间 → 拾取与补充 → 接近满载撤离`

每件战斗或非战斗物品都要检查：

1. 携带三件会挤掉多少食物、探索用品或战利品；
2. 经历多场战斗后还剩多少次使用；
3. 消耗后释放多少空间；
4. 途中获得替代品时是否仍值得一直占格；
5. 它是否让某一类物品失去装包意义。

### 4.3 目录占格分布

| 格数 | 长期目录目标 | 主要物品 |
|---:|---:|---|
| `1` | `15%` | 硬币、针、戒指、小药瓶、小符 |
| `2` | `30%` | 卷轴、磨刀石、短工具 |
| `3` | `25%` | 长瓶、工具包、小型法器、食物组合 |
| `4` | `20%` | 圆盾、书、箱装补给、中型器物 |
| `5–6` | `8%` | 大型工具、成套补给、大型战利品 |
| `7–9` | `2%` | 巨型珍品、任务物、远征目标 |

常规物品的 `75%` 位于 `2–4` 格。该比例是战斗道具、非战斗消耗品和战利品共同扩展后的长期目录目标，不要求首批 15–20 件战斗道具机械复刻全部比例。

首发最大单品为 `9` 格。`12` 格只保留为未来任务级战利品：其设计意义是无法放入 `3×3` 保险箱，玩家必须承担主背包撤离风险；当前不为它新增运行规则。

形状先服从物件直觉，再接受空间审查。若效果撑不起自然尺寸，应更换为更小的物件身份或重做效果，不能把大型盾牌硬压成单格，也不能为惩罚强度把硬币拉成多格。

## 5. 金币价格基线

### 5.1 百万满载锚

成功撤离总容量为 `79` 格：

`100万 ÷ 79 ≈ 1.27万/格`

因此常规价格密度保持：

| 经济身份 | 满耐久单格价 |
|---|---:|
| 笨重低值 | `0.2万–0.5万` |
| 普通物品 | `0.5万–1.0万` |
| 值得保留的主力物品 | `1.0万–1.6万` |
| 紧凑高值物品 | `1.6万–2.5万` |
| Jackpot | 高于 `2.5万`；首批 15–20 件禁用 |

保险箱不要求再次下调价格。例如主背包 `70` 格平均 `1.1万/格`、保险箱 `9` 格平均 `2万/格`，成功撤离总值约为 `95万`；与“百万需要接近满载且质量较好”一致。

### 5.2 逐件定价步骤

1. 先确定自然形状和格数；
2. 决定它是笨重低值、普通、主力还是紧凑高值；
3. 用对应单格区间得到满耐久价格审查带；
4. 在区间内根据剩余用途、取得稀缺性、需求与资产风险确定具体值；
5. 按各次剩余使用的边际价值给出残损价格；
6. 检查同密度装满 `70` 格与装满 `79` 格的结果；
7. 金币价格、战斗评分与单次机制价值始终分账。

临时件继续显示同名、同耐久真实件的正常估值，但可兑现价值为 `0`。

## 6. 单件审批卡新增字段

在既有名称、玩家文案、稀有度、机制价值、费用、耐久、占格、价格、独立用途、顺序、Combo、反制与边界自检之外，每件候选还必须明确填写：

1. 最接近的公共行动费用锚；
2. 与「波 / 大防 / 大波」并用的总费用；
3. `S/70`、`S/9`、`S/79`；
4. `D/S` 与三件同名总使用次数；
5. 满耐久金币密度与各残损状态金币密度；
6. 三件同名对食物、探索用品和战利品空间的挤压；
7. 入场、中途消耗和撤离三个阶段的空间身份。
