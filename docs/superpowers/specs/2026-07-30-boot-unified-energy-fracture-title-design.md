# Boot 标题 B：统一能量断层

## 目标

重做纵排“波波攒”三字，使其首先是清楚、简约、可识别的像素游戏标题；细看时再发现三字共享同一套斜向能量断层。Godot 中现有朝角色内旋的平面透视保持不变。

## 视觉系统

- 三字继续拆成三个独立透明 PNG，竖直排列。
- 字形使用直立、粗黑、几何化的中文无衬线骨架，不采用水墨、倾斜书法或花体。
- 原有 `24×24` 手工字模过粗，改为 `63×63` 逻辑像素画布，再以 nearest 放大至 `252×252`。
- 每个字都沿同一角度形成一条“左低右高”的断层：
  - 断层本体是一格透明裂隙，不位移上下字面，避免与 Godot 透视叠加后产生卡帧感；
  - 裂隙下沿使用深蓝黑结构色；
  - 朝向角色的一侧仅保留一条短促朱红能量边；
  - 不挖穿关键偏旁，不额外添加水波、圆环或独立徽记。
- 两个“波”使用同一字形骨架，但断层相位略微错开；“攒”的断层避开左侧提手旁主干，优先保持复杂字形可读性。
- 透视只负责展示方向，不能代替标题自身的设计。

## 简约色卡

色卡来源：[Lospec — Baldur - Neon Darkness](https://lospec.com/palette-list/baldur-neon-darkness)。

- 主字面：`#F5E8D1`，象牙暖白。
- 结构暗面与断层槽：`#0F1B26`，深蓝黑。
- 能量边：`#DD5639`，克制朱红。
- 原色卡中的 `#20A5A6` 本轮不使用，避免在当前暖白角色和金色星芒之间引入孤立青色，也避免把“波”误读为水。
- 不使用渐变、随机噪点、多层金色、高光描边或图片内发光。

## 范围保护

- 不修改背景。
- 不修改角色位置、比例、调色、拆层或 idle 动画。
- 不修改后手星芒。
- 不修改点击进入 Main Menu 的交互。
- 不改变标题三节点、现有纵排位置和朝角色内旋方向；除非运行截图证明新字形在原容器内被裁切。

## 验收

1. 关闭透视并临时视作单色时，三字仍能在一秒内读作“波波攒”。
2. `25%` 缩略图中仍能分辨三字轮廓，并能看出统一的断层方向，而不是三个普通文本框。
3. 朱红只占少量断层边，不形成彩字或散乱装饰；角色后手星芒仍是全画面最亮点。
4. 标题透明边角干净，nearest 采样下无半透明脏边、线性模糊和旧金色残留。
5. Godot 运行截图通过，标题朝角色内旋；点击和 `ui_accept` 进入 Main Menu 的既有行为不回归。
