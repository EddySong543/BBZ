# Boot Remaster 草稿打磨设计

## 目标

在不改变正式 Boot 入口的前提下，继续打磨独立 Boot Remaster 动画预览：

- 更早进入猛烈拉远，减少近景停留。
- 消除云海轮廓上一两格宽的细碎凸起、缺口和短线。
- 画面定格后加入类似 Battle Stage 的水平鼠标视差。
- 降低能量球补光造成的人物脸部焦黄。

## 设计

### 时间轴

拉远由约 2.05 秒提前到约 1.55 秒。聚焦结束、背景和标题进场随之整体前移，总演出收束到约 3.35 秒；演出结束前仍禁止进入。

### 云海轮廓

继续复用 Scene2 Lower Cloud Shader，不修改共享 Shader 源码。仅在 Boot 两层云材质中降低轮廓采样密度、扩大最小阶梯宽度，并关闭连续云墙接缝的随机细碎变化。轮廓保留像素风，但不出现 `res/boot1.png`、`boot2.png`、`boot3.png` 所示的单格突出和短线。

### 待机鼠标视差

鼠标视差只在演出定格后启用。横向鼠标位置经过指数平滑后：

- 云海移动最大，月亮和星空移动最小。
- 人物与前后能量层保持相同的小幅偏移，使能量球继续固定在双手之间。
- 标题只做极轻微偏移。
- 不加入纵向移动或运镜，鼠标回到中间时画面平滑归位。

### 人物补光

保留能量球对人物的局部补光，但将橙色改为淡金色并降低强度和环境提亮。头脸区域额外使用轻微冷色平衡，人物原图不修改，避免草稿阶段产生不可逆素材变化。

## 验证

- GUT 验证新时间点、云海材质参数、视差层级和人物光照参数。
- Godot 窗口探针重新生成演出接触表。
- 额外生成鼠标左、中、右三个位置的待机对照图。
- 检查独立预览与正式 Boot 入口仍保持分离。
