# 左侧图鉴侧签重设计

> **历史文档提示（2026-08-27）**：本文保留当时通过方向，但书本 `(210, 86)`、四张侧签素材及入口架构等内容已经过期。当前权威合同见 `docs/reports/2026-08-27-codex-production-retrospective.md`；实现以当前代码和测试为准。

## 已通过方向

- 统一图鉴使用 1920×1080 画布；书本为保证原书页文字可读，显示为约 1612.8×907.2，左上角位于 (210, 86)，英雄与道具内部仍按原 1920×1080 设计坐标运行，页面相对排版不变。
- 书本之外使用低饱和烟褐背景：中心略亮、边缘略暗但不接近纯黑；无木板缝、道具摆件、国风或西式装饰。
- 主菜单图鉴入口删除文字与长条导航底板，精确复用战斗 UI 的 108×108 奶油纸果冻方钮、64×64 书本图标、shader 参数与 ButtonJuice。
- 主章节侧签采用左缘夹页索引：右端插入书页、左端露出；外露左端仅做轻微阶梯削角，右端保持平直。
- 主签为“英雄/道具”；道具章节内再展开紧凑的“普通/稀有/传说”二级页码签。
- 二级签只以窄蓝、紫、金纸边表达稀有度，纸张与主签同材质。

## 交互

- 未选中主签使用较短、较暗、仅有小倒角的独立纸签资产；选中签切换为更宽、更高、更亮且下缘纸影更厚的资产。两态共用稳定点击区，按下时向右压入 3px。
- 不缩放、不弹跳、无金色闪光；使用短促 cubic ease-out，并在新动画前终止旧 Tween。
- 道具二级签由“道具”签后方紧凑向下错开展开，轻微顺序延迟；收起时反向合拢。
- 底部分页跨稀有度时，二级签选中态继续自动同步。

## 素材

- 主签与二级签各自使用独立 ImageGen idle/selected 左向美术源，经确定性抠图与真像素缩放后输出透明 PNG，不再用脚本模拟纸纹与轮廓。
- 2D 真像素、硬 alpha、Lossless、无 mipmap、Nearest；无文字、无西式花纹、无伪 3D、无漂浮阴影。
- 生图只提供纸张材质与形状基础，最终尺寸、调色、透明边与整数像素由确定性脚本锁定。

## 验证

- GUT 守卫主菜单图鉴钮尺寸/图标/shader、左签方向几何、二级展开层级和连续分页联动。
- 1920×1080 非保存运行探针读取实际帧像素，验证静态烟褐底图不黑屏、独立微动层、约 1612.8×907.2 书本显示边界、双状态侧签、切换缓存与动画终态。
