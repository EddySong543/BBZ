# 左侧图鉴侧签重设计

## 已通过方向

- 图鉴书本继续完整占用 1920×1080，不移动、不缩放，英雄与道具内部排版不变。
- 主菜单图鉴入口删除文字与长条导航底板，精确复用战斗 UI 的 108×108 奶油纸果冻方钮、64×64 书本图标、shader 参数与 ButtonJuice。
- 主章节侧签采用左缘夹页索引：右端插入书页、左端露出；外露左端仅做轻微阶梯削角，右端保持平直。
- 主签为“英雄/道具”；道具章节内再展开紧凑的“普通/稀有/传说”二级页码签。
- 二级签只以窄蓝、紫、金纸边表达稀有度，纸张与主签同材质。

## 交互

- 未选中主签向右藏入书页，选中签向左抽出；按下时先向右压入 3px，再完成切换。
- 不缩放、不弹跳、无金色闪光；使用短促 cubic ease-out，并在新动画前终止旧 Tween。
- 道具二级签由“道具”签后方紧凑向下错开展开，轻微顺序延迟；收起时反向合拢。
- 底部分页跨稀有度时，二级签选中态继续自动同步。

## 素材

- 新建左向主签与二级签透明 PNG，不覆盖被否决素材。
- 2D 真像素、硬 alpha、Lossless、无 mipmap、Nearest；无文字、无西式花纹、无伪 3D、无漂浮阴影。
- 生图只提供纸张材质与形状基础，最终尺寸、调色、透明边与整数像素由确定性脚本锁定。

## 验证

- GUT 守卫主菜单图鉴钮尺寸/图标/shader、左签方向几何、二级展开层级和连续分页联动。
- 1920×1080 非保存运行探针验证书本位置与缩放、切换缓存、侧签动画终态。
