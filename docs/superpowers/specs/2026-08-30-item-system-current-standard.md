## 1. 设计目标

道具是围绕「波 / 攒 / 防 / 大波 / 大防」、英雄与背包形成组合的主动计划件。取得必须让对手获得信息窗口，使用必须与核心能量决策竞争，同一回合内的真实结算顺序必须能够改变结果。

本标准已经审批 **当前单机战斗内取得、公开、锁定、使用费用和权威序列**。所有规则都服务当前 PvE 原型，不再维护平行模式分支。

## 2. 通用局内取得基线

1. **每战开局随机装三件真实UID。** 库存不足时装入全部，不复制或补假件，不新增最低UID。
2. **开局一次免费部分调换。** 被换出件隔离到整次替换完成后才回背包；替换件从初抽之外的储备一次无放回抽取，数量不能超过可替换储备，不再次调换。
3. **第一回合锁定，第二回合可用。** 开局取得不付能量，R1没有额外抽取机会。
4. **R2起每轮至多一次付费补充。** 有空框、真实储备且当前至少1能才能开启；开启即付1能并固定 `min(3,N)` 个不同UID候选。
5. **只选一件或放弃。** 选中件进入编号最小的空框，R+1可用；未选件留背包。开启后放弃不退能、不重抽；未开启就跳过则不收费。不能在行动规划后返回补充。
6. **不自动补充、不累计、不付费重抽。** 同次候选不重复UID，同名不同UID可出现；不同回合允许未选件再次出现。
7. **敌方费用与实例对称。** 敌方先补充并锁定公开整段序列，随后玩家补充与规划；敌方不能响应玩家本轮未提交选择。
8. **存活占框道具不能免费替换。** 耐久归零最终清理才腾框；最早下回合可补，不能倒回本轮取得阶段。

完整状态机、开启费边界、UID隔离、死亡与战末归还以 [`2026-09-05-item-opening-and-paid-refill.md`](2026-09-05-item-opening-and-paid-refill.md) 为准。开局免费不免使用费、耐久、真实资产风险或公开窗口。

## 3. 使用费用

- 每件道具有独立的**逐次使用费**，取值为 `0–4` 能；每次实际使用都重新支付，多耐久道具也不例外。
- 大部分道具位于 `1–2` 能。`0` 能主要留给严格受限的连接件、状态搬运或带有明确风险的工具；必须重点审查循环和无损收益。
- `3–4` 能是正式设计空间，不是禁区。能够改变局势、成为整轮计划或 build-around 的道具可以进入这一档，例如梦蝶一类传说道具。
- 使用费不与 T1/T2/T3 机械绑定。稀有度描述机制职责和质变程度；费用描述本次战斗中启动它需要放弃多少核心选择。
- 机制价值不是固定能量汇率。每件道具仍按下限、常态、峰值和反制窗口评估，不能因为“付了 4 能”就允许无反制地结束对局。

## 4. 有序结算与能量支付

玩家提交的是一段统一有序序列，例如：

`[道具 A, 波, 道具 B]`

每段序列必须且只能含一个主行动。权威战斗核心将我方与敌方主行动固定在共同 `0` 拍，主行动前后的步骤保持与它的距离和原顺序；缺位处生成不收费、不触发效果的对齐等待。同拍双方已经开始的步骤均完成，拍结束后才进入下一拍。权威效果可以在某方下一真实步骤前额外生成等待，但玩家不能提交，也不能改写剩余步骤的原顺序。完整边界见 [`2026-09-03-action-anchor-sequence-design.md`](2026-09-03-action-anchor-sequence-design.md)。

当前 PvE 先由敌方生成、提交并公开完整序列，玩家看到后再规划；敌方一经锁定不得根据玩家选择重算。每拍双方步骤完成后统一检查死亡，任一出战英雄确认阵亡就取消双方所有尚未开始的步骤；被取消道具不扣能量、不扣耐久、不写使用历史，后备英雄单独阵亡不截断。完整边界见 [`2026-09-04-pve-public-intent-and-death-truncation.md`](2026-09-04-pve-public-intent-and-death-truncation.md)。

权威战斗核心在状态副本上逐步骤重放。每个道具步骤固定按以下次序：

1. 检查该步骤在当前状态是否合法，以及当前能量是否足够；
2. 支付这件道具本次使用费；
3. 扣除该真实实例 1 点耐久；
4. 结算道具效果；
5. 后续步骤读取已经改变的能量、生命、状态、目标和道具实例。

前一件道具产生的能量可以支付后一件；后一件产生的能量不能倒过来支付前面的步骤。界面可以预演剩余能量，但费用、效果与耐久都以权威战斗核心为准。

当前 P1 测算进一步固定白板时点：每轮被动 `+1` 在本轮最终结算时到账，只能供下回合使用；「攒」的 `+1` 在其行动步骤立即到账，可以支付排在它后面的道具。`0–4` 基线只审批五个整数费用档；半点费用仍未批准。

英雄改变基础行动时，**选招与付费身份**和**实际结算身份**必须分开读取。行动合法性与基础费用看玩家原本选择的行动；写明「波 / 大波」或“下一次攻击”的道具效果看该时点实际结算出来的行动。牛金【牛】仍选择并支付「波」，但升级后按「大波」结算，因此消费火蜥蜴油而不消费磨刀石；玄冥【鼠】仍选择并支付一次「大波」，但实际依次结算两次独立「波」，因此不消费火蜥蜴油，等待“下一次波 / 下一次攻击”的效果由第一波正常读取并消费，不能复制给第二波。

整段序列若在提交时基础非法，权威战斗核心原子拒绝，不执行合法前缀，也不扣能量或耐久。合法道具步骤已经进入权威结算后，即使效果被反制、免疫或最终收益为 0，费用和耐久仍然消耗。

## 5. 稀有度与传说道具准入

- T1、T2、T3 成品都可以作为真实资产装入战备，并通过同一套开局随机装框与后续付费三选一进入公开道具框。
- 不设通用图纸、固定材料配方或统一升级梯子作为 T3 准入门槛。
- 个别道具、事件或商店以后仍可拥有明确写在内容里的制造、交换或转化效果，但它们是独立内容，不是玩家必须背诵的系统规则。
- T3 的风险由使用费、锁定一回合、公开框占用、耐久、真实资产风险、机制反制与候选概率共同承担；不能再靠“先升金”兜底平衡。

## 6. 五维平衡

每件正式道具必须同时填写并联合审核：

1. **机制价值**：裸用下限、普通常态、理想 Combo 峰值，以及它实际改变的选择；
2. **逐次使用费**：`0–4` 能，每次使用都支付；
3. **耐久**：实体能用几次，每多一次会不会重复或放大 Combo；
4. **占格**：固定形状和格数，作为携带与搜刮价格，不与稀有度机械绑定；
5. **金币价格**：正常显示价值、残损曲线、可兑现价值和单格价值。

五个维度彼此独立但联合定价。强力、高价、紧凑的珍品可以存在；昂贵、笨重或低耐久也不能替单场无反制超模开脱。

## 7. 信息、交互与权威回放

- 按住左键拖出但未松开只作本地预览；在合法区域松开才把使用追加到本地待提交序列。
- 玩家本地施放动画只是编排反馈，不公开待提交序列，也不作为结算真相；敌方序列必须在玩家规划前公开。
- 最终提交完整有序步骤；由本地权威结算器逐步校验费用、实例、耐久、目标和状态，再产生权威事件流。
- 回合结算时必须按权威事件流播放道具、行动、扣费、耐久变化和效果动画，并提供可回看的动作列表；否则玩家无法理解长序列为何得到当前结果。
- 双方唯一主行动在共同 `0` 拍结算；其他步骤按相对位置逐拍推进。同拍双方已经开始的步骤均完成，核心内部遍历顺序不能制造先后手。对齐等待与列间效果等待只能由核心生成，玩家不能提交。

## 8. 当前实现与目标设计的边界

新版单机道具运行时已经落地统一有序步骤、行动锚点调度器、敌方先锁定公开和逐拍死亡截断；H03 已改为负伤增幅并退出旧等待机制。旧的 1 能补充、免费使用、一次性清槽、旧稀有度过滤、通用 PRE/POST 道具批次和仅保存道具 ID 的背包模型仍然存在，只可作为迁移期测试资产，**不能反向定义新规则**。

取得侧待迁移：开局真实UID装框、一次隔离部分调换、R1锁定、R2起付费补充事务、固定候选、每轮一次与原来源归还。其他历史迁移列表不由此次取得修订重新裁定完成状态；当前代码不能覆盖新专项。

旧道具资产不删除。Demo 未启用的旧件保留目录、资源与注册信息，通过显式启用标记隐藏；之后应能按 ID 单件恢复，而不是从 Git 历史找回。新版 20 件纵切已完成纸面冻结，但运行时迁移与目录交接尚未完成，旧道具设计文档暂保留，交接完成后再删除。

## 9. 当前单机取得边界已封板

以下规则已经批准，作为当前单机原型的状态机边界：

- 开局随机填三框并允许一次部分调换，R1锁定、R2可用；库存不足不生成实例；
- 合法实例不足 3 件时展示全部，不补假候选；同名不同 UID 可以同时出现；
- R2起补充采用“敌方付费取得/跳过 → 锁定公开序列 → 玩家付费取得/跳过 → 玩家规划”；当前原型不设置未批准的外部倒计时分支；
- 耐久归零的框在最终清理时腾空；存活实例被效果移走时可立即腾框，但不能倒回已经结束的抽取阶段；
- 抽取或规划被取消时不产生隐式道具或免费行动；行动超时规则由当前单机战斗入口统一处理；
- 实例分离资产归属与战斗控制，区分真实、Run 临时和本场临时；战斗内交换不改变永久所有权；
- 复制效果不生成实体；复制 / 生成实体使用新 UID 且默认仅本场存在；
- Demo 暂不开放通用单件偷取或免费弃置 / 销毁按钮。

以上取得、锁定和逐次收费是当前 PvE 原型的唯一基线。付费重抽等未批准分支不在当前产品范围内，不能从旧设计恢复。

### 9.1 英雄—道具身份边界（由历史审计合并）

- 英雄负责玩家反复采用的长期许可：改变基础行动的目标、支付或结算，建立持续的队伍生产 / 转换 / 终端能力，或迫使对手改变可读且可反制的选择。
- 道具负责这一轮如何准备、连接和兑现，也可以共同构成跨战管理的build；实际使用损耗后，玩家依据残余接口和新供应调整组合。仍不能稳定复制某名英雄的完整循环、永久占有英雄规则、凭空增加完整行动或关闭全部技能。
- 新英雄必须能写出“它让队友具体改选什么”、可见的对手出口和真实代价；新道具必须检查 24 名英雄与最强三件链，不能与某英雄拥有相同的触发—奖励结构。
- 玩家可以用道具组合描述构筑，不能仅据此判为越界。英雄提供稳定的能力接口，道具构筑提供会损耗和变化的战术安排；边界检查针对具体规则复制与反制缺失，不限制玩家以哪一方命名build。不额外增加资源条，不用复杂堆层和解释依赖的例外补洞。
- 跨战构筑验收以 `design/gdd/expedition-mode.md` §3.1.3 与 `design/expedition-economy.md` §3.2 为准。当前再审没有批准新道具、取得变更或耐久调整。
