# Scene3 传导弹动与鱼跃天门设计

## 目标

Scene3 底部云海恢复左键弹动反馈，但彻底排除圆形涟漪、独立云团、拨云开洞、暖光缺口和层间延迟传导。每次有效云层点击继续低概率触发垂直向上的带翅飞鱼群。

## 传导弹动

- 点击层继续使用 `MOUSE_FILTER_PASS`，不消费战斗或 UI 输入。
- 整个云海使用统一点击区域，不再划分容易错位的前、中、后点击带。
- 每次有效点击先启动前景云，约 0.06 秒后传到中层，再于约 0.12 秒时传到后层。
- 前 0.12 秒内，点击中心下压，两侧云瓣同步上鼓；随后中心快速回弹并略高于原轮廓，再以一次很轻的收势恢复。
- 三层强度降低为约 72%、46%、22%；最近景最明显，中层次之，远层只保留轻微呼应，避免弹动过于夸张。
- 连续点击会刷新整条传导的位置和时间，不叠加强度。
- 不绘制额外云絮，不改变云层颜色、透明度或光照，也不恢复旧旋转采样。

## 鱼跃天门彩蛋

- 前两次有效云层点击只累计；从第 3 次开始，每次按 5% 概率抽取。命中后约 0.07 秒从点击横坐标处随机升起 2-3 条带翅飞鱼。
- 鱼群复用 Scene3 现有四帧飞鱼图集，鱼头朝上，领头鱼略大；各鱼以约 0.035 秒间隔跟随，最后一条额外慢半拍。
- 鱼群在约 0.78-0.9 秒内突然飞出屏幕顶部，不回落，不产生水花或额外烟团，整体强调短促的喜剧效果。
- 鱼群飞行期间不叠加；成功后保留 6 秒再触发冷却，之后后续点击可以再次抽取。现有两组定时飞鱼不受影响。

## 验证

- 单元测试覆盖输入优先、统一点击区域、前中后延迟传导、衰减强度、概率边界、飞行中防叠加和重复触发。
- 无截图实机探针检查三层命中结果、默认概率、鱼群垂直飞行和重复触发。
- Scene3 视觉完整性与环境丰富度测试保持通过。
