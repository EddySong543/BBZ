# Boot Screen 分层待机动画设计

## 本轮目标

重建 Boot Screen 最终待机画面的背景和标题。蓝色笔刷与金色环形能量必须由素材本体运动，不得继续用静态底图上的粒子、追光弧线或透明副本冒充运动。

本轮不制作开场演出。最终待机画面通过后，再单独制作开场时间轴。

## 背景结构

现有 `boot_pressure_background_v2.png` 只作为分层素材来源，不再作为运行时整张背景板显示。

运行时背景拆为：

1. 米色纸张底层：程序生成的低对比纸张纹理，保持整体明亮。
2. 深蓝笔刷主体：包含完整蓝色笔触，沿笔触方向缓慢位移和轻微弯曲。
3. 中蓝纹理层：包含中间亮度的蓝色笔触细节，运动幅度略大。
4. 浅蓝笔锋层：包含高光和笔锋，运动幅度最大但透明度最低。
5. 金色内、中、外环：从原图按色相和半径分成三张透明素材；三层素材本身围绕后手星芒中心逆时针旋转。

旧的 `PressurePlate`、`BlueDeepFlow`、`BlueMidFlow`、`BlueLightFlow`、`GoldenHalo` 和 `EnergyFragments` 运行时节点全部移除。

## 待机运动

- 深蓝主体：14 秒循环，最大位移 2 像素。
- 中蓝纹理：10 秒循环，最大位移 5 像素。
- 浅蓝笔锋：7 秒循环，最大位移 8 像素。
- 位移主方向为右上至左下，附加不超过 1.5 像素的垂直方向弯曲。
- 金色内环：18 秒逆时针一圈。
- 金色中环：24 秒逆时针一圈。
- 金色外环：32 秒逆时针一圈。
- 金环的缺口、粗细、散点和笔触纹理必须随各自素材一起旋转。
- 粒子不承担背景运动；本轮移除旧粒子层。

背景继续复用现有鼠标视差和轻微待机漂移，不改变 Boot Screen 的进入逻辑和角色待机动画。

## 标题

本轮采用蓝色高对比配色，不增加背景板：

- 字面钢蓝：`#476F8E`
- 结构与外轮廓深海军蓝：`#132B3B`
- 刀光峰值米白：`#F1E5D0`
- 能量刻印珊瑚红：`#E25D49`
- 偏移阴影继续使用深蓝体系

外描边从 1 像素改为连续 2 像素。压力切口素材保持不变，标题控制器当前的慢速循环、错峰和尘埃释放节奏保持不变。

## 后期开场演出固定规则

开场演出不在本轮实现，但后续必须遵守：

1. 十字星芒在爆发前只闪烁两次。
2. 蓝色笔刷从右上向左下刷出、金色环形能量逆时针旋转出场、标题刀光从左向右划过，三项同时启动、并行发生。
3. 刀光经过前标题没有红色，刀光经过后红色能量刻印才出现。
4. 开场演出结束后无缝进入本轮完成的待机状态。

## 验收标准

- 静态截图中不出现旧背景板残留或蓝色重影。
- 连续帧中蓝色笔刷轮廓和内部层次发生可见位移。
- 连续帧中金色三层环的素材缺口和笔触纹理发生逆时针位移。
- 标题在米色区域上无需背景板即可一眼辨认。
- 角色、标题循环、鼠标视差和 Boot Screen 原有交互不回归。
- Godot 运行截图探针和全量 GUT 测试通过。
