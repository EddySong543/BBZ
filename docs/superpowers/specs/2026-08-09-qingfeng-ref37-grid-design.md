# 晴风稻田 Ref37 格子视觉设计

## 已确认目标

- 以已通过的 `qingfeng_ref37_composition_preview_v1_1920x1080.png` 为视觉契约。
- 1920×1080 画面约显示 18–19 列、10–11 行正方形格；不横向拉伸。
- 每格使用同地貌深色外描边与较亮内沿，描边全部位于格内，格间不露黑底。
- 草地由少量深浅正式变体按固定坐标散列混排；相邻有节奏，但不是棋盘格。
- 未探索格仍显示地表纹理与描边，只由深绿色半透明迷雾压暗；未探索物体继续隐藏。
- 麦穗继续是已通过的独立透明物体层，不烘焙进草地。
- 整屏只增加低频暖光与深绿暗角，不增加高频噪声、模糊或逐格随机光照。

## 实现边界

- 晴风稻田逻辑地图保持 18×14，不改道路、墙体、敌人、搜索点或撤离点。
- 单格改为 107×107；1920×1080 实际可见约 17.94×10.09 格，作为“约 19×11”的最小安全落地。
- 保留当前镜头死区、0.28 秒平滑补间、三层地图结构和背包屏幕空间行为。
- 本轮不处理已否定的补给篮，也不扩展新地图内容。

## 渲染分层

1. 地表：四张草地变体与现有泥土地表，统一格内双描边。
2. 迷雾：读取现有探明数据，未探索区以深绿压暗，仍可辨认格子。
3. 麦穗：保留 `RiceFoliageLayer`。
4. 物体：田界、搜索容器等仅在探明后显示。
5. 标识与角色：保留运行时角标和角色 token；尺寸随 107px 格缩小。

## 验收

- Godot Import 与全量 GUT 通过。
- 1920×1080 截图中地图铺满四边，中心格横纵间距误差不超过 1px。
- 同屏出现深浅草地且不是严格棋盘格。
- 迷雾下仍看见地表与描边，搜索物体不会泄露。
- 搜索物体移除后地表不变；麦穗仍叠在草地上。
- 镜头在死区内不移动，越界后平滑移动且无逐步抖动。
