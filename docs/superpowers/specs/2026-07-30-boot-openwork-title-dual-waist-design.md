# Boot 开孔标题与双腰布 Idle 设计

## 目标

撤销未通过的图形波场背景，重新制作“波波攒”标题，并补齐角色左右腰布的慢速 Idle。角色位置、头发动画、后手星芒和点击进入 Main Menu 的逻辑保持不变。

## 背景

- 删除 `canvas_boot_graphic_wave_field.gdshader` 及场景中的材质引用。
- `Background` 恢复为全屏纯黑 `Color(0.004, 0.003, 0.009, 1)`。
- 不保留旧波环、金色方块、蓝灰斜切面或任何透明残影。

## 标题：A「24 格开孔金字」

- 标题继续使用独立透明 PNG，文案固定为横排“波波攒”。
- 不再从 12×12 字模直接放大，也不再使用 `MaxFilter` 或任何全向膨胀描边。
- 三个字在约 24×24 的手绘网格中重新定义：
  - 主笔画宽度约 2 格。
  - 关键字内通道和负形至少 3 格。
  - 两个“波”保持相同节奏。
  - “攒”保留“扌 + 赞”的识别骨架，通过更宽的右部和底部增加重量，不进行机械缩放。
- 字距：
  - 两个“波”之间 4–5 格。
  - 第二个“波”与“攒”之间再增加 1 格。
- 色彩继续使用既定四金色：
  - 主亮金 `#f4c84b`
  - 下部金 `#d6a73d`
  - 局部高光 `#ffe08a`
  - 右下单侧投影 `#7a5518`
- 黑色背景本身承担对比，不增加深蓝外轮廓、字符底板、共同方框或发光。
- 字内孔洞保持完全透明，PNG 四角透明，最近邻显示且不生成 mipmap。

## 腰布拆分

为了避免角色左右称呼混淆，节点和资源按画面方位命名。

- `WaistScreenRight`：当前已经拆出的画面右侧长灰白腰布，源图范围约 `x=172..194, y=88..123`，pivot 为 `(183, 91)`。
- `WaistScreenLeft`：新增画面左侧白色短腰布，源图范围约 `x=108..143, y=87..108`，pivot 为 `(139, 91)`。
- 两层都必须直接从 `assets/import/bootchar.png` 的原像素提取。
- 生成器必须继续保证中立姿势重建结果 `changed_pixels == 0`。

## 腰布动画

- 保留现有头发和后手星芒的 `4.8s` 主 Idle，不改变速度。
- 新增独立 `WaistAnimationPlayer`，腰布循环时长固定为 `8.0s`。
- 使用 cubic-angle 插值，避免当前线性折返产生的快速机械感。
- 画面右侧长布最大旋转约 `±0.030rad`。
- 画面左侧短布最大旋转约 `±0.022rad`。
- 两块腰布相位错开约 `0.10–0.125` 个周期，不做完全镜像同步。
- 首尾旋转值一致，循环处不得跳变。

## 验收

- 1920×1080 截图中只存在纯黑背景，无旧背景残留。
- 标题三字的字内孔洞清楚，字符之间互不粘连，不呈现三个按钮或三块底板。
- 画面左右两块腰布都能被观察到慢速摆动，根部不脱节。
- 头发与星芒速度和本次修改前一致。
- 角色 neutral composite 与原图逐像素一致。
- Godot 无资源、Shader、脚本或空节点错误；点击仍能进入 Main Menu。
