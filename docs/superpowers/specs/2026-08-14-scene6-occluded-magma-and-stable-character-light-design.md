# Scene6 遮挡岩浆与稳定角色光影设计

## 目标

Scene6 底部必须明确读作岩浆，但岩浆不能成为覆盖战斗区的墙或底部整块亮色。它必须位于平台之后，并由平台桥腹、左右近景和 HUD 自然遮挡。角色只保留稳定的场景环境光；战斗动作不得触发夸张的红色全身闪烁。

## 已确认方案

### 1. 角色稳定受光

- 保留 P1 左下、P2 右下的主光方向。
- Scene6 角色 shader 增加边缘光峰值上限。共享战斗代码仍可调用 `pulse_rim()`，但 Scene6 材质的实际输出不会超过克制的暖金峰值。
- 边缘光由高饱和红橙改为低饱和橙金，只照亮光源侧约 1 像素轮廓。
- 下半身岩浆反光保持静态分层，不读取 `TIME`，不随背景岩浆同步呼吸。
- 减少红色 ambient、fill 与 bounce 的总能量，保护人物皮肤、黑衣和金甲本色。
- 不修改共享受击白闪、角色位置、尺寸、动作、翻转或战斗节奏。

### 2. 被遮挡的岩浆湖

- 新增独立 `MagmaLake`，绘制顺序位于 `ThermalAtmosphere` 之后、`BattlePlatform` 之前。
- 岩浆主体覆盖屏幕下部，液面起点约为屏幕 `y=840–870`；实际值以 1920×1080 运行图微调。
- `BattlePlatform` 继续绘制在岩浆之上，平台桥腹和垂石自然遮挡液面；`ForegroundLeft`、`ForegroundRight` 继续在最前方遮挡两侧和下部。
- 岩浆只通过平台透明缝隙、垂石间隙与下方中央局部露出，不增加覆盖平台的前置岩浆层。
- 当前 `UnderbridgeForge` 不再承担伪造岩浆主体的职责。它删除或收缩为静态、细窄的桥腹下缘暖反光，不能绘制独立熔火通道或大面积色块。

### 3. 岩浆视觉语言

- 暗酒红与炭黑熔壳占约 70–80%。
- 红橙流纹占约 12–18%。
- 黄白核心不超过约 5%，只出现在少数裂流交汇处。
- 液面轮廓使用 4px 像素台阶和破碎暗边，禁止整条水平黄线。
- 主体是缓慢横向对流和纵深错层，不做水面正弦波，不做高密度气泡。
- 时间连续；运动保持慢速，通过相邻像素相位插值或边缘羽化改善流畅度，不使用全画面 `stepped_time`，不通过提高速度掩盖跳帧。
- 不读取屏幕，不扭曲人物或 HUD；全镜头热浪继续由现有 PostFX 负责。

## 明确禁止重走的路线

1. 不恢复从人物腰腿高度开始的高位岩浆墙。
2. 不使用覆盖整个底部的黑色 `ColorRect` 作为“深渊”。
3. 不再只依赖平台 alpha 孔洞生成主体——此前结果几乎不可见。
4. 不把岩浆放在平台之后绘制并用 y 阈值硬裁切——此前在底栏后形成橙色方块。
5. 不使用整齐液面、连续金色亮唇、规则立柱或大面积黄橙核心。
6. 不加入方形气泡，也不以加快或放慢到不可见的方式处理动画卡顿。
7. 不让角色环境光跟随岩浆动画脉冲；动作 rim 峰值必须由 Scene6 shader 限制。

## 场景结构

```text
MidgroundLeft / MidgroundRight
ThermalAtmosphere
MagmaLake                 # 岩浆主体
BattlePlatform            # 主遮挡
PlatformMagmaContact      # 可选静态窄暖边
ForegroundLeft / Right    # 近景遮挡
```

岩浆、平台与接触暖边使用接近地面的视差系数，避免鼠标视差时露出接缝。不得调整平台和近景现有位置、尺寸及构图。

## 验收

- 1920×1080 中一眼能识别底部为岩浆，而不是黑洞、炉芯或橙色矩形。
- 岩浆至少被平台桥腹和左右近景三处明显遮挡；战斗站立区没有岩浆覆盖。
- 相隔至少 2 秒的截图能看出内部纹理缓慢迁移，但液面位置和整体轮廓稳定。
- 待机角色不出现周期性红闪；出招、格挡和受击时不出现夸张红色全身包边。
- P1/P2 保留各自素材颜色，并能读出来自下方左右两侧的稳定热反光。
- Scene6 单元测试、导入和运行探针通过；完整测试中的既有无关失败单独报告。
