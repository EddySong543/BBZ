# Boot 标题微错峰脉冲与换色设计

## 目标

保留当前纵排“波波攒”的字形、布局、朝角色内旋透视和三张独立 PNG，只让小面积断层能量色产生低强度 idle 脉冲，并提供一个集中修改整套标题颜色的入口。

## 动效

- 顺序固定为 `攒 → 中间波 → 顶部波`。
- 三字启动时间分别为 `0.00s / 0.10s / 0.20s`。
- 总周期为 `4.8s`，与角色主 idle 周期一致。
- 单字脉冲使用 `0.10s` 快速升亮和 `0.42s` 自然回落。
- 只修改断层能量色；字面、结构暗面、透明度、节点位置、缩放、旋转、透视 UV 全部静止。
- 能量基础色始终可见；峰值只混入 `22%`，不熄灭、不闪白、不连续呼吸。
- 每轮脉冲结束后保持约四秒静止，避免霓虹灯和跑马灯观感。

## 换色

`TitleColumn` 提供一处集中参数：

- `face_color`：主体字面。
- `structure_color`：结构暗面与断层下沿。
- `energy_color`：断层基础色。
- `energy_peak_color`：脉冲峰值目标色。

Shader 根据三张 PNG 中现有精确色卡识别职责槽，再映射到以上颜色。透明像素先按 alpha 排除；其余颜色使用最近色键分类，不使用浮点 RGB 直接相等判断。

三字继续使用独立 `ShaderMaterial`，共享颜色和节奏参数，只保留各自的 `pulse_delay`。`TitleColumn` 使用一个从 `0.0` 到 `1.0` 循环的场景局部 Tween 驱动共同相位，因此每次进入 Boot Screen 都从同一相位开始。运行时调用 `TitleColumn.apply_palette(...)` 后，三字静态颜色与后续脉冲同时使用新配色，不需要重做 PNG。

## 范围保护

- 不修改三个标题 PNG。
- 不修改标题位置、尺寸、间距和透视强度。
- 不修改角色、角色 idle、腰部动画、后手星芒、背景或点击进入 Main Menu 的逻辑。
- 不增加新的可见节点。
- 不使用 UV 位移、节点亚像素位移或透视强度动画，避免 nearest 采样下产生像素爬动。

## 验收

1. 默认运行截图与当前静态构图一致，只有断层能量色发生短促脉冲。
2. 脉冲顺序为底部“攒”、中间“波”、顶部“波”，相邻相差约 `0.10s`。
3. 三字主体和结构色在整个周期内保持不变。
4. 运行时应用测试配色后，三个材质的四个颜色参数同时更新，脉冲相位继续前进。
5. 恢复默认配色后截图成功；点击仍能进入 `res://src/ui/main_menu.tscn`。
