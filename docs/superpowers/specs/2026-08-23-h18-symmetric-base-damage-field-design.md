# h18 相柳对称攻击基础伤害场设计

## 状态

- 2026-08-23：Eddy 采用本方案并授权实装。
- 玩家可见技能名尚未定稿；本次实现统一使用“待命名”占位，不沿用此前候选名。

## 玩家规则

- 英雄：h18 相柳【蛇】
- HP：5
- 技能类型：被动
- 主定位：控制；旧三分类 `team_role` 使用“防守”呈现。
- 玩家文案：`相柳【蛇】出战时，双方「波」与「大波」的基础伤害均视为1点。`

## 结算边界

1. 战场效果只在相柳存活、出战且技能有效时存在；相柳位于替补席、阵亡或被沉默时不生效。
2. 双方同时有相柳出战时效果不叠加，攻击基础伤害仍为1点。
3. 战场效果在本回合切换、强制换位和转变完成后，于基础攻击 hit 快照生成时读取；hit 快照形成后不因后续伤害或死亡倒推改值。
4. 只修改基础「波 / 大波」的基础伤害：内部值统一为2个半点，即1 HP。
5. 强化波、攻击总加减伤、毒素、印记、脆弱、出伤与受伤 hook 均在基础值归一后照常结算。
6. 「大波」仍穿「防」并被「大防」阻挡；h02 升级波在场内仍获得大波的有效类型与穿透，但基础伤害为1点。
7. h13 拆分大波的两段各自仍是1点基础伤害。
8. 攻击型主动技、追击、反击与其他独立伤害不属于「波 / 大波」，不受本效果影响。
9. 不新增计数器、持续时间、状态图标、联机字段或快照字段。

## 引擎设计

- 在 `HeroSkill` 增加无状态战场 hook：`modify_battlefield_base_attack_damage(...) -> int`。
- `BattleCore._calc_outgoing()` 从 `ActionDef.get_base_damage()` 取得基础值后，依次读取双方当前出战且有效的技能，先应用战场 hook，再进入出手英雄和团队出伤修正。
- h18 的技能组件只覆盖该 hook，返回 `ActionDef.HP_UNIT`；不再提供主动技接口或生命均分逻辑。
- 该接口仅由基础攻击构建路径调用，攻击型主动技继续直接走 `_apply_team_outgoing()`，从结构上保证其不受影响。

## 验收

- 相柳出战时，己方与敌方普通大波均只造成1点基础伤害，但仍穿普通防御。
- 普通波仍造成1点伤害。
- 相柳位于替补席或被沉默时，大波恢复2点基础伤害。
- 强化波在相柳场内造成2点伤害；脆弱继续在归一后的基础值上追加0.5点。
- 昴日攻击型主动技等独立伤害保持原伤害。
- h18 数据为 HP5、被动、`team_role="防守"`、技能名“待命名”及新玩家文案。
- 旧生命均分主动技测试和实现全部移除。
