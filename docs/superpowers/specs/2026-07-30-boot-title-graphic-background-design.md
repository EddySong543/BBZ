# Boot 标题与图形波场背景设计

## 目标

在不改变当前角色、后手星芒、Idle 动画和点击进入 Main Menu 逻辑的前提下，为 Boot Screen 补齐两个正式视觉单元：

1. 独立透明的“波波攒”定制标题资产。
2. 明亮、近景、能承接角色夸张透视的图形化波场背景。

## 标题

- 文案固定为横排“波波攒”，输出为透明 PNG，可独立替换。
- 字形以厚重方块为骨架，使用小切角和明确的像素台阶，不使用书法、王冠、印章或火焰装饰。
- 两个“波”保持同一节奏；三点水局部形成轻微下落台阶，体现“波”。
- “攒”比“波”约大 8%，笔画更密、视觉重量更高，作为落点。
- 色彩遵循现有硬决议：
  - 上半：`#f4c84b`
  - 下半：`#d6a73d`
  - 高光：`#ffe08a`
  - 深影：`#7a5518`
- 外轮廓采用深蓝黑，以保证标题在明亮背景上仍清楚。
- 标题位于屏幕左侧，不遮挡角色前伸手掌和后手星芒。

## 背景

- 不使用山、云海、月亮、地平线或广角风景。
- 基底为明亮暖灰沙色，整体亮度足以摆脱黑底，但不能洗掉白发和白衣。
- 右侧使用一块大面积、低饱和蓝灰斜切形体承托角色；斜向顺着角色由左后向右前的冲势。
- 以角色后手能量点为视觉圆心，布置两条不闭合的粗环，代表两个“波”。
- 圆心附近使用少量金色方块聚集，代表“攒”，但不能与现有星芒争夺亮度。
- 边缘允许有限的像素断裂与颗粒，但不得形成单个异常像素、卡顿感或大面积噪点。
- Idle 只保留非常慢的环形外扩、金色颗粒漂移和纹理呼吸；无运镜。

## 层级

从后向前：

1. `Background`：全屏图形波场 Shader。
2. `Title`：独立透明标题 TextureRect。
3. `Character`：现有 `boot_character_idle.tscn`，完全保留。

## 验收

- 1920×1080 下标题、角色和背景构图完整，无黑边。
- 标题在亮底和蓝灰块交界处均可读。
- 白发、白衣、肤色和深色裤装均与背景拉开。
- 后手星芒仍位于手掌中心，且比背景金色元素更亮。
- 场景无 Shader、资源加载或空引用报错。
- 左键点击与 `ui_accept` 仍能进入 `main_menu.tscn`。
