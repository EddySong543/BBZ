# Boot 云海与月光重建设计

## 目标

在独立 Boot Remaster 预览中完成第一批场景化改造：

- 从结构上消除云海轮廓的孤立单格和一格宽尖刺。
- 为巨大圆月增加类似 AE Deep Glow 的多尺度加色辉光。
- 为人物增加来自背后月亮的冷色背光，同时保留能量球的淡金色正面补光。

正式 Boot 入口与生产场景保持不变。

## 云海结构

现有 Scene2 Lower Cloud Shader 使用多个量化圆弧取并集。调大像素格只能放大孤立单格，无法保证轮廓拓扑。

新建 Boot 专用云海 Shader：

- 轮廓使用固定、连续的横向高度场，不再由随机圆弧拼接。
- 云体在轮廓以下连续填充，不生成内部孔洞。
- 对轮廓格执行上下左右邻接检查；邻接不足两个的格子直接剔除。
- 轮廓本身保持固定，内部月光明暗缓慢流动。
- 两层云使用不同的高度场参数、颜色和内部流速；整体移动继续由现有分层漂移和鼠标视差驱动。

## 月亮 Deep Glow

保留 Scene1 月亮贴图与原有近距离月晕，并新增 Boot 专用 Deep Glow 层：

- 紧邻月面的高亮核心辉光。
- 中尺度蓝白扩散辉光。
- 大范围低透明度冷蓝色外溢。
- 三层辉光采用加色混合，并带有极弱呼吸；月亮进场期间统一受 `moon_entry_progress` 控制。

## 人物背光

在标题之后、人物之前增加 `CharacterBacklight`：

- 与人物使用同一张透明贴图和完全相同的布局。
- 从透明边缘向外采样，形成蓝白色外轮廓和软辉光。
- 头发、肩部和袖口的上半身权重更强，下半身逐渐减弱。
- 背光跟随人物显现、鼠标视差和所有位置调整，保证不会与人物错位。
- 现有人物材质继续负责能量球的正面淡金色补光和脸部冷色平衡。

## 验证

- GUT 检查 Boot 云海不再引用 `canvas_env_dark_smoke.gdshader`。
- GUT 检查云海拓扑清理参数、Deep Glow 层和 CharacterBacklight 层。
- Godot 窗口探针重新生成静态图、演出接触表、背景运动表和鼠标视差表。
- 实际检查云海边缘、月亮辉光范围、人物轮廓光与图层错位。
