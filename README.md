## 这是什么

波波攒之王把街头巷尾的手部游戏「波波攒」（攒气 → 波 → 防 → 大波 → 大防 的猜拳式博弈）做成了带形状背包和撤离决策的英雄远征游戏。

玩家在远征前选择 **3 个英雄**组成队伍，在「攒 → 波 → 防 → 大波 → 大防」的心理博弈骨架上，叠加英雄独特技能与道具搭配。当前 PvE 由敌方 AI 先公开完整行动序列，玩家随后规划自己的步骤，双方按共同节拍结算；一方全部英雄血量归零即失败。

> 「我知道你知道我会出波，所以我出防」——核心乐趣是读心与反读心，而不是数值碾压。

## 核心玩法

- **5 个基础动作 + 切换**：攒（攒能量）/ 波（1 伤）/ 防（挡波）/ 大波（穿防）/ 大防（全挡）；切换英雄占动作、不耗能。
- **共同节拍**：敌方序列先公开，玩家随后规划；主行动仍按共同节拍结算，不制造先后手。
- **能量经济**：能量是全队共享的资源闸门，被动回能与攒的额外回能共同支撑爆发选择。
- **24 名英雄**：12 生肖 + 12 暗生肖，每个一个独特技能（主动 / 被动），按进攻 / 防御 / 能量 / 节奏 / 状态 / 干扰 六维度设计。
- **道具系统**：新版 20 件纵切已完成纸面冻结；真实背包候选、公开锁定、逐次 `0–4` 能量费用和耐久共同约束搭配。
